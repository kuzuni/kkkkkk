# 소탕! 방치형 헌터

세로형(9:16) **2D 방치형 자동사냥 게임**. 뱀파이어 서바이벌식 난전을 조작 없이 지켜보며, 스킬 · 장비 · 펫 · 유물 도감을 모아 성장하는 한국식 모바일 방치형 구조입니다.

HTML 파일 하나 + 스프라이트 에셋으로 동작합니다.

## 실행

`index.html`을 브라우저로 열면 끝입니다. (더블클릭 / `file://` 로도 동작 — 별도 서버 불필요)

## 화면 구성

```
┌──────────────────────────────────────┐
│ ⚔️전투력  💰골드  💎다이아 [+]        │ 프로필 + 재화 (+버튼)
│  🥉계급  🔮유물석[+] 🏆도감           │
├──────────────────────────────────────┤
│            1-5 스테이지 최고 5         │ 챕터-스테이지 + 처치 진행바
│ [출석]                       [퀘스트]  │
│ [룰렛]      전투 화면         [던전]   │ 좌우 세로 아이콘 (알림 뱃지)
│ [우편]                       [승급전]  │
│ ▓▓▓▓▓ 플레이어 HP ▓▓▓▓▓▓▓▓▓▓          │
│ [검기][냉기][표창][오라][+][+][+][+]   │ 스킬 슬롯 8칸 (쿨다운 표시)
├──────────────────────────────────────┤
│ 📌 튜토리얼: 스킬 1회 소환   [보상받기] │ 튜토리얼 배너
├──────────────────────────────────────┤
│            탭 콘텐츠 (스크롤)          │
├──────────────────────────────────────┤
│  강화  스킬  장비  펫  유물  상점       │ 하단 6탭
└──────────────────────────────────────┘
```

- 프로필을 누르면 **내 정보**(전투력 상세 · 누적 보너스 · 통계 · 초기화)가 열립니다
- 재화 옆 **[+]** 버튼은 상점으로 이동합니다
- 던전 · 퀘스트 · 출석 · 룰렛 · 우편 · 승급전은 **사이드 아이콘 → 팝업**으로 열립니다

## 게임 방식

- 스테이지마다 **적 50마리**가 맵에 흩어져 소환되고, 10스테이지마다 **보스**가 추가 등장
- 플레이어는 **완전 자동** — 거리를 벌리며 장착 스킬을 쿨타임마다 발동, 펫은 따라다니며 자동 공격
- 전멸시키면 다음 스테이지. 죽어도 몇 초 뒤 부활하고 진행은 이어집니다

## 성장 시스템

### 강화 (골드)
공격력 · 공격속도 · 치명타 확률/피해 · 관통 · 최대체력 · 체력재생 · 방어력 · 이동속도 · 골드획득
`x1 / x10 / MAX` 구매 단위와 **자동 강화**(기본 ON)

### 도감 4종 (소환)
| 도감 | 종류 | 장착 | 소환 재화 |
|---|---|---|---|
| 스킬 | 24종 — **6등급 × 등급당 4종** (공격 · 범위/제어 · 보조(버프·회복)) | 8개 | 💎 다이아 |
| 장비 | 무기·방패·목걸이 각 36종 (108종) — **8등급**, 마지막(불멸) 등급 1종·그 외 등급당 5종, 종류별 개체차 배율(0.9~1.15) | 부위별 1개 | 💎 다이아 |
| 펫 | 9종 | 3마리 | 💎 다이아 |
| 유물 | 9종 | 3개 | 🔮 유물석 |

- 등급: 일반 → 고급 → 희귀 → 영웅 → 전설 → **신화** — **장비만** 그 위로 **초월 → 불멸** 2단계가 더 있습니다(8등급). 스킬·펫·유물·코스튬은 신화가 최고 등급입니다
- **보유 효과**(가지고만 있어도) + **장착 효과**(장착한 것만)
- 자동장착 / 최고 장착 / 일괄 강화 지원

### 소환 레벨 · 경험치 · 확률
- **무기 · 방패 · 목걸이는 각각 별도 배너**이며, 배너마다 소환 레벨(1~100)과 경험치가 따로 쌓입니다
- 소환 1회 = 경험치 1. 레벨이 오르면 **상위 등급이 해금되고 확률이 상승**합니다

| 등급 | 해금 소환레벨 | Lv.1 확률 | Lv.100 확률 |
|---|---|---|---|
| 일반 | 1 | 80% | 5% |
| 고급 | 1 | 20% | 15% |
| 희귀 | 5 | – | 30% |
| 영웅 | 15 | – | 25% |
| 전설 | 30 | – | 15% |
| 신화 | 40 | – | 10% |
| 초월 (장비만) | 55 | – | 6% |
| **불멸 (장비만)** | **75** | – | **3%** |

(장비 배너만 초월·불멸 행이 있는 8행 표를 쓰고, 스킬·펫 배너는 신화까지의 6행 표를 씁니다. 표기 확률은 재정규화 전 가중치입니다)

### 강화 · 합성 · 환불
- **강화**: 같은 아이템 5개 소모 → 1레벨. 레벨마다 필요량 +1, **20개 상한** (Lv.1→100 = 총 1,860개)
- **레벨 상한 100** — 단, **최고 등급(불멸) 장비만 무한 강화**
- **합성**: Lv.100 장비 + 같은 장비 5개 → **다음 등급 5종 중 랜덤 1개** (초월→불멸은 1종 고정)
- **환불**: 스킬·펫 도감을 전부 Lv.100까지 완성하면 소환 종료 + 남은 재료를 다이아로 환불

### 컬렉션 보너스
도감을 일정 종수 모으면 단계별 **[보너스 강화 받기!]** 버튼이 열리고, 누르면 영구 스탯 보너스를 획득합니다. (스킬 6 · 장비 6 · 펫 5 · 유물 5단계)

### 승급전 (계급)
브론즈 → 실버 → 골드 → 플래티넘 → 다이아 → 마스터 → 그랜드마스터 → **챌린저**

최고 스테이지 + 전투력 조건을 만족하면 **승급 수호자**가 등장하고, **60초 안에 처치**하면 승급합니다. 승급마다 공격력·체력 **+25%**(누적).

### 던전 6종 (하루 3회씩)

| 던전 | 보상 | 요구 전투력(1층) | 해금 |
|---|---|---|---|
| 황금 동굴 | 골드 | 2,500 | 처음부터 |
| 수정 광산 | 다이아 | 4,000 | 처음부터 |
| 고대 유적 | 유물조각 ×1 | 5,000 | 가이드미션 15 클리어 |
| 잊힌 신전 | 유물조각 ×2.5 | 12,500 | 고대 유적 5층 클리어 |
| 용의 무덤 | 유물조각 ×6 | 30,000 | 잊힌 신전 5층 클리어 |
| 창세의 제단 | 유물조각 ×15 | 75,000 | 용의 무덤 5층 클리어 |

유물조각 던전 4단은 **보상 종류가 같고 난이도·보상량만 배수(1 / 2.5 / 6 / 15)** 로 갈립니다 —
하루 최대 수급은 4던전 × 3회입니다.

제한 시간 30초 안에 요구 피해를 채우면 클리어하고 다음 층 해금. **소탕**으로 이전 층 보상을 즉시 받습니다.

### 일일 콘텐츠
- **출석** 28일 달력 (7일·28일차 대박 보상)
- **룰렛** 하루 5회 무료, 8칸
- **퀘스트** 5종 반복형 (모두 받기 지원)
- **튜토리얼** 11단계 — 메인 화면 배너에 목표·진행도 상시 표시
- **우편함** 신규 지원 5통

### 상점
- **코스튬** 50종 — 영웅 탭 → `코스튬` 서브탭에서 다이아로 구매, **보유 효과 영구 적용** + 기사 외형(색상) 변경
  (일반 12 · 고급 10 · 희귀 10 · 영웅 8 · 전설 6 · 신화 4. 7종은 스테이지·계급·도감 **조건 해금**)
- **유물석 교환소** — 다이아 → 유물석
- **다이아 패키지** — ₩3,300 / ₩12,000 / ₩33,000 / **₩110,000 (200만)** / ₩520,000
  ※ 실제 결제는 연동되지 않은 **데모**이며, 버튼을 누르면 다이아가 즉시 지급됩니다

### 편의 기능
- **오프라인 보상** (최대 8시간) · **자동 저장**(localStorage) · 정보 탭에서 전체 초기화

## 밸런스 (측정치)

헤드리스 시뮬레이터로 **무과금 / 소과금(₩110,000) / 고과금(₩10,000,000)** 3시나리오를 각각 30분(≈3일 상당) 자동 플레이해 측정했습니다.

| 구분 | 스테이지 | 전투력 | 계급 | 도감 | 소환레벨 | 신화 장비 |
|---|---|---|---|---|---|---|
| 무과금 | 112 | 2.1T | 플래티넘 | 10/49 | 스킬 18 | – |
| ₩110,000 (200만 다이아) | 196 | 5.0×10²² | 마스터 | 37/49 | 47/38/38/38/26 | – |
| ₩10,000,000 (1.8억 다이아) | 467 | 2.0×10⁴⁶ | 챌린저 | 42/49 | 전 배너 100 | **Lv.521** |

- **무과금 다이아 수입 ≈ 15.7K/일** (목표 15K)
- 적 처치 시간 약 1.8초, 피격당 체력 6.3% — 진행 속도는 6.5 → 3.0 → 1.7 스테이지/분으로 완만히 감소
- 무한 소모처는 **불멸 장비 무한 강화**이며, 1등 경쟁은 **최고 스테이지 + 전투력**으로 결정됩니다

주요 곡선: 적 체력 `55×1.25^s` · 적 공격력 `6×1.14^s` · 골드 `4×1.175^s` · 공격력 강화 `18×1.12^lv` (비용 `45×1.19^lv`)

## 구조

```
index.html                      게임 전체 (데이터 · 전투 · 렌더 · UI)
assets/
  atlas-data.js                 스프라이트 프레임/애니메이션 좌표 (자동 생성)
  knight.png / .json            플레이어 — idle · run · attack · get_hit · die
  elves-craft-pixel.png / .json 적(고블린/다크엘프/보스/승급 수호자)
  zombie.png / .json            적(좀비)
  bird.png / robo.png / stormlord-dragon96x64.png   펫 3종족 (색상 틴트로 9종 파생)
  explosion.png                 스킬 이펙트 (23프레임)
  buch-dungeon-tileset.png      바닥 타일맵 (16×16 → 3배 확대)
```

- 바닥은 월드 전체(960×1536)를 오프스크린 캔버스에 타일맵으로 한 번 그려두고 카메라가 잘라 씁니다
- 펫 색상과 코스튬은 원본 시트를 캔버스 `multiply` 합성으로 **런타임 틴트**
  (코스튬 50종은 색상환을 고르게 나눈 틴트로 구분 — 쌍별 최소 색차 ΔE 10.3)
- 아틀라스를 JS로 변환해 두어 `fetch` 없이 `file://` 에서도 동작합니다
- 밸런스 수치는 파일 상단 데이터 블록(`GRADE`/`SKILLS`/`EQUIPS`/`PETS`/`RELICS`/`AVATARS`/`BANNERS`/`GRADE_ROLL`/`COLL`/`DUNGEONS`/`ATTEND`/`ROULETTE`/`RANKS`/`QUESTS`/`TUTO`/`MAILS`/`PACKS`/`UPG`)에 모여 있습니다
