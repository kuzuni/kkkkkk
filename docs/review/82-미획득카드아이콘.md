### 바꾼 것 (index.html 3곳)

1. **스킬 카드 격자**(`renderSkill`, `#bSk .sk-gp`): `own ? 아이콘 : 자물쇠` →
   **아이콘 항상 + 미보유면 자물쇠 추가**(형제 순서 아이콘 → 자물쇠 = 자물쇠가 위에 그려짐).
2. **펫 카드 격자**(`renderPet`, `#bPet .sk-gp`): 동일 패턴 동일 수정.
3. **CSS**: `.sk-card.lk>.sk-ci{opacity:.35;filter:grayscale(1)}` — 05 의 `.wgc.lk>.ic{opacity:.35}` 와
   같은 컨셉. 지시대로 `brightness(0)` 완전 실루엣은 쓰지 않았다. Lv 글자 회색(`#ACACAC`)은 기존 유지.

**안 바꾼 것**: 카드 기하(bbox·pitch)·보유 카드 렌더·클릭 경로. 미보유 카드 클릭은 기존대로
상세 팝업(스킬 = 08 `showSkillDetail` «아직 획득하지 못했습니다. 스킬 소환으로 획득하세요» /
펫 = `showItem` «소환으로 획득하세요»)이 뜨고, 소환 이동은 기존 `[data-sksum]`/`[data-ptsum]` 버튼 경로 그대로다.
코스튬(50) 카드도 같은 `own ? : ` 패턴이지만 전 카드가 같은 🛡️ 아이콘이라 «무엇인지 보이기» 의

### 검증 방법 메모 (지시문과 다르게 잰 부분)

- 지시문의 «자물쇠 바깥 영역 평균 밝기가 빈 카드보다 높음» 은 **성립하지 않는 판정식**이다 —
  카드 바탕이 밝은 베이지(평균 밝기 ~114)라 어두운 이모지가 비치면 평균 밝기는 오히려 **내려간다**.
  대신 «아이콘 표시/숨김 두 캡처의 픽셀 차이(변화율·평균 Δ)» 로 가시성을 직접 쟀다.
- 판정 하한은 **05 무기 잠금 카드(주인이 기준으로 지목한 구현)를 같은 프로브로 잰 값**에서
  캘리브레이션했다(§0). 05 실측 0.0~0.2% → 하한 0.8%. 새 스킬·펫 카드는 1.0~7.6% 로
  **기준 구현보다 한 자릿수 더 잘 보인다.**
- 게임 루프가 패널을 상시 재렌더해 element 핸들 스크린샷이 `detached` 로 죽는다 —
  §3 캡처 동안 `renderUI` 를 no-op 으로 동결하고 clip 캡처 + 전역 style 토글로 쟀다.
