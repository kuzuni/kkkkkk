## 2. 바꾼 것 (1회차 = 완료)

1. **`.sm-btns`**: `top:1682px` 폐기 → `bottom:min(426px, calc(100% - 1416px))`.
   - **426**(지시서는 427): 측정표 y 는 **포함 행**이라 ref 하변 1913 의 edge 는 1914 → 2340−1914 = 426.
     427 로 두면 버튼이 1px 위로 간다. 426 에서 top·하변 모두 **Δ0**.
   - `min()` 은 **짧은 프레임 보호**다(아래 4).
2. **`.sm-close`**: `bottom:174px` → `bottom:min(175px, calc(100% - 1480px))`.
   - **175**(지시서는 176): 우리 잉크는 **43px**(ref 41)이고 CSS 박스 하변보다 1px 아래로 나가므로
     잉크 상·하변을 동시에 맞출 수 없다. 실측으로 **잉크 중심**을 ref 중심(2084)에 맞추는 175 를 골랐다
     (174 → 중심 +1·간격 211 / 175 → 중심 **Δ0**·간격 210 / 176 → 중심 −1·간격 209).
   - 지시서의 176 은 «잉크 하변 = CSS bottom» 가정에서 나온 값이라 실측으로 1px 정정.
3. **패널(`top:709`)·리본(`top:641`)은 손대지 않았다** — 상단 앵커가 맞는 요소다(게이트에 회귀 항목).

## 3. 부수 버그 — 재소환 버튼을 누르면 결과 팝업이 닫힌다 (74 «탭 유실» 계열)

지시서 «기능 완성 규칙» 의 기능 체크를 돌리다 잡았다. **앵커와 무관한 기존 버그**이고 12 구간이라 같이 고쳤다.

- **증상**: `[10회 소환]`·`[30회 소환]` 을 누르면 소환은 되는데(💎 차감·`S.summons` 증가)
  **결과 팝업이 그대로 닫혀** 새로 뽑힌 것을 볼 수 없다.
- **원인**: 버튼 중앙(=클릭 지점)은 `.cost` 안의 `i.sm-fat` 인데, 버튼 `onclick` 이
  `doSummon → syncSummonBtns` 로 그 `i` 를 `innerHTML` 로 갈아 끼운다. 이벤트가 `#sumw` 까지
  버블링해 올 때 `e.target` 은 **DOM 에서 떨어져 나간 노드**라 `closest('.sm-b')` 가 `null` →
  «배경 탭» 으로 오인 → `closeSummonResult()`.
- **수정**: `#sumw` 클릭 핸들러를 `e.target.closest()` → **`e.composedPath()`** 로.
  경로는 **디스패치 시점**에 확정되므로 중간 재렌더에 영향받지 않는다.
- 74 가 잡은 것과 같은 «재렌더가 이벤트를 삼킨다» 패턴이다 → `docs/LESSONS.md` 에 추가.
