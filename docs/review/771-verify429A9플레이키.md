## 2. 뿌리 — «자기 힘으로 초록인 적이 없었다»

`openRel()`(`tools/verify429.js` 50)은 정착을 **자기가 하지 않는다**:

```js
const openRel = async (page) => {
  await page.evaluate(() => { closeModal(); openRelw(); });
  await page.waitForTimeout(300);        // ← 고정 대기 하나뿐
};
```

여태 초록이던 것은 **공용 `settle291` 훅** 덕이다 — `launch()` 가 `waitForTimeout` 을 감싸
`MIN_WAIT`(250) 이상이면 정착을 대신 돌려 준다(`tools/pwlaunch.js` · `tools/settle291.js` 114).
그 훅은 entry 가 `verify*.js` 일 때만 자동으로 붙으므로, 끄면(`PW_SETTLE=0`) [A] 가 재는 값이
**곧바로 0% 프레임**이 된다. 수리 전 트리로 직접 대조한 결과:


**A9 만의 병이 아니다** — 같은 축소에 `A2`(76×76)·`A5`(띠 108 → 106.4)·`A7`(우변 100 → 106.6)이
전부 물려 있었다. A4·A6·A8·A10 이 초록으로 남은 것은 그 항들이 «사분면» · «겹침 0» 처럼
**등방 축소에 둔감한** 질문이기 때문이지, 그 자리가 성했던 게 아니다.

### 사다리가 이 창을 왜 못 막나

`settle291` 은 값싼 선검사부터 한다(`PENDING_SRC` · settle291.js **55**·**106**):

> «부를 때 `jz(Pg|Sheet)` pending 이 **0** 이면 곧바로 끝낸다»

이 선검사는 **일부러** 있는 것이다 — 없으면 64·262·107 처럼 **시간 자체를 재는** 자에
rAF 두 프레임이 얹혀 300ms 홀드가 350ms 문턱을 넘는다(그 파일 주석). 문제는 연출이
**다음 프레임에 붙는** 순간이다: 그 찰나엔 pending 이 0 이라 사다리가 그냥 지나가고,
바로 뒤의 `getBoundingClientRect()` 가 스타일을 flush 하면서 애니를 **0% 에서 시작**시킨다.
`probe771` [3] 이 그 순간을 `jzPgIn:running@0` 으로 찍었다.

**764 가 `settleBox` 를 따로 세운 이유 ⓑ 와 정확히 같은 구멍이다.**

## 3. 처방 — 왜 자리 쪽(ⓐ)인가

등재문은 후보 둘을 적어 뒀다.

| | 안 | 대가 |
|---|---|---|
| ⓐ | `openRel()` 뒤에 «두 프레임 연속 정적» 정착을 건다 | 자 한 곳 · **권함** |
| ⓑ | 구멍 자체를 `settle291` 사다리에서 막는다 | 그 자는 **게이트 44개**를 지나간다 — 64·262·107 이 흔들린다 |

**ⓐ 를 골랐다.** ⓑ 는 이 한 자리를 위해 시간을 재는 자 전부를 위험에 놓는 거래이고,
같은 판단을 764 가 이미 `.mbox` 쪽에서 내려 `settleBox` 를 세워 뒀다 — **선례가 같은 파일 안에 있다.**

```js
const settlePg = async (page) => page.evaluate(async () => {
  const pend = () => (document.getAnimations ? document.getAnimations() : [])
    .filter((a) => /^jzPg/.test(a.animationName || '') && a.playState !== 'finished');
  const t0 = performance.now();
  for (let quiet = 0; quiet < 2 && performance.now() - t0 < 1500;) {
    const P = pend();
    if (P.length) { await Promise.all(P.map((a) => a.finished.catch(() => 0))); quiet = 0; }
    else quiet++;
    await new Promise((r) => requestAnimationFrame(() => requestAnimationFrame(r)));
  }
});
```

핵심은 «**두 프레임 연속으로** 돌 것이 없을 때만 끝낸다» 는 것 하나다 — 한 번 비어 있는 것으로는
안 끝내므로 «다음 프레임에 붙는» 창이 닫힌다. 상한 1500ms 는 291·764 와 같은 값이라
`finished` 가 안 와도 자를 멈추지 않는다.

⚠ **무르게 푼 수리가 아님**은 지표가 아니라 **조건**으로 못박았다 — 처방의 값은
«부하에서 안 빨개진다»(증명 불가)가 아니라 **«공용 사다리가 없어도 옳다»** 이고,
그것은 `PW_SETTLE=0` 한 줄로 언제든 다시 잴 수 있다.
