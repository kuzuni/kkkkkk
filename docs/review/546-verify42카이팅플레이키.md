## 2. 기전 — `sp = 0` 이 안 먹는 자리는 정확히 한 곳이다

`index.html` 적 이동식(~21335):

```js
let spd = (isBoss ? Math.max(e.sp, stat.speed*BOSS_CHASE) : e.sp) * (e.slow > 0 ? 0.55 : 1);
if(e.dashT > 0) spd = 0;                                   /* 예고 — 제자리 */
else if(dashing) spd = stat.speed * DK.spd * (e.slow > 0 ? 0.55 : 1);   /* ← e.sp 를 안 읽는다 */
```

* **잡몹도 돌진한다** — 359 는 «보스·일반 적 대시 공격» 이라 `DASH.mob`(cd 5.0~8.0 · tel 0.42 ·
  dur 0.26 · spd ×2.6 · 사거리 120~380)이 좀비에게도 붙는다.
* `setup7` 은 좌표·hp·`sp` 만 덮어쓰고 **`dashT`/`dashD`/`dashCd` 는 그대로 물려받는다.**
  그 셋은 개체가 태어날 때 `rnd(0.6, cd1)` 로 **난수 초기화**되고 매 프레임 돈다 = 회차마다 위상이 다르다.
* 창의 크기가 곧 빨강 비율이다: (tel 0.42 + dur 0.26) / (주기 5.0 + 창) ≈ **최대 12%** —
  직접 잰 자연 빈도 **2/12(16.7%)** 와 같은 자릿수다(창에 걸치는 «반쪽» 까지 세면 더 크다).
  ⚠ `probe546` [2] 가 찍는 «개체 × 표본 0.4%» 는 **하한**이다 — 그 시점 필드의 몹 대부분이 남서 구석에
  주차돼 **대시 사거리(120~380) 밖**이라 예고 분기가 안 열린다. 게이트가 무는 개체는 플레이어와 계속
  붙어 있는 `enemies[0]` 하나뿐이라 훨씬 자주 걸린다.
* ⚠ 예고 중에는 `spd = 0` 이라 **더 그럴듯하게 서 있다** — «주차가 먹었다» 로 보이는 프레임이
  0.42초나 되고 그 뒤에 튀어나온다.

## 3. 처방 — «허용 오차» 가 아니라 «표본» 을 고쳤다

등재문이 못박은 대로 «허용 오차를 넓히는 길»(예: `> d0 + 5` 를 `> d0 - 40` 으로)은 **카이팅이 죽어도
초록인 헛초록**이라 안 골랐다. 고친 것은 주차 주문 한 줄이다.

⚑ **처방을 새로 지어내지 않았다 — 저장소가 이미 같은 병을 두 번 앓고 같은 약을 썼다.**
**507**(2026-08-30)이 `verify193` [3] 에서 «8종이 스킬과 무관하게 전부 같은 79.733px 를 냈다» 를
`probe507` 로 파고들어 **`e.sp = 0` 하나로는 모자라다** 를 확정했고, **510** 이 같은 줄을 `verify288` 에
붙였다. 두 자리가 쓰는 주문이 **글자 그대로 이것**이다:

```js
enemies.forEach(e => { e.sp = 0; e.dashT = 0; e.dashD = 0; e.dashCd = 1e9; });
```

`verify42` 는 그때 **전수에서 빠진 세 번째 자리**였다(507 은 `verify193`, 510 은 `verify288` 만 봤다).
같은 값 **79.7px** 이 두 작업의 실측에 나란히 찍혀 있는 것이 그 증거다 — 507 의 79.733 과
이번 s9·s12 의 «1020.0 → 940.3» 은 **같은 산식의 같은 숫자**다.

```js
for (const e of enemies) { e.x = 40; e.y = WORLD.h - 40; e.dashT = 0; e.dashD = 0; e.dashCd = 1e9; }
```

* 표적 하나가 아니라 **전원**을 얼린다 — 남서 구석의 몹도 같은 상태 기계를 돌고, «지금은 멀어서
  안 걸린다» 는 다음 세대에서 또 뒤집힌다(LESSONS 540-① «지금 초록 ≠ 안 걸린다»).
* `dashCd = 1e9` 는 상태 기계의 **가장 앞 가지**(쿨다운 감소)에 영원히 머무르게 한다 — 예고로 넘어가는
  분기는 `e.dashCd <= 0` 일 때만 열린다.
* **[9]**(«손을 떼면 자동 카이팅이 즉시 복귀한다», 600ms 창)도 같은 `setup7` 을 쓰므로 **같이 닫혔다** —
  그쪽은 창이 더 길어 확률이 더 컸다.
