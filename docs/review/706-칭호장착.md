⚑ **결손은 «끊긴 선» 이 아니라 «없는 축» 이다.** 201 ②(2026-08-27)가 «보유» 를 파생(`i <= S.rank`)에서

## 2. 처방 — 축을 하나 더 세운다

| 축 | 값 | 읽는 자 |
|---|---|---|
| 보유 | `S.titles` (201 ②) | `titleOwn(i)` |
| **장착(신설)** | **`S.titleEq`** | **`titleIdx()` · `titleOf()`** |
| 계급(판정) | `S.rank` — **한 줄도 안 건드렸다** | `rankOf()` · `nextRank()` · 계급 보너스 |

```js
const titleIdx = () => {
  const t = S.titleEq;
  return (Number.isInteger(t) && t >= 0 && t < RANKS.length && titleOwn(t))
    ? t : Math.min(S.rank, RANKS.length - 1);
};
```

폴백이 두 겹인 것이 이 처방의 전부다:

1. **`null` = «한 번도 고른 적 없음»** → 계급을 따라간다.
   **구 세이브가 정확히 그 상태**라 KEY 를 안 올리고도 706 이전 화면과 한 픽셀도 안 다르다.
2. **고른 값이 보유 밖이면**(세이브 손댐·표 축소) 조용히 계급으로 접힌다 —
   못 가진 칭호가 HUD 에 걸리는 길을 **구조적으로** 막는다. 단 **회수하지는 않는다**(다시 얻으면 되살아난다).

**제품 6자리**: ⑴ `DEF()` `titleEq:null` ⑵ `load()` 정규화 ⑶ `titleIdx`/`titleOf`/`titleEquip` 신설
⑷ `renderProfile`(배너·`eq`·`data-ttl`) ⑸ `#pfCards` 위임 클릭 ⑹ `drawHud` `#rankN` · `rankRows` `me.t`

### 승급과의 상호작용 — 위임 규약 채택

## 3. 게이트가 잡은 **진짜 버그** — `Number(null) === 0`

초판 `load()` 는 `const te = Number(d.titleEq)` 였다. `verify706` [D] 가 그것을 빨갛게 만들었고
파 보니 **자의 문제가 아니라 제품의 버그**였다:

> «한 번도 안 골랐다» 는 `null` 로 저장돼 JSON 왕복으로 `null` 로 되돌아온다.
> `Number(null)` 은 **0** 이고 `Number.isInteger(0)` 은 참이라 —
> **칭호를 한 번도 안 고른 세이브가 전부 «브론즈를 골랐다» 로 살아난다.**

즉 초판대로 냈으면 지금 플레이어 **전원의 칭호가 브론즈로 굳는** 회귀를 만들 뻔했다.
날값을 그대로 보는 것으로 닫았고, [D] 를 **네 모양 전수**로 넓혔다(키 없음 · `null` · 문자열 `"3"` · 정수 1).

⚠ **[D] 를 «페이지 안에서 세이브를 만들고 reload» 로 짜면 안 된다** — 오토세이브가 그 사이에 덮어써서
초판이 «키를 지웠는데 로드가 0 을 봤다» 는 **엉뚱한 지문**을 냈다. `addInitScript` 로
**제품 스크립트가 돌기 전에** 심어 경합을 없앴다.

## 7. 교훈 (LESSONS 706)

1. **«안 눌린다» 의 뿌리가 핸들러인 적이 없었다.** 고른 값을 적을 자리가 없으면 핸들러도 없다 —
   결선을 먼저 달지 말고 **축이 있는지부터** 물어라(`probe706` [0b][0d] 가 그 질문이다).
2. **`Number(null) === 0`.** «없음» 을 `null` 로 저장하는 필드를 `Number()` 로 정규화하면
   «없음» 이 «0 번을 골랐음» 으로 부활한다. 날값을 `Number.isInteger` 로 보라.
3. **세이브 이관 자는 오토세이브와 경합한다.** 페이지 안에서 세이브를 만들고 `reload()` 하면
   그 사이 오토세이브가 덮어써 **엉뚱한 지문**을 준다 — `addInitScript` 로 제품 스크립트보다 먼저 심어라.
4. **291·353 함정이 «클릭» 에도 걸린다.** 지금까지는 rect 를 «재는» 자리의 문제로만 적혀 있었는데,
   입장 연출 중의 rect 로 **마우스를 내리면 클릭이 카드 밖에 떨어진다**.
   `pwlaunch` 의 정착 훅은 **250ms 이상**의 `waitForTimeout` 뒤에만 도므로
   클릭 직전 대기를 그 문턱 아래(200ms)로 두면 **위상에 따라 초록/빨강이 갈린다** — 실제로 그렇게 흔들렸다.
