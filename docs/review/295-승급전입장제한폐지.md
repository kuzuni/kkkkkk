### 등재문이 «같이 볼 것» 으로 남긴 셋

- **ⓐ 버튼 disabled·회색 처리가 자동으로 풀리는가** → **푼다.** 두 버튼 다 `nextRank()` 가 있을 때만 그려지는
  자리라(정보 탭은 `nr ?` 삼항 안 · 팝업은 `if(!r) return` 뒤) 게이트가 걷힌 뒤로는 `disabled` 가 붙을 조건 자체가
  없다. 그래서 삼항을 남겨 두는 대신 **아예 뗐다** — 남겨 두면 «항상 참인 조건» 이라는 죽은 분기가 된다.
- **ⓑ 레드닷** → **`promoReady()` 신설로 해결.** «점등 폐지» 도 후보였지만 택하지 않았다: 권장 기준을 넘긴 순간은
  실제로 «누를 게 생긴» 순간이고, 승급하면 다음 계급의 기준이 다시 올라가 **저절로 꺼진다**(게이트 [4] 가
  꺼짐 → 켜짐 → 꺼짐 3상태를 전부 잰다). 상시 점등이 아니므로 166 을 지킨다.
- **ⓒ 실패해도 잃는 것이 없는가** → **없다, 그대로 둔다.** `startPromo()`·`endPromo(false)` 어디에도 재화·입장권
  차감이 없다(실패 경로는 `notify()` 한 줄 + `spawnStage()` 뿐). 무제한이 된 만큼 «될 때까지 재도전» 이 기본
  동선이 되는 것은 맞지만, **여기서 비용을 새로 붙이면 그건 «제한» 이 이름만 바꾼 것**이라 지시에 반한다.
  대신 게이트 [3] 이 «실패 전후로 S 가 한 칸도 안 변한다» 를 못 박아, 나중에 누가 조용히 비용을 붙이면 빨개진다.

### 게이트를 짜다 잡은 자기 함정 3건 (다음 세션용)

1. **정의를 «첫 `;` 까지» 로 자르면 안 된다.** `const promoReady = () => { const r = …; return …; };` 는 본문에
   `;` 가 있어 `/const\s+promoReady\s*=[^\n;]*;/` 가 **`const r = nextRank();` 에서 끊긴다** — 단언이 «S.best 참조 없음»
   으로 잘못 빨개졌다. 한 줄 정의는 **줄 단위로** 집는다.
2. **`pr-note` 는 CSS 에도 있다.** `.mbody .pr179 .pr-note{…}` 가 먼저 걸려 «BOSS_SEC 참조» 단언이 **엉뚱한 자리를
   보고 통과**했다(가짜 초록). `class="pr-note"` 로 마크업 쪽만 못 박았다.
3. **`closeModal()` 은 본문 DOM 을 안 지운다** — `#modal` 의 `.on` 만 뗀다. «모달이 닫혔나» 를 `getElementById('pgo')`
   유무로 재면 **항상 «안 닫혔다»** 가 나온다. 판정은 `#modal.classList.contains('on')` 으로.
