## 1. 착수 — 등재문의 가설을 재현이 **기각**했다

등재문의 읽기는 «아마 뷰포트 안 초기 표시분은 즉시, 그 외/스크롤 유입분은 등장 애니» 였다.
338 규칙대로 처방 전에 `tools/probe717.js` 로 **실제로 등록된 애니메이션**(`Element.getAnimations()`)을 세니
갈래가 셋 다 아니었다:

| 관측 | 수리 전 값 |
|---|---|
| `#chList` 자식 행 수 | **24** (`CHAT_SEED` 24행) |
| 애니가 붙은 행 | **0..19 — 앞 20행** (애니 이름 `jzSt`) |
| 안 붙은 행 | **[20, 21, 22, 23] = 목록 끝 4행** |
| 스태거 지연 `--jzd` 가 꽂힌 행 | 20행 (첫 값 `60ms`) |
| 그려진 값 | 최저 opacity **0.000** · 최저 scale **0.940** |

⚑ **«하단 4개» 는 뷰포트도 스크롤도 아니라 상수 하나였다.**
60 쥬시의 카드 스태거가 `jzStagGo(kids, Math.min(kids.length, 20))` 로 **앞 20칸만** 걸고,
채팅은 24행이라 **끝 4행이 남는다**. 주인이 «하단 4개» 라고 말한 자리가 `24 − 20` 이다.

가설이 셋 다 틀렸다는 것이 왜 중요한가 — 뷰포트/스크롤 가설을 그대로 따랐으면
«스크롤 유입분에 애니를 안 붙이는» 분기를 새로 만들었을 것이고, 그것은
**애초에 없던 분기**라 결손은 하나도 안 없어지고 코드만 늘었다.

## 2. 처방 — 부품이 아니라 **호출부**만 뗀다 (659 규약)

`jzStagger`/`jzStagGo`/`@keyframes jzSt` 는 카드 격자 여럿이 그대로 쓰는 공용 부품이라 지울 수 없다.
이 저장소에는 그 자리에 쓰라고 만들어 둔 표시가 이미 있다 — **`jz-x` = «손대지 마라»**.
363 이 세운 축이 그대로 맞는 자리다: «내가 건다»(`fx-pop`) 와 «아무것도 안 건다»(`jz-x`) 는 다른 말이고,
채팅은 후자다.

```
- return '<div class="ch-row' + (m.vs ? ' vs' : '') + '">' + …
+ return '<div class="ch-row jz-x' + (m.vs ? ' vs' : '') + '">' + …
```

**제품은 이 한 자리가 전부다.** 선언 쪽(`chRowHTML`)에 붙였으므로 `renderChat()` 이 innerHTML 을
다시 써도 표시가 같이 딸려 온다 — 새 메시지 유입(`chSend`)에서 그 점이 게이트로 선다(`verify717 [C2]`).

### 안 한 것 두 가지 (그리고 왜)

- **상수 20 을 안 올렸다.** 24 로 올리면 채팅은 «전 행 애니» 가 되어 지시와 정반대고,
  30 으로 올려도 시드가 늘면 똑같이 잘린다(726 이 «6은 상한이 아니라 열 수였다» 로 배운 자리와 같은 꼴).
  이 지시가 원하는 것은 **애니 0** 이지 «애니가 고르게» 가 아니다.
- **`jzStagger` 자체에 채팅 예외를 안 넣었다.** 부품이 화면 이름을 알면 다음 화면에서 또 고쳐야 한다.
  표시는 화면이 달고, 부품은 표시만 읽는다.
