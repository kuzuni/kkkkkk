### ② 처방 — 문법을 «한 줄» 로 적고, 코드에 그 이름을 세웠다

등재문이 요구한 «먼저 무엇을 문법으로 삼을 것인가를 한 줄로 정해 적어라» 에 대한 답:

> **모든 투사체는 ① 후광(저알파) · ② 본체(`b.col` 불투명) · ③ 하이라이트(근백색 코어)
> 세 층을 전부 갖는다. 하드 외곽선은 쓰지 않는다** — 외곽선처럼 보이는 것은 ①이나 ③이 흡수한다.

말로만 두지 않고 `shotBody()` 안에 **층의 이름**을 세웠다(제품 3줄):

```
const SPEC = 'rgba(255,255,255,.94)';   /* 하이라이트는 한 색 — 종별 사본 금지(402) */
const halo = fn => { … };               /* ① 본체 앞에 부른다 */
const spec = fn => { … };               /* ③ 본체 뒤에 부른다 */
```

⚑ **형상은 한 획도 안 바꿨다.** 710 이 여덟 회차에 걸쳐 갈라 놓은 17개 실루엣이 이 작업의 재료다 —
792 가 더한 것은 **층뿐**이고, 그래서 ①(분간)이 흔들리지 않는다(아래 ④).

· 후광 신설 **5자리** · 하이라이트 신설 **13자리** · 밸런스·판정·자리·속도·수명 **0줄**
· 세이브 이관 없음(KEY 불변 — 그리기만 만진다: 114·541 «그리기만» 문법)
