# 26 동료 팝업 — 작업 기록

**작업 성격**: 신규 화면이지만 **레퍼런스 스크린샷이 없다**(원본은 동료 서브탭이 잠금).
설계상 «07 스킬 팝업 구조·규격을 그대로 복제하되 장착 슬롯만 3칸» 이므로(UI-REFERENCE §26),
레퍼런스 대조형 비평 루프([3]-나)가 아니라 **07 스킬 시트를 기준으로 한 구조 복제 + 구조/상호작용 검증**으로 진행했다.

## 구현 (sess-1844-1435, 2026-08-24)

- `renderPet()` + `#bPet` 클릭 핸들러 신설 — `renderSkill()` 을 1:1 복제.
- **CSS 는 새로 만들지 않았다.** 기존 `#bSk` 스코프 규칙 16개를 `:is(#bSk,#bPet)` 로 바꿔
  스킬 시트와 **픽셀 동일 규격**을 공유한다(`:is()` 는 ID 특정성을 보존하므로 07 렌더에 영향 0).
  대상: `#panel:has(#bSk.on)` 3종 · `#bSk.on` · `#bSk>*` · 자식 display · `.sk-btn>i` ·
  `.sk-tab>i` · `.sk-tab.on>i` · `.ol1~.ol5` 외곽선 유틸 6종.
- **데이터는 기존 것 재사용 — 저장 구조 미변경(KEY 유지).** `PETS`(9종)·`S.eqPet`(최대 3)·
  `petEquipped`·`toggleEquip(it,'pet')`(3칸 상한 이미 존재)·`itemIcon`(펫 이모지)·`ownVal`.
- 장착 슬롯 3칸: 크기 115·pitch 125(07 동일), 패널(1037) 안 **가로 중앙** — 좌 = (1037−(2·125+115))/2 = **336**.
  실측 슬롯 x = 357/482/607, 그룹 중심 539.5 ≈ 화면중심 540 (Δ0.5).
- 그리드: `PETS` 9종을 5열×3행(2행은 4칸 + 빈칸 1). 카드 규격·진행바·`장착 중`·잠금 전부 07 그대로.
- 버튼: `[동료 소환]` = 그 자리 소환 X → `goTab('shop')` 로 **10 상점 소환 탭(#shopw) 이동**(§26 규칙).
  `[일괄 강화]` = `levelUpAll(PETS)` → 09 결과 연출(`openUpAll`).
- 서브탭: 장비/스킬/동료/기타, **동료 활성**. 기타는 잠금(스킬 시트와 동일).
- 카드 세부 = `showItem()` → **08 스킬 세부 팝업 껍데기 재사용**(펫 카테고리 자동 라우팅).
- 진입 디스패치: `renderUI()` 의 pet 분기를 `renderBanner('pet','bPet')` → **`renderPet()`** 로 교체,
  `bindBanner('bPet', …)` 배너 핸들러 제거.
