## 4. 곁들여 잡은 것 — 게이트가 **세로 배율에 눈이 멀어 있었다**

옛 코드는 `.si3` 의 computed transform 에서 **matrix 의 첫 성분(a = scaleX)만** 읽었다:

```js
const m = tr.match(/matrix\(([^,]+)/); if (m) sx = parseFloat(m[1]);
```

그래서 `scaleY` 로 잉크를 12% 늘려도 h 축은 **그대로 초록**이었다. d(= scaleY)도 읽어 잰 h 에 곱하게 했다
(지금 `.si3` 는 scaleX 만이라 **sy = 1**, 즉 **오늘 값은 한 칸도 안 움직인다** — 새로 생긴 것은 «감시 범위» 뿐이다).
이 자리는 `probe361` **N3** 가 못박는다.
