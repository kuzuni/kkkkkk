## 3. ⚑ 이 작업의 본체 — «내가 건다» 와 «아무것도 안 건다» 는 다른 말이다

스킵을 «`fx-pop` 을 안 붙인다» 로 구현하자마자 프로브가 **2 프레임을 미완성으로** 물고 나왔다.
범인은 252 가 심어 둔 가드였다:

```js
/* jzStagger() — 60 쥬시 ④ 카드 그리드 등장 */
if(!kids[0].classList.contains('fx-pop')) jzStagGo(kids, Math.min(kids.length, 20));
```

252 는 `fx-pop` 을 «이 그리드는 **내 등장은 내가 건다**» 는 표시로 썼다(그 표시가 없으면 쥬시가
자기 스태거를 얹는다). 그런데 363 이 스킵에서 그 표시를 떼자, 쥬시는 그것을 «등장 연출이 없는
그리드» 로 읽고 **자기 스태거를 대신 얹었다** — `.jz-st` 에 `--jzd` 60ms + 25ms × i,
20칸이면 **최대 535ms**. 스킵을 켰는데 연출이 반쯤 살아 있는 상태다.

**표시가 하나로는 모자랐다.** «내가 건다» 와 «아무것도 안 건다» 는 다른 말이라 표시도 둘이어야 한다
→ `jz-x` = «손대지 마라» 를 신설하고 가드를 한 항 넓혔다(제품 2줄).
앞으로 «등장을 일부러 안 하는» 그리드는 `fx-pop` 이 아니라 이 표시를 단다.

§R 되돌림 시험이 이것을 못박는다 — `jz-x` 가 붙은 채로 `jzStagger()` 를 다시 부르면 `.jz-st` **0개**,
표시만 떼고 같은 호출을 하면 **20개**(`--jzd` 60ms → 535ms). R-1 이 헛초록이 아님을 R-2 가 증명한다.

## 4. 무엇을 껐고 무엇을 남겼나

주인의 말은 «연출 스킵» 이다. 그래서 끄는 것은 **시간축에 얹힌 것 전부**로 잡았다.

### 헛초록 방지 (LESSONS 338 ④)

§3 의 «첫 프레임부터 전 칸 최종» 은 **기대값이 0** 인 단언이라 «자가 아무것도 못 봐서 0» 일 수 있다.
짝을 셋 붙였다 —
① §4 가 **같은 자**를 «끔» 에 대고 `first = 30`(0 이 아닌 값)을 낸다 ·
② §R-ⓑ 가 스킵 상태의 카드에 `fx-pop` 을 **도로 붙여** 그 자가 실제로 빨개지는지 본다 ·
③ §2 는 «키를 지우면 false» 만으로는 «화이트리스트에서 빠져 뭉갠 false» 와 구별이 안 되므로
   «true 로 저장된 세이브가 true 로 살아 돌아온다»(2-9)를 짝으로 물었다.

### ⚠ 세이브 이관은 `reload` 로 재면 못 잰다

`beforeunload → save()`(index.html 32177)가 새로고침 **직전**에 메모리의 `S` 를 통째로 다시 써서,
localStorage 에서 지운 키가 그대로 되살아난다(실측: 지웠는데 reload 뒤 `true`).
그래서 §2 의 이관 항은 `load()` 를 **직접** 부른다.
⚠ `load()` 는 상태를 돌려주지 않는다 — 안에서 `S = b` 를 하고 **`d.time` 을 돌려준다**(17542·17554).
읽을 곳은 반환값이 아니라 `S.opt` 다. (처음에 `load().opt.sumSkip` 로 썼다가 즉사했다.)
