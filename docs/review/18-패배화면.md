### 이번 회차에 새로 확정한 것

- **카드1 아이콘의 정체는 «보물상자»** 다. 측정표 §4.2 는 «보물상자+검 · 노란 검» 이라 적었지만
  픽셀맵을 뜨면 노란 잉크는 x195–216·y999–1018 의 **자물쇠 하나뿐**이고 검은 없다.
  구조는 뚜껑(청록 패널)/몸통(은청+자물쇠)/받침(청록 패널) 3단이며 CSS 로 작화했다.
  실측색 은백 `#D7DAFF` · 페리윙클 `#8E93CA`/`#A6A9DE` · 청록 `#2B7051`/`#26553F` · 자물쇠 `#FFD247`.
- **해골은 타원이 아니라 각진 두개골**이다 — ref y608–668 이 **전폭(x481–599)** 인 라운드렉트이고
  안와가 훨씬 크다(좌 x496–530 / 우 x549–584, 사이 흰 비량 17px). 타원 → path 로 교체.
- **자평(획 굵기)은 «회수 불가» 가 아니었다.** `-webkit-text-stroke` 를 두 겹으로 쓰면 된다:
  바깥 검정 스트로크를 목표의 2배로 키우고 **그 위에 «채움색» 스트로크 레이어**를 덮으면
  흰 잉크가 살찌고 남는 검정 링 두께는 `(검정/2 − 채움/2)` 로 유지된다.
  제목은 `::before{content:attr(data-t)}` 로, 외곽선이 없는 «터치하여 닫기» 는 채움색 스트로크만으로.
  → **A1·A3·01·02 가 «서체 한계» 로 남긴 감점의 상당 부분이 이 방법으로 회수 가능하다.**
  (제약: `attr(data-t)` 는 `<br>` 을 못 담으므로 여러 줄 문구에는 쓸 수 없다 — 카드3 문구가 그 경우다.)
