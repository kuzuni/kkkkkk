## 2. 진짜 원인 — 옛 [I] 의 «900ms» 는 **격자가 짧아서** 참이었다

옛 [I] 는 **두 점 표본**이었다.

```js
await pg.mouse.up();
await pg.waitForTimeout(900);        /* 95 관성이 멎을 때까지 */
const dragged = await pg.evaluate(`window.__sc('#bSk .sk-gp')`);
await pg.waitForTimeout(3000);
const after = await pg.evaluate(`window.__sc('#bSk .sk-gp')`);
if (after !== dragged) fail('드래그 ' + dragged + ' → 3초 뒤 ' + after + ' 로 되돌아갔다');
```

주석의 «900ms 면 95 관성이 멎는다» 는 **관성의 수명을 잰 값이 아니었다.**
95 의 `dsFling` 은 `Math.abs(sp) < DS_VMIN(0.02)` **또는 `!moved`** 에서 멎는데,
107 당시 격자 여지는 **455px** 이라 드래그(≈310px) + 관성이 **바닥에 먼저 닿아** `moved === false` 로
**351~404ms 에 끊겼다.** 900ms 는 그 위에 얹힌 두 배 반짜리 여유였을 뿐이다.

193 이 스킬을 24 → **27종**(공격 8종 신설 · 버프 5종 폐기)으로 바꿔 격자 여지가 **455 → 675px** 이 되자
관성이 **바닥에 안 닿고 제 수명(≈0.92~0.98s)을 다 살았다.** 그래서 900ms 표본이 «아직 미끄러지는 중» 이 되고,
3초 뒤 표본과 **2~3px** 차이가 나 FAIL 했다.

`tools/probe236.js`(신설, 읽기 전용)로 손 뗀 뒤 4.2초를 rAF 마다 훑은 궤적:

```
t=  0  312  glide     t=612  476  glide     t=903  491  glide
t=294  432  glide     t=778  486  glide     t=950  493  glide   ← 관성 마지막 프레임
… 이후 4185ms 까지 493 고정 · 재렌더 변이 0건 · 궤적 단조 증가(되돌아간 프레임 0)
```

**주인이 보고한 증상(«아래로 끌었는데 자꾸 위로 올라간다»)은 일어나지 않는다** —
값이 뒤로 간 프레임이 0이고, 그 3초 동안 본문 재생성도 0건이다. 107 의 수정은 멀쩡히 살아 있다.

### 간헐 FAIL 인 이유

관성 종료(≈0.92~0.98s)가 표본 지점(0.90s)을 **아슬아슬하게 지나간다.** 프레임 타이밍에 따라
900ms 시점이 관성의 마지막 한두 프레임 앞이냐 뒤냐가 갈려 **같은 트리에서 RED 와 GREEN 이 둘 다 나온다**
(첫 실행 RED 473→476 · 같은 트리 재실행 GREEN 477→477). 등재문의 «게이트/제품 미확인» 은 이 흔들림 때문이다.

## 3. 처방 — 대기 시간을 **다시 고르지 않았다**

**상수를 고르는 자리를 없앴다.**

`tools/verify107.js` [I] 를 **1항 → 4항**으로 (게이트 전체 12항 → **15항**):

| 항 | 묻는 것 | 옛 형태와의 관계 |
|---|---|---|
| **ⓐ** | 95 관성이 **유한 시간에** 멎는다 (멎은 시각을 제품에게 묻는다) | **옛 900ms 상수를 대신하는 자리** |
| **ⓑ** | 드래그가 먹혔다(0px 면 95 회귀) | 옛 `dragged <= 0` 분기 그대로 |
| **ⓒ** | 멎은 뒤 3초 동안 **한 프레임도** 안 움직인다 | 옛 물음 그대로 · 두 점 → **전 프레임** |
| **ⓓ** | 손 뗀 뒤 **위로 되돌아간 프레임 0** | **신설** — 주인이 보고한 문장 그대로 |

- 대기 상수는 사라지지 않고 **`I_WATCH`(감시창 4200ms) 하나**로 남는다. 다만 이 값은 **판정에 안 쓰인다** —
  창이 모자라면 ⓐ 가 «관성이 안 멎었다» 로 **빨개져 늘리라고 말한다**(조용한 오판이 아니다).

- 궤적은 rAF 마다 `[t, scrollTop, dsGlide 살아있음]` 으로 뜬다. `dsGlide` 를 읽는 것이
  «관성이 멎었나» 를 **제품의 상태로** 묻는 유일한 길이다.

**`index.html` 은 한 줄도 안 고쳤다.** 저장 구조 미변경.
