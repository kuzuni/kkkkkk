## 2. B1·B3·C2 — 111 → 150 표기 전환 (212 가 세운 관례 그대로)

150(주인 지시 2026-08-27)이 표기층을 갈랐다 — `fmtG` = **골드 전용** 알파벳 단위(구 `fmt`),
`fmt` = **기본** 숫자 그대로. 다이아는 골드가 아니므로 `fmt` 가 맞다(index.html:13011~13040 규약 주석).
게이트의 `LAB` 은 111 시절 리터럴 `['×5.00A','×35.0A','×75.0A','×450A','×1.00B']` 로 굳어 있었다.

**기대값을 화면이 쓴 식으로 만들지 않았다** (LESSONS **212-①**). 화면은
`q: '×' + fmt(p.dia)`(index.html:20719) 인데, 게이트가 페이지의 `fmt` 를 다시 부르면
**화면이 방금 실행한 식을 한 번 더 실행해 자기 자신과 비교**하는 항등식이 된다 — 표기층이 망가져도
기대값이 같이 틀려 초록으로 샌다. 게이트가 **자기 상수 `DIA` 에서 직접** 쉼표를 찍는다:

```js
const comma = n => String(n).replace(/\B(?=(\d{3})+(?!\d))/g, ',');
const LAB = DIA.map(d => '×' + comma(d));
const LAB111 = ['×5.00A', '×35.0A', '×75.0A', '×450A', '×1.00B'];  /* 되돌림 감지용 */
```

**«잴 수 있는 크기인가» 를 같이 못 박았다** (LESSONS **212-②**). `fmt` 와 `fmtG` 는 1000 미만에서
같은 문자열을 낸다 — 상품 값이 작아지면 «골드 규약으로 되돌아간 회귀» 가 빨간 게 아니라 초록으로
지나간다. 신설 **B1-1** 이 다섯 값 전부에서 `fmtG(dia) !== fmt(dia)` 를 확인하고, **B1-2** 가
옛 111 문자열로의 복귀를 직접 잡는다.
