## 2. 처방 — 제품 3자리

1. **`fxbPressVals()`** — 누름의 두 값(`.94`·`8px`)을 손으로 안 적는다. `.jz-dn` 을 단 빈 노드를 하나
   붙였다 떼며 **그 클래스를 실제로 읽는다**(한 번만 · 캐시). CSS 변수로 올리는 길은 **가 봤다가 되돌렸다** —
   `verify579` [1-b]·`verify621` [A10] 이 그 **문자열**을 «어휘» 로 단언하고 있어 값이 같아도 빨개진다.
2. **`fxbPressPair(el, r)`** — 그려진 상자 하나에서 «쉬는» 과 «눌린» 을 같이 낸다.
   버스트는 눌림의 **어느 위상에서나** 터지므로(첫 발은 트랜지션 .06s 전 = 쉬는 자세, 홀드 둘째 틱부터는
   다 앉아 있다 — 실측 6틱 `310×106 · 291.4×99.64 · 309.71×105.9 …`), «지금 얼마나 눌렸나»
   `sNow = 그려진 폭 ÷ offsetWidth(배치 폭)` 를 읽어 양쪽 끝을 복원한다:
   `k = (1−sNow)/(1−s)` · 쉬는 = 지금을 `1/sNow` 로 되돌린 것 · 눌린 = 남은 몫(`s/sNow` · `dy(1−k)`)만큼 더 누른 것.
   위상 0 이면 종전 식과 같고, 다 앉았으면 «눌린 = 지금 그려진 상자» 다.
3. **`fxbHoldBox(el, r)` = 쉬는 ∩ 눌린** — `fxBurst` 의 가둠 네 변(`inM`·`bx0`·`bx1`·`by0`·`by1`)만 이 상자를 읽는다.

**안 바뀐 것(의도)**: 탄생 타원(`rx`·`ry` = 반축 + `FXB_M`) · 알 크기(`fitK`) · 발원(`fxPt`) ·
**838 12회차의 밑각 배분(`ADIS` 대표 상자)** · 점(좌표) 대상 전부 · 안 눌리는 호스트 전부.

## 3. 함정 둘 — 둘 다 자가 잡았다

**⚠ ① 쉬는 상자를 «벗겨서» 뽑으면 버튼이 홀드 내내 눌렸다 풀린다.**
1회차 첫 시안은 `r` 을 567 `jzRestRect`(스타일을 박았다 되돌리는 손)로 뽑았다. 그러면 버스트마다
`scale` 인라인이 붙었다 떨어지며 **트랜지션이 다시 시작**한다 — `verify621` [R1] 무력화 사본이
`restPct 0.68 / 0.63 / 0.60`(문턱 0.05)으로 즉시 빨개졌다(`jzPressTick` 을 껐는데도 왕복이 남았다).
⇒ 제품은 **읽기만** 한다. `offsetWidth` 는 변환이 안 들어간 **배치** 폭이라 같은 답을 공짜로 준다.
게이트 [A8] 이 그 자리를 지킨다.

**⚠ ② 되돌림 사본이 «절반만 수리 전» 이면 부호가 안 뒤집힌다.**
첫 사본은 가둠 네 변만 되돌렸는데 `ADIS`(밑각 배분)가 **같은 상자를 한 번 더** 쓰고 있어
사본이 −5.05px 로 나왔다(진짜 수리 전 +0.07px). 결국 `ADIS` 를 **원래대로 되돌리는 것**이 답이었다(아래 §4).
