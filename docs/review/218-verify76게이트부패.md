## 4. 처방 — 지우지 말고 이사시켰다 (LESSONS 185-④)

| 자리 | `$('modal').classList.contains('on')` + `$('mtitle')+$('mbox')` | `#fxl .fx-toast` 의 `textContent` |
| 기대 문구 | 리터럴 `/목걸이/` | **런타임 계산** `BANNERS.amulet.n` (185-①) |
| 횟수·획득 수 | 리터럴 `'2,1,0,0'` · `20` | **런타임 계산** `SHOP_FREE` · `SHOP_FREE × [data-shn]` (185-①) |
| 타이밍 | 한 `evaluate` 안에서 즉시 | 클릭과 판정을 갈라 **300ms 대기** (185-⑥) |
