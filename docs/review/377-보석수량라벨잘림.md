## 2. 처방 — 등재문의 셋 중 ⓒ, 단 «한 칸» 이 아니라 «네 칸 같은 값»

| 후보 | 판정 |
|---|---|
| ⓐ 우측 앵커 `right:14` 를 이 칸만 넓히기 | **버림** — ref 는 `×N` 을 5칸 전부 **dx171 좌측 정렬**로 못 박는다(측정표 §5-2 6행) |
| ⓑ 외곽선 8 → 6 | **버림** — ref 실측 «검정 4px → CSS 8px» 이고 126 서체 규약과 충돌 |
| ⓒ 자릿수를 받아 글자를 줄이기 | **채택** (등재문 권장) — 단 **한 칸만 줄이면 안 된다** |

**왜 네 칸 다인가.** a1 만 ref 폭으로 내리면 그 칸의 글자만 이웃보다 **19% 좁아진다**(글자당 22.4 vs 27.7px).
레퍼런스는 두 문자열을 **같은 크기**로 쓴다 — 측정표 §5-3 의 fs(라틴)이 ×100·×50 **둘 다 42.9** 다.
즉 «자릿수에 따라 글자를 줄인다» 를 칸별 보정으로 읽으면 **레퍼런스에 없는 불일치**를 새로 만든다.

**값은 지어내지 않았다 — ref 잉크 폭에서 역산했다** (파일이 이미 쓰는 규약: «fs/sx 는 레퍼런스 잉크에서 역산»).

```
×50  : 1.24 × 81   / 93  = 1.080
×100 : 1.24 × 97.5 / 115 = 1.051
        ⇒ 둘을 함께 담는 하나의 값 **qx 1.08**
```

## 4. 다음 세션이 볼 것

1. **잉크가 넘치는 결함은 `overflow`·`scrollWidth`·`rect` 셋 다 «정상» 이라고 답한다.**
   외곽선(`-webkit-text-stroke`)은 advance 상자 밖에 그려지고, 상자를 자르는 자는 그것을 안 센다.
   → 계산 스타일을 그대로 복사한 **사본을 단색 판 위에 띄워 찍고 잉크 bbox 를 재라**(probe377 ⓑ).
2. **`overflow:hidden` 으로 잘린 부분은 캡처 차분으로 안 보일 수 있다.** 여기서 넘친 것은 검정 외곽선이고
   그 자리는 카드의 검정 테(`.fr` border 7px)라 **검정 위의 검정**이다. 사람이 보는 신호는
   «흰 채움이 테 위로 올라탔는가» 였다 — 차분이 0 이라고 «안 잘린다» 로 읽지 마라.
3. **캡처 차분을 쓰려면 의사요소까지 얼려라.** 요소 인라인 `animation:none` 은 122 상시 연출의
   `::before/::after` 를 못 멈춰, 1회차에 카드 한복판(x282..373)이 통째로 «달라진 픽셀» 로 나왔다.
4. **옛 커밋 사본은 저장소 폴더 안에서 열어라.** /tmp 에 두면 웹폰트가 안 붙어 **같은 커밋이 다른 수를 낸다**(+1 → +3).
