# 893 — 89 유물 소환 «계단 최소 1단 84» 가 사라졌다 (T1 «버그(약속 소실)»)

> 1회차 · 2026-09-04 · `sess-2113-24378` 루틴 워커 A · **제품 로직 0줄**(주석 2곳) · 자 3파일 + 신설 1

## 결론 먼저

**등재문의 가설은 기각됐다. 그리고 그 자리에서 «진짜 사라진 것» 이 나왔다 — 결정이 아니라 그 결정을 지키는 자다.**

| | 등재문이 말한 것 | 재현이 답한 것 |
|---|---|---|
| 하한 | «주석 219 ↔ 코드 174 가 **45px 조용히 갈라졌다**» | 219 → **231**(14회차) → **174**(16회차)로 **두 번, 이유를 적고** 갱신됐다 |
| 1600 의 0단 | «13회차가 못박은 약속이 소실됐다» | **16회차가 비평 AJ·AK 의 처방으로 확정한 설계**다(11회차 AC 의 «찌그러진 단을 만드느니 안 그린다») |
| 재원 | «니치 제로섬에 걸린다»(813 §49, 산문) | **실측으로 검산됐다** — 1단을 되살리면 두 게이트가 **동시에** 깨진다([R2]) |
| 진짜 결손 | — | **`verify120` ③ 이 «억제» 를 이유도 안 묻고 통과시킨다** — 계단이 다섯 프레임 전부에서 사라져도 초록이다([R1]) |

등재문 스스로 판정 기준을 적어 뒀다 — «**내린 이유가 있으면 주석이 틀린 것이고, 없으면 약속이 조용히
사라진 것이다**». 이유가 있었으므로 **주석이 틀린 쪽**이고, 제품 로직은 한 줄도 안 건드렸다.

## §1 착수 재현 — 등재문 수치는 그대로 재현된다(338 규칙)

`node tools/probe813.js` (수리 전 트리):

```
(관측) 계단(.rw-steps) 높이 — 1600 = 0 · 1841~2600 = 82.7
```

즉 «1600 에서 계단이 0단» 은 **사실**이다. 갈리는 것은 그 사실의 **뜻**이다.

## §2 `git log -S` — 174 를 넣은 커밋과 그 이유

```
$ git log --oneline -S'174px * var(--rwc,1)) / 2' -- index.html
226b32de wip(120): 16회차 — 2인 이상 공통 4건 수정 + r17 캡처. AJ 3/3 · AK 4/4.
```

⚠ **이 저장소의 클론은 얕다**(착수 시점 51커밋). `git fetch --unshallow` 없이는 이 한 줄이 안 나오고,
그러면 «찾아봤는데 없다 ⇒ 조용히 사라졌다» 라는 **정확히 반대의 결론**이 나온다(지시서 [-2] «얕은 클론 주의»).

하한의 사슬은 셋이고 **전부 제품 주석에 근거가 적혀 있다**:

| 회차 | 하한 | 왜 |
|---|---|---|
| 13회차 | **219** = 94 아님(82) + 137 | 위 «8 + 상인방 66 + 8» · 아래 «받침 40 + 띠 13 + **계단 1단 84**» |
| 14회차 | **231** | 위쪽 8px 이 금테 안쪽 테두리(inset 2 + 두께 5)를 못 피한다 — AG ③ ⇒ 82 → 94 |
| **16회차** | **174** | 아래에서 **계단 1단 84 를 빼고 바닥 27**(= 40 + 13 + 27 = 80). **비평 AJ·AK 가 각자 독립으로** «1600 은 계단을 지우고 바닥만» 을 처방했다 |
| 18회차 [M] | (식) | 구간을 «피치 84 의 정수배» 로 잘라 «찌그러진 단» 을 구조적으로 없앴다 — 16회차의 60px 문턱을 흡수 |

⇒ 893 이 «45px 이 갈라졌다» 로 읽은 것은 **13회차 블록 한 개만 읽었기 때문**이다. 바로 아래 두 블록이
그 219 를 차례로 고쳐 적고 있었다. 이 오독에 회차 하나가 들었으므로 **13회차 주석 자리에 사슬을 적어 뒀다**
(이 작업의 제품 변경 ①).

## §3 ★ 진짜 결손 — 결정은 코드에 남았는데 **자가 그 결정을 안 지킨다**

`tools/verify120.js` ③ (18회차 [M] 이 세운 항):

```js
const stSup = r.steps.h < 0.6;
ck(`[${H}] ③ 계단 구간 = 84 정수배 · 접합선 +14 아래 · 잔여 < 84`,
  stSup ? Math.abs(r.steps.b - r.mid.t) < 1.0
        : (...));
```

`stSup` 분기는 **«구간이 0 이다» 하나만 보고 통과**한다 — 억제가 «재원이 없어서» 인지
«누가 계단을 죽여서» 인지 **구분하지 않는다**. 그래서:

> **다섯 프레임 전부에서 계단이 통째로 사라져도 `verify120` 은 초록이다.**

`verify893` [R1] 이 그 사본을 실제로 굴려 찍는다(2280 에서 `--rw-gs:var(--rw-sh)` 로 계단을 죽인다):

```
[R1] 계단 0.0 · 보이는 단 0 · 재원 R 103.7 (≥ 피치 84.0 이므로 1단이어야 한다)
     · 이 자 빨강 · 120 술어 초록
```

⚑ **이것이 «약속 소실» 의 정확한 자리다.** 등재문의 방향(제품)은 틀렸지만 **냄새는 맞았다** —
LESSONS 122 «자를 안 댄 곳은 자동으로 무결점» 계열이고, 328 이 «누른 항을 묻는 항으로 갈아 끼워라» 로
정리한 것과 같은 병이다(«329 가 통째로 사라져도 초록인 게이트»).

## §4 재원은 정말 없는가 — 산문을 실측으로 바꿨다 ([R2])

813 §49 는 «재원이 니치 제로섬(879 §17)에 걸려 813 이 못 낸다» 고 **산문으로** 넘겼다.
`verify893` [R2] 는 그 문장을 **기계가 검산하는 사실**로 바꾼다 — 예약 174 → **258**(= 94 + 80 + 84)로
1600 에 계단 1단을 실제로 되살린 사본을 굴린다:

|---|---|---|---|---|
| 계단 | 0단 | **1단** | — | 지시대로 돌아온다 |
| `--rw-av` | 136.0 | **94.0** | — | −42 |
| 격자 하변 ↔ 배수 바 상변 | 39.0 | **−3.0** | 8 (`probe813` [C]) | ❌ **바가 격자를 파고든다** |

**둘이 동시에 깨진다.** 813 8회차 [H2 기각]이 «1600 의 세 요구는 서로의 재원이다» 로 적어 둔 그 자리이고,

## §6 곁다리 관측 — 등재하지 않았다

**859 의 그릇 캡 이후 «계단» 은 어느 프레임에서도 1단뿐이다**(1841~2600 재원 R = 103.7 ⇒ 1단 + 민 바닥 19.7).
12회차가 «아래에서 위로 5단», 14회차가 8단으로 설계했고 18회차 실측이 «1920 1단 · 2280 4단 · 2600 7단»
이었는데, 859 가 그릇을 ref 비례 1527 로 캡하면서 **네 긴 프레임이 픽셀 동일**해져 전부 1단이 됐다.
`.rw-st1`~`.rw-st8` 여덟 칸 중 일곱은 어느 프레임에서도 안 보인다.

⚠ **이것은 결함이 아닐 수 있다** — 859 의 캡은 레퍼런스 비례를 맞추는 주인 축이고, 8회차·9회차 채점자
넷이 «≥1841 은 상단 구역·아치 거의 정확»(813 §51-3)이라고 적었다. **지금 이것을 등재하면 «손대지 마라»
고 못박힌 자리를 다시 여는 것**이라 등재 대신 여기 관측으로만 남긴다. 891(상단 띠 분할)이 닫히고
10회차 재채점에서 채점자가 이 자리를 짚으면 그때가 등재 시점이다.

## §9 교훈

1. **«주석과 코드가 갈라졌다» 는 주장은 주석을 **끝까지** 읽고 하라.** 이 저장소의 주석은 회차 로그라
   바로 아래 블록이 위 블록을 고쳐 적는다. 한 블록만 읽으면 «갈라짐» 이 항상 보인다.
2. **얕은 클론에서 `git log -S` 가 비면 «없다» 가 아니라 «못 봤다» 다.** 이 작업은 `--unshallow`
   (51 → 6,220커밋) 뒤에야 답을 얻었다. 지시서 [-2] 의 경고가 게이트뿐 아니라 **판정에도** 걸린다.
3. **«이유를 안 묻는 예외 분기» 는 게이트에 뚫린 구멍이다.** `stSup` 처럼 «X 면 통과» 로 쓴 분기는
   X 를 만든 원인을 같이 묻지 않으면, X 를 만드는 **다른 방법**을 전부 초록으로 통과시킨다(328 계열).
4. **«재원이 없다» 는 산문이 아니라 되돌림 시험으로 적어라.** [R2] 는 여덟 줄이고, 이 자리에서
   세 회차(8·9·893)가 되풀이한 «못 낸다» 를 다음 워커가 다시 재보지 않아도 되게 만든다.
