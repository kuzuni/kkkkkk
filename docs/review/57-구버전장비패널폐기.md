## 4. 남기는 것 / 다음 세션에 넘기는 것

1. **`#herosub`(⚔️장비·📜스킬·🐾동료 구버전 서브탭 3칸)는 이제 어떤 경로로도 안 보인다.**
   스킬·동료는 CSS `#panel:has(:is(#bSk,#bPet).on) #herosub{display:none!important}` 가 이미 가리고 있었고,
   장비는 이번에 패널 자체가 접혔다. DOM·클릭 핸들러는 **남겨 뒀다**(다른 작업 구간이라 손대지 않음).
   50(코스튬)이 서브탭 3곳을 손볼 때 같이 지우는 것이 맞다.
2. `S.eqTab` 은 읽는 코드가 없어졌지만 세이브 필드로 남아 있다(하위 호환·`KEY` 유지 목적).
3. 회귀 스크립트 2개를 루트에 남긴다 — **장비 경로를 다시 손대는 세션은 전/후로 돌릴 것**:
   `node repro57.js`(구버전 노출 0 + 05↔06 전환) · `node geom57.js`(HEAD 대비 좌표 회귀).
4. **환경 메모**: 이 컨테이너에는 chromium **1194** 만 깔려 있어 최신 playwright(1.62 → chromium 1234)가 실행되지 않고
   `npx playwright install chromium` 은 다운로드가 막혀 실패한다. **`npm i --no-save playwright@1.56.0`** 이면 1194 와 맞아 바로 돌아간다.

## 5. 교훈 (다른 화면에서도 재발한다)

1. **«추가 리스너만 붙이고 기존 핸들러는 건드리지 않는다»가 버그의 씨앗이다.**
   05 진입점을 06 에 붙일 때(LESSONS 05 비고) 기존 06 핸들러를 남겨 둔 것이 그대로 이 버그가 됐다 —
   같은 요소에 **의미가 상충하는 리스너 2개**가 붙으면 «둘 다 실행»된다. 신규 화면이 구버전을 대체하면
   **구버전 경로는 그때 지워야 한다**(살려 두면 무해한 게 아니라, 새 화면을 내리는 코드로 남는다).
2. **«안 보이니까 없는 것» 이 아니다.** 구버전 패널은 장비 화면에서 계속 `1080×759` 로 렌더되고 있었고
   06 시트가 덮고 있었을 뿐이다. 폐기 작업은 «가려졌나» 가 아니라 **`getBoundingClientRect` + computed style 로
   실제 렌더 여부**를 재야 한다(25 교훈 2 «가림을 걷으면 드러나는 버그» 의 반대 방향 사례).
3. **본문을 지우면 그 본문을 담던 컨테이너도 같이 접어라.** `#bEq` 만 지우고 `#panel` 을 그대로 두면
   배경색만 남은 빈 패널(844px)이 새 시트 뒤에 남는다. `TABBODY`/`HEROBODY` 처럼 **id 를 문자열로 매핑한 표**는
   DOM 을 지울 때 같이 고치지 않으면 `$(...)` 가 null 이 되어 즉시 터진다 — 둘은 항상 한 커밋에서 움직인다.
