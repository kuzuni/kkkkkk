### 처방 ① 제품 — 색상에 기대지 않는 «알파 후광»

색을 접어 버리는 것이 원인이므로, 색이 아니라 **알파(윤곽)** 로 대비를 만든다.

```css
.sk-card.lk>.sk-ci{opacity:.35;
  filter:grayscale(1) drop-shadow(0 0 2px #000) drop-shadow(0 0 2px #fff) drop-shadow(0 0 2px #fff)}
```

- 검정 한 겹이 **밝은 면색**(예 `lance` 카드 `rgb(176,35,56)`)을, 흰색 두 겹이 **어두운 면색**
  (예 `frost` 카드 `rgb(102,22,145)`)을 받는다 — 면색이 무엇이든 한쪽은 반드시 대비된다.
- `drop-shadow` 는 잉크를 **한 픽셀도 옮기지 않는다** → 아트 자리 규칙(bbox) 위반이 없다.
- `text-shadow` 가 아니라 `filter` 인 이유: 174 이후 펫·50 코스튬 아이콘은 글자가 아니라 `<canvas>` 다.
- `opacity .35` 와 `grayscale(1)` 은 **그대로 남는다** — §2(주인 승인 스타일)는 손대지 않았다.
- 같은 기법이 이미 저장소 안에 있다(`index.html:1065`·`1356` 의 잠금/실루엣 처리) — 새 관용구가 아니다.
