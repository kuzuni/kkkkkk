## 3. 진짜 위험은 «지운 칸» 이 아니라 «남은 칸» 이었다

`#botleft` 는 **bottom 앵커 flex 컬럼**이다:

```
#botleft{position:absolute; left:17; bottom:170; display:flex; flex-direction:column; gap:21}
  └ 채팅 100  ┐
  └ (gap 21)  ├ 컬럼 높이 279 — 바닥에 앉는 것은 «마을»
  └ 마을 158  ┘
```

`bottom:170` 은 **마을 라벨 외곽선 하단(ref 1990)** 기준값이었다. 마을을 빼면 컬럼이 100 으로 줄고
**바닥에 앉는 것이 채팅으로 바뀌므로**, 앵커를 그대로 두면 채팅이 **179px 아래로 내려앉는다**
(되돌림 시험에서 실측: 채팅 하단 348 → **388**, 즉 남겨 두면 40px 어긋난 채로 굳었을 값).

측정표 §3 의 «채팅 하단 ref 1812» 를 그대로 쓴다 → **`bottom: 2160 − 1812 = 348`**.
`gap:21` 은 형제가 없어 무의미하므로 같이 뺐다.

실측(1080×2280 헤드리스, `#app` 스케일 되돌림):

| 항목 | 목표(측정표 §3) | 실측 | Δ |
|---|---|---|---|
| 채팅 w × h | 100 × 100 | **100.0 × 100.0** | 0 |
| 채팅 중심 x | 85 | **84.5** | −0.5 (변경 전과 동일 — 189 가 만든 값 아님) |
| 채팅 하단 (stagearea 바닥 기준) | 348 | **348.0** | 0 |
| `#botleft` 좌단 | 17 | **17.0** | 0 |
| `#tuto` left / w / 하단 | 620 / 460 / 171 | **620.0 / 460.0 / 171.0** | 0 (이웃 무회귀) |

프레임 좌표로는 채팅 y **1652..1752** — ref 1712..1812 대비 **−60**,
즉 UI-REFERENCE 가 못박은 «탭바 위 고정 요소 = `ref y − 60`» 과 정확히 일치한다
(`#tuto` 도 1779 vs ref 1839 = −60). 변경 전 값은 1651..1751 이었으므로 **실이동은 1px**이고,
그 1px 이 측정표 쪽으로 붙은 것이다.
