## §7 교훈 (LESSONS 480)

1. **«색 이모지처럼 생겼다» 는 것은 색 이모지라는 뜻이 아니다.** ▶·★·◆ 같은 기하 문자는 VS16 없이
   쓰면 **텍스트 글리프**라 `color` 를 물려받는다 — 옆 칸의 🎟·⏳ 가 멀쩡한 것이 오히려 진단을 가린다.
   이모지를 아트 자리에 앉힐 때는 **«이 글리프가 제 색을 갖고 오는가» 를 한 번 물을 것.**
2. **잉크를 셀 때 «가장 흔한 색 = 배경» 은 남의 픽셀이 겹치는 순간 거짓말이 된다.** 대상만 숨긴
   한 장을 더 찍어 **차이**로 세면 겹침이 구조적으로 빠진다(350 의 «찍힌 픽셀» + 한 겹).
3. **외곽선 보정(380)은 «ref 잉크» 가 목표일 때만 쓴다.** 우리 잉크가 ref 보다 이미 작으면
   fs 를 되내리는 것은 ref 에서 멀어지는 쪽이다 — 손을 쓰기 전에 **어느 쪽이 목표인지** 적을 것.
4. **가독성 결함의 게이트는 «색을 무엇으로 적었나» 가 아니라 «찍힌 픽셀의 대비» 다.** 선언만 세면
   «흰 글자에 흰 외곽» 이 통과한다 — [B4]·[B5](테 비중·코어 비중)가 그 구멍을 막는다.
