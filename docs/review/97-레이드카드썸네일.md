### 2-1. 슬롯 기하 — «재는» 게 아니라 «인용» 이다

레이드 탭에는 레퍼런스가 없다. 46 의 전제(«껍데기·카드 규격은 03 던전 것 그대로»)를 따라
§3-8 던전 값을 그대로 옮겨 쓴다. 카드별 **고정값**이며 잠금 여부로 바뀌지 않는다 —
r30·r120 은 스테이지 15·30 에서 해금되는데, 그 순간 슬롯이 리사이즈되면 칸이 흔들린다.

### 2-2. 아트 — 이모지가 아니라 «실제로 소환되는 보스»

주인 지시 ②(«이모지 대신 가능하면 기존 스프라이트 프레임 1장»)를 따랐다.
세 측정장이 소환하는 샌드백은 전부 `ETYPE.boss` = **elves 파랑 «군주»** 하나다
(`startRaid()` → `makeEnemy('boss')`). **없는 몬스터를 그리지 않기 위해** 셋 다 같은 프레임을 쓰고,
칸 구분은 **카드 팔레트 틴트**로만 한다(MOBS 가 같은 스프라이트를 `tint` 로 변주하는 것과 같은 방식).

프레임 선택은 눈대중이 아니라 실측이다 — LESSONS 72-②(«아트 자리 종횡비에 맞는 글리프를 먼저 재고 고른다»)를
스프라이트에 적용해 `tools/probe97.js` 로 후보 13종의 **알파 잉크 bbox** 를 쟀다:

### 2-3. `drawSpriteTo` 가 `drawHeroTo` 와 다른 점

`drawHeroTo` 는 앵커가 **발밑**(전투 씬과 같은 기준)이라 `fr[4..7]`(논리 프레임 오프셋·크기)을 쓴다.
그 값을 그대로 쓰면 elves 프레임은 논리 폭 235 에 잉크 107 이라 **잉크가 상자 왼쪽 끝으로 밀려**
슬롯의 절반이 빈다. 여기 쓰임새는 «씬에 세우기» 가 아니라 «아트 자리 채우기» 이므로
**잉크 rect(`fr[0..3]`)를 슬롯 캔버스에 그대로 늘려** 넣는다 — 나중에 일러스트로 교체하면 자리가 그대로 맞는다.
틴트는 87 의 `lite` 경로(그린 자리에서 multiply → destination-in)라 `tintCache`(아틀라스 통째 사본)를
늘리지 않으면서 색은 전투의 `tinted()` 와 픽셀 단위로 같다.

### 4-1. 곁가지로 고친 것 — `verify72.js` 가 main 에서 죽어 있었다

이 작업 전에 `node tools/verify72.js` 는 **한 줄도 못 돌았다**. 두 가지가 겹쳐 있었다.

1. **런처** — `require('playwright')` + `chromium.launch()` 를 직접 부르고 있어, 번들 브라우저가 없고
   미리 깔린 `/opt/pw-browsers`(빌드 번호 불일치)만 있는 클라우드 러너에서 즉사했다.
   → 110 이 만든 공용 `tools/pwlaunch.js` 로 교체. 캔버스 잉크를 읽어야 해서
   `--allow-file-access-from-files` 도 준다(`file://` 이미지는 캔버스를 오염시켜 `getImageData` 가 막힌다).
2. **기대치** — 작업 90 이 던전을 5장 → **6장**(골드·다이아·유물조각 4단)으로 재편했는데
   `EXP` 배열이 5장에 멈춰 있어 `EXP[5] undefined` 로 크래시했다(90 은 `verify90` 만 돌렸다).
   → 카드 수만 6 으로 올렸다. 기하는 relic 3종과 같은 330×330/11 이라 값 자체는 변경 없음.

**교훈: 구성(데이터) 변경이 그 화면의 «옛 게이트» 를 앞지르면, 다음 사람은 게이트가 죽은 줄도 모른다.**
화면 구성을 바꾸는 작업은 자기 게이트(verify90)만 돌리지 말고 **그 화면을 보는 다른 게이트도 한 번 돌려야** 한다.

## 5. 하지 않은 것 (의도적)

- **던전 카드 5(6)장의 이모지 → 스프라이트 교체.** 주인 지시 ②에 «선택» 으로 적힌 항목이다.
  던전 카드는 레퍼런스가 있는 화면이고 72 가 «보류(아트 대기)» 로 7회차까지 돌려 놓은 상태라,
  대체물을 바꾸면 72 의 점수 기준(이모지 bbox·`--tsx`)이 통째로 흔들린다. 72 의 상태를 유지한다.
- **레이드 보스를 측정장마다 다르게 만들기.** 지금 셋 다 같은 보스를 소환하는 게 사실이라
  그림만 다르게 하면 화면이 거짓말을 한다. 아트 발주서(부록 D-2)에 선택지 ①②로 남겼다.
