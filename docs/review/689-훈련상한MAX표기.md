### ⚑ 이 작업의 성격이 재현 한 줄로 바뀌었다

등재문은 이것을 «표기 교체» 로 적었지만, 실제로는 **한 카드 안에서 갈려 있던 표기의 통일**이다.
486(2026-08-30)이 알약을 «MAX» 로 바꿀 때 **바로 옆 칸인 비용 줄은 «상한» 으로 두었고**,
그때부터 상한 카드는 한 장 안에서 두 가지 말을 하고 있었다:

```
 [ MAX ]      ← .cv i  (486 이 바꿈)
 💰 상한       ← .cb i  (그대로 남음)
```

주인이 본 것이 바로 이 어긋남이다. 그래서 게이트도 «MAX 라고 쓰는가» 가 아니라
**«알약과 버튼이 같은 말을 하는가»**([D3])를 본체 항으로 세웠다 — 한쪽만 되돌아가도 빨개진다.

## 3. 380(라틴 폴백) 걱정은 여기서 구조적으로 없다

등재문의 ⚠ 는 «GameKR 서브셋에 라틴이 빠져 폴백 서체로 렌더될 수 있다» 였다. 둘 다 사실이 아니다:

1. **서브셋이 ASCII 를 포함한다.** `index.html` 서두 `@font-face` 주석:
   «서브셋 = ASCII + KS X 1001 한글 2,350자 + UI 기호». 실렌더 서체도 `GameKR` 로 찍힌다.
2. **폭 예산의 주인은 비용 문자열이지 «MAX» 가 아니다.** 같은 밴드에서 실측(`probe689` [D]):

| 문자열 | 잉크 폭 | 밴드 안쪽 299px 대비 |
|---|---|---|
| «상한» (수리 전) | 78.11px | 여유 220.9 |
| **«MAX» (수리 후)** | **92.83px** | **여유 206.2** |
| «1.23K» (흔한 비용) | 106.50px | 여유 192.5 |
| «999.99AA» (최장 비용) | **208.98px** | 여유 90.0 |

«MAX» 는 **평소에 늘 지나가는 비용 문자열보다도 좁다.** 잘림이 나려면 최장 비용 문자열이
먼저 잘려야 하는데 그쪽이 90px 여유로 통과한다 ⇒ **보정할 것이 없다.**

3. **코인이 밀리는 축도 예산 안이다.** 비용 줄은 `<s>💰</s><i>글자</i>` 가 가운데 정렬로 놓인
   flex 라 글자가 길어지면 코인이 왼쪽으로 밀린다. «상한»→«MAX» 의 이동은 **−7.36px** 이고,
   이는 «1.23K» 하나만 떠도 생기는 이동(−14.19px)의 절반이다. 상시 일어나던 폭 안이다.
   (`.cv i` 가 486 에서 같은 걱정을 안 겪은 이유도 여기 있다 — 그쪽은 홀로 놓인
    `text-align:center` 라 형제를 밀 일이 없다. 이 자리는 **flex 형제가 있어** 따로 쟀다.)

레이아웃 Δ0px 은 상수를 외우지 않고 **두 상태를 재서** 못박았다([G4]) —
상한 판과 미달 판의 밴드 상자가 `[310, 106, 43, 1767]` 로 **완전히 같다**.
