## 2. 수정 (2곳, index.html)

```js
// fit() — 스케일을 폭·높이 중 «작은 쪽» 으로
app.style.transform = 'scale(' + Math.min(AW / FRAME_W, AH / frameH) + ')';
```
```css
/* #wrap — 남는 영역(필러박스/레터박스)은 검정 */
#wrap{ ... background:#000; overflow:hidden; ... }
```

중앙 정렬은 `#wrap` 의 기존 `display:flex; align-items:center; justify-content:center` +
`#app{transform-origin:center center}` 로 **이미 성립**해 추가 변경이 없다(실측 Δx·Δy = 0.0 전 비율).

**`frameH` 계산식·`FRAME_H_MIN/MAX` clamp·`resizeCanvas()` 는 건드리지 않았다.**
`stagearea` 높이는 프레임 로컬 px 이므로 스케일 변경의 영향을 받지 않는다(같은 비율에서 pre/post 모두 동일값).
