## 2. 좌표 근거

- 칸 폭: 바 960 − 좌우 여백 6+6 = **948** → 2등분 **474**. 경계 local 480 = 바 정중앙(960/2). 실측 Δ0.00.
- 구분선: 4칸일 때의 `+8px` 은 **레퍼런스 4등분 경계 3개(538/774…)의 실측 보정**이라 2칸에는 전제가 없다.
  남는 경계가 «바 정중앙» 하나뿐이므로 폭 4 를 경계에 2·2 로 물렸다(`right:-2px`).
- 알약: **크기만 실측 유지**(253×62 · r31 · 다크캡 9)하고 위치는 `(474−253)/2 = 110.5` 로 새로 잡았다.
  옛 `left:0;right:-15px` 는 칸 240 을 전제한 값이라 칸 474 에서는 **칸을 통째로 덮는 띠**가 된다.
  45 §2 «알약은 크기만 실측 유지, 위치는 칸 중앙으로 새로» 와 같은 처리다.
- 라벨·레드닷은 **알약에 붙은 요소**라 알약과 같은 양(+110.5)만큼 움직였다. 라벨은 알약 중심 = 칸 중심이 되면서
  보정값이 0 이 됐고, 레드닷은 알약 안에서의 위치(local 210)를 그대로 보존했다.
- 라벨 `scaleX(.9)`·`font-size:43`·`-webkit-text-stroke:5` 는 **건드리지 않았다** — LESSONS 43-2:
  «지시로 카피·칸 수가 바뀐 자리에는 그 문자열의 ref 목표폭이 없다. 형제와 같은 장체감을 유지하는 쪽이 맞다.»
