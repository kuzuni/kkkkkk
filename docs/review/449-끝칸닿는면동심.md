## 2. 왜 «인셋 0» 인가 — 한 줄로

`::before` 는 이미 **세로 인셋 0 · 반경 30**(= 알약 반경)이다. 어긋난 축은 **가로 하나뿐**이었고,
그 인셋을 0 으로 두면 이 코너의 원 중심이 `(7+30)` → **`(30)` = 알약 코너 중심**으로 와서
**옛 상자가 그대로 동심이 된다.**

⇒ **등재문 후보 ⓑ 의 «비대칭 반경» 은 필요 없었다.** 반경은 한 글자도 안 건드렸다.
그리고 4회차의 판단(«끝 칸은 손대지 않는다»)은 **«새 상자를 그대로 거는 것» 에 대해서만** 옳았다 —
그 상자는 «검정의 안쪽 윤곽» 이라는 전제 위에 서 있는데 이 면엔 그 검정이 없다. 필요한 것은 상자를
**안으로** 미는 것이 아니라 **밖으로** 미는 것이었다.

```
  가운데 칸 :  윤곽 ┃ K7(링) ┃ D7 ┃ B7 …      ← ::before 사방 7 인셋 · r23
  닿는 면   :  윤곽 ┃        ┃ D7 ┃ B7 …      ← ::before 가로 0 · 세로 0 · r30  (검정만 셸로)
```
