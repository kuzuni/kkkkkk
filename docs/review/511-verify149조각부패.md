## 2. 처방

### 2-1. `callerOf()` — 주석을 빼고, 출현을 **전부** 본다

```js
function inComment(src, i){          /* 블록 주석 안 / 줄 주석 안(URL 의 «://» 제외) */
function callerAt(src, i, len){      /* 옛 판정(앞 900자에서 notify/popup 중 뒤엣것) — 그대로 */
function callerOf(frag, src){        /* 주석 출현은 건너뛰고, 남은 출현이 갈리면 «자리가 n곳» */
```

- **허용 오차는 한 칸도 안 넓혔다.** 판정식(`callerAt`)은 옛 판과 **글자 그대로 같다.**
  바뀐 것은 «그 판정식을 **어느 출현**에 대고 도느냐» 뿐이다.
- 조각에 `popup(` 을 넣어 자리를 특정하는 손쉬운 길은 **일부러 안 갔다** — 그러면 그 항은
  «어느 호출자가 이 문구를 내보내는가» 를 더는 못 묻는 헛초록이 된다.
- 남은 출현이 서로 다른 호출자를 가리키면 조용히 첫 자리를 답하지 않고
  **«자리가 n곳(notify/popup) — 조각이 자리를 하나로 못 가리킨다»** 로 빨개진다.

### 2-2. 조각 둘 — 살아 있는 문구로 (333 처방, 자리는 안 비웠다)

| | 옛 조각 | 새 조각 |
|---|---|---|
| 다이아 부족 | `if(S.dia < ex.dia){ notify(` | `if(S.dia < n){ notify(` |
| 완료 | `'</b> → ' + curIc('relic')` | `'</b> → ' + curIc(ex.k)` |

항목 이름도 «유물조각 교환» → **«재화 교환»** 으로 넓혔다 — 한 자리가 두 재화를 답하는 것이
490 의 구조다. 두 조각 다 **소스에서 1건씩만** 나온다(중복 없음).

⚠ **자리를 비우지 않았다**: 490 이 통째로 되돌아가 묶음 표가 살아나면 `ex.k`·`< n` 이 사라지므로
두 항이 곧바로 «조각을 못 찾음» 으로 빨개진다.
