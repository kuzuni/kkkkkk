## 2. 승격 — «CSS 한 벌 · 상태 한 벌 · 호스트 둘»

등재문이 «부품을 새로 짜면 반려» 라고 못박았다. 승격으로 실제로 바뀐 것은 **셋**이다.

### 2-1. 자리를 부품에서 뺐다

```
    .sm-sk{position:absolute;right:36px;bottom:28px;height:56px;z-index:3;display:flex;…}
 →  .sm-sk{height:56px;display:flex;…}                    /* 생김새 */
    #sumSkip{position:absolute;right:36px;bottom:28px;z-index:3}   /* 12 의 자리 */
    #rouSkip{width:fit-content;margin:14px 0 0 auto}               /* 16 의 자리 */
```

자리는 호스트마다 다르고(12 는 패널 안 절대배치 · 16 은 버튼 아래 흐름 배치) **부품이 아니다.**
`verify363` 6-9(«왕복 뒤 토글 자리 Δ0»)와 `verify514` 1-12·1-13 이 12 쪽 값(패널 우변 36 · 하변 28)이
한 칸도 안 움직였음을 각각 잰다.

⚠ **이름의 `sm-` 접두는 일부러 뒀다.** 299·341 선례 — 자리를 옮기면서 이름까지 바꾸면 앞 세션들이 남긴
grep 경로가 통째로 끊긴다(341 은 `.updot` 을 찾다가 `.dot` 을 못 봐 «노드가 없다» 는 오진을 했다).
부품인지 아닌지는 이름이 아니라 주석과 셀렉터가 말한다.

### 2-2. 상태도 한 벌 — `S.opt.sumSkip` → `S.opt.fxSkip`

두 벌로 쪼개지 않은 근거는 190·367 이 재고를 한 벌로 둔 것과 같다: **나누면 «어느 쪽을 껐는지» 를 사람이
기억해야 한다.** 주인이 같은 토글을 두 화면에 요구했으므로 값도 하나다.

이관은 한 줄이고 **KEY 는 안 올렸다**(취향 값이라 44 교훈 2 «없으면 기본값» 으로 흡수된다):

```js
['bgm','sfx','shake','push','night','fxSkip'].forEach(…);
if(o.fxSkip === undefined && o.sumSkip !== undefined) b.opt.fxSkip = !!o.sumSkip;
```

새 키를 **한 번이라도 만진** 세이브는 안 덮는다(`verify514` 6-10). 구 키는 `b.opt` 를 항목별로 다시 짓는
구조라 다음 `save()` 에 저절로 사라진다.

### 2-3. 곁다리로 스코프 구멍 하나를 닫았다

라벨 획 두께 규칙이 `#sumw .sm-fat` 로 갇혀 있어 **부품이 호스트를 갈아타면 라벨만 얇아진다**
(397 «스캐너가 출석 패스 탭을 한 번도 안 봤다» · 429 «`.ol1~.ol5` 가 세 시트 스코프라 «?» 만 민짜» 와 같은 계열).
규칙을 복제하지 않고 선택자를 `,.sm-sk>.sm-fat` **한 항씩** 늘렸다(429 처방).

**색만** 호스트 면에 맞춘다 — 12 는 남색 패널(#2A2835) 위라 크림 `#EADCC6`, 16 은 베이지 본문(#F0D9BA)이라

### ⚠ `showModal` 의 «꼬리 빼내기» 함정

`showModal()` 은 «끝에 붙은 BUTTON/.mrow 묶음» 을 베이지 패널(`.mwell`) **밖으로** 빼낸다. 토글 div 를
HTML 문자열 **끝**에 붙이면 그 루프가 토글에서 멈춰 **[룰렛 돌리기] 가 패널 안에 갇힌다**(다른 팝업과
어긋난 그림). 그래서 `showModal(h)` **뒤**에 `$('mbox').appendChild()` 로 붙였다.
`verify514` 1-9·1-10·1-11 이 셋을 **각각** 묻는다(«토글은 본문 직계» · «패널 안이 아니다» · «버튼도 패널 밖»).

딤 닫기 필터는 **안 건드렸다** — `#modal` 핸들러는 `e.target === #modal` 만 보므로 본문 안 노드를 누른 탭은
애초에 닫기로 안 간다(12 는 `#sumw` 전체가 닫기 영역이라 363 이 필터를 고쳐야 했던 것이고, 여기는 다르다).

## 4. 스킵 ON 의 최종 상태 — «과정만 접는다»

접는 것: 6바퀴 감속(`ROUL_MS`) · 되감기(`ROUL_OVER`/`ROUL_BACK_MS`) · 칸 경계 틱음(`rtick`).
**남기는 것**: 당첨 칸 하이라이트 · `rstop` 정지음 · «획득!» 문구 · 재화 연출 · 횟수 표시.
363 이 «스킵인데 더 센 연출이 되면 안 된다» 와 함께 못박은 반대쪽 규약이다.

원판은 **정답 칸에 멈춘 그림**으로 즉시 선다 — 애니메이션 경로의 최종 각과 **같은 식**(`land`)을 쓰므로
각도 오차가 구조적으로 0 이다(`verify514` 3-9 실측 0.00°).

⚠ **`rouSpinning` 을 한 프레임도 안 켠다.** 켰다 끄면 65 의 `rou-spin` 표식이 붙었다 떨어지며 팝업 애니가
한 프레임 죽고, 321 레드닷·367 ▶AD 도 껐다 켜는 깜빡임이 된다. 그래서 목표 각을 **UI 를 건드리기 전에** 잡도록
`roulSpinTo` 안에서 target 계산을 위로 올렸다(그 위치가 이 작업에서 옮긴 유일한 기존 줄이다).

### «켜는 즉시»(363 규약)도 지킨다

회전 **한복판**에 켜면 rAF 루프 안 `cut()` 이 그 프레임에 각을 `land` 로 스냅하고 `fin()` 을 지난다.
실측: 600ms 시점에 켰을 때 1초 안에 종료(`verify514` 5-6·5-7).

⚑ **끊는 곳을 루프 안에 둔 것이 지급 1회 보증의 근거다.** 밖에서 `roulFinish` 를 직접 부르면 아직 살아 있는
루프가 나중에 `fin()` 을 **한 번 더** 밟는다 — 181 이 `paid` 로 막는 바로 그 자리다. 루프가 **자기 발로**
끝나게 두면 «지급은 정확히 한 번» 이 구조로 유지된다.

## 6. 헛초록 방지 (338 ④)

§3 은 «빨라졌다» 를 재는 항이라 **혼자 두면 무엇이든 빠르면 통과**한다. 짝을 둘 붙였다.

1. **§2 가 같은 자를 OFF 에 댄다** — 3.9초(±400ms)와 «결과 없는 프레임 ≥60» 을 요구한다.
   스킵이 «항상 켜진» 상태가 되면 여기가 즉시 빨개진다.
2. **§R-ⓐ 가 «514 이전» 사본을 만든다** — 소스에서 `roulSpinTo` 를 떼어 **514 가 더한 세 자리만** 지운
   사본(`if(fxSkipOn()){…}` 조기 종료 · `step`/`back` 의 `if(cut())` 두 줄)을 페이지에 물리고 같은 클릭을 먹인다.
   결과 3.9초 → «빠른 이유가 스킵 분기» 임이 못박힌다. **[전제] R-0** 이 그 세 자리가 소스에 실재하는지부터 묻는다
   (398 §R 의 길 — 자리가 사라지면 되돌림 시험이 조용히 무력해진다).

⚠ **그 되돌림 시험이 실제로 한 번 조용히 죽었다.** playwright 는 첫 인자가 **문자열이면 뒤 인자를 안 넘긴다** —
사본을 문자열 표현식으로 넘겼더니 `src` 가 `undefined` 로 들어와 사본이 통째로 죽고 §R 이 «-1» 로 빨개졌다.
**사본은 함수로 넘긴다**(게이트 주석에 남겼다).

⚠ **구 세이브 이관은 «같은 페이지 + reload» 로 못 잰다** — `beforeunload → save()` 가 메모리의 `S` 로 덮어
지운 키가 되살아난다(LESSONS 363 ①). §6 은 **새 컨텍스트 + `addInitScript`** 로 구 세이브를 심고 처음부터 띄운다.

## 8. 교훈 (LESSONS 514)

1. **«부품 승격» 의 실체는 자리를 부품에서 빼는 것**이다 — 생김새는 공용, 자리는 호스트. 자리까지 부품에
   들어 있으면 두 번째 호스트는 반드시 CSS 를 한 벌 더 만들게 된다.
2. **이름은 안 바꾼다.** 승격했다고 `sm-` 접두를 떼면 앞 세션들이 남긴 grep 경로가 끊긴다(341 이 그래서 오진했다).
3. **Δ0px 가 불가능한 화면이 있다.** 그때 필요한 것은 타협이 아니라 **빈 띠 전수 실측표**다 — 표가 있으면
   «자란다» 는 결정이 취향이 아니라 산수가 된다.
4. **playwright `evaluate` 의 첫 인자가 문자열이면 두 번째 인자는 안 간다.** 되돌림 시험을 사본으로 짤 때
   여기서 죽으면 게이트가 «-1» 로 빨개지는 게 아니라 **되돌림이 무력해진 채 초록일 수도** 있다.
5. **연출을 밖에서 끝내지 마라.** 굴러가는 rAF 루프가 있으면 «끊는 조건» 을 루프 안에 두어야 지급·정리가
   한 번만 일어난다(181 `paid` 규약).
