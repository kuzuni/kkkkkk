## 1. 등재문과 재현

등재문(199 21회차 `probe199r21` 의 곁다리 관측)은 이렇게 적었다 —
«부지런 유저가 광고 버튼만 누르면 하루 오프라인 예산의 **23.4%** 를 통째로 못 받는다».

**338 규칙대로 처방 전에 재현했다**(`tools/probe650.js`). 봇(`bot199.js`)의 «부지런» 프로필
(접속 8·12.5·19·22.5시 · 활성 45분 · 광고 ×1.5)로 하루치 오프라인 수령만 떼어 4번째 수령을 세웠다.

| | 수리 전 |
|---|---|
| 실효 배수 `offPend.gain` | **1.0000** |
| 표에 실린 자리비움 | **337.5분** = 하루 예산 1,440분의 **23.44%** |
| 라벨 `#ofrGet15` | **«내일 다시»** (opacity .45) |
| 광고 버튼 누름 | 발행 분 **Δ0** · 골드 **Δ0** · 다이아 **Δ0** · 팝업 **열린 채** |
| **[받기](×1) 누름** | 발행 분 **Δ337.5** · 골드 **Δ49,572** · 다이아 **Δ25,312** · 팝업 닫힘 |

**등재문의 가설이 그대로 확인됐고, 재현이 한 칸을 더 못박았다** — R4 다.
**같은 표를 [받기]로 누르면 정상 지급된다.** 즉 이것은 «오늘 줄 것이 없다» 가 아니라
**«오늘 줄 것이 있는데 버튼이 아니라고 말한다»** — 손실이 아니라 **유도 실패**다.
그래서 고칠 자리가 **지급식이 아니라 버튼**으로 확정됐다(등재문은 이 갈림길을 열어 두고 있었다).

⚑ 라벨이 왜 거짓말인가: «내일 다시» 는 «오늘은 끝났다» 는 말이다. 실제로 끝난 것은
**광고 이득**뿐이고 **오늘 몫은 337.5분이 남아 있다.** 유저는 그 문장을 읽고 팝업을 닫는다.

## 2. 뿌리

199 4회차가 세운 «결손A» 가드 자체는 **옳다** —

```js
if(mul > 1 && offPend.gain <= 1.0005){ fxToast('오늘 오프라인 보상 한도를 모두 받았어요'); return; }
```

광고를 보고도 지급이 ×1 과 같아지는 상태에서 **광고를 헛되이 태우지 않게** 막는다.
결함은 가드가 아니라 **그 다음이 없다는 것**이었다: 막은 뒤에 유저를 «그럼 그냥 받으세요» 로
보내 주는 경로가 없고, 라벨은 정반대를 말한다.

## 3. 처방 — 등재문 후보 셋 중 **ⓑ**

등재문은 셋을 남겼다. **ⓐ(가드에서 ×1 로 대신 지급)·ⓒ(라벨을 «남은 n분 그냥 받기» 로)는
199 밸런스 손잡이**라 199 lock 이 살아 있는 동안 199 회차가 잡는다고 적혀 있다(같은 상수를
두 세션이 돌리지 않기 위해서다). 그래서 **밸런스 Δ0 인 ⓑ 만** 골랐다 — §5 가 그 Δ0 을 실측으로 못박는다.

**ⓑ = 버튼이 배수를 고른다.** 네 자리다:

1. **`offNoGain()` 신설** — «광고를 봐도 실효 이득이 0인가» 를 **한 곳에서만** 묻는다.
   문턱을 라벨·클릭·가드 세 곳에 손으로 적으면 **402 의 «표 두 벌» 부패**가 그대로 재발한다.
2. **라벨** — «내일 다시» → **«광고 이득 없음»**. 거짓말을 걷어내되 «오늘 끝났다» 는 말은 안 한다.
   초록 [받기]가 그대로 살아 있고, 이 버튼도 이제 같은 값을 준다.
3. **배선** — `$('ofrGet15').onclick = () => claimOffline(offNoGain() ? 1 : 1.5)`.
4. **가드** — `offNoGain()` 을 읽도록 갈되 **그대로 존치**. §4 를 볼 것.

⚑ **▶AD 뱃지도 같이 감춘다.** 이 상태의 누름은 광고를 태우지 않으므로 뱃지가 남으면
**그것이 새 거짓말**이 된다. 새 규칙이 아니라 이미 있던 뜻의 두 번째 자리다 —
`#app.noads .ofr-ad{display:none}`(124 평생 광고 제거)가 «광고가 아닌 누름에는 뱃지가 없다» 를
이미 적어 뒀다. CSS 는 안 만졌고 인라인 한 줄이라 되돌림도 한 줄이다.

## 4. ⚠ 가드를 지우지 않은 이유 (죽은 코드가 아니다)

ⓑ 이후 버튼은 이 상태에서 애초에 ×1 로 부르므로, 가드는 **UI 에서 안 닿는다**.
그렇다고 걷어내면 «광고를 헛되이 태우지 않는다» 는 **불변식이 통째로 사라진다** —
`claimOffline` 은 전역 함수이고 봇·검증 도구·미래의 다른 호출부가 직접 부른다
(실제로 `bot199.js` 1240 · `probe199r21` 이 그렇게 부른다). 이 자리는 UI 가 아니라 **API 쪽 난간**이다.

무르게 풀지 않았음을 **두 겹**이 못박는다 —
`probe650` **R9** · `verify650` **[C4]** 가 «`claimOffline(1.5)` 직접 호출은 여전히 분 Δ0» 을 단언한다.

## 5. ⚑ 밸런스 — 실측 Δ0 (199 이관 없음)

등재문은 이 행을 «199 이관» 으로 적었다. **ⓑ 를 고른 결과 이관할 계수가 없다** —
`node tools/probe199r21.js --before=<수리 전>` 실측:

| 프로필 | 수리 전 다이아 | 수리 후 다이아 | Δ | 발행 분 Δ |
|---|---|---|---|---|
| 부지런한 유저 | 82,686 | 82,686 | **+0 (×1.000)** | **+0.00** |
| 대충 유저 | 105,750 | 105,750 | **+0 (×1.000)** | **+0.00** |

**왜 Δ0 인가 — 199 의 계측 경로가 버튼이 아니라 API 이기 때문이다.**
`bot199.js` 1240 은 `claimOffline(a.offlineMul)` 을 **직접** 부르고 버튼을 누르지 않는다.
ⓑ 는 배선(onclick)만 바꾸고 가드·지급식은 그대로 두었으므로 그 경로는 **한 칸도 안 움직인다.**
⇒ **지금까지의 21개 회차 표는 재계산이 필요 없다.**

⚠ **그 대신 새 결손이 드러났다 — 봇이 이제 «실제 플레이어» 보다 적게 받는 모델이다.**
수리 후 실제 유저는 광고 버튼만 눌러도 하루 1,440분을 받는데, 봇은 API 를 직접 불러
여전히 1,102.5분에서 멈춘다(337.5분 = **23.4% 과소평가**). 199 의 «부지런» 오프라인 수입이
그만큼 낮게 잡혀 있다. **이것은 계수가 아니라 계측기 결함**이라 이 행에서 안 고치고
**673 로 등재**했다(`bot199.js` 는 199 의 자이고 `199.lock` 이 살아 있다 — 남의 구간이다).

## 8. 교훈 (→ `docs/LESSONS.md` 650)

1. **«막는 가드» 는 «보내 주는 경로» 와 한 벌이다.** 결손A 가드는 옳았는데 결함이 남은 이유가
   그것이다 — 막기만 하고 «그럼 어디로 가라» 가 없으면, 유저에게는 **막힌 것이 아니라 없는 것**이다.
   가드를 새로 세우는 세션은 «막은 뒤 유저가 갈 곳» 을 같은 회차에 적어라.
2. **라벨이 상태를 말하게 하지 말고 «남은 행동» 을 말하게 하라.** «내일 다시» 는 상태(광고 이득 0)를
   말했는데 유저가 읽은 것은 행동(«오늘은 할 게 없다»)이었다. 둘이 어긋나면 유저는 **행동 쪽을 믿는다.**
3. **★ 재현의 값어치는 «가설 확인» 이 아니라 «갈림길 확정» 에 있다.** 등재문은 처방 셋을 열어 뒀고
   어느 것을 고를지는 **«막힌 그 상태에서 [받기]가 얼마를 주는가»** 한 칸에 달려 있었다(R4).
   그 한 칸을 재고 나서야 «손실이 아니라 유도 실패» 가 확정됐고, 고칠 자리가 지급식에서 버튼으로 옮겨졌다.
   **338 규칙은 «가설이 맞나» 보다 «어느 처방인가» 에서 더 크게 값을 한다.**
4. **주석에 적은 상수도 사본이다.** `verify650` [A1] 이 내 주석을 잡았다 — 402 의 «표 두 벌» 은
   표끼리만 생기는 게 아니라 **코드 ↔ 주석** 사이에도 생기고, 그쪽이 더 오래 안 들킨다.
5. **«밸런스 이관» 은 처방을 고르고 나서 다시 판정하라.** 등재문은 이 행을 199 이관으로 적었지만,
   ⓑ 를 고르자 이관할 계수가 **0** 이 됐다(§5). 대신 **계측기 쪽에 새 결손**이 드러나
   이관의 내용이 «계수» 에서 «봇 경로»(673)로 통째로 바뀌었다.
