# 151 — 10 상점 «이용권» 탭 카드 전면 교체 (레퍼런스 디자인 3장)

> 주인 지시(2026-08-27): «이 이미지와 똑같은 방식으로, 불꽃·마일리지 알약만 빼고 마일리지 쿠폰 +1/+2 로 —
> 지금 이용권 탭 카드들 대신 이 디자인이 들어가면 됨» + 추가 지시 «3번째 카드 = 오프라인 보상 +4시간 ₩7,500».
> 레퍼런스 `docs/ref/151-이용권-카드.png` · 측정표 `docs/measure/151-이용권카드.md` ·

**작업 종류**: T2 기능 + 레이아웃 재구성. 지시서 [3]-(나) 비평 루프 대상이다(레퍼런스 대조가 있는 화면).
다만 레퍼런스가 **전체 화면 스크린샷이 아니라 카드 2장 크롭(504×709)** 이라, 이 작업의 비교 단위는
«프레임» 이 아니라 **«카드 하나»** 다 — 지시서 [2] 의 «프레임 y = 레퍼런스 y − 84» 변환은 해당 없음.
비평가에게도 그렇게 브리핑한다(카드 폭을 1 로 놓은 비율로 비교).

## 5회차 — 2회차 비평(C·D) 처리

**채점: C ①5 ②6 ③6 ④5 (⑤9 ⑥6) · D ①5 ②5 ③6 ④6 (⑤8 ⑥5) — ①~④ 최저 5 / 5**

**두 비평가가 각자 1순위로 같은 결함을 냈다**: 금색 젬 뱃지가 리본 **왼끝**(x48~54)에 붙어
문구를 가린다 — 기대는 리본1 x350 · 리본2 x406. C 는 Δ−296/−352, D 는 Δ−302/−358 로 냈다.
**원인은 CSS 가 아니라 렌더 호출부였다** — `rib()` 에 `--gx` 인자를 안 넘겨 인라인 스타일이
`--gx:undefinedpx` 로 박혔고, 무효 계산값이라 `right` 가 정적 위치로 떨어졌다.
CSS 만 노려봤다면 못 찾았을 자리다(값은 맞고 **전달**이 끊긴 것).

| 지적 | 처리 |
|---|---|
| 금색 판 앵커 (2인 1순위) | 인자 전달 복구 + 6px 계통 오차 보정 → 리본1 **x350** · 리본2 **x406** |
| 가격 글자 +41~45% | 잉크 58 → **41**(ref Δ−0.7%). fs 70/scaleX .74 → **fs 50/scaleX 1.09** |

| 검정 테 −1 | 9 → **10**(측정표 서브픽셀 4.84×k) · 라운드 44 |
| 크림 접힘캡 x9 w21 | **x3 w27**(검정 테 안쪽에서 시작해 6px 늦던 것) |
| 제목 ✦ +30% | 35×30 → **27** |
