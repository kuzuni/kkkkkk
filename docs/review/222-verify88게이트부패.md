## 2. 고친 것 — 지우지 않고 **이사**(168-② · 185-④)

### [B] «재화 💰» → «재화 = 골드 아이콘» + «가격 칸이 읽히는 값» (1항 → 2항)

`curIc()` 가 내는 `<img class="cic" alt="">` 는 `alt=""` 이라 `textContent` 에 **한 글자도 없다**
(LESSONS 175-② · 185-⑤). 아이콘은 **키**(`img[data-cur-ic].dataset.curIc === 'gold'`)로 잰다.

여기서 아이콘만 옮기면 **`.cb` 가 통째로 비어도 «gold 3개» 로 조용히 통과**한다.
그래서 «가격 칸이 읽히는 값인가» 를 **한 항 더** 박았다(212-②의 «잴 수 있는 크기» 규칙).
88 이 지키는 성질은 «훈련 카드 3장이 **골드로 산다**» 이지 «아이콘이 있다» 가 아니다.

### [G] ×3 — 인덱스 스냅샷을 **성질**로 바꿨다

`idx 16` 은 88 시점의 스냅샷이다(LESSONS 185-①: 리터럴 기대값은 기능이 아니라 «그때의 데이터»를 감시한다).
88 이 소유한 성질은 넷이고, 그것만 잰다:

| 새 단언 | 무엇을 지키나 |
|---|---|
| «스탯» 미션 0개 + «훈련 30회 하기» 1개(이름의 n = goal) | 88 의 «같은 자리 교체» 자체 |
| `GUIDE_V ≥ 4` | 88 이 3→4 로 올린 **기준선 리셋이 되돌아가지 않았다** (154 가 5 로 더 올린 것은 정상) |
| 훈련 미션 카운터 = `S.upgrades` (값을 37 움직여 확인) | 카운터 배선 |

**⚠ 「이름으로 하나뿐인가」로 쓰면 안 된다** — `/^훈련 \d+회 하기$/` 는 표에 **둘**이다
(idx 4 «훈련 10회 하기» 는 88 이전 것). 초안이 그렇게 썼다가 바로 FAIL 이 나서 잡았다.
88 의 미션은 **goal 30** 으로 집고, 카운터는 **훈련 미션 전부**를 본다.

카운터는 «지금 같나» 가 아니라 «따라 움직이나» 로 잰다 — 옛 단언 `GUIDE[16].get() === S.upgrades` 는
둘 다 0 인 순간에는 **무엇을 배선해도 참인 항등식**이었다(212-①).

**표의 이름·순서·개수 자체는 여기서 겹쳐 박지 않았다** — 154 의 `verify154` §1 이 통째로 못 박는다.
