## 2. 이 작업의 본체는 «지웠다» 가 아니라 «무엇을 안 지웠나» 다

죽은 코드 철거의 실제 사고는 «지우는 김에» 가 **공용 부품을 데려가는** 것이다
(LESSONS 9263-② «하네스가 부르는 함수는 죽은 코드가 아니다» · 11024-③ «유일한 호출자가 사라져도
함수가 죽은 것은 아니다»). 지우기 전에 `grep -rn tools/` 를 먼저 돌렸고, 나온 16개 자 전부를 갈랐다:

| 안 걷은 것 | 이유 |
|---|---|
| `FX3_FLYS` · `FX3_LAND` · `FX3_BSPITCH` · `fxGrainSc()` | 543 공용 축 — **획득 비행(`fxTick`)이 계속 읽는다** |
| `fxPill()` · `.fx-fly` · `.fx-land` · `@keyframes fxLand` | 획득 쪽 몸·착지 |
| `FXPAL.upNow` | 소비처는 0 이지만 **표에 남겼다** — 512 «색은 표에서만» 규약이라 팔레트에서 칸을 빼는 것은 이 청소와 **반대 방향**이다. 걷으려면 별도 번호로. |

`verify678` [B] 9항이 이 표를 매 실행 단언한다 — **[A](걷힘) 와 같은 무게**로 뒀다.
