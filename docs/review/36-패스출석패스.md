## 껍데기 판정

35 가 만들어 둔 **`#psw` 전용 전체화면 페이지**(딤 없음)를 **그대로 쓴다.**
35 측정표 §9-1 이 «x=4 열 RGB 대조에서 전 y Δ<12» 로 공유를 확정해 뒀고, 이번에 스팟 재검해도 일치했다.
따라서 이 작업의 범위는 **탭이 갈리는 슬롯 4가지**다(35 §9-3 이 지정한 그대로):

| # | 슬롯 | 36 의 값 |
|---|---|---|
| ① | 히어로 아트 + 타이틀 + 부제 + 스탯 2줄 + 가격 | 진파랑 하늘 + 빛살 + 반짝임 + 광차 + 얼음지대 / «출석 패스 1» / «매일매일…» / «접속일 / 2» / ₩5,900 |
| ② | 프리미엄 열 칸 개수 | **1개** (x741..898, 컬럼 중앙 819.5) |
| ③ | 리스트 선두 라벨 알약 | **«접속일»** 172×72 r31 @ ref(454, 865) |
| ④ | 육각 라벨 의미 | 스테이지 → **접속 일수(1일 단위 연속)** |

기능 쪽은 슬롯이 아니라 **규칙**이 갈린다 — 해금 진행도가 `S.best` 가 아니라 **`S.att.n`(접속 누적일)** 이고,
프리미엄과 수령 기록이 **패스마다 따로**여야 한다(§«저장 구조» 참고).

### 2회차 — 비평 반영 (캡처 `36-r2.png` → `36-r3.png`)

1. **라벨 행을 진짜 «행» 으로 만들었다** — `.ps-r.ps-hr` 안에 `.ps-cf`/`.ps-cp` 컬럼 배경 + 알약.
   (A1·B1 치명 해소. 도구 셀렉터도 `.ps-r:not(.ps-hr)` 로 전부 바꿨다)
2. **선두 오프셋 221.5** — 레퍼런스는 스크롤 0 에서 첫 구분홈이 ref **1017.5**(= 리스트 시작 796 + 221.5)다.
   pitch 를 쓰면 행 경계가 통째로 8.35px 내려간다. (B7 해소 — 재측정 933.5, ref 930 대비 Δ3.5)
3. **출석 히어로** — 구름을 끄고(`#psw.att .ps-cl{display:none}`) 진파랑 하늘·빛살 5쐐기·흰 4각 반짝임 3개·
   광차 아트 자리(396×369)·전폭 얼음지대(1080×234)를 깔았다.
4. **보상표를 레퍼런스대로** — 전 행 다이아, 무료 1,000 고정 / 프리미엄 1일차 30,000 그 뒤 10,000, **전 칸 에픽**.

### 3회차 — 진행 중 (`36-r3.png` 채점 중)

**자체 스캔으로 먼저 잡은 것 — 얼음 지대 능선이 100px 아래로 내려가 있었다.**
`.ps-ice` 의 `clip-path` 를 만들 때 **레퍼런스 y 를 밴드 비율로 환산하지 않고 그대로 % 로 썼다.**
밴드는 frame 301..534(h234)이고 능선 실측은 ref y384..470 = frame 300..386 이므로 **밴드의 위 0~36%** 인데,
43~74% 로 적혀 있었다. 컬럼별 «첫 밝은 시안 픽셀» 프로파일을 ref 와 대조해 잡았다:

| x | 120 | 220 | 1020 |
|---|---|---|---|
| ref 능선(frame y) | 332 | 324 | 332 |
| 수정 전 | 검출 안 됨(밝은 층이 클립으로 잘려 안 보임) | 〃 | 〃 |
| 수정 후 | 314 | 303 | 317 |

남은 Δ≈−18~21px 은 **레퍼런스 크리스탈의 검정 외곽선(6~10px) + AA** 만큼이다(우리는 외곽선이 없어 시안이 클립 경계에서 바로 시작한다).
실루엣 자체는 맞다.

> ⚠ **운영 사고 — 비평가가 읽는 중에 `36-r3.png` 을 재캡처로 덮어썼다**(LESSONS 52 운영메모의 그 사고).

> 3회차 지적 중 얼음 지대에 관한 것은 이 점을 감안해 읽을 것.

## 저장 구조 (KEY 미변경 · 마이그레이션으로 흡수)

36 이 붙으면서 «패스가 하나» 라는 전제가 깨졌다. 두 가지를 바꿨다:

| | 35 시절 | 지금 |
|---|---|---|
| 수령 기록 | `S.pass.got['단계:칸']` | `S.pass.got['탭:단계:칸']` |
| 프리미엄 | `S.pass.prem` (boolean) | `S.pass.prem[탭]` (맵) |

네임스페이스가 없으면 **스테이지 패스 3단계를 받은 사람이 출석 3일차도 받은 것**이 되고,
프리미엄도 ₩14,900 한 번에 ₩5,900 짜리까지 열린다. `load()` 가 구 세이브를 **전부 stage 로 이관**한다
(44 교훈 2 대로 `KEY` 는 올리지 않는다). `tools/verify35.js` 의 키 단정 2곳도 새 형태로 맞췄다.

## 잔여 문제

1. **프리미엄 칸 자물쇠 폭이 아직 −25% 다.** 🔒 이모지는 가로세로가 같이 커져서
   `font-size` 로는 ref 잉크(79×87, 코어 49×56)의 «가로로 넓은» 비율이 안 나온다. `scaleX 1.32` 로 밀었지만
   글리프 자체가 좁다 → **아트 대기**(측정표 §11 «아트 필요» 표에 올려 뒀다).
2. **헤더 밴드의 무료/프리미엄 리본 배지가 좁다**(프리미엄 잉크 폭 −75%, 중심 +26.5px).
   35 가 이모지(🎗️/🏅)로 자리만 잡아 둔 것이고 레퍼런스는 **은/금 날개 리본 125×89 / 125×108** 이다.
   **35 구간이자 아트 대기** — 이모지를 아무리 늘려도 리본 형상이 안 나온다.
3. **육각 배지 형상**(45° 챔퍼 8각 vs 6각)은 35 가 실측으로 확정한 껍데기라 손대지 않았다.
   내 측정(외곽 105×111)과 35 표(108×107)가 4px 어긋나 **확정적이지 않다** — 35 를 다시 잡는 세션이 가릴 것.
4. **비활성 탭 fill** 이 36 실측에서는 바 배경과 같은 `#49322C` 인데 35 표는 `#3F2D29` 로 적혀 있다.
   ⑤ 색 항목이라 통과를 막지 않아 이번 라운드에는 미반영.
