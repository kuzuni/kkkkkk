## 0. 무엇이 없었나

03 던전 카드(`.dnc`)는 **좌측 텍스트 클러스터(던전명·재화 알약·레벨/횟수 알약)만** 있고
레퍼런스의 **우측 몬스터 일러스트가 통째로 빠져 있었다.** 카드 우측은 선버스트(방사) 배경만 깔려 있다.

## 1. 레퍼런스 실측 (신규 — `tools/scan72.py`)

측정표 `docs/measure/03-던전팝업.md` 에는 «우측 일러스트 바탕색» 만 있고 **일러스트 bbox 는 없었다.**
그래서 이번에 스캐너를 새로 만들어 잰다. 방식: 3px 간격 국소 경사(gradient) 밀도 —
선버스트는 큰 부채꼴이라 경사가 완만(열당 4px 내외)하고, 몬스터 아트는 외곽선·하이라이트로 급하다.

| 카드 | 경사 밀도가 배경 수준(4/열)에서 뛰는 x | x 질량 2% / 50% / 98% | y 질량 2% / 98% (카드 top 기준 상대) |
|---|---|---|---|
| 1 골드 던전 | **713** | 713 / 855 / 1017 | **9 / 336** |
| 2 보석 던전 | **723** | 670 / 860 / 1019 | **9 / 338** |

- 카드 안쪽 박스는 x **57~1022**, 세로는 카드 top+8 ~ top+341 (테두리 좌우 7 · 상하 8).
- → 일러스트는 **카드 안쪽 우측 x 708~1022(w 315)** 를 차지하고 **세로는 안쪽 전체(h 334)** 를 채우며
  **카드 하단에서 잘려 들어간다.** 좌측 경계는 하드 엣지가 아니라 배경으로 **페이드**된다.
- 잠금 카드(3·4·5)는 딤이 걸려 경사 신호가 죽어 별도 측정 불가 — 레이아웃은 5장 동일(측정표 §3-7-4).

## 2. 구현 (1회차)

| 요소 | 값 |
|---|---|
| 슬롯 `.dnc>.th` | `right:7px; top:8px; 315×334; overflow:hidden` → 프레임 x **708~1023**, 카드 안쪽 세로 전체 |
| 좌측 페이드 | `mask-image:linear-gradient(90deg,transparent 0,#000 64px)` (레퍼런스의 페이드 경계 재현) |
| 대체 아트 | 던전별 큰 이모지 — 🐉 황금 동굴 / 🐍 수정 광산 / 🗿 고대 유적 / 👺 수련의 탑 / 👹 마왕의 성 |
| 이모지 박스 | `font-size:310px; line-height:340px; top:8px; width:340px` → 잉크 세로 344 = **슬롯 334 보다 커서 하단 잘림** |
| 폭 정규화 | 이모지 잉크 폭은 글리프마다 **0.81~1.13em**(fs300 실측 242~338px) 로 제각각이라 카드별 `--tsx` scaleX 로 맞춤 (🐉1.03 · 🐍0.88 · 🗿1.21 · 👺0.89 · 👹0.87) |
| z 순서 | `.bg` → **`.th`** → `.sh` → `.fr` → 텍스트 → `.lk`(잠금 딤·자물쇠) — 잠금 카드는 썸네일도 같이 어두워지고 자물쇠가 위에 온다 |

실측(캡처 `--geo`): 카드 5장 전부 `th` = 프레임 x **708~1023 · w315 h334**, 카드 top+8 (ref 환산 y249/609/969/1329/1689) — **설계값과 0px 일치**.

도구: `tools/scan72.py`(레퍼런스 스캐너) · `tools/cap72.js`(캡처 + `--geo` 기하 덤프 + `--probe` 잉크 측정용 평탄화 + `--unlock`)

## 4. 2회차 수정 (5건)

1. **카드별 슬롯 기하** — `--thw`(폭) · `--tht`(상단 인셋) 도입. 카드1 **311×305 @ top+36**,

2. **이모지 배치 산식 교체** — 잉크 폭·높이 비가 글리프마다 다르므로(fs300 실측 w 242~338 · h 324~338)
   카드마다 `font-size`(세로) 와 `scaleX`(가로) 를 따로 풀고, 400px 정사각 상자의 중심을
   `--thcx/--thcy` 로 옮겨 **우측 6px · 하단 16~18px 오버플로**를 만든다(= 두 방향 잘림).
   결과: 🐉 fs291/1.147 · 🐍 fs282/0.962 · 🗿 fs281/1.25 · 👺 fs284/1.005 · 👹 fs280/0.986.
3. **페이드 마스크 64px → 12px** (P 지적. 레퍼런스는 하드 엣지).
4. **아트 바닥판** — 레퍼런스 아트는 슬롯을 꽉 채운 그림이라 이모지 하나만 띄우면 우측 100px 커버리지가

5. **잠금 카드 씬 아트 자리 신설(`.dnc>.scn`)** — 레퍼런스 잠금 카드는 우측 썸네일이 아니라
