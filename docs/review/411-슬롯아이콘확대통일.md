## 2. 처방 — 값을 **한 곳**에 두고, 세 출처가 «자기 잉크» 를 재서 담는다

```js
const SLOT_ART = { h: 80, w: 88 };          /* 그림 자리 — 잉크 목표 높이 · 가로 상한 */
```

* **스킬(이모지)** — `slotEmoji(ch)` 가 글자마다 한 번 잉크를 재서(캐시) `font-size` 와 중심 보정을 인라인으로 준다.
  세로 보정식은 `dy = s·((D−A)/2 − iyRel − ih/2)` 로 **line-height 가 상쇄**돼 상자 높이를 몰라도 된다.
* **펫(스프라이트 캔버스)** — `PET_TH.slot = { w: SLOT_ART.w + 6, h: SLOT_ART.h + 6, fit: 3 }`.
  contain 이 `(W−2·(fit+림))` 안에 담고 림 2px 이 사방에 더 붙으므로 «잉크 = SLOT_ART» 가 되는 캔버스는 `+6` 이다.
* **코스튬(기사 캔버스)** — 캔버스를 **그림 자리와 같은 크기**(88×80)로 두고 `cosSlotSc()` 가 배율을 역산한다.
  `drawHeroTo` 가 잉크 밑동을 캔버스 바닥에 앉히므로 잉크가 캔버스를 정확히 채우고, 그러면 **가운데 정렬 = 잉크 가운데 정렬**이다.
* **상자** — `.sk-si` 를 링 안쪽 전체(12..103 · 91×91)로 넓히고 `Lv.n` 은 **레퍼런스 좌표 그대로** 둔 채
  `.sk-si` 밑동 그라데이션(스크림) 위에 얹는다.
* **형제** — `.sk-plus` 52 → **64**, 슬롯 자물쇠 `scale(1.061)` → **1.28**(394: 하나만 키우면 잠금 칸이 왜소해진다).

### 2-1. ⚑ 눈금을 무엇으로 삼았는가 — **세로 잉크 높이**(폭도 면적도 아니다)

394 가 남긴 숙제다. 여기서 고른 답과 근거:

* **고른 것: 세로 잉크 높이.** 채점이 «세 시트의 슬롯 줄을 한 장에 나란히 놓고» 보는 것이라 눈이 맞대어 보는 축이 높이다.
  폭은 **상한만** 준다(등방 contain 의 «높이 우선» 변형).
* **실측 종횡(w/h)**: 이모지 0.683~1.129 · 펫 0.579(robo)~1.469(dragon) · 기사 0.933.
  ⇒ 종횡 ≤ 88/80 = 1.10 인 그림은 **전부 정확히 80**, 그보다 넓은 것만 폭에 걸린다.
* **폭에 걸리는 것은 게임 전체에서 둘뿐**이다(`verify411` [C] 전수 스윕): 🔻 lance 88×76.5 · dragon 88×60.
* ⚑ **dragon 은 어떤 눈금을 골라도 못 키운다** — 종횡 1.469 인 그림이 세로 80 이 되려면 폭이 **117** 이어야 하는데
  링 안쪽이 91 이다. 즉 이 한 자리는 «눈금 선택의 대가» 가 아니라 **상자의 한계**이고, 늘려 채우는 것은 356 이 금지한다.
* 면적(√wh)을 눈금으로 삼는 안도 검토했다. robo(0.579)가 상자 세로에 먼저 닿아 목표가 **67** 로 내려가고
  — 즉 지금 이모지(65)보다 겨우 3% 크다 — 주인 지시(«커져야함»)를 못 지킨다. 그래서 기각했다.
