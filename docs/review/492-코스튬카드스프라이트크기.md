## 2. 처방 — «그림 자리» 를 한 곳에 적고 둘이 읽는다 (411 규약)

```js
const CARD_ART = { h: 90, w: 120 };            /* 카드 «그림 자리» — 눈금은 세로, 폭은 상한 */
const cosCardSc = () => Math.max(1, Math.round(Math.min(CARD_ART.h/COS_INK.h, CARD_ART.w/COS_INK.w)));
PET_TH.card = { w: CARD_ART.w + 6, h: CARD_ART.h + 6, fit: 3 };   /* 슬롯과 같은 역산식 */
```

* **세로 90 의 근거**: 주인 기준 0.906 을 영역 96 에 옮기면 87 인데, 픽셀 아트라 배율은 **정수**여야
  한다(79/80 · 처방 ②). 45 x 2 = **90** 이 87 에서 **+3.5%** 로 처방의 ±5% 안이다.
  ⚠ 411 이 슬롯에서 비정수(1.7778)를 쓴 것은 «세 시트의 잉크 높이를 한 상자에 맞춘다» 는
  **다른 제약** 때문이었다 — 여기서는 배율을 쪼갤 이유가 없다.
* **캔버스·카드 기하는 한 픽셀도 안 건드렸다**(96x96 그대로 · 카드 168x171 · pitch 190/220 ·
  라벨 52,14 · 진행바 126) — 바뀐 것은 **배율 하나**다.

## 4. 반증한 것 — 비평가 제안을 그대로 받지 않은 자리 둘

* **AW «90 → 78 로 줄이고 하단 정렬»**(라벨 겹침 20 → 7px) — **안 받았다.**
  78 도 87 도 **비정수 배율**(1.733 / 1.933)이라 원본 픽셀이 1:2 로 고르지 않게 퍼진다.
  같은 회차의 AV 는 반대로 «90 유지, 더 키우면 진행바에 닿는다» 였고 **둘이 정면충돌**했다.
  판정 근거는 눈이 아니라 규약이다 — 79/80 정수 배율 + 주인 기준 ±5%(90 은 +3.5%).
  라벨 겹침은 **이 부품의 원래 성질**이다: 26 펫 카드가 수리 전부터 13.5px 겹쳐 있었고
  (`probe492`), 비평가 6인 중 **«못 읽는 칸» 을 든 사람은 0명**이다(흰 글자 + 검정 외곽선).
* **AX·AY «폭 상한을 코스튬에도 올려라»** — 상한은 공유하되 **코스튬 폭은 안 움직인다.**
  50종이 전부 같은 기사 실루엣(원본 42폭)이라 정수 배율인 한 폭은 항상 84 다.
  ⚠ 그리고 AX 가 짚은 자리가 **실재한다** — 카드 좌상단 «+»/«─» 뱃지(`.sk-eq` 49x49 @ −4,−4
  ⇒ 카드 x −4..45)가 **50칸 중 39칸**에 뜨고, 잉크 좌단이 카드 x42 라 **3px 이 뱃지 밑**이다
  (수리 전에는 잉크가 42폭이라 18px 떨어져 있었다 = 이 3px 은 이번 확대의 대가다).
  26 펫 격자에는 이 뱃지가 **아예 없어**(0/36칸) 폭 상한이 자유롭다 — 그래서 상한 인상이
  펫에서만 실효가 있고 코스튬에서는 무해하다. 그 전제가 깨지면 `verify492` **[E5]** 가 빨개진다.
