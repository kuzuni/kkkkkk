### [함정] rAF 만 얼려서는 차분이 안 나온다

차분은 «사이드 스택 말고는 동일한» 두 장이어야 성립한다. 처음엔 전투 캔버스가 살아 있어
차분이 화면 전체로 번졌고, `requestAnimationFrame` 과 `setInterval` 을 얼린 뒤에도
**라벨 밴드에 아이콘이 섞여 들어왔다** — 60 쥬시 모듈이 붙은 뒤로 CSS 애니메이션이 돌기 때문이다.
CSS 애니메이션은 rAF 로 안 돈다. `animation-play-state:paused` + `transition:none` 까지 얹어야
라벨 잉크 높이가 48 → 30 으로 «진짜 값» 이 됐다(48 은 흔들린 아이콘을 문 값이었다).

## 4. 5회차 반영 — 무엇을 어떻게 고쳤나

### (1) [MAJOR] 아트 잉크 bbox 를 레퍼런스에 다시 앉혔다

`--sf`(font-size 배율)·`--sx`(가로 배율)를 **비평가 실측치 → 레퍼런스 목표** 비율로 다시 역산했다.

| 행 | 4회차 --sf/--sx | 5회차 --sf/--sx |
|---|---|---|
| 1 출석 📅 | .971 / 1.091 | **.925 / 1.084** |
| 2 룰렛 🎰 | .891 / 1.126 | **.839 / 1.111** |
| 3 퀘스트 📜 | .959 / 1.066 | **.862 / 1.125** |
| 4 승급전 🏆 | .956 / 1.220 | **.848 / 1.143** |
| 5 축복 🙏 | .930 / 1.150 | **.876 / 1.069** |

결과(같은 정의·같은 마스크로 재측정):

| 행 | Δ폭 | Δ높이 | Δ중심x | Δ잉크top |
|---|---|---|---|---|
| 1 출석 | **0** | **0** | **0.0** | **0** |
| 2 룰렛 | **0** | **0** | **0.0** | −1 |
| 3 퀘스트 | **0** | **0** | **0.0** | **0** |
| 4 승급전 | +1 | +1 | −0.5 | +2 |
| 5 축복 | **0** | −1 | −1.0 | +2 |

4회차의 «폭 +18~44% / 높이 +15~25%» → **전 행 2px 이내.**

### (2) ③ 여백은 처방대로 자동 회복됐다

| 구간 | 4회차 | 레퍼런스(E/F) | 5회차 |
|---|---|---|---|
| 1행 아트 하단 → 2행 아트 상단 | 55 | 61 | **60** |
| 2행 라벨 하단 → 3행 아트 상단 | 16~18 | 25 / 21 | **22** |
| 3행 라벨 하단 → 4행 아트 상단 | 18~20 | 27 / 22 | **21** |
| 4행 라벨 하단 → 5행 아트 상단 | 20~22 | 23 / 17 | **21** |

3행만 19 로 남아 두 사람의 하한(21)에도 못 미쳐 **3행 라벨을 −2px** 올렸다
(같이 얻은 것: 아트 하단→라벨 잉크 간격 6 → **4** 로 레퍼런스와 일치).

### (3) 원인 — 왜 이렇게 커져 있었나

`--sf/--sx` 는 «그 칸의 레퍼런스 스프라이트 bbox» 로 역산한 값이라 **칸 내용이 바뀌면 다시 재야 한다**
(CSS 주석에 그렇게 적혀 있다). 그런데 48(던전 삭제)·71(우편 삭제)·34(축복 신설)이 칸을 지우고
새 이모지를 끼워 넣으면서 그 재역산을 안 했다. 그래서 **4행 🏆 는 ref 6행(폭 107) 규격 그대로
ref 4행(폭 94) 자리에 앉아 있었고**, 5행 🙏 는 역산 자체가 없었다.

## 5. [함정] 측정 하네스에서 잡은 것 3개 — 다른 화면에도 그대로 재발한다

1. **`.bdg`(빨강 알림닷)가 잉크 bbox 를 오염시킨다.** `.si` 밖에 있고 슬롯 우상단으로 튀어나와서
   (x 114..156 · top −6) 차분에 그대로 잡힌다. 게다가 알림 상태가 회차마다 달라 **같은 빌드에서 수치가 5px 씩 흔들렸다.**
   더 고약한 건, 아트가 크던 4회차에는 닷이 아트 bbox **안에 들어가 있어서 안 보이다가**, 아트를 줄이자
   비어져 나와 «줄였는데 수치가 커지는» 현상으로 나타난 것이다. 측정용 캡처에서는 반드시 끈다.
2. **rAF 만 얼려서는 부족하다.** CSS 애니메이션은 rAF 로 안 돈다(60 쥬시 모듈 부착 이후). 
   `animation-play-state:paused` + `transition:none` 까지 얹어야 차분이 안 번진다.
3. **`visibility` 를 껐다 켰다 하지 마라.** 라벨을 껐다가 되살렸더니 뒤 캡처에서 다시 보여
   아이콘 밴드가 라벨을 물었다(높이 80 → 132). 캡처 시퀀스는 **단방향**으로 짠다.
4. **임계값은 비평가와 맞춰야 한다.** 내 차분 마스크(임계 26)는 소프트 섀도의 옅은 프린지를 물어
   축당 6px 부풀었다 — 같은 빌드에서 비평가 112×106 vs 내 125×115. **임계 120** 에서 두 사람 수치와
   ≤1px 로 붙는다. 채점자와 다른 자로 재면 처방이 통째로 어긋난다.
