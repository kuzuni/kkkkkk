### 1.2 썸네일 «들썩» (지시 ⑥)

슬롯(`.th`)의 기하 `--thw/--tht/--thcx/--thcy` 는 **1px도 안 건드렸다.** 움직이는 것은 슬롯 안의 잉크뿐이고,
`overflow:hidden` 이 슬롯 밖 유출을 막는다.

- `transform` 은 이미 **폭 정규화(`scaleX(--tsx)`, 작업 72)** 가 쓰고 있으므로 건드리지 않았다.
  대신 **개별 변환 속성** `translate`(들썩) 과 `scale`(스쿼시)에 애니메이션을 따로 걸었다 —
  서로 다른 속성이라 충돌이 없고, 개별 속성은 `transform` 보다 먼저 적용돼 72 의 정규화가 그대로 산다
  (`verify72` 의 «`matrix(` 적용» 항목 102/102 유지).
- 한 루프(`--thb` 3.9~5.0s) 안에 **짧은 들썩 4번(−8px)** + **큰 점프 1번(−14px, 90% 지점)**.
  짧은 들썩 주기는 그 1/5 = **0.78~1.00s**(지시 «0.7~1.0s»), 큰 점프는 **3.9~5.0s 마다**(지시 «3~5s»).
- 스쿼시 `scale: 1 .96` ↔ `1 1`, `transform-origin` 은 **발밑(50% 100%)**.
- 위상 `--thd` = −0.37s × 카드 인덱스 — 6장이 한 몸처럼 움직이지 않는다.

### 1.3 컨텐츠(레이드) 카드 — 스프라이트 아이들 프레임 순환

## 2. 이번에 잡은 함정 4개 (다음 세션도 그대로 밟는다)

### ① `animation:` 단축 속성은 `animation-play-state` 를 **running 으로 되돌린다**

처음에 이렇게 썼다:

```css
.dnc>.bgm::before,.dnc>.bgm::after{ … ; animation-play-state:paused}   /* 기본은 정지 */
.dnc>.bgm::before{ … ; animation:bgmA var(--bgt1) linear infinite var(--bgd1)}  /* ← 여기서 running 으로 리셋 */
```

**페이지를 닫아도 배경이 계속 도는 상태**가 됐다. `animation-play-state` 는 반드시 **단축 속성 뒤**에 적어야 한다.
같은 함정이 레이드 전용 `::after` 오버라이드(2개 애니메이션 지정)에도 있었다.

### ② 그 회귀를 **게이트가 못 잡았다** — `[].every()` 는 true 다

`#dunw` 는 닫히면 `display:none` 이라 **의사요소가 상자를 못 만들고**, `getAnimations({subtree:true})` 가
**빈 배열**을 돌려준다. 그래서 «전부 paused 인가» 를 `every()` 로 물으면 **무엇을 넣어도 통과**한다.
실제로 기저 규칙을 `running` 으로 되돌리는 회귀를 주입했더니 그대로 PASS 했다.
→ 게이트를 둘로 갈랐다: ⓐ 닫히면 «살아 있는 애니메이션 0개»(렌더 자체가 없다) ⓑ **렌더만 강제로 살리고
`.on` 은 뺀 상태**에서 12개 전부 paused 인지. ⓑ 가 «규칙» 을 지키는 쪽이고, 회귀 주입이 여기서 걸린다.
(LESSONS 132 «고친 게이트에는 회귀를 주입해 봐라» 의 재현)

### ③ `filter:brightness()` 로 어둡게 하면 **스크롤이 17% 느려진다**

잠금 카드 4장을 `filter:brightness(.58) saturate(.72)` 로 어둡게 했더니 03 리스트 왕복 스크롤 평균이
**31.9 → 26.4fps**. 필터는 매 프레임 그 카드를 다시 래스터한다. 같은 «어둡게» 를 `opacity:.45` 로 내면
합성만으로 끝나고 fps 가 기준선으로 돌아온다. 레이어 높이도 130% → 100% 로 줄였다(합성 텍스처만 커진다).

### ④ `transform-origin` 을 **id 리셋이 이긴다** (LESSONS 21-①·90-④ 세 번째 재발)

`#dunw i,#dunw em,#dunw b{transform-origin:50% 50%}`(1-0-1)이 `.dnc>.th>em`(0-3-1)을 이겨,
스쿼시 축이 «발밑» 이 아니라 «잉크 한가운데» 로 남아 있었다. `#dunw` 로 되받아 고쳤고 게이트에 항목을 넣었다.
