## 구현 요약

- **껍데기**: 하단에서 올라오는 «바닥 시트» 전용 오버레이 `#trw` (06 `#eqw`·07 스킬 시트와 동종).
  상단 경계가 물결 곡선이라 `.tr-wave` 레이어로 따로 그린다.
- **진입**: 하단 탭 «성장» → **«훈련»** 으로 라벨 교체 + 탭 클릭 시 이 시트 직행(중간 성장 패널 폐기).
  열려 있는 동안 그 칸은 A1 의 ✕ 로 바뀐다(`syncTrainNav`, 10·13 의 `syncShopNav` 와 같은 규칙).
- **시스템**(UI-REFERENCE 23 «우리 게임 설계»):
  - 훈련 대상 3종 = 공격력 · 체력 · 체력 회복 (`TRAIN_STATS`)
  - 각 스탯 상한 = **훈련 단계 × 100**, 진행바 = 3종 합 / (3 × 상한)
  - 3종 모두 상한 → ↑ 버튼 활성 → **17 스탯업 연출**(`openStatUp`) → 단계 +1 → 상한 재확장(무한)
  - 단계당 **공격력·체력·체력회복 각 +10% 누적**(`bonus()` 의 `tb`)
  - 구매 단위 **x1 / x10 / x30** (상한을 넘겨 사지 않는다)
  - 서브탭 2 = **스탯 훈련** — 같은 구조, 소모 재화만 스탯 포인트(`S.spAtk/spHp/spRegen`, `S.statStage`)
- **저장 구조**: `trainStage` · `statStage` · `spRegen` 3개 추가. `DEF()` 기본값이 있고 `load()` 가
  `Object.assign(DEF(), d)` 를 하므로 **구 세이브도 그대로 열린다** → KEY 버전 유지(`idle_hunter_save_v4`).
  기존 `S.buyQty === 'MAX'` 세이브는 `trainQty()` 가 1로 정규화한다.
- **UPG 나머지 7종**(공속·치명타·치확·관통·방어·이동·골드획득)은 데이터와 기존 세이브 값을 그대로 두어
  스탯 계산에는 계속 반영되지만 **구매 경로에서 빠졌다**(`autoBuyTick` 도 3종만 산다).
