## 1. 등재문이 맞았다 — 그리고 깨진 겹이 하나가 아니라 둘이었다

175 는 워커 B 가 작업 120 18회차 회귀 확인 중 «내 수정 이전 상태(`git stash`)에서도 같은 항목이
같은 문구로 FAIL» 로 등재한 것이다. 재현부터 했다 — `origin/main` 그대로에서 **G3 만 FAIL, 35/36**.

옛 단언은 이랬다:

```js
S.relic = 99; summonRelic();                 /* quiet 아님 → 안내 팝업 */
const t = document.body.innerText;
return { open: /유물조각 부족/.test(t) };
ok(G2.open, 'G3 첫 누름 부족은 «🔮 유물조각 부족» 안내 팝업');
```

이 한 줄이 **서로 다른 두 작업에 의해 두 겹으로** 낡았다.

| 겹 | 옛 기대 | 지금 | 바꾼 작업 |
|---|---|---|---|
| ⓐ 매체 | «안내 **팝업**»(`#modal`) | `#fxl .fx-toast` 토스트, `#modal` 은 안 열림 | **149** — «클릭 없이 사라지는 단순 안내» 전면 토스트화 |
| ⓑ 문구 | «🔮 유물조각 **부족**» | «`<img data-cur-ic="relic">` **1 더 필요합니다**» | **125** — 화폐 이모지 → 화폐 아이콘 `<img>` |

ⓑ 가 특히 조용한 함정이다. 현재 문구는 `notify(curIc('relic') + ' <b>1</b> 더 필요합니다')`
(`index.html:20507`)이고 `curIc()` 는 **`<img class="cic" alt="">`** 를 돌려준다(`~13078`).
`alt` 가 비어 있으므로 «🔮» 은 `innerText` 에 **한 글자도 남지 않는다** — 즉 옛 정규식은
매체를 팝업으로 되돌려 놓아도 여전히 통과하지 못한다. **«토스트로 바뀌어서 FAIL» 이 아니라
«팝업으로 되돌려도 FAIL» 인, 어느 쪽으로도 못 맞추는 단언**이었다.

**게임 동작은 149·125 가 의도한 그대로다.** 고칠 곳은 게이트 하나였다(등재문 판단과 일치).

## 2. 고친 것 — 기대값을 «옮겼다», 느슨하게 풀지 않았다

낡은 단언을 지우는 가장 쉬운 길은 «본문에 «필요» 가 있으면 통과» 처럼 넓히는 것이고,
그러면 게이트가 **죽는다**(127·130·132·133·134·138·139·140·146 계열이 전부 그렇게 죽어 있었다).
그래서 옛 단언이 지키려던 성질 셋을 **매체만 갈아 끼워 그대로** 옮겼다.

**G3 — 첫 누름 부족은 안내 1건 · 팝업 아님**

```js
clear(); S.relic = 99; summonRelic();          /* quiet 아님 = 첫 누름 */
```
- 토스트 정확히 **1건**(옛 «안내가 뜬다»)
- 문구에 **부족분 «1»** + **«더 필요합니다»**(옛 «부족» 문구)
- 토스트 안에 **`img[data-cur-ic="relic"]`**(옛 «🔮» 의 125 이후 대응물 — 아이콘이 빠지면 잡힌다)
- **`#modal` 은 off**(149 가 세운 성질을 새로 못 박는다 — 옛 단언에는 없던 보강)

**G4 — 홀드 반복분(quiet)은 조용하다** (신설, 36 → 37항목)

`index.html:20533` 주석이 «반복 중 부족은 조용히(shake만), 첫 누름 부족만 안내» 라고 계약을
적어 두었는데 게이트는 **한쪽(시끄러운 쪽)만** 보고 있었다. `summonRelic(true)` 뒤 토스트 0건 ·
`#modal` off 를 단언해 **양쪽에서** 못 박았다. F1~F6 홀드 항목이 이 조용함에 의존하므로
(홀드 3회 뒤 4회차 부족 → 토스트 폭포가 나면 안 된다) 이미 게이트 안에 있던 전제를 명시화한 것이다.

## 3. 음성 시험 — «FAIL 할 줄 아는가»

낡은 단언을 고칠 때 진짜 위험은 «통과하도록 고쳐 놓고 아무것도 못 잡게 만드는 것» 이다.
`index.html` 을 일부러 세 가지로 망가뜨려 **각 항목이 자기 것만 잡는지** 확인했다(전부 시험 뒤 복원, 최종 diff 0줄).

| 시험 | 망가뜨린 것 | G3 | G4 | 판정 |
|---|---|---|---|---|
| N1 | `notify()` 의 `fxToast` 를 죽여 **팝업 폴백**으로 회귀(149 역행) | **FAIL**(토스트 0 · `#modal` on) | PASS | 149 회귀를 G3 이 잡는다 |

토스트만 지우고 **G3 이 띄운 폴백 팝업을 그대로 뒀기** 때문에 그 `#modal` 이 G4 로 새어

## 6. 교훈 (LESSONS §175 에 같이 적음)

1. **낡은 게이트는 «한 작업» 이 아니라 «여러 작업» 이 겹쳐 깨뜨린다.** 여기서는 149(매체)와

2. **`alt=""` 인 아이콘은 `innerText` 에 없다.** 125 이후 «이모지가 보이는가» 로 쓴 단언은
   전부 «`img[data-cur-ic]` 가 있는가» 로 옮겨야 한다. 텍스트 정규식으로는 영영 못 본다.
