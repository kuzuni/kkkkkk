## 2. 뿌리 — «키 하나가 축 둘을 갈랐다»

원판은 `typeof S.sumLv === 'number'` **하나**로 «496 수리 전/후» 를 갈랐다. 그런데 496 이 한 번에

| 축 | 무엇을 묻나 | 496 | 714 |
|---|---|---|---|
| **공유 축** | 다섯 배너가 «한 주머니» 인가 | 켰다(`S.sumLv` 스칼라) | **껐다**(배너별 5 벌로 복귀) |
| **곡선 축** | 곡선이 «식» 인가 «196 표» 인가 | 켰다(만렙 50 · `A + B·n`) | **그대로 둔다** |

714 가 **공유 축만** 되돌리자 하나뿐인 키가 오늘 트리를 «496 수리 전» 으로 읽었고, 그래서
**곡선 축의 기대값이 196 시절 손 상수로 되돌아갔다.** 값이 틀린 게 아니라 **판을 잘못 골랐다.**

판이 셋인데 갈래가 둘이었던 것이다 — `probe568` 이 이미 «갈래를 가르는 키가 둘이 됐다 —
`sumVer`(714) · `sumLv`(496)» 라고 적어 두고 있었다(`tools/probe568.js:111`).

| 판 | 공유 | 곡선 | 만렙 | 8행 사다리 |
|---|---|---|---|---|
| 196 이전 | 배너별 | 표 | 25 | 1,1,5,8,12,16,20,24 |
| 496 | **공용** | 식 | 50 | 1,1,10,16,24,32,40,49 |

## 3. 처방 — 등재문 ⓐ (키 둘 + 제품 역산), ⓑ 는 안 골랐다

등재문의 갈래 ⓑ(«수리 후 갈래가 도달 불가임을 인정하고 역사 기록으로 마감») 는 **틀린 진단**이었다.
도달 불가가 된 것은 «수리 후» 갈래 전부가 아니라 **공유 축의 496 쪽 한 칸뿐**이고, 곡선 축의
«수리 후» 는 오늘도 살아 있다(오늘 트리가 바로 그 곡선을 쓴다). ⇒ ⓐ 를 골랐다.

**① 갈래 키를 축마다 하나씩, 둘로 쪼갰다.**

```js
const T = await p.evaluate(() => ({
  shared: typeof S.sumLv === 'number',   /* 공유 축 — 496 이 켜고 714 가 껐다 */
  curve : typeof SUM_EXP_A === 'number', /* 곡선 축 — 496 이 켠 뒤 그대로다 */
  ver   : typeof SUM_VER === 'number' ? SUM_VER : 0
}));
```

첫 줄이 이제 이렇게 찍힌다:

```
트리: 714 (배너별 레벨 5 벌 · 496 식 곡선)  |  sumLv 없음 · SUM_EXP_A 있음 · SUM_VER 2
```

**② 손 상수를 전부 제품에서 역산으로 갈아 끼웠다**(LESSONS **522-①** «만렙을 손으로 적지 마라 —
게이트가 더 잘 썩는다»). 지운 숫자와 그 자리에 들어간 술어:

| 옛 단언(손 상수) | 새 단언(제품 역산) |
|---|---|
| `SUM_MAXLV === 25` | ⓑ1 `sumNeedExp(n) === SUM_EXP_A + SUM_EXP_B·n` **전 구간 Δ0** |
| — | ⓑ2 구(196) 곡선은 **이관 전용** — `SUM_MAXLV_V196 < SUM_MAXLV` · 표 16칸 · 산 곡선에 안 샌다 |
| `one === 76,450` | ⓑ3 누적 = 닫힌식 `A(M−1) + B·M(M−1)/2` (루프 합과 항등) |
| `all === 382,250` | ⓑ4 **199 과녁 268,000 ±1%** (아래 §5) |
| `'1,1,5,8,12,16'` | ⓒ1 6행 · **바닥 두 행 `unlock:1`** · 그 위 순증가 |
| `'…,20,24'` | ⓒ2 8행 = 6행+2 · **불멸 해금 = `SUM_MAXLV − 1`**(496 «만렙 직전 1레벨 램프» 규칙) |
| `Math.abs(immP − 0.001)` | ⓒ4 `IMMORTAL_P_MAX` 파생(115 규약) · 허용 오차도 목표치의 5% |

**③ 항등식 옆에 «그 자리에서만 참인 조항» 을 세웠다**(LESSONS **522-③**). 파생만 남기면
«그 절이 통째로 사라져도 초록» 이 된다. 그래서 ⓒ2 는 «8행 = 6행 + 2» 라는 항등식 옆에
**`불멸 unlock === SUM_MAXLV − 1`** 을 같이 세웠고, ⓒ1 은 «6행» 옆에 **바닥 두 행 = 1** 을 세웠다
