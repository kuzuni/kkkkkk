## 3. no-op 을 다시는 조용히 못 지나가게 — [전제] 한 줄

```
ok(T.miss.length === 0, '§2 [전제] 오늘 판에서 만질 자리를 구조로 캐냈다(글자 그대로 든 것 0개)')
```

이 수리의 **본체**다. 자리가 또 움직이면 치환이 no-op 이 되는 대신 **여기가 빨개지고
