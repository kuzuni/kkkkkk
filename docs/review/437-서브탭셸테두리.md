## 1회차 (2026-08-30, sess-0858-2521 워커 D) — 재현

### 1-1. 자를 먼저 검산했다 — «우리 캡처는 진실을 CSS 가 안다»

문턱 논쟁(«순검정 6 이냐 느슨 8 이냐»)을 말로 풀지 않고, **자 넷을 동시에 대고 우리 PNG 로 먼저 검산**했다.
우리 쪽 진실은 CSS 가 알고 있다 — `.stabs{border:6px}` · `.stab.on{box-shadow:inset 7px 0 0 #000}`.

| 자 | 무엇 | cap 셸(진실 6.00) | cap 알약(진실 7.00) |
|---|---|---|---|
| `pure` | 순검정 ≤4 런 (352 가 쓴 자) | 6.00 | 7.00 |
| `loose` | 느슨 ≤24 런 (352 가 기각한 자) | 6.00 | 7.00 |
| `x50` | 50% 교차 부분화소 (CV·CW 의 자) | 6.00 | 7.00 |
| `cov` | 커버리지 적분 (352 4회차 AW 의 자) | 6.00 | 7.01 |

**넷 다 오차 0.00~0.01 이다.** 우리 캡처는 PNG · DSF1 · 정수 좌표라 AA 가 아예 없어서 어떤 자를 대도 같은 값이 나온다.
⇒ **문턱 논쟁은 ref(JPEG) 쪽에서만 벌어진다.** 그러니 «어느 자가 옳으냐» 를 다투는 대신
**ref 를 색 분류(band map)로 갈라 읽어** 무엇이 무엇인지 이름을 붙였다.

### 1-2. ref 를 색으로 갈라 읽으면 문턱이 필요 없다

`.stabs` 세로 단면을 팔레트(K 검정 · B 베벨 #634F37 · F 채움 #4B3E2D · D 바닥띠 #413122 ·
R 림 #705F4B · S 셸바닥 #61523D · W 시트 바깥)로 분류한 것 — **07 스킬 시트, 활성 알약 «스킬» 열**:

```
ref x330  W..2019  R2020(1)  K2021..2027(7)  B2028..2034(7)  F2035..2097(63)
                   B2098..2102(5) S2103 F2104  D2105..2111(7)  K2112..2117(6)  F2118(1)  W2119..
cap x400  W..1960            K1961..1966(6)  B1967..1973(7)  F1974..(…)
                   B2038..2044(7)            D2045..2051(7)  K2052..2057(6)  W2058..
```

읽히는 대로 적으면 **ref 바 = K7 · [B7 F63 B7 D7] · K6(+AA)** 이다.

* **검정 테두리 = 7** (상 2021..2027 · 하 2112..2117 + AA 2118) — 우리는 **6**.
* **칸(패딩) 상자 = 84** (2028..2111 = 7+63+7+7) — 우리는 **85**.
* **바 바깥 = 98** (부분화소 50% 교차로 2020.24 ↔ 2118.27 = **98.02**) — 우리는 **97.00**.

세 값이 **서로를 검산한다**: 7 + 84 + 7 = 98. 우리 쪽도 6 + 85 + 6 = 97 로 닫혀 있다.
⇒ 등재문의 방향(**ref 가 우리보다 두껍다**)은 **맞다**. 다만 **값은 7.91 이 아니라 7** 이고,
그 대신 **바 바깥 높이가 97 이 아니라 98** 이라는 것이 같이 나왔다 — 셋은 한 덩어리다.

### 1-3. «7.91» 의 정체 — 활성 알약이 없는 열에서만 한 칸이 더 붙는다

같은 자(`cov`)를 열마다 대면 값이 **두 무리**로 갈린다:

| 자리 | ref 상 검정 | ref 하 검정 |
|---|---|---|
| 활성 알약이 닿는 열 (x400·x470) | **7.00** | 7.0 |
| 알약이 없는 열 (x150·x700) | **8.38** | **7.00** |

색 분류가 그 1.4 의 정체를 말한다 — 알약 없는 열은 `K2021..2028(8) S2029 R2030..2035(6)` 이고,
알약 열은 `K2021..2027(7) B2028…`. 즉 **2028 한 줄이 셸 안쪽의 어두운 립**이고, 활성 알약이 그 자리를 덮는다.
좌·우도 같다 — 직선 구간(y 2064..2074)에서:

| ref | 좌 | 우 | 활성 칸 |
|---|---|---|---|
| 06 장비 | **7.01** | 8.39 | 첫 칸 |
| 07 스킬 | 8.38 | 8.39 | 가운데 칸 |
| 23 훈련 | **7.00** | 8.39 | 첫 칸 |

**활성 알약이 닿는 면은 7.0 · 안 닿는 면은 8.4** — 세 화면·네 면이 예외 없이 이 규칙을 따른다
(378 이 «끝 칸이 활성이면 검정을 셸에 넘긴다» 로 적어 둔 것과 같은 자리다).
하변만 립이 없다(7.00).

⇒ **CV·CW 의 7.91 은 «7(테두리) + 1.4(안쪽 립)» 을 한 덩어리로 읽은 값**이고,
**352 의 «순검정 6» 은 ref 의 AA 한 줄을 통째로 버린 값**이다. 둘 다 반쪽이었다.

### 1-4. 등재문의 ⓑ(내부 일관성)는 **기각**된다

CV 의 논거는 «ref 안에서 셸 테두리 = 알약 좌우 검정인데 우리는 아니다» 였다. 재현 결과:

| | 셸 테두리 | 알약 좌 검정 | 비 |
|---|---|---|---|
| ref | **7.00** | **6.99** | **1.00** |
| cap | 6.00 | 7.00 | **0.86** |

ref 는 둘이 **같은 7** 이 맞다 — 그런데 **우리가 어긋난 이유는 알약이 두꺼워서가 아니라 셸이 얇아서**다.
알약 7 은 이미 ref 와 Δ0.01 이고(352 4회차가 세운 «7 규약»), 어긋난 것은 셸 6 하나다.
⇒ **알약을 건드리면 안 된다.** 등재문이 «둘 다 7.9» 라고 읽어 알약까지 올렸다면 그쪽이 Δ0.9 로 틀어졌을 것이다.

### 1-5. 세 화면 교차검증 (같은 부품 · 서로 다른 스크린샷)

`cov` 로 바 안쪽 전 열을 훑은 값(중앙값):

| ref | 상 | 하 |
|---|---|---|
| 06 장비 | 8.49 | 6.97 |
| 07 스킬 | 8.51 | 6.98 |
| 23 훈련 | 8.50 | 6.98 |

세 스크린샷이 **8.50 / 6.98 로 소수 둘째 자리까지 같다** — JPEG 개별 잡음이 아니다.

### 1-6. 처방

**`.stabs` 세 값을 한 덩어리로 옮긴다** — 셋 중 하나만 고치면 나머지 둘이 어긋난다.

| | 지금 | ref | 바꾼다 |
|---|---|---|---|
| 바 바깥 높이 | 97 | 98.02 | **98** |
| 검정 테두리 | 6 | 7.00 | **7** |
| 칸(패딩) 상자 | 85 | 84 | **84** |

⚑ **호스트 앵커가 이 처방을 공짜로 만든다** — 여섯 호스트 중 다섯이 `bottom:42px` 다.
바 하변(1960+98 = 2058)은 **Δ0** 이고 상변만 1961 → **1960** 으로 올라간다.
테두리가 6 → 7 이 되면서 **패딩 상자 상변은 1967 그대로**이고(1961+6 = 1960+7), 하변만 2052 → 2051 이다.
⇒ 알약 안 라벨·배지·구분선·`sk-lock` 은 **절대 좌표가 한 픽셀도 안 움직인다**(전부 패딩 상자 기준 top 앵커).
ref 대조: 바 바깥 상변 ref 2020.24 ↔ 우리 2020.00(캡처 1960) = **Δ0.24**(지금은 Δ0.74) ·
하변 ref 2118.27 ↔ 우리 2118.00 = **Δ0.27**.

**안 건드리는 것**: 알약 검정 7 · 알약 베벨 7 · `PILL_LIP 14` · 알약 반경 30 · 셸 반경 43 ·
`.stab-sep top:16` · `.stab>.bdg top:-6` · 라인하이트 87/77.
`.stab.on::before/::after` 의 띠는 **알약 자기 상자 기준**이라 84 로 줄어도 규약(0..7 · 77..84)이 자동으로 따라온다.

**곁다리로 나온 것(437 범위 밖 — 따로 등재)**: ⓐ 셸 안쪽 **1.4px 어두운 립**(상·좌·우, 하변 없음 —
활성 알약이 덮는 면만 없다) · ⓑ 바 바깥 **폭** ref 948.33 ↔ 우리 950.00(**+1.67**).
