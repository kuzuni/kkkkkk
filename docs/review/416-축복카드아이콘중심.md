## 2. 왜 «아트 몫» 으로 안 넘겼나 — 이 작업의 본체

등재문은 «ref 가 왜 카드1·2 만 오른쪽에 두는지 먼저 확인할 것 — 아트 실루엣의 여백 비대칭일 수
있고, 그렇다면 아트 몫이다» 로 닫혀 있었다. **판단은 저장소 안에 이미 있었다.**

1. **지시서 [3] «아트 자리 규칙»** — «이모지·CSS 작화로 대체한 요소는 **레퍼런스 bbox(w×h·중심)를
   정확히 차지**하게 만든다 — 나중에 이미지로 교체만 하면 되게.» 중심은 **규칙의 본문**이다.
2. **발주 bbox 는 «잉크» bbox 다**(측정표 34 §17-3 — ⚔️ 150×153 · ❤️ 145×154 · 🌀 132×156).
   즉 아트는 **잉크로 잘린 그림**으로 들어오고, 그 그림의 상자 중심 = ref 잉크 중심이다.
   그러므로 «ref 의 비대칭이 아트의 것인가» 는 **자리를 정하는 데 아무 것도 안 바꾼다** —
   어느 쪽이든 대체물이 앉을 자리는 ref 잉크 중심이다.
3. **선례가 같은 측정표 안에 있다** — §17-4 의 보너스 바를 356 6회차가 `T = C − B − s·(N − B)` 로
   **잉크 중심을 ref 잉크 중심에 얹었고**, 발주표에 «115×117 **@중심 (195, 1332)**» 로 적어 뒀다.
   416 은 그 선례를 카드 3장에 편 것뿐이다.

⇒ 그래서 **아트 대기로 미루지 않고 대체물을 옮겼고**, 발주표에 쓸 «@중심» 세 값을 측정표
**§17-7** 에 적었다(§17-3 의 발주 bbox 는 한 줄도 안 바뀐다).

## 3. 처방 — 이동 3줄, 배율 0줄

```
#blsC_atk  .ic{transform:translate(6px,-1.5px) scale(.9745)}
#blsC_hp   .ic{transform:translate(4px,-2px)   scale(1.0694)}
#blsC_rate .ic{transform:translate(0,-4px)     scale(.9936)}
```

- **값은 위 표의 Δ(ref − 우리) 그대로다** — 손으로 고른 수가 아니다.
- **`translate` 는 `scale` «앞» 이다.** 최종 행렬이 T·S 라 px 값에 배율이 안 곱해진다.
  뒤에 적으면(`scale() translate()`) 카드2 는 1.0694 가 곱해져 +4 가 **+4.28** 로 들어간다.
  `verify416` [1] 이 **곱해진 뒤의 e·f** 를 재므로 순서를 뒤집으면 그 자리에서 빨개진다.
- **공용 `top:21px` 은 안 건드렸다** — 상자(=발주 자리)는 카드 폭 전체로 두고 옮긴 것은 잉크뿐이다.

### 왜 «세로만 공용 −2»(등재문 권고)로 안 갔나

등재문은 «세로는 공용 `top` 을 −2 하면 셋 다 좋아진다(−0.5 / 0 / +2)» 고 적었다.
그것은 **세로 잔차를 남기고**(카드3 +2) **가로를 하나도 안 닫는다**(−6 / −4).
카드별 규칙이 **이미 셋 다 있으므로**(394 의 배율) 새 규칙을 만들 필요 없이 같은 줄에
이동을 붙이면 두 축이 **동시에** 닫힌다. 그 차이를 게이트 **[R2]** 가 못박는다 —
공용 −2 만 심으면 `atk (−6, −0.5) · hp (−4, 0) · rate (0, +2)` 로 **세 장이 다 빨갛다**.

## 7. 남기는 것

- **«어느 축인가» 를 먼저 적어라** — 394 와 416 은 **같은 세 노드**를 고쳤지만 축이 다르다
  (크기 ↔ 위치). 축이 직교하면 두 작업은 서로의 게이트를 **무수정으로** 통과한다.
  통과 못 하면 축을 잘못 갈랐다는 뜻이다.
- **«아트 몫인가» 는 «중심» 에는 안 묻는다** — 종횡(§17-3)은 아트 교체로만 닫히지만 **자리**는
  대체물을 옮기면 닫히고, 발주 bbox 가 잉크 bbox 인 한 옮긴 자리가 곧 아트가 앉을 자리다.
  묻는 것이 옳은 자리는 «**크기·종횡**» 이지 «중심» 이 아니다.
- **`transform` 목록의 순서는 값이다** — `translate() scale()` ↔ `scale() translate()` 는 다른 결과다.
  자를 «선언 문자열» 이 아니라 **computed matrix 의 e·f** 에 걸면 순서 실수가 그 자리에서 잡힌다.
- **«모여 있다» 와 «맞다» 를 한 항으로 묻지 마라** — 수리 전 우리는 세로 중심 span 이 **1.0** 으로
  ref(2.5)보다 오히려 고왔지만 **자리가 3~4px 아래**였다. 군집만 재는 자는 그 상태를 초록으로 부른다.
