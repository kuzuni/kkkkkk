### 2-4. 발화 지점 — 성공한 시전에만

`castSkill` 을 **한 겹 감쌌다**. 기존 본문은 `castSkillRaw` 로 이름만 바뀌었고(내용 무변경),
바깥 `castSkill` 이 «성공(true)일 때만» `sfxCast(s.id)` 를 부른다. 86 의 `castGeneric` 으로 떨어지는
신설 11종도 같은 지점을 지나므로 분기마다 손댈 필요가 없었다.

```js
function castSkill(s){
  const ok = castSkillRaw(s);
  if(ok) sfxCast(s.id);     /* 대상 없음·버프 중복이면 false → 무음 */
  return ok;
}
```

### 2-5. 소음 대책 (지시서 ④)

8칸이 동시에 쿨을 돌리므로 **두 겹**으로 막는다.

1. 이름별 디바운스 — 기존 `sfx()` 안의 `AU_MIN_DEF` 30ms.
2. **계열 무관 공용 최소 간격 `SK_SFX_GAP = 90ms`** — `sfxCast` 가 `skSfxLast` 하나로 전 계열을 함께 게이트한다.
   이론 상한 11.1회/s, 실측 **1.22회/s**(전투 60초, verify99 §E).
3. 게인 0.296~0.326 → 최종 −26 dBFS (전투 반복음 `hit`·`coin`·`clear` 와 같은 레벨).

## 4. 게이트를 손본 곳 (78·98 회귀 유지)

두 게이트가 **SFX 20종을 하드코딩**하고 있어 27종이 되면 무조건 실패한다. 값을 소스에서 읽도록 바꿨다.

- `tools/verify78.js` — `SFX_N` 을 `index.html` 의 `AU_SFX` 길이에서 뽑는다(파일 수 = SFX×2 + BGM 2,
  버퍼 수, `<audio>` 요소 수 전부 연동). 하드코딩 «20/22» 제거.
- `tools/verify98.js` — 목표표 `TARGET` 에 시전음 7종을 **−26**(전투 반복음)으로 추가하고,
  §C의 SFX 평균에서 빼는 `LOOP` 목록에도 넣었다(반복음이 평균을 끌어내려 BGM 여유를 왜곡한다).
- `tools/verify98.js` §D의 «createGain 호출 수 == SFX 수» 는 **99 이후 결정적이지 않다** —
  루프 사이 `await` 구간에 전투가 시전음을 스스로 울려 +1 이 섞인다(실측 28 vs 27).
  «최소 개수 ≥» 로 완화하고, 정확히 1개인지는 **끼어들 수 없는 동기 단일 호출**로 따로 본다.
  (같은 비결정성을 93 작업자도 독립적으로 만나 ≥ 로 고쳤다 — rebase 에서 양쪽을 합쳤다.)
