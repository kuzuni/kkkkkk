## 2. 수정 — «상한 + 본문 뷰포트» 2단

지시서 규칙 그대로: `max-height = frameH − 104 − 180`, 넘치는 만큼은 **본문만 내부 스크롤**,
헤더·서브탭 바는 고정, 폭·가로 규격 불변.

### (1) 공통 뷰포트 `.shsc` 신설

```css
.shsc{position:absolute;left:0;right:0;overflow-x:hidden;overflow-y:auto;
  overscroll-behavior:contain;scrollbar-width:none}
.shsc::-webkit-scrollbar{width:0;height:0}
.shsc-in{position:relative;width:100%}
```

- 뷰포트를 **헤더·서브탭 바의 «형제»** 로 두는 게 핵심이다. 그래야 시트가 접혀도 둘은 안 움직인다.
- `.shsc-in` 높이 = **본문 콘텐츠의 마지막 bottom**. 9:16 에서는 뷰포트가 항상 그보다 커서
  **스크롤이 아예 안 걸린다 → 세로 폰 회귀 0**.
- 자식 좌표는 **시트 local 을 그대로** 쓴다(측정값 재계산 없음). 뷰포트를 시트 `top:0` 에서
  시작시키고 헤더를 `z-index` 로 위에 얹어, 스크롤된 본문이 헤더 «뒤로» 지나가게 했다.

### (2) 시트별 적용

| 시트 | 상한 | 뷰포트 | `.shsc-in` | 서브탭 재앵커 |
|---|---|---|---|---|
| `#panel`(스킬·동료·기본) | `max-height:calc(100% - 284px)` | `top:0;bottom:140px` | 1289 | `.sk-tabs` `top:1337` → `bottom:41` |
| `.eqp`(장비) | `max-height:calc(100% - 104px)` | `top:0;bottom:140px` | 1418 | `.eqtb` `top:1444` → `bottom:43` |
| `.tr-sheet`(훈련) | `max-height:calc(100% - 104px)` | — (안 걸림) | — | — |

- `#panel` 은 `#app`(=frameH) 기준 absolute + `bottom:180` 이므로 `100% − 284px` 가 곧 상한이다.
- `.eqp`·`.tr-sheet` 는 `#eqw`·`#trw`(둘 다 `top:0;bottom:180`) 기준이라 `100%` 가 이미
  `frameH − 180` 이다 → `100% − 104px` 가 상한.
- `.eqp-bd`(크림 면) 는 `height:1465` → **`bottom:1px`** 로 바꿔 시트가 접혀도 서브탭 뒤까지 채운다
  (1584 에서 118..1583 = h1465 로 종전과 Δ0).
- `.tr-sheet` 는 상한만 걸었다. 시트 1245 가 최저 상한 1316 보다 작아 **오늘은 발동하지 않는다.**
  시트가 1316 을 넘게 커지면 06·07 처럼 `.shsc` 를 넣어야 한다 — 그냥 두면 서브탭 바가 잘린다(주석에 명기).

### (3) 잡은 함정 3개 — 다른 화면에서도 그대로 재발한다

1. **`부모>*{position:absolute}` 규칙은 래퍼를 끼우는 순간 죽는다.** `.eqp>*` · `:is(#bSk,#bPet)>*`
   에 의존해 `position` 을 안 적은 자식들(`.eqc`·`.eqc-fr`·`.eqc-hl`·`#eqCards`·`.sk-gp` …)이
   래퍼 안으로 들어가면 **전부 static 이 되어 좌표가 통째로 무너진다.**
   → `.eqp>*,.eqp .shsc-in>*{position:absolute}` 처럼 래퍼 안쪽도 같이 적을 것.
2. **`setBody()` 는 `el.scrollTop` 만 살린다 — 뷰포트가 innerHTML 안에 있으면 매 재렌더마다 맨 위로 튄다.**
   `renderUI()` 는 골드가 늘 때마다 `renderSkill()`/`renderPet()` 을 돌려 시트를 통째로 다시 그린다.
   처음 구현에서 스크롤이 0.7초 만에 되돌아갔다. `setBody()` 가 `.shsc` 의 `scrollTop` 도 옮겨 심게 고쳤다.
3. **`.sk-head` 는 `#bSk`·`#bPet` 양쪽에 있다.** 검증 스크립트가 `document.querySelector('.sk-head')`
   로 잡으면 문서 순서상 앞선 «숨은» `#bSk` 쪽이 걸려 좌표가 전부 0 으로 나온다(동료 시트 오탐 1건).
   → 시트 검증 셀렉터는 반드시 `#bPet .sk-head` 처럼 스코프를 줄 것.
