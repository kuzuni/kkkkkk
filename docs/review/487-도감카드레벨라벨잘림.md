## 3. 고른 것 — 넘칠 때만 그 문자열을 줄인다

**부품을 새로 만들지 않았다.** 같은 화면의 452 가 같은 종류의 문제(효과문이 [강화] 버튼을
파고듦)에 이미 `fitNum(el, maxW)` 을 쓰고 있다 — `collFitEff()` 바로 옆에 형제 하나를 세웠다.

```js
function collFitLv(){                       /* index.html — collFitEff() 다음 */
  document.querySelectorAll('#collList .clb .cd').forEach(cd => {
    ...
    const bd = parseFloat(cs.borderLeftWidth) || 0;      /* 카드 테두리를 좌우 여백의 거울로 */
    const sw = parseFloat(getComputedStyle(el).webkitTextStrokeWidth) || 0;
    const room = (cd.clientWidth - bd * 2 - sw) * sc;
    if(room > 0) fitNum(el, room);
  });
}
```

호출은 `collFitEff()` 가 불리는 **같은 두 자리**(`renderColl21()` 끝 · `openColl21()`)다 —
452 주석이 적어 둔 이유(숨은 채로 그리면 잴 것이 0 이라 보이게 만든 «뒤» 에 한 번 더)가
그대로 적용된다.

⚑ **방(room)도 상수가 아니라 카드에게 묻는다**(368 처방). 새 상수 **0개** —
클라이언트 폭(111)에서 **카드 자신의 테두리 두께**(5)를 좌우 거울로 빼고,
`-webkit-text-stroke` 가 Range bbox 밖으로 나가는 몫(sw = 5)을 마저 뺀다(340 교훈:
사람이 보는 것은 레이아웃 상자가 아니라 잉크다). ⇒ 방 96 · 잉크 상한 101 · 여백 5/5.

**수리 후 30/30 초록**이고, 등재문이 요구한 통과선(좌우 ≥ 2px)에 **최소 5.0px** 로 닿는다.
