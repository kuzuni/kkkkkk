## §6 교훈

1. **`revert` 는 «작업 단위» 를 모른다.** 409 는 CSS 훅 여섯 개짜리 작업인데 되돌림이 훅 20개를

2. **`smoke` 는 «없어진 기능» 을 못 본다.** 앱이 도는 한 PASS 다. 되돌림·병합 뒤에는
   **그 자리의 자를 직접 돌려야** 한다 — 이번에 빨간 것을 찾아낸 것은 smoke 가 아니라
   `verify351` 이 84/86 으로 내려앉은 것이었다(17회차 세션의 곁다리 관측).
3. **이관 항이 상수로 서 있으면 복구가 저절로 검산된다.** `verify351` [9-i]·[9-k] 는 451 값을
