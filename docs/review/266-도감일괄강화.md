## 1. 지시 원문

> 도감에 강화할 게 생기면 일괄강화 버튼이 탭들 위에 가운데에 생기게. 적당히 큰 크기로.
> 무기 탭 클릭해서 일괄강화 누르고, 펫 탭 클릭하고 일괄강화 누르고 그런 느낌.

## 2. ⚑ 등재문이 갈라 놓은 갈림길 — «일괄 강화» 가 무엇을 강화하는가

등재문(PROGRESS 266)은 **표시 조건**과 **동작**을 서로 다른 축에서 적어 놓았고, 그 둘이 함께
설 수 없다. 이 작업의 실질은 여기를 확정한 것이다.

| | 표시 조건 (등재문) | 동작 (등재문) |
|---|---|---|
| 적힌 것 | `collTabReady(tab)` — «그 탭에 강화 가능한 **세트**가 있다» · «새 판정 만들지 말 것» | `levelUpAll(list)` → 09 일괄 강화 결과 팝업 — «그 카테고리 **아이템**을 조각으로 레벨업» |

두 축이 다르다. `collTabReady` 는 **`collStep < collCap`**(= 세트 단계를 받을 수 있다) 이고,
`levelUpAll` 은 **조각으로 아이템 Lv 를 올리는** 완전히 다른 자원·판정이다.
등재문대로 둘을 붙이면 **버튼이 자기 조건을 해소하지 못한다** — 아이템을 아무리 레벨업해도
`collStep` 은 그대로라 조건이 계속 참이고, 버튼은 한 번 뜨면 영영 안 사라진다.
지시의 «강화할 게 **생기면** 생기게» 와 정면으로 어긋난다.

**확정: 「도감의 강화」 = 세트 블록의 `[강화]`(= `claimColl`) 다.** 근거 4개 —

1. **화면 안의 «강화» 가 그것뿐이다.** 21 도감에서 «강화» 라는 글자를 달고 있는 것은 세트 블록의
   `.clb-btn` 뿐이고(`renderColl21` — 라벨 `강화`/`MAX`), 그 통보도 «… 도감 **n단계 강화**!» 다.
   조각 레벨업(`levelUpAll`)은 06·07·26 시트의 일이고 도감 화면에는 **입구조차 없다**.
2. **등재문이 스스로 못 박은 표시 조건이 이쪽 축이다.** «`collTabReady` 를 그대로 쓰면 된다 ·
   새 판정 만들지 말 것» 은 «누르면 조건이 꺼진다» 를 전제해야 성립한다.
3. **`claimColl` 은 «한 번에 한 단계» 다**(91 이 그렇게 만들었다). 세트 8개가 각 6단계 밀려 있으면
   **48번** 눌러야 한다 — 지시가 없애려는 마찰이 정확히 이것이다.
4. **탭 6개 전부에서 성립한다.** `levelUpAll` 축은 유물 탭에 대응하는 일괄 강화 목록 자체가 없다.

**뒤집는 법**(주인 판단이 반대일 경우): `collUpAll()` 의 몸통을
`const r = levelUpAll(COLL_SETS.filter(st=>st.tab===collTab).flatMap(st=>st.it.map(itemById)));
if(!openUpAll(r.ups)) notify(...)` 로 갈고, 표시 조건을 `collTabReady` → «그 탭에 조각으로 올릴
아이템이 있나»(`canLevel` 계열) 로 **같이** 바꾼다. **둘 중 하나만 바꾸면 위의 «안 꺼지는 버튼»
상태로 돌아간다** — 조건과 동작은 한 몸이다.

## 4. 배치 — «탭들 위에 가운데», 적당히 큰 크기

21 도감의 탭(`.cl-tabs`)은 **모달 밑에서 돌출하는 깃발 서브탭**(`bottom:-154px`)이다.
따라서 «탭들 위» = **모달 바닥 안쪽**이고, 버튼은 목록 위에 떠 있는 형태가 된다.

|---|---|---|
| 부품 | `.ifbtn`(104 공용 베벨 버튼) | 22 `[모두 받기]`·69 `[전체 받기]` 와 **같은 부품** — 243 통일 기준 |
| 높이 · 폰트 · 테두리 · 라운드 | 130 · 46.6px · `--gb-bw:7px` · 43px | 22 `.qs-all` 그대로 (한 값도 새로 만들지 않음) |
| 폭 | **380** | 워스트 라벨 «일괄 강화 (80)» 라벨 박스 실측 **264.9** + 22 의 라벨 여백(272−160 = 좌우 56) = 377 → 한 눈금 올려 380 |
| left | **252.5** | `.cl` padding-box 폭 885 → (885−380)/2. 실측 버튼 중심 **cx 540.0 = 프레임 중심** |

«탭 최대 단계 합» 이 80 인 근거: 한 탭 최대 세트 수 8(등급 8) × `COLL_MAX_STEP` 10.
