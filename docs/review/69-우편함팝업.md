레퍼런스에서 **그대로 살린 구성**:

- 카드 좌단 **세로 악센트 밴드 25px** — ref 에선 읽음 마커지만 우리 게임엔 읽음 개념이 없어 **수령 여부** 마커로 전용

- ✕ 가 아래로 떨어져 있지 않고 **바닥 테두리에 걸침**

**1회차 채점 — A ①7 ②7 ③6 ④7 → 6 / B ①7 ②7 ③6 ④9 → 6** (⑤ 6·6 · ⑥ 4·6)

두 비평가가 **독립적으로 같은 1순위**를 냈다 — 그리고 그것은 요소별 bbox 채점으로는 안 보이는 것이었다:

> **«licensed 된 +30px 이 리스트 패널이 아니라 푸터 아래 사공간으로 갔다.»**
> B 의 밴드 예산표가 이걸 한 줄로 보여 준다: 패널 바닥·안내 1줄·버튼 바닥까지 **모든 랜드마크가 환산
> 레퍼런스와 ±9px 안에** 들어오는데, 상자 바닥만 +30.7 이다. 즉 «상자를 30px 키운 이유»(5행을 담기 위해)가
> 정작 패널에는 안 갔고 버튼 아래 빈 공기로 빠졌다. 패널은 851 로 목표 890.5 보다 **−39.7** 이었다.

A 가 잡은 것 중 B 가 못 본 것: 제목↔초록요약 **간격 3px(목표 10)** — 제목 글자 +13% 와 외곽선 +67% 가
아래 줄을 밀어붙여 두 줄이 한 덩어리로 붙어 보였다. 팝업이 화면 중심보다 **40.5px 위**에 있던 것도 A 만 잡았다
(✕ 를 세로 플렉스 항목으로 붙이면서 그 높이만큼 그룹 중심이 밀린 것).
B 가 잡은 것 중 A 가 못 본 것: 레퍼런스 카드에 **검정 테두리 6px·상단 베벨 5px·패널 인셋 룰 5px** 3겹이
있는데 우리는 **전부 없이 «틴트 계단» 하나**로 행을 나누고 있었다. 그리고 레퍼런스 패널은 마지막 행 아래에
**0.215 pitch 의 슬랙**을 남기는데 우리 패널은 5행에 딱 맞춰 잘려 있었다(6번째 우편이 «스크롤» 이 아니라
«넘침» 으로 보인다).

## 4. 함정 기록 (다른 화면에서도 재발한다)

1. **`.mbox{overflow:hidden}` 안에는 «상자 밖으로 나가는 요소» 를 둘 수 없다.**
   ✕ 는 팝업 바닥 테두리에 걸쳐야 하는데 `.mbody` 안에 두면 잘리고, 헤더 라운드를 살리려면 그 클립을
   풀 수도 없다. → `#modal.ml69{flex-direction:column}` 으로 돌려 **`.mbox` 의 형제**로 두고
   `margin-top:-58px`(지름의 절반)로 겹쳤다. 21 도감의 깃발탭(모달 «밑으로» 돌출)과 같은 문제, 다른 해법이다.
2. **`fmt()` 는 1000 이상을 «3.00K» 로 접는다.** 수량 검증에서 숫자만 발라내 비교했다가
   `3000 → "300"` 이 되어 회귀가 오탐으로 떴다. 표기 문자열은 `fmt()` 를 통해 비교할 것.
3. **A5 공용 override 클래스는 «끄는 자리» 가 3곳이다** — `showModal()` · `closeModal()` · 각 전용
   오프너(`openQuest` 등). 하나라도 빠뜨리면 다음에 여는 모달에 남는다. `ml69` 를 세 곳 전부에 추가했고,
   회귀 검사(퀘스트 전환 · 공용 `popup()` 전환)를 게이트에 넣었다.
4. **`box-shadow` 로 그린 «바깥» 링은 부모의 `overflow:hidden` 에 조용히 잘린다 — 그리고 bbox 채점에
   절대 안 잡힌다.** 5회차에 잡은 F 의 1순위가 이것이다. `box-shadow` 는 요소의 `getBoundingClientRect()`
   에 포함되지 않으므로 **DOM 게이트도, 비평가의 요소별 bbox 스캔도 «링이 U자» 라는 걸 못 본다.**
   → 바깥 링을 쓰면 **부모 안쪽 여유 ≥ 링 두께**를 회귀로 못박아라(`verify69.js` 에 추가했다).
5. **밝은 링·어두운 링은 «색» 이 아니라 «극성» 이다.** 같은 `#A1815B` 링이 레퍼런스의 어두운 프레임 위에서는
   캐치라이트(+37L)인데 우리 크림 본문 위에서는 두 번째 다크 스트로크(−87L)로 읽힌다. 레퍼런스에서 색을
   그대로 떠 오면 **대비 부호가 뒤집힌다** — 배경 대비 ΔL 을 보고 옮길 것.
6. **비평가 둘이 같은 글자를 정반대로 지적하면 «코어 vs 외곽선 포함» 마스크 차이다.** 폰트를 키우고
   스트로크를 그만큼 줄이면 둘을 동시에 만족시킨다(LESSONS 16-② · 20-⑤ 의 재현).
7. **`claimAllMail()` 이 `popup()` 으로 자기 화면을 덮고 있었다.** 리스트가 수령 상태를 그대로 보여 주는
   화면에서는 결과 모달이 오히려 화면을 가린다 → 토스트 + 재렌더로 바꿨다(회귀 검사에 포함).
