## 2. 처방 — 허용 오차가 아니라 «자를 좁힌다» (334 처방 ① vs ②)

등재문의 ⚠ 를 그대로 지켰다: **«허용 오차 ≤4» 로 풀면 «출석이 골드를 준다» 가 통째로 통과한다.**
대신 두 겹으로 다시 쟀다.

- **ⓐ 동기 창** — `click()` 디스패치는 동기라 `claimAttend → giveReward` 가 **한 태스크 안에서** 끝난다.
  같은 태스크에는 rAF 콜백(`step`)이 끼어들 수 없으므로 그 안의 차분은 «출석이 준 것» 뿐이다.
  ```js
  const sync = await p.evaluate(() => {
    const g0 = S.gold, r0 = S.relic, d0 = S.dia;
    document.querySelector('#mbox [data-att]').click();
    return { dg: +(S.gold - g0).toFixed(3), dr: S.relic - r0, dd: S.dia - d0 };
  });
  ```
- **ⓑ 귀속** — 그래도 «비동기로 주는 경로»(setTimeout·연출 콜백)가 새로 생길 수 있으니, **420ms 창 전체**의
  `S.gold` 변화를 **스택째** 기록해 `claimAttend`/`giveReward` 를 지나는 몫이 **0** 임을 단언한다.
  창 전체 Δ 는 0 이 아니어도 된다(전투 몫) — 자는 이제 **«얼마나 늘었나» 가 아니라 «누가 늘렸나»** 를 묻는다.

**유물조각은 창 전체로도 그대로 0 을 요구한다**(전투가 안 주는 재화라 좁힐 이유가 없다).

### 감시자 구현에서 걸린 함정 하나

`S.gold` 를 `Object.defineProperty` 로 갈아 끼울 때 **`enumerable:true` 는 선택이 아니다** —
`save()` 가 `JSON.stringify(S)` 라 기본값(false)으로 두면 **세이브에서 골드 키가 통째로 사라져**
§3 «새로고침 후에도 유지» 가 즉시 빨개진다. 자 안에 그대로 주석으로 못박아 뒀다.
