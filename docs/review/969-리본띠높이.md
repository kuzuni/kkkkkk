### §2-1 ⚑⚑ 재현이 등재문보다 한 겹 아래를 찍었다 — **결손은 «테» 다**

사다리는 리본 한 장을 **네 칸**(바깥 윗변 · 안쪽 윗변 · 안쪽 아랫변 · 바깥 아랫변)으로 찍는다.
그 넷으로 띠를 셋으로 가르면 등재문의 «1.06 짧다» 가 어디서 오는지가 한 번에 나온다:

| | 테(위) | 속(빨강) | 테(아래) | 총 |
|---|---|---|---|---|
| ref 리본1 | 8.67 | 60.22 | 8.23 | **77.12** |
| ref 리본2 | 8.61 | 59.60 | 8.90 | **77.11** |
| 우리(수리 전 · 두 줄 같다) | **7.97** | 60.81 | **8.27** | 76.05 |

**속은 처음부터 맞아 있었고**(60.81 ↔ ref 59.91 평균) 모자란 것은 **테 두 겹**이다(각 −0.48 ⇒ 합 −0.96 ≈ 1.06).
⇒ 여기서 **높이 한 값만 올리면 안 된다**: 총 높이는 `height` 가 정하고 검정은 그 «안쪽» 에 그려지므로,
76 → 77 만 하면 늘어난 1px 이 통째로 **속**으로 가서 속이 60.81 → 61.8 이 된다(ref 59.91 에서 더 멀어진다).

⚑ **76 이 «8 + 60 + 8» 로 667 [G7b] 의 «속 60» 과 맞아떨어져 보였던 것은 상쇄였다** —
테가 얇은 만큼 총 높이가 짧아 속이 제자리로 보였다. 총 높이를 닫는 순간 그 상쇄가 풀린다.
(실제로 높이만 77 로 올린 중간 상태에서 [G7b] 는 **61 vs 과녁 60 · 대역 ±1** = 대역 끝에서 겨우 초록이었다.)

## §3 수리 — 제품 `index.html` **두 값 + 사본 하나 삭제**

```
  .pvc>.rb{ height: 76 → 77px ;  box-shadow: inset 0 0 0 2 → 2.5px #000 }
  .pvc>.rb::before{ top/bottom: 2 → 2.5px }        (규약: 캡은 «inset 두께만큼» 물린다)
  .pvc>.rb2::after,.pvc.ban1>.rb1::after{ height:76px → top:-6px;bottom:-6px }   ← 손 상수 삭제
  .pvc.ban1>.rb2::after,.pvc.ban1>.rb1::after{ height:67px }                     ← 규칙째 삭제
```

`.pvc>.rb1{bottom:196}` · `.pvc>.rb2{bottom:62}` 는 **한 글자도 안 건드렸다** — 아랫변이 앵커이고
결손은 윗변에만 있었다. 검산: 273−77=196 · 139−77=62 (두 값이 안 바뀌는 것이 그 증거다).

### §3-1 제비꼬리 — **높이 손 상수 둘을 지웠다**(402 «사본을 지운다»)

제비꼬리는 «리본 상자를 그대로 덮는 것» 이 뜻인데 높이를 `76px`(불릿) + `67px`(배너)로 **두 번 더**
적어 두고 있었다. 969 가 띠를 77 로 올린 순간 그 사본이 1px 모자라 꼬리가 띠보다 짧아진다 —
**부패가 이번에 실제로 발화하는 자리**였다. `top:-6px;bottom:-6px`(테 6 을 위·아래로 되짚어 테두리 상자를
덮는다)로 바꿔 두 형이 자기 띠를 따라오게 했다. 배너는 여전히 67 · 불릿은 77 · 배너 픽셀 **Δ0**.
되돌림 시험 `[R2]` 가 옛 손 상수를 되먹여 **배너 꼬리가 자기 띠보다 9px 길어지는 것**을 찍는다.

### §3-2 딸린 넷은 «따라온다» — 위임 규약 채택

등재문의 ⓒ 대로 크림 캡(`::before` 는 top/bottom 이라 늘어난다) · 제비꼬리 · 금색 판(`>b{top:-19}`) ·
라벨·수량 잉크가 **띠와 같이 1px 올라간다**. 이 넷의 **세로** 자리를 못박은 자는 저장소에 하나도 없고
(전부 가로 축이다 — `verify833` [7-c][7-d][11-e] · `verify667` [F3][F4]), 넷 다 리본에 매달린 부품이라
띠를 따라가는 것이 이 부품의 규약이다. **되돌림은 값 하나**(77 → 76)다.
