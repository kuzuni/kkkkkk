## 5. ④ 라벨 — «단련 🪨 n pt»

```
'투자 ' + fmt(c) + ' pt'   →   '단련 ' + curIc('tstone', TR_CUR_PX) + fmt(c) + ' pt'
' (투자 n회)'              →   ' (단련 n회)'
```

- ⚠ **«pt» 는 안 지웠다.** 단련은 «단련석 → 포인트» **2단계**라(519 가 그 판정을 고쳤다) 버튼은
  «무엇을 쓰는가(🪨)» 와 «얼마를 쓰는가(n pt)» 를 **같이** 말해야 뜻이 산다.
- ⚠ **297 규약이 여기서 깨질 뻔했다** — `liveTemper()` 의 `put(row,'.tb i', x.btn)` 은 `textContent`
  경로였다. 라벨에 `<img>` 가 들어온 순간 홀드 중 첫 갱신에서 **태그가 글자로 찍힌다**. html 경로로
  바꿨고 `verify584` [6-b] 가 그 한 글자(`&lt;img`)를 직접 잡는다.
- ⚠ **폭**: 라벨이 아이콘 53 + 여백 6 만큼 길어져 `.tb` 300 은 `probe584` §E 스윕에서 **8자리부터**

  `right:26` 은 불변이라 우측 정렬(같은 행 `.tc` 축)은 그대로다. 좌변 632 ↔ `.td` 우변 586 = **46px**.
  577 이 [충전]에서 «자릿수는 상한이 없다» 를 배운 그 자를 착수 전에 이 자리에 먼저 댄 것이다.
