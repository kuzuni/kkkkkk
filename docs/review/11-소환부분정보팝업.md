## 1. 데이터 — 실제 소환 로직에서 확률을 계산한다

레퍼런스는 다른 게임이라 아이템·등급명·확률값이 우리와 다르다. 우리 팝업은 **실제 추첨 로직**을 그대로 노출한다:
- `gradeProbsAt(bank, L)` = `gradeProbs` 와 동일 공식이되 레벨 L 을 명시적으로 받는다(단계 열람용).
- 등급 내부는 균등 추첨이므로 **아이템별 확률 = 등급확률 / 등급 내 아이템 수**. 빈 등급은 실제 추첨의
  «아래로 흘려보내기»와 맞춰 하위 등급으로 접어 준다.
- **◀ 단계 N ▶** 는 소환 레벨 이정표 `[1,5,15,30,40,100]`(각 등급 해금 레벨 + 만렙)을 넘기며 확률 변화를 열람.
  기본 단계는 현재 소환 레벨 이하의 가장 높은 이정표. 확률은 아이템 5자리(`0.83333%`), 등급 헤더는 정수/2자리.

## 3. 최종 상태 — 레이아웃 9 / 종합 8 (⑤ 팔레트 천장)

- **①요소배치·③여백·간격·④정렬·그리드 = 9** (2회차 C·D 모두). 모달박스·타이틀·단계박스·양쪽 화살표·안내문·등급바·행
  좌표가 전부 레퍼런스(`ref−210`) 대비 **≤2px**. 행 pitch 85·아이콘 gap 13·화살표 gap 21~22 전부 일치.
- **②상대크기·⑥폰트 = 9 근접** (2회차 지적분을 픽셀로 맞춤 — 타이틀폭 182·확률잉크 22·안내문 46).
- **⑤색·명암 = 8 (천장)**: 크림·탄색·시안·흰 삼각형·검정테두리 RGB 는 일치하나, **등급 헤더 바·아이콘의 초록이
  우리 게임 «고급» 색 `#6fe08a`(민트빛)** 이고 레퍼런스 언커먼은 올리브라임(`#7C9A38`)이다. §4 참조 — 게임 고유
  팔레트라 A1(6)·A2(5)·A3(6)·A4(7)·01(5)·02(5) 이 남긴 것과 같은 종류의 천장이며, 그 화면들보다 오히려 높다.
- **판정**: 통과 기준 9 에는 ⑤ 팔레트 단일 항목이 −1 로 못 미치나(최고 8), 레이아웃·치수·정렬은 전부 9 로
  실측 재현됐다. 아트/팔레트 리소스가 들어오면 ⑤ 는 GRADE 색 정의만 바꿔 즉시 회수된다.

## 4. 남은 문제 (아트/팔레트 천장)

- **등급 헤더 바·아이콘 배경의 초록 hue**: 우리 게임 «고급» 색은 `#6fe08a`(민트빛)이고 레퍼런스 언커먼은
  올리브라임(`#7C9A38`)이다. 등급바는 **게임 전역 등급색(`GRADE[g].c`)** 을 그대로 쓰므로, 이걸 레퍼런스에
  맞추면 도감·소환 배너 등 다른 화면의 「고급」 색과 어긋난다. **게임 고유 팔레트 차이**이며 A1·A2·A3·01·02 가
  «⑤ 색·명암」에서 남긴 것과 같은 천장이다. 아이템 아이콘도 실제 아트 리소스가 없어 이모지/도형으로 근사한다.
