## 2. 처방 — 새 기계를 안 만들었다

발원을 **가격바 유물화폐 아이콘**(`#rwCost [data-cur-slot]`) 중심으로 묶었다.
666 이 주인에게서 받은 문장이 «유물 소환 버튼에서 **유물화폐 아이콘** 파티클» 이므로
이것은 새 설계가 아니라 **규약 위반의 수리**다(대조 — 838 씬 A 훈련 골드는 같은 계측이 0.095배).

```js
function rwPayFrom(){
  const c = $('rwCost'), ic = c && c.querySelector('[data-cur-slot]');
  return (ic ? fxPt(ic) : null) || fxPt($('rwBasin'));
}
```

⚑ **838 2회차의 `--burst-from`(발원 = 신고한 자식의 중심)과 같은 뜻**이고 공용 부품(`fxBurst`)은
**한 글자도 안 건드렸다.** 그 신고를 그대로 못 쓴 이유는 하나다 — `fxBurst` 는 `t.querySelector`
로 **호스트 안**만 보는데, 이 화면의 가격 알약은 `#rwBasin` 의 **형제**다(120 이 `.rw-mid` 로 묶어
둔 두 덩이). 그래서 같은 산수(«자식 중심 · 없으면 호스트 중심» — 부품 자신의 폴백까지 같다)를
이 자리에서 적었다.

### 2-1. `RW_FX_Y` 는 선언째 걷었다 (죽은 코드 금지 — 295-②·399·460)

666 3회차가 «발원점을 그릇 아가리로»(상자 높이의 28%) 올린 이유는 **라벨 잉크와 비용 알약을
밟지 않게** 하려는 것이었다. 그 이유는 이제 **4회차의 상향 반구가 구조로 지킨다** — 아래로 가는
알이 0 이라 발원 «아래» 인 가격 알약은 한 알도 안 지나고, 위로 나는 알은 3회차 시절과 같은 곳
(라벨 위)을 지난다. 값이 쓰이지 않으므로 `const RW_FX_Y` 는 지웠다.
⚠ **3·4회차 머리말은 안 지웠다** — «왜 그 값이었나» 의 유일한 근거이고 되돌릴 때 읽을 자리다
(58·683 규약). 그래서 `verify666` [A3] 도 «글자가 없다» 가 아니라 **«`const` 선언이 없다»** 를 묻는다.

## 4. 이관 — 세 벌, 전부 «항을 지우지 않고 묻는 것을 갈았다»(333 처방)

### 4-1. `verify666` 32/32 → **34/34**

- **[A3] 갈아 끼움.** 종전 항은 발원을 «그릇 아가리(`RW_FX_Y`)» 로 **못 박고 있었다** — 즉
  **게이트가 규약 위반 쪽을 지키고 있었다.** 지금은 ① 발원을 손 상수가 아니라 가격바 화폐
  아이콘에서 읽는가 ② `PAY_CUR.relic` 로 터지는가 ③ `const RW_FX_Y` 가 없는가 를 묻는다.
- **[A3b] 신설(런타임 짝).** 선언만 물으면 «모양은 맞고 값은 딴 데» 를 못 잡는다.
  한 버스트의 알은 발원 한 점에서 갈라지므로 **«태생점 + 최종 방향» 직선까지의 수직거리**가
  전부 0 이어야 한다 — 실측 **최악 0.06px**(문턱 2px = `toFixed(1)` 반올림 한 칸).
  ⚑ 이 항을 짜면서 **자의 좌표계 함정** 하나를 잡았다: `rec.x/y` 는 append 순간의
  `getBoundingClientRect`(= `fxBurst` 가 링 위에 앉힌 **수리 전** 자리 · 뷰포트 좌표)이고,
  `rwSummonFx` 는 그 뒤 **같은 각으로 태생점을 옮겨 적는다**. 그 값으로 재면 발원이 맞아도
  **24.38px** 이 나온다(= r0·sin Δθ). ⇒ 최종 `left/top`(fx 좌표)을 `rec.lx/ly` 로 따로 남기고
  아이콘도 같은 좌표(`iconFx`)로 물었다. `rec.x/y` 는 [C1][C2][C4] 가 뷰포트 상자와 짝이라 그대로 뒀다.
- **[R4] 되돌림 신설.** 창에서 `rwPayFrom()` 만 990 이전 자리로 되돌리면 [A3b] 가 빨개진다 —
  실측 **123.18px**. 이 값이 등재문 DM 의 **124.6px** 과 1.1% 안에서 맞는 것이 이 회차의 가장
  짧은 검산이다(세 회차·네 사람·두 자가 같은 수를 냈다).

### 4-2. `verify880` 20/20 → **22/22** — ⚑ 이 회차의 핵심 이관

**[C5b]·[C6]·[R1]·[R1b] — «벽이 실제로 알을 잘랐는가» 를 묻는 네 항이 «잘린 알 0개» 로 빨개졌다.**
