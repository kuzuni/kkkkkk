## 2. 「연쇄인가 각각인가」 — 등재문이 1회차의 첫 일로 지목한 것

등재문의 경고: 세 항이 한 `b.click()` 을 공유하므로 앞 항이 던지면 뒤 둘이 같이 죽는다.
**연쇄가 아니라 각각이었다.** 같은 블록의 `diaUp`(수령 → 다이아 증가)이 **초록**이므로
클릭 자체는 성립했고, 세 항은 각자 다른 이유로 빨갛다:

| 항 | 자가 기대한 것 | 799 뒤의 실제 | 왜 빨간가 |
|---|---|---|---|
| `stepUp` | `S.quest.summon.s === s0 + 1` | `s` 가 **밀린 칸 수만큼** 오른다 | 표본이 `S.summons = 1e6` 이라 한 번에 66,666칸이 오른다 |
| `rebased` | `S.quest.summon.base === 1e6` | `base` 를 **아무도 안 읽고 안 쓴다** | 799 가 기준선을 선언째 없앴다 |
| `saved` | `raw.quest.summon.s === s0 + 1` | 저장값은 `s0 + 밀린 칸` | `stepUp` 과 같은 뿌리(값이 +1 이 아니다) |

즉 **제품은 옳고 자가 낡았다.** 799 행이 «이관 2종(`verify156`·`verify322`)» 이라고 적었는데
같은 축을 묻는 자가 **넷째로 `verify22` 가 있었다** — 22 는 «퀘스트 화면» 게이트라
799 의 이관 목록(«퀘스트 축» 게이트)에서 눈에 안 띈 자리다.

## 3. 처방 — 333 처방대로 **자리를 비우지 않고 방향을 뒤집었다**

지운 것은 «옛 축을 묻는 문장» 이고, 그 자리를 **799 가 실제로 약속한 것**이 대신한다.
표본은 `verify799` [C]·[E] 에서 옮겨 왔다(47 / 15 = 3칸 — 1e6 보다 사람이 읽을 수 있는 수다).

| 지운 항 | 갈아 끼운 항 | 무엇을 지키나 |
|---|---|---|
| — | **전제** 등차 첫 칸 목표 15 / 밀린 칸 3 | 표본이 «받을 수 있는 상태» 임을 먼저 못박는다 |
| `stepUp` (+1) | `stepJump` — 밀린 칸 3 개가 **한 번에** 오른다 | 799 ⚑ «한 번 누르면 밀린 칸을 전부» |
| — | `diaExact` — 보상 = **칸당 정액** × 3 | 799 «등차에서는 칸마다 보상이 같다»(등비 시절 `c0 + s·d` 로 되돌아가면 빨강) |
| — | `goalNext` — 다음 목표가 **등차**로 4번째 칸(60) | 목표 축이 등비로 되돌아가면 빨강 |
| — | `noMore` — 47 < 60 이라 더 받을 게 없다 | 「한 번에 전부」 가 과잉 지급이 아님(음성항) |
| `rebased` (기준선 재설정) | `progKept` — **수령해도 진행이 안 깎인다**(누적 절대값) | 옛 규칙이면 여기서 진행이 0 으로 떨어진다 = 주인이 본 «554 인데 35 가 안 열린다» |
| — | `baseIgnored` — 구 세이브의 `base` 키를 심어도 진행·목표 불변 | `S.quest[].base` 부활 감시(`verify799` [C] 표본 이관) |
| `saved` (s0+1) | `saved` — 저장값 `s0 + 3` | 같은 문장, 799 뒤의 정답으로 |

⚠ **표본을 1e6 → 47 로 줄인 것이 부수 효과가 아니라 처방의 일부다.** 1e6 은 밀린 칸이
66,666개라 «한 번에 전부» 가 맞는지 눈으로 읽을 수 없고, `S.quest.summon.s` 를 안 초기화하면
직전 절(탭 전환)이 남긴 상태에 따라 기대값이 흔들린다. 그래서 `S.summons = 47; S.quest.summon.s = 0`
으로 **두 축을 다 고정**했다.

## 4. 되돌림 시험 — 무르게 푼 수리가 아님을 두 겹으로 못박았다

제품 사본에 옛 규칙을 되살려 실제로 빨개지는지 직접 돌렸다(둘 다 확인 뒤 `index.html` 원복 — 커밋에는 없다).

  → `VERIFY22 FAIL 6건 / 71` : **`diaExact`·`stepJump`·`goalNext`·`noMore`·`saved`·`baseIgnored` 빨강**.

두 시험 모두 원복하면 71/71 로 돌아온다. **허용 오차·문턱은 한 칸도 안 넓혔다**(값 판정은 전부 등호다).
