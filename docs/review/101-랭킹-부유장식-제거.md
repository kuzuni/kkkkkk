## 5. 교훈 (LESSONS 로 옮김)

1. **«장식 제거» 지시는 «게이트 반전» 작업이다.** 지운 요소를 기대하던 검사가 두 파일에 흩어져 있었고
   (`verify54` GEO 4행 · `verify80` A2 «유지»), 둘 다 안 고쳤으면 다음 세션이 인계받자마자 FAIL 로 죽는다.
   제거 작업의 마지막 단계는 항상 `grep -n '<지운 셀렉터>' tools/*.js` 다.
2. **«존재하지 않음» 게이트는 고정 개수로 적지 마라.** 씬의 `<em>` 을 «3개» 로 박으면 방패가 늘 때 깨진다.
   `씬 em 수 == .rk-sh 수` 처럼 **DOM 끼리 비교**하면 장식이 다시 얹힐 때만 깨진다(LESSONS 52-⑤ 재적용).
3. **내 작업 때문에 깨진 게 아닌 FAIL 을 먼저 갈라내라.** `verify54` 의 3건은 `git stash` 로 원본을 되돌려
   같은 3건이 뜨는 것을 확인하고서야 «작업 80 이 남긴 낡은 검사» 로 판정했다. 확인 없이 기대값을 내 쪽으로
   맞췄으면 80 의 캔버스 규격을 무너뜨릴 뻔했다.
