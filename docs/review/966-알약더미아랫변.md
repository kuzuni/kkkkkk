### §2-3 ⚑⚑ 결손의 정체 — «앵커» 가 아니라 **«쌓임»**

등재문은 «알약 자체는 결백하다(±0.5 = 맞다)» 와 «더미 아랫변이 떴다» 를 나란히 적어 뒀는데,
**둘 다 참이고 그 둘이 같은 것**이다:

```
   알약 높이   −0.20(GZ·HA) / −0.24(probe966)   ×3
   사이 틈     −0.31        / −0.29             ×2
   ─────────────────────────────────────────────────
   합 3×0.2 + 2×0.3 ≈ 1.2 ~ 2.0 우리px  =  마지막 알약 아랫변 Δ
                                            (+1.62 GZ · +1.85 HA · +1.88~+2.48 probe966)
```

세 칸 모두 **±0.5 안**이지만 **부호가 셋 다 같아서** 더미 길이에 쌓인다.
⇒ 손잡이는 «앵커 한 곳» 이 아니라 **그 세 칸**이고, 그것이 곧 등재문의 «아래 여백» 이다
(윗변을 고정한 채 더미가 아래로 더 닿게 한다).

### §2-4 «얼마나» — 사다리가 스스로 답한다

우리에게 쓸 수 있는 세로 공간은 **밴드 아랫변 → 리본1 윗변 = 306.72 우리px** 이고,
ref 의 «자기 성분으로 3알약을 쌓았을 때» 필요한 길이는

```
   22.10(밴드↔p1) + 3×72.39(높이) + 2×9.97(사이 틈) + 45.52(틈) = 304.73
```

**차이 = 1.99 우리px.** 이것이 «어디엔가 반드시 남는 여분» 이고, 그 여분이 지금은 **전부 틈에**
쌓여 있다. ⇒ **2.00 을 알약 더미가 흡수하게 한다.**

## §4 ⚠⚠ 틈은 여기서 다 안 닫힌다 — 그리고 **그게 맞다**

