### 3-1. 사본을 만드는 법 — «주입» 이 아니라 «인자 하나»

`verify683` 이 `labelShot(…, noKeep)` 에서 쓰는 것과 **글자 하나까지 같은 방법**이다:

```js
if (NOKEEP) { window.__p788ff = window.fxFlash;
  window.fxFlash = function (el, iv, inset) { return window.__p788ff.call(this, el, iv, inset); }; }
```

803-③(«미는 값이 실험 조건이면 주입하지 마라»)이 경고한 자리가 아니다 — 여기서 만드는 것은 **값**이 아니라
**있고 없음**이고, 그것이 803 이 «주입이 안전한 경우» 로 남겨 둔 쪽이다. 두 자가 같은 사본을 쓰므로
`verify683` [H4](«패치를 걷으면 봉우리가 다시 3:1 아래») 와 이 자의 [4-a] 가 **같은 세계를 말한다**.

### 3-2. 짝 항을 세웠다 — [4-c]

사본만 재고 «그럼 지금은?» 을 안 물으면 이 자는 **795 가 통째로 되돌려져도 초록**이다(328~330 «누른 항을
묻는 항이 없으면 안 된다»). ⇒ **[4-c] = 현행 트리에서는 봉우리가 3:1 이상**. 두 항이 짝이라 한쪽만으로는
못 푼다.

### 3-3. 분모도 같이 봤다 (803-④)

글리프 차분은 **마스크가 비면 조용히 0 을 낸다** ⇒ **[4-s]** 신설: 두 세계 모두 골라낸 글리프 화소가
**≥200** 인가(실측 1094개 · 채움 460 · 테 399 급). 이 항이 없으면 «차분이 아무것도 못 골랐다» 가

⚠ **[2]·[3] 은 이미 사본이라 손대지 않았다** — 거기의 «RND» 는 788 이 고치기 전 경로를 이 자가 **자기 안에서**

**문턱은 한 칸도 안 움직였다**(334) — 3:1 그대로다. 바뀐 것은 **[4] 가 누구에게 묻는가**(현행 트리 → 사본)와
**무엇으로 재는가**(상자 마스크 → 글리프 차분)다.

### 4-1. 사본의 2.40:1 은 남의 자가 이미 아는 값이다

(표본 시각 격자가 같고 마스크가 같다). **두 자가 서로를 검산한다.**

### 4-2. [7] 은 «축 대조» 로 갈아 끼웠다 (값이 아니라 자의 성질)

[4] 가 글리프로 옮겨 갔으니 [7] 에서 다시 잴 것은 값이 아니다 — **같은 프레임을 두 마스크로 재면

| 마스크 | 사본(수리 전) | 현행 | 세계 간 분리도 |
|---|---|---|---|
| **글리프 차분** | **2.40:1** | **21:1** | **×8.74** |
| 상자(788 이전) | 3.23:1 | 6.17:1 | ×1.91 |

⇒ **[7-a]** = 「글리프 마스크가 두 세계를 더 크게 가른다」. 그리고 같은 표에서 **상자 마스크는 사본에서도
3.23 으로 문턱 3 을 넘는다** — 즉 **상자로 재면 결함이 안 보인다**. 그 줄은 판정이 아니라 **측정만**으로 뒀다:
