### 1-1. 자 — 무엇을 재는지부터 이름 붙였다 (`tools/probe450.py` 신설)

437 의 `cov`(커버리지 적분)를 그대로 이식해 **검정 잉크 총량**을 면마다 갈라 재고,
띠 경계는 문턱이 아니라 **밝기 축 한 개**로 푼다:

```
α = c·R / R·R      (R = 림 #705F4B)   ⇒  검정 0 · 림 1.00 · 셸바닥 #61523D 0.85
검정끝 = α 가 0.5 를 지나는 자리 · 림끝 = α 가 (1+0.85)/2 = 0.925 를 내려가며 지나는 자리
립 = 검정 − 테두리 7(437 확정) · 림 = 림끝 − 검정끝
```

⚑ **«두 축» 으로 가르면 헛값이 나온다 — 1회차에 실제로 그랬다.** K↔R 축과 R↔S 축을 따로 세워
읽으면, K 와 R 이 섞인 경계 화소(ref 07 x700 y2029 = `(84,74,62)`)가 **셸바닥보다 어두워**
R↔S 축에서 «림이 벌써 끝났다» 로 읽힌다 ⇒ **ref 림이 1.0** 으로 나온다. 세 색은 거의 한 직선
(S ≈ 0.85·R) 위에 있으므로 **한 축**으로 읽어야 한다. 고친 뒤 ref 림은 6.94~7.03 이 된다.

### 1-4. 제품 (`index.html` 한 자리 · CSS)

| | 전 | 후 |
|---|---|---|
| 손잡이 | `--sb:7px` | `--sb:7px` + **`--sl:1.5px`** |
| 배경 | `linear-gradient(180deg,#705F4B 0 7px,#61523D 7px 77px,…)` | **`linear-gradient(180deg,#61523D 0 77px,#705F4B 77px 84px,#61523D 84px)`** (상단 림이 그림자로 옮겨졌다 · 하단 띠는 그대로) |
| 그림자 | `inset ±7 #705F4B` | **검정 립 `inset 0 --sl` · `inset ±--sl`** + **림 `inset 0 (--sl+7)` · `inset ±(--sl+7)`** |

⚑ **왜 그라데이션이 아니라 그림자인가 — 1회차에 그라데이션으로 먼저 세워 보고 갈았다.**
`linear-gradient` 의 세로 하드 스톱 `#000 0 1.5px` 는 크로미움에서 **정수로 스냅**돼 립이
**1.0** 으로 깎였다(재캡처 실측 cov 8.00). 게다가 그라데이션은 **좌·우가 없다** — 옆면은 원래
`box-shadow` 몫이라 손잡이가 두 곳으로 갈린다. 세 면을 **같은 `--sl`** 로 묶으니 값도 1.50 으로
정확히 찍히고(반화소 오프셋은 그림자가 정직하게 AA 한다) 손잡이도 하나가 된다.
그림자는 **먼저 적은 것이 위**라 검정 셋을 앞, 림 셋을 뒤에 둔다.

**레이아웃 Δ0px · 판정·밸런스·세이브 0줄.** 립은 패딩 상자 **안쪽 칠**이라 칸 상자·라벨·배지·

### 1-7. 게이트 신설 — `verify450` (61항)

세 값이 아니라 **«면마다 다르다» 는 규약**을 문다. 한 갈래만 물면 «립이 통째로 사라져도 초록»
이거나 «네 면에 다 세워도 초록» 이 된다(LESSONS 328-330·334).

  **★ 하변에는 립이 없다**(그라데이션 첫 정지점이 셸 바닥이어야 한다)
* **[P]** 찍힌 픽셀 다섯 면(350 처방) — 안 닿는 면 순검정 **8** @림 8.5 · **닿는 면 7** · **하변 7** ·
  각 면의 «다음에 무엇이 오는가»(림 → 셸 바닥 / 알약 열은 곧바로 베벨) ·
  **★ 비대칭 자체를 두 항**(상−하 = 립 · 상−알약열 = 립)
* **[E]** 끝 칸이 활성인 호스트(06) — 닿는 변 7 ↔ 반대 변 8.5 (378 규약과 교차)
* **[S]** `--sl:5` 를 주입하면 검정도 **림 시작도** 따라오는가 (두께 7 유지)
* **[R]** 되돌림 4항 — `R-a` `--sl:0` = 450 이전 그림으로 **돌아간다** · `R-a2` 그때 **하변은 안 변한다**
  (음성 대조) · `R-b` **네 면 대칭**으로 세우면 하변이 빨개진다 · `R-c` **그라데이션으로만** 세우면
  좌·우가 사라져 빨개진다(§1-4 의 함정을 게이트가 기억한다) · `R-d` 원복

⚠ **«립 없는 면» 은 ±0.5(사실상 등호)로 문다** — ±1 로 두면 7 ↔ 8 이 허용폭 안이라
«립이 없어야 할 면에 립이 생겨도» 초록이다. 우리 렌더는 정수 좌표·DSF1 이라 흔들리지 않는다.
