### 178 은 «보스» 를 넣었지만 «판정» 은 안 건드렸다

```js
if(dunRun.dmg >= dunRun.need) endDunRun(true);   // index.html step() 던전 분기
```

### 고친 것 — 클리어 조건을 «누적 피해» 에서 «보스 격파» 로

등재문의 세 선택지 중 **ⓑ(몹 파도 → 보스 등장 → 격파)** 다. 누적 피해는 버리지 않고
**«보스를 부르는 눈금»** 으로 자리를 옮겼다 — `DUN_DMG_K`·`DUNGEONS`·`DUN_TRY` 는 한 줄도 안 건드렸다.

| 자리 | 바뀐 것 |
|---|---|
| `step()` 던전 분기 | `dmg >= need` → **`dunRun.bossDown`**. 시간 초과 실패는 그대로 |
| `killEnemy()` dunboss | 격파가 `dunRun.bossDown` **깃발만** 세운다(162 `stageWin` 과 같은 예약제 — 적 순회 도중 `enemies` 를 비우면 그 순회가 빈 배열 위를 돈다) |
| `dunBossTick()` | `bossDown` 이면 즉시 반환(격파 뒤 다음 보스를 안 세운다) · 필드에 실제로 선 순간 `bossIn` 기록 |
| `startDunRun()` | `bossIn:false, bossDown:false, bossLeft:1` |
| `endDunRun()` | 남은 보스 체력을 걷어 둔다 — `spawnStage()` 가 전장을 갈아엎어 `finishDunRun` 시점엔 개체가 없다 |
| `finishDunRun()` 실패 통보(206) | «피해 n / m» → **«보스 체력 40% 남음» / «보스 미등장»** |
| `drawDunHud()` / `dunRunProg()` 신설 | 진행바가 **클리어까지의 거리**를 그린다(아래) |
| `DUN_BOSS_HPK` | 0.5 → **0.3**(아래 실측) |

**탑(209·210)은 옛 판정 그대로 남겼다.** `DUN_UI` 항목이 없어 보스가 «그 카드의 몬스터» 가
되지 못하고(dragon 폴백), 등재 **264**(«시련의 탑도 보스 전투여야») 가 그 몫이다.
게이트 §F 가 탑 두 종이 여전히 누적 피해로 깨지는지 회귀로 지킨다.

### 진행바는 이제 «클리어까지 얼마나 왔나» 다

옛 눈금(`dmg/need`)을 그대로 두면 **바가 꽉 차도 런이 안 끝나는** 거짓말이 된다.
두 국면으로 갈랐다 — 기하(574px)는 30 측정표 값 그대로고, 바뀐 것은 «무엇을 재는가» 뿐이다.

| 국면 | 눈금 |
|---|---|
| 보스 소환 전 | `dmg / (need × 0.3)` × **0.3** — 눈금을 5배 넘겨도 30% 에서 멈춘다 |
| 보스 국면 | `0.3 + 0.7 × (1 − 보스체력/최대)` |
| 격파 | 1.0 (574px) |

### `DUN_BOSS_HPK` — 판정이 바뀌면서 이 값이 곧 난이도가 됐다

178 때 0.5 는 «보스가 30초를 버티되 혼자 요구치를 못 채우는» 자리였고 **클리어를 막지 않았다**.
255 가 판정을 보스 격파로 바꾸면서 이 값이 그대로 난이도가 된다. 스윕했다
(`node tools/probe255.js 3 0.20,0.30,0.50` · «cp = 요구 전투력» 인 딱 맞는 플레이어):

| HPK | ×1 클리어 | ×1 클리어초(최소~최대) | 판정 |
|---|---|---|---|
| 0.20 | **18/18** | 5.0 ~ 17.5s | 통과하지만 보스가 형식이 된다 |
| **0.30** | **18/18** | 5.4 ~ 20.7s | **채택** — 보스 국면이 런의 40~68% |
| 0.50 | **15/18** | 5.9 ~ 29.5s | 탈락 — S12 gold 3층 1/3 · S25 relic1 2층 2/3 로 **층이 안 깨진다** |

0.5 는 «178 이 클리어를 안 막았으니 그대로 둬도 된다» 가 성립하지 않는 값이었다.
0.3 에서 가장 오래 걸린 판이 20.7초로 30초 예산에 9초가 남는다.

### 게이트가 잡은 것 3개 — 셋 다 **제품이 아니라 게이트 자신**이 틀렸다

1. **`rel` 보상은 `S.rel` 이 아니라 `S.relic` 이다**(`giveReward` ~20233). 「보상 0 지급」으로 보였다.
2. **전투 골드가 보상 차분에 섞인다.** 보스를 잡으면 `killEnemy` 가 `S.gold += e.gold × goldMul`
   을 더하므로, 황금 동굴 보상이 9000 기대에 10747(+19%)로 보였다. → `giveReward` 에
   **무엇이 넘어갔는가**로 본다(상태 차분이 아니라 호출 인자).
3. **relic2~4 는 잠겨 있다** — `DUN_UI[id].pre`(앞 단 던전 n층 클리어)를 안 풀면
   `challengeDungeon` 이 조용히 되돌아간다(「startDunRun 실패」 3건). 잠금 사슬을 따라 풀어 준다.
