# 931 — 사슬 밖 44 를 «장치가 뜻을 갖는가» 로 갈라 무장한다

> 925 가 «화소를 재는 자» 를 0 으로 만든 뒤 남은 여집합. 화소를 안 재므로 918/922 걷개도 907 깃발도
> 안 걸리지만, **291 정착**과 **731 소실 차단기**는 화소와 무관한 장치다.
> 등재문이 못박은 것은 «전부 갈아 끼워라» 가 아니라 **«갈아 끼운 뒤 각 자의 판정이 «장치 없는 세상»
> 에서 굳었는지 대조하라»** 이고(925-①), 그 대조는 **갈래를 나눠야** 뜻이 있다.

## 1회차 (2026-09-05, sess-1213-7483 루틴 워커 A)

### §1 먼저 «44 가 무엇인가» 를 실측했다 — 등재문의 수가 그대로 참이다

`tools/probe931.js` 신설. 갈래는 손으로 적지 않고 **세 부품의 실제 관문을 그대로 읽는다**
(402 «사본을 지운다» — 여기서 «291 이 언제 도는가» 를 다시 적지 않는다):

| 장치 | 관문 | 이 44 에 걸리는 자 |
|---|---|---|
| 291 정착 | `settle291.enabled()`(entry 가 `verify*.js`) **∧** `MIN_WAIT`(250ms) 이상 고정 대기가 있다 | **16** |
| 731 소실 차단기 | 페이지 안에서 도는 코드가 있다(`evaluate`/`$eval` 계열) — 삼킬 것이 있어야 뜻을 갖는다 | **41** |
| 918/922 걷개 | `shell918.qualifies(entry)` | **0** |
| 907 깃발 | entry 가 `verify*.js` **∧** `raster907.qualifies(entry)` | **0** |

⚑ **918/922 걷개 0자 · 907 깃발 0자 — 등재문의 «화소를 안 재서 걷개는 필요 없다» 가 실측으로 참이다.**
그래서 이 작업이 바꾸는 장치는 **731(과 갈래 B 의 291)뿐**이고, 그것이 곧 **대조의 범위가 좁다**는 뜻이다.
