## 1. 등재문이 시킨 것 셋

925 등재문(PROGRESS 행)이 착수 조건을 세 줄로 적어 두었다.

1. 넷을 `pwlaunch.launch()` 로 갈아 끼운다.
2. 갈아 끼우기 **전후로 종료 코드를 1:1 대조**한다.
3. «사슬을 안 지나는 자 0» 을 자로 못박는다(`verify922` [2] 옆이 그 자리다).
   ⚠ `verify471` 처럼 **자식 프로세스**에 심는 자가 있으므로 정적 grep 은 갈래를 갈라 세야 한다.

셋 다 했고, ②에서 **등재문이 예상하지 못한 것 하나**가 나왔다(§4).

## 2. 갈아 끼운 것 — 넷이 똑같이 들고 있던 사본 두 벌

넷(`probe523`·`verify77`·`verify79`·`verify80`)은 **같은 두 벌을 손으로 복사**하고 있었다.

- ⓐ 모듈 해석 IIFE — `require('playwright')` → `~/.npm/_npx` 훑기 → `console.error('playwright 없음')`
- ⓑ 실행 파일 폴백 — `chromium.launch()` 실패 시 `PW_CHROMIUM || '/opt/pw-browsers/chromium'` 로 재시도

둘 다 `pwlaunch` 의 `pw()`·`launch()` 와 **같은 말**이다. 다른 것은 «말» 이 아니라 **자리**다 —
사슬을 안 지나면 그 뒤에 걸린 장치를 **하나도** 못 받는다:

| 장치 | 작업 | 넷이 못 받던 것 |
|---|---|---|
| 입장 연출 정착 | 291 | «고정 대기 뒤 rect» 함정(`verify*` entry 한정) |
| 조용한 소실 차단기 | 731 | `page.evaluate` 가 페이지 안에서 죽어도 종료 코드 0 |
| 판 결정성 깃발 | 907 | 부분 리라스터(넷은 `raster907.qualifies` = **false** 라 이번에도 안 켜진다) |
| 껍데기 걷개 | 918/922 | `#defw`(inset:0 · z39 · 검정 .62)가 측정 창을 통째로 덮는 것 |

⚑ **918·922 가 조건을 아무리 넓혀도 이 넷은 안 걸렸다** — 규칙의 문제가 아니라 **부트스트랩이 빠져 있었기**
때문이다. 실제로 넷 다 `shell918.qualifies` = **true**(=922 규칙을 만족)인데, 걷개가 심길 자리인
`launch()` 를 지나지 않아 «자격은 있는데 안 받는» 상태였다.

제품 편집 0줄, 자 편집은 파일당 두 자리(머리 + launch 한 줄)다.

## 4. ⚑ 이 회차의 본체 — «1회 대조» 가 만들어 낸 유령

`verify79` 가 0 → 1 로 바뀐 것을 보고 **처음에는 사슬이 판정을 흔들었다고 읽었다.** 등재문이 미리
경고한 그 위험(«각 자의 판정이 깃발 없는 세상에서 굳었는지 대조하라»)의 얼굴 그대로였다.

장치를 하나씩 꺼 보니 **말이 안 맞았다**:

| 세상 | 결과 |
|---|---|
| 사슬 전부(기본) | FAIL Δ=17 |
| `PW_SETTLE=0`(291 끔) | FAIL Δ=14 |
| `PW_SHELL918=0`(걷개 끔) | PASS Δ=0 |
| `EVGUARD=0`(731 끔) | PASS Δ=0 |

걷개를 끄면 초록인데 731 만 꺼도 초록이다 — **한 장치의 탓이면 나올 수 없는 표**다. 그래서 **같은 트리에서
다섯 번씩** 돌렸다:

| 트리 | 결과 5회 |
|---|---|
| **갈아 끼우기 전**(사슬 밖) | PASS · PASS · PASS · **FAIL Δ=17** · **FAIL Δ=14** |
| **갈아 끼운 뒤**(사슬 안) | **FAIL Δ=19** · **FAIL Δ=14** · PASS · PASS · PASS |

⇒ **`verify79` [E] 는 사슬과 무관하게 원래 5회 중 2회 빨간 자다**(양쪽 2/5 · Δ 0 ↔ 14~19).
처음의 «전 0 / 후 1» 은 **1회씩만 잰 것이 만든 유령**이었다. `flip` 부호(±25 장치px)와도 상관이 없다
(초록 판에도 +25·−25 가 섞인다). 927 로 등재했다.

⚑ **교훈**: 플레이키한 자를 전후 **1회씩** 재면 부호가 반반 확률로 뒤집힌다 — «전후 대조» 는
**같은 자를 여러 번** 재야 대조다. 912 «반복으로 재현하려 들지 마라» 의 반대편 짝이다:
판정이 이미 흔들리는 자에서는 **반복이 유일한 대조**다.
