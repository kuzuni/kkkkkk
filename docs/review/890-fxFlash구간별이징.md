## §2 세 번째 자 — 추정을 그만둔다 (`tools/probe890.js`)

두 채점자의 공통점은 **결론이 아니라 방법**이었다: 둘 다 **찍힌 픽셀의 휘도(ΔL)로 opacity 를 «추정»** 했다.
그래서 답이 ① 열창 밑에 무엇이 깔렸는가 ② 어떤 격자로 표본했는가 **둘 다에** 흔들린다.

⇒ 세 번째 자는 **추정하지 않는다.** `getComputedStyle(el).opacity` 로 **애니메이션이 실제로 굴리는
그 속성값 자체**를 읽는다. **열창이 없으므로 «어디를 봤는가» 로 갈릴 자리가 아예 없다.**
시간은 `Animation.currentTime` 으로 감으므로 **벽시계 표본이 아니라 결정적 표본**이다(플레이키 0).

자를 두 겹으로 세웠다 — 한 겹은 상대를 못 이긴다:

* **[A] 산수** — `index.html` 선언에서 키프레임과 timing-function 을 **읽어 와** opacity(t) 를 푼다
  (손 상수 0개 · 402 «사본을 지운다»).
* **[B] 브라우저** — 실제로 `fxFlash()` 를 켜고 1ms 격자로 읽는다.

**[A] ↔ [B] 최대 오차 `0.00000`**(341점). ⇒ 「**계단은 표본 거칠기가 아니라 CSS 에 있다**」가 못박혔다.
브리핑이 열어 둔 «80ms 표본 거칠기» 갈래는 이것으로 닫힌다.

## §3 판정 — **둘 다 안 틀렸다. 서로 다른 자리를 봤다.**

⚑⚑ **이 작업의 본체는 «누가 맞나» 가 아니라 «절벽이 어디인가» 였다.**

* **EC 의 절벽은 실재한다** — 60fps **한 프레임(16.67ms)** 에 **Δ0.2364**(브라우저 실측 · 산수 Δ0.2360).
  EC 의 20ms 격자로 재면 **Δ0.2605@177ms** 로 EC 보고값 **Δ0.258@177ms** 가 그대로 재현된다.
* **절벽 자리는 `177ms` = 키프레임 `52%` 경계, 즉 «한복판»** 이다. **ED 가 본 꼬리가 아니다.**
* **ED 의 80ms 격자로는 그것을 원리적으로 못 본다** — 177ms 는 ED 의 한 칸 **[160, 240] 안쪽에 숨는다**
  (나이퀴스트: 16.7ms 짜리 사건에는 ≤8ms 격자가 필요하다). 같은 곡선을 ED 의 격자로 다시 표본하면
  칸 낙폭이 `0.0636 · 0.1356 · 0.3494 · 0.4368 · 0.0145` 로 **꼬리 두 칸이 «거의 등속» 으로 읽힌다.**
* **ED 의 양성 주장도 참이다** — `opacity(279ms) = 0.230` 으로 **중간 알파 프레임은 실재한다.**

⇒ 갈림은 **EC 쪽으로 닫힌다**(절벽은 있고, 재원이 있는 축이다). 동시에 **ED 의 관측은 한 항도 기각되지 않았다** —
꼬리는 실제로 매끄럽고, 문제는 꼬리가 아니라 한복판이었다.

## §4 뿌리 — 값이 아니라 **timing-function 이 걸리는 자리**

⚑⚑ **868 이 왜 못 고쳤는지가 여기서 설명된다.**

CSS 는 timing-function 을 애니 **전체**가 아니라 **구간마다 다시** 적용한다. 그래서 이즈아웃
`cubic-bezier(.2,.8,.3,1)` 하나가 다섯 구간에서 **다섯 번 반복**되어
«구간 앞에서 급락 → 구간 끝에서 정체» 를 **5단으로 쌓는다.**

868 은 키프레임 **값**(.92→.80 · .72→.45 · .34→.22)을 재배치했다. 값은 실제로 고르게 펴졌는데
채점자들이 계속 절벽을 잰 이유가 이것이다 — **계단은 값이 아니라 구조에서 나온다.**

자에 그 명제를 못박아 뒀다(`verify890` **[R4]**): 키프레임 값을 **완전 등간격**(1/.8/.6/.4/.2/0)으로
펴도 옛 이징이면 한 프레임 낙폭이 **Δ0.1765** 로 **여전히 문턱 위**다.

### ⚑⚑ 선례가 저장소 안에 있었다 — 같은 결함의 **두 번째 자리**

`index.html` **~3954** (`.fx-plus`, 작업 **93 29회차**):

> 「`cubic-bezier(.2,.8,.3,1)` → `linear`. CSS 는 이 함수를 애니메이션 «전체» 가 아니라 **키프레임 구간마다**
> 적용하므로, 구간이 성길수록 «급출발 → 정지» 톱니가 커진다(28차 2인 공통 «구간속도 비단조»).
> 감속은 아래 키프레임 간격이 만든다.」 …「**원인은 키프레임 값이 아니라 이징이다**」

**진단도 처방도 글자 그대로 같다.** 그쪽은 «톱니(급출발→정지)» 로, 여기는 «절벽» 으로 읽혔을 뿐
**기계가 같다** — 채점자가 무엇을 세느냐(이동 속도 ↔ 알파 낙폭)만 달랐다.
93 도 **28차 2인이 갈렸다가 29차에 이징으로 닫았다**는 점까지 같다.

⇒ 이것은 **한 자리의 실수가 아니라 관행**이다. 그래서 이번 회차의 산출을 한 자리에 안 가두고
`docs/UI-REFERENCE.md` 58 «감쇠 곡선 규약» 으로 올렸다 — **여러 정지점 `@keyframes` 에 이즈아웃을
거는 것은 폐기된 관행**이다(402 «사본을 지운다» 의 규약판).
⚠ 남은 자리를 세어 뒀다: `cubic-bezier(.2,.8,.3,1)` 잔존 **0건**(주석 인용 3건 제외).
다만 **다른 이즈아웃 × 다중 정지점** 조합의 전수 스윕은 이 행 밖이다(890 은 `fxFlash` 한 부품이 스코프) —
`verify890` 의 자(`metricsOf`)를 그대로 가져다 쓸 수 있으므로 **다음 세션이 잡을 수 있게 등재로 넘긴다** — **894**
(⚠ 891 로 등재했다가 상류 경쟁으로 밀려 번호를 옮겼다 · 281·286·542·568·572·755 선례).

## §6 게이트 (`tools/verify890.js` — 16/16)

**토큰이 `linear` 인지를 «글자로» 묻지 않는다**(328~330 「누른 항을 묻는 항」). 그러면 다른 이징이
들어와도 초록이거나, 뜻이 같은 표기에 빨개진다. 묻는 것은 **성질**이다 —
「60fps 한 프레임 안에서 opacity 가 떨어지는 최대 폭이 문턱 아래인가」. 값은 제품 선언에서 **읽어 와** 푼다.

* **문턱 0.15** = 지금 판 **0.090** 과 옛 판 **0.236** 의 사이. **양쪽에서 각각 1.6배 이상** 떨어져 있어
  한쪽으로 무르지 않다. (근거: 한 프레임에 진폭의 1/4 가까이 사라지면 채점자 셋이 각자 절벽으로 읽었다.)
* **[A] 선언 불변항** 5항 — 키프레임 opacity · `FXFLASH_MS` · `FXFLASH_PEAK` · CSS duration ↔ 상수 ·
  키프레임 최대 scale ↔ `FXFLASH_PEAK`(619 [F2] 규약).
* **[B] 성질** 4항 — 한 프레임 낙폭 · 감쇠율 고르기 · 봉우리 Δ0 · **노출이 옛 판보다 늘었다**.
* **[R] 되돌림 시험(양방향)** 4항 — 옛 이징을 도로 끼우면 [B1]·[B2] 가 **실제로 빨개진다**
  (Δ0.2360 > 0.15 · 98,103배 > 60). **음성항이 공허하지 않다**(422 교훈 — 이 자가 절벽을 **볼 수는 있는지**를
  실제 값으로 못박는다). **[R3]** 은 «절벽은 한복판(52% ≈177ms)» 을, **[R4]** 는 «값을 펴도 못 고친다» 를 남긴다.
* **[C] 실물 대조** 3항 — 브라우저 `getComputedStyle().opacity` ↔ 산수 **오차 0.00000**.

## §9 교훈

1. **두 채점자가 갈리면 «누가 맞나» 보다 «각자 무엇을 쟀나» 를 먼저 적어라.** 여기서는 둘 다 옳았고,
   갈린 것은 **열창과 격자**였다. 세 번째 자의 값어치는 «심판» 이 아니라 **«두 사람의 자를 같은 축 위에 올린 것»** 이다.
2. **추정하는 자끼리는 안 갈린다.** ΔL 로 opacity 를 추정하는 두 자는 영원히 서로를 못 이긴다 —
   **속성 자체를 읽는 자**가 들어와야 닫힌다(`getComputedStyle`·`Animation.currentTime`).
3. **격자를 안 밝힌 «절벽 없음» 은 주장이 아니다.** 나이퀴스트가 결론을 미리 정한다 —
   80ms 격자는 16.7ms 사건에 대해 **«없다» 를 말할 자격이 없다.**
4. **값을 고르게 폈는데도 계단이 남으면 손잡이가 값이 아니다.** CSS 의 timing-function 은 **구간마다**
   걸리므로, 구간이 다섯이면 이즈아웃도 다섯 번 걸린다. 868 이 값으로 세 번 시도해 못 없앤 자리다.
