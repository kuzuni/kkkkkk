### «장착=청록» 은 왜 초록으로 바꿨나 (171 의 판단을 뒤집은 근거)

171 은 «장착=청록(08 `.sk-e` 와 한 벌) · 강화=초록» 으로 갈랐다. 그런데

* 그 갈래는 **레퍼런스 근거가 없다** — 171 자신이 §6 에 «05 ref 는 두 버튼 다 회색 면» 이라고 적어 뒀다.
  즉 청록은 171 이 08 과 짝을 맞추려고 고른 값이지 ref 실측이 아니다.
* 그 결과 **같은 뜻의 버튼이 화면마다 색이 달랐다** — 50 코스튬 시트 [착용]은 `.sk-b1.ok` 라 **초록**,
  05·08 [장착]은 **청록**. 202 지시문의 «전 시트 공통» 과 정면으로 어긋난다.
* 주인 지시가 «장착 버튼은 초록» 이라고 명시했다.

⇒ 규칙을 하나로 줄였다: **지금 눌러서 되면 초록 · 못 하면 회색.** (102 의 «색과 입력차단은 별개 축» 은 그대로 —
회색이어도 클릭은 살아 있어 «왜 안 되는지» 안내가 뜬다.)

### `.sk-e:disabled{filter:saturate(.3) brightness(.82)}` 는 왜 지웠나

청록을 «흐리게» 만드는 보정이었다. 기본 배색을 회색으로 바꾼 뒤에도 남겨 두면 회색을 한 번 더 어둡게 만들어
바로 옆 `.sk-u` 의 «불가» 회색과 어긋난다. 초록에 그대로 얹으면 **올리브색**(≈rgb(123,138,107))이 되어
ⓒ 가 요구하는 «회색» 이 아니다 — 그래서 `filter` 가 아니라 **배색 자체를 갈랐다**. 이제 두 버튼의 «불가» 는 픽셀 동일하다.

## 3. ★ 이번에 찾은 결함 — 166 ⓔ 와 **똑같은** 특이성 함정이 하나 더 있었다

새 배지를 붙이고 게이트를 돌리자 «`.alert` 가 없는데도 켜져 있다» 가 나왔다. 원인은 202 의 코드가 아니라
**07·26·50 시트의 공용 규칙**이었다:

```
:is(#bSk,#bPet,#bCos) i,b,u,s,em{display:block; …}    /* ID 급 — 시트 안 인라인 요소를 통째로 블록으로 */
.stab>.bdg{ … display:none}                            /* 클래스 급 — 진다 */
```

`<s class="bdg">` 가 그 `s` 에 걸려 **`.alert` 와 무관하게 상시 점등**이었다.
166 이 도감 탭 6칸에서 잡은 것(`#collw s{display:inline-block}` vs `.cltab>s.dot{display:none}`)과 **같은 모양**이고,
처방도 166 이 쓴 것과 같다 — 같은 급의 스코프를 붙여 규약을 복구한다:

```
:is(#bSk,#bPet,#bCos) .stab>.bdg{display:none}
:is(#bSk,#bPet,#bCos) .stab.alert>.bdg{display:block}
```

**166 의 전수 감사에는 이 호스트가 없었다** — 그때는 `#dunSub .stab` 한 곳뿐이었고 영웅 서브탭엔 배지가 없었다.
그래서 `verify166` 의 SITES 에 **두 호스트를 추가**했다(`#eqTabs .stab[data-upk]` · `:is(#bSk,#bPet,#bCos) .stab[data-upk]`).
이제 «새 배지를 어디에 달든 그 호스트를 SITES 에 넣는다» 가 규약으로 굳는다.

> ⚠ 게이트를 넓히다 한 번 헛디뎠다 — 시트 안 바를 DOM 에 만들려고 영웅 패널을 **열어 둔 채** 감사했더니
> `.tab .bdg` 절이 «켜짐 위반 1» 로 빨개졌다. 열린 탭 칸은 `.tab.close` 로 ✕ 치환되고
> `.tab.close .bdg{display:none}` 이기 때문이다. **바를 만든 뒤 패널을 다시 닫고** 잰다(시트 DOM 은 남는다).
