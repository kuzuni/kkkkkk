## §1 등재문의 진단을 재현이 **한 칸 정정했다**

등재문은 이렇게 적혀 있었다:

> `verify866` 16/16 이 초록인 채이므로 **그 자가 세로를 안 묻고 있다**는 뜻이다 —
> 892 와 같은 꼴로 **자 이관이 본체일 가능성이 높다**

**자는 세로를 묻고 있었다.** `verify866` [C1] 은 «알약 바깥 상자가 ref 260.0×**57.8**» 을
네 프레임에서 ±1px 로 단언한다. 틀린 것은 **질문이 아니라 과녁**이다.
338 규칙대로 처방 전에 `tools/probe904.js` 를 세워 ref 를 다시 쟀다(ref ↔ 우리를 **같은 함수**로).

| | 866 의 값 | **904 실측** | Δ |
|---|---|---|---|
| ref 알약 **바깥** | 117×**26** ref px = 260.0×**57.8** | **117×24 = 260.0×53.3** (x184..300 · y595..618) | 세로 **−2 ref px** |
| ref 알약 **속** | **111**×20 = 246.7×44.4 | **113×20 = 251.1×44.4** (x186..298 · y597..616) | 폭 **+2 ref px** |
| ref **테**(속→바깥) | 3 ref px = 6.6 | **2 ref px = 4.44 · 가로·세로 등방** | −1 |
| 우리 렌더(수리 전) | — | 260×**58** ⇒ **세로 +8.7%** · 가로 **0.0%** | — |

**+8.7% 는 채점자 EG 의 «+8.8%» 와 같은 값이다.** 등재문이 남긴 «어디가 부풀었나»(그릇·잉크·패딩)의
답은 셋 중 어느 것도 아니고 **테 한 겹**이었다.

## §2 뿌리 — `probe866.py` `edge()` 의 «국면 없는 2칸 건너뛰기»

```py
if lum < 25: last = 여기; bright = 0          # 검정 테두리 = 바깥 모서리 후보
else:        bright += 1; if bright > 2: break # ← ⓒ **뒤에서도** 2칸을 건너뛴다
```

이 걸음은 «속 → 베벨(밝음) → 검정 테두리(어두움) → 바깥» 을 **국면으로 구분하지 않는다.**
알약 하변 **y618** 바로 아래는 이렇게 생겼다(x194 열):

| y | 617 | **618** | 619 | 620 | 621 |
|---|---|---|---|---|---|
| L | 59.1 (베벨) | **12.2 (검정 테두리)** | 26.2 (밝음) | **4.9 (받침 그늘)** | 32.8 |

y619 **한 행만** 밝고 y620 이 다시 어둡다. 두 칸까지 건너뛰는 걸음은 그 한 칸을 **다리** 삼아
y620 을 하변으로 삼는다 ⇒ 세로가 24 가 아니라 **26** 으로 읽힌다(+8.3%).
그 다리가 놓인 열은 알약 폭 **113열 중 6열**이고, 하필 866 이 세로를 재려고 고른 열
(`vx = l + 10`)이 그 안이었다. **한 열만 옆이었으면 24 가 나왔다.**

속 «폭» 쪽 오차는 다른 기계다 — `iw` 를 **bbox 가 아니라 최장 연속**으로 쟀다.
알약 속에는 아이콘·숫자 잉크가 있어 연속이 끊기므로 113 이 **111** 로 읽힌다(−1.8%).

⚑ **두 오차가 «테 3 ref px» 를 우연히 등방으로 보이게 만들었다** —
가로 (117−111)/2 = **3** · 세로 (26−20)/2 = **3**. 옳은 값은 (117−113)/2 = **2** · (24−20)/2 = **2** 다.
866 은 그 «3»(=6.6)을 보고 «두 눈금을 동시에 맞추려면 테를 두껍게» 라고 결론지어
테두리 3 → **4.5** · 베벨 2 → **2.2** 로 키웠고, 그만큼 바깥 세로가 **+4.5px** 부풀었다.
게이트는 자기 자가 만든 과녁을 다시 물었으므로 **끝까지 초록**이었다.

⚑ **측정표는 처음부터 24 를 적고 있었다** — `docs/measure/89-유물팝업.md` §코스트 필 행의
«검정 테두리 바깥 117×**24** ⇒ 260.0×**53.3~57.8**». 그 «~» 가 자와 표가 갈렸다는 표시였고,
같은 줄의 앞부분(«117×24»)이 뒷부분(57.8)을 이미 반박하고 있었다.

## §4 처방 — **테 한 겹**(356 «확대는 등방» 을 안 어긴다)

```
- .rw-cost{... height:57.8px; ...  border:4.5px solid #000; border-radius:28.9px;
-   box-shadow:0 0 0 1px #513229,inset 0 0 0 2.2px #403320;
+ .rw-cost{... height:53.3px; ...  border:2.22px solid #000; border-radius:26.65px;
+   box-shadow:0 0 0 1px #513229,inset 0 0 0 2.22px #403320;
```

- **가로는 한 점도 안 옮겼다**(260.0 = ref · Δ0.0%). 줄어든 것은 테 두께 6.7 → **4.44**
  (= ref 의 «검정 1 ref px + 베벨 1 ref px»). ⇒ «아이콘을 세로로만 눌렀다» 가 아니다.
- 그 한 줄이 **두 눈금을 같이 닫는다** — 바깥 세로 57.8 → **53.3**(ref 53.3) ·
  속 폭 246.6 → **251.1**(ref 251.1) · 속 세로 44.4 **불변**.
- `top:149` 는 **안 건드렸다** — 줄어든 4.5px 은 아래에서만 나온다.
  하변 206.8 → **202.0** ⇒ 수반 구획(226) 아래 여백 19.2 → **24.0** 인데 **ref 환산이 24.4** 라
  이 회차는 «세로» 를 닫으면서 «아래 여백» 도 같이 회수했다(안 노린 이득이라 게이트에는 안 적었다).
- radius 는 규약(«높이 절반»)을 그대로 따라 28.9 → **26.65**. **규칙을 바꾼 게 아니라 따라간 것**이다.

⚠ **내용 자리는 안 줄었다** — 테 안쪽 상자 49.8 → **49.3**(−0.5px = −1.0%).
바깥이 4.5px 줄었는데 내용은 0.5px 다(크로미움이 border-width 를 정수로 내려 4.5→4 · 2.22→2).
`verify904` [3]·[R2] 가 이것을 **되돌림 사본과 나란히** 못박는다.

## §8 곁다리 등재 1건 — **935**(모서리 반지름)

ref 알약의 **최외곽 열이 24행 중 20행 어둡다** ⇒ 곧은 변이 20 · 모서리 반지름 **≈2 ref px = 4.4**.
우리는 `border-radius = 높이 절반`(26.65) 이라 **양 끝이 완전한 반원(stadium)** 이다.
stadium 이라면 최외곽 열은 1~2행만 어두워야 한다 — **다른 축이고 크기가 6배 갈리는 자리**라

⚠ 잡는 세션은 **736 «양 끝은 원» 규약이 이 부품에도 적용되는가**부터 정해야 한다 —
866 주석이 그 규약을 근거로 28.9 를 골랐고, 904 는 그 규칙을 **바꾸지 않고 따라만 갔다**(26.65).
