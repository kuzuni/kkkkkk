## 1. 무엇이 문제였나 — 라벨이 «채움 끝» 을 따라다녔다

`.sk-pb b` 의 가로 좌표를 CSS 가 정하지 않고, 그리는 쪽이 매번 인라인으로 박고 있었다.

```js
'<b style="left:calc(' + p + '% + 3px)">' + (maxed ? 'MAX' : have + '/' + need) + '</b>'
```

즉 라벨이 **주황 채움이 끝나는 지점**에 붙어 따라다닌다. `p` 가 0이면 바 좌단, `p` 가 100이면
바 오른쪽 밖이다. 여기에 라벨의 `-webkit-text-stroke:6px #000` 과 바 테두리 `border:6px solid #000`
이 겹치면 **검정 위의 검정**이 되어 글자가 사라진다 — 주인 보고 그대로다.

가장 흔한 상태가 가장 나빴다. **스킬을 새로 뽑은 직후(재료 0, `p=0`)** 가 기본값이라,
플레이어가 08 세부 팝업을 처음 열면 거의 항상 그 «안 보이는» 상태를 본다.

## 2. 왜 여태 안 잡혔나 — 레퍼런스가 «운 좋은 한 컷» 이었다

이 배치는 내가 지어낸 게 아니라 **08 측정표 §2.4 의 실측값**이다:

> 위치 | 주황 채움이 끝나는 지점(660) **바로 오른쪽**부터 시작 (3px 뒤)

레퍼런스 스크린샷은 채움비 **4/9 ≈ 44%** 상태다. 그 한 장에서는 «채움 추종» 과 «가운데» 가
**구별되지 않는다.** 측정은 정확했고, 구현도 측정에 충실했다. 틀린 것은 «한 컷에서 본 위치를
위치 규칙으로 일반화한» 추론 쪽이다.

→ 그래서 이번 수정은 정오표(§7, «실측이 틀렸던 것») 감이 아니다. 측정표에 **§8 «의도적 이탈»**
절을 새로 만들어 «레퍼런스가 맞는데 주인 지시로 일부러 다르게 뒀다» 로 적었다.
다음 세션이 «측정표와 다른데?» 하고 되돌리지 않게 하는 것이 그 절의 유일한 목적이다.

## 3. 고친 것 (3곳, 전부 `index.html`)

### ① `.sk-pb b` — 가운데 고정 (~1915)

```css
.sk-pb b{position:absolute;left:0;right:0;top:0;height:100%;
  display:flex;align-items:center;justify-content:center;
  font-size:25px;color:#F4F6B0;-webkit-text-stroke:6px #000}
```

`left:0;right:0` 은 **패딩 박스** 기준이라 검정 6px 테두리 **안쪽** 트랙(폭 424)의 정가운데다.
겉 박스(436) 기준으로 잡으면 테두리 두께만큼 중심이 밀린다.

### ②③ 인라인 좌표 제거 — 스킬 세부(~21095) · 코스튬 세부(~25327)

```js
'<b>' + (maxed ? 'MAX' : have + '/' + need) + '</b>'          /* 스킬 세부 */
'<b>' + (own ? lv + '/' + COS_MAXLV : '🔒' + cosReqText(a)) + '</b>'   /* 코스튬 세부 */
```

**코스튬 미보유 칸이 더 나빴다** — 라벨이 `🔒` + 획득 조건 문장(«🔒🥈 실버 승급전 클리어»)이라
가장 긴데, 미보유는 `p = 0` 이라 그 긴 문장이 통째로 좌단에서 시작해 바 밖으로 흘렀다.

## 4. 전수 — «채움 끝에 붙는» 라벨은 `.sk-pb` 뿐이었다

등재문이 지시한 전수 확인을 그대로 했다.

| 바 | 라벨 CSS | 판정 |

## 7. 이번에 걸린 함정 2개 (게이트 쪽 — 다른 화면에서도 재발한다)

1. **세이브 모양을 짐작하고 심으면 게이트가 즉사한다.** 처음에 `S.own[id]=true; S.frag[id]=n` 으로
   썼는데 실제 구조는 `S.own[id] = {l: 레벨, n: 조각}` 하나다(`has`/`oLv`/`frag`, ~16153).
   `TypeError: Cannot set properties of undefined` 로 [A] 에서 죽었다. **접근자 정의를 먼저 읽고 심을 것.**
   같은 자리에서 `AV` 도 틀렸다 — `AV` 는 `byId(AVATARS)` 인 **맵**이고 배열은 `AVATARS` 쪽이다.
2. **CSSOM 은 선택자를 정규화해 돌려준다.** `.sk-bar>b` 로 찾으면 못 찾는다 — CSSOM 이
   `.sk-bar > b` 로 공백을 넣어 준다. 문자열 비교 전에 **공백을 전부 지워야** 한다.
   안 그러면 [F] 회귀 칸이 «규칙이 없다»(빈 문자열)를 «가운데가 아니다» 로 읽어 **가짜 빨강**이 뜬다.
