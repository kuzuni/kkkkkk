## ③ 폴백을 팝업 → **큐**로 바꿨다 (가장 중요한 변경)

149 의 폴백은 이랬다:

```js
const el = fxToast(txt);
if(!el) popup('알림', '<p>' + txt + '</p>');   /* ← 스택 4장이면 여기로 온다 */
```

`fxToast` 는 토스트가 **4장 이상 쌓이면 드롭**한다. 즉 알림이 몰릴수록 «안내성 팝업» 이 뜬다 —
**주인이 없애라는 바로 그것**이고, 토스트를 14곳 더 늘린 이번 작업이 그 확률을 키운다.
그래서 큐로 바꿨다:

```js
function notify(txt){
  if(!txt) return null;
  const el = fxToast(txt);
  if(el) return el;
  if(!fxL()){ popup('알림', ...); return null; }   /* 레이어 자체가 없을 때만 */
  if(noteQ.length < 12) noteQ.push(txt);
  notePump();                                      /* 120ms 틱 — 자리가 나면 띄운다 */
  return null;
}
```

`fxToast()` 는 손대지 않았다(58 구간). `notify()` 안에서만 끝난다.
실측 — 4장 쌓인 뒤 `notify()` → **1181ms 뒤 실제로 표시**, 모달 0건 (`verify149 §4` 3항목).
