## 2. 실제로 고친 것 — 상세

### ⓐ 훈련 배수 탭 (주인 확정 사례) — 배지 폐기

`renderTrain()` 이 `TRAIN_QTYS.map(…)` 안에서 **칸마다 조건 없이** `<em class=dot>` 을 박고 있었다.
배수 탭은 «x1 / x10 / x30» 중 하나를 고르는 **수량 스위치**라 알림 대상 자체가 아니다 —
지시서가 적어 둔 «기본 처방 = dot 제거» 를 그대로 따랐다.

CSS `.tr-qty .dot` · `.tr-qty>.q:nth-child(3) .dot` 두 규칙도 같이 지웠다.
남겨 두면 작업 134 가 지운 `.tr-sub>.sg.on>.dot` 과 같은 **죽은 선택자**가 된다.
12·13·21회차의 실측(«ref 배지 체계 트레이 31 / 카드 42 / 서브탭 45»)은 `.tr-card>.dot` 쪽에 살아 있어
정보가 사라지지 않는다.

**「훈련 가능」 알림을 탭바 «훈련» 칸으로 옮기지 않은 이유**를 코드 주석에 남겼다 — 골드는 방치로
계속 차오르므로 «강화 가능» 은 사실상 상시 참이 되고, 주인이 지적한 그 노이즈로 그대로 되돌아간다.
카드별 `.tr-card>.dot` 이 이미 «그 자리에서» 알려 준다.

### ⓑ 던전 서브탭 — 토글이 한 군데도 없었다

`<div class="stab dns-t on" data-dsub="dun">…<s class="bdg"></s></div>` 는 **마크업에만** 있었고,
`.stab>.bdg` CSS 에 `display:none` 이 없었으며, `.alert` 를 켜는 JS 도 없었다.
즉 이 배지는 게임을 시작한 순간부터 끝까지 켜져 있었다.

다른 배지 전부와 같은 규약(기본 꺼짐 + 조건 클래스)으로 통일하고, 조건은 **탭바 «던전» 칸과 같은
`dunAlert`** 를 쓴다 — 이제 탭과 서브탭이 함께 켜지고 함께 꺼진다. 60 쥬시 애니(`jzDotIn`/`jzDotPulse`)
목록에도 추가해 손맛 한 벌을 같이 받는다.

### ⓒ 던전 카드 — 「들어가 봐야 지는 던전」에도 켜져 있었다

새 세이브 실측: **cp 503 vs 골드 던전 요구 2500** 인데 카드 2장(골드·다이아)에 빨간점이 켜져 있었다.
탭바 «던전» 칸은 `cp() >= req` 를 보는데 카드는 안 봐서 **탭은 꺼져 있고 카드만 켜진** 상태였다.
카드 조건을 탭바와 같은 식으로 맞췄다.

> ⚠ 113 가이드 손가락(`gmHintDun`)이 이 dot 으로 «입장 가능 카드» 를 찾는다. 조건이 좁아졌지만
> dot 이 하나도 없으면 `cards[0]` 으로 폴백하므로 손가락이 사라지지는 않는다(코드에 주석으로 명시).

### ⓓ 측정장·아레나 — 입장 제한이 없어 「영영 안 꺼지는」 dot

둘 다 `!lock` 만 봤다. 그런데 이 둘은 던전과 달리 **하루 입장 횟수가 없다** — 해금되는 순간부터
게임을 접을 때까지 빨간점이 켜져 있는다. 「누를 게 있다」로 읽히는 자기소멸 조건으로 바꿨다:

- 측정장: **아직 최고 DPS 기록이 없다**(한 번 재면 꺼진다)
- 아레나: **전적이 0-0 이다**(한 판 하면 꺼진다)

### ⓔ 도감 탭 6칸 — 클래스 셀렉터가 ID 셀렉터에게 지고 있었다 ★

게이트 [7]을 «한 칸 표본» 이 아니라 **호스트 전수**로 돌린 덕에 잡혔다. CSS 는 멀쩡해 보였다:

```
.cltab>s.dot{display:none; …}
.cltab.alert>s.dot{display:block}
```

그런데 파일 위쪽(7118)에 `#collw i,#collw s,#collw b,#collw em{display:inline-block}` 이 있다.
**ID 셀렉터(1,0,1)가 클래스 2 + 타입 1(0,2,1)을 이긴다** — `display:none` 이 한 번도 먹은 적이 없고,
`collTabReady()` 로 `.alert` 를 토글하는 코드(~21060)도 **화면에는 아무 영향이 없었다.**
도감 탭 6칸이 강화 가능 여부와 무관하게 상시 빨간점이었던 것이다.

이 함정은 **같은 파일이 두 번이나 주석으로 경고해 둔 것**이다(7215 «⚠ 특이성 함정 — `#collw i` 는
ID 셀렉터라…» · 7262 «같은 특이성 함정»). 두 번 다 «안 보여야 할 게 보인다» 가 아니라 «인라인이 됐다»
쪽으로 발현해서, **`display:none` 이 안 먹는 세 번째 발현형**은 아무도 보지 못했다.
→ 교훈으로 `docs/LESSONS.md` 에 등재.

### ⓕ 상점 탭 — 받을 게 있는데 안 뜨던 자리 (③)

상자별 하루 **무료 10연 2회**(`SHOP_FREE`)가 남아 있는데 탭바 «상점» 칸은 `false` 고정이었다.
자정에 되돌아오고 다 쓰면 꺼지는 **자기소멸 조건**이라 알림으로 적합하다.
