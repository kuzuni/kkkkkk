## 1. 재현 — 등재문 가설 셋이 **전부 확인**됐다

338·341·350 규칙대로 처방 전에 `tools/probe410.js` 를 신설해 재현했다.
(338·341 은 등재문 가설이 **기각**된 자리였다 — 여기는 그 반대다.)

| 가설 | 결과 | 실측 |
|---|---|---|
| ⓐ 뿌리는 `offC()` 의 `el.style.display = inl` | **확인** | 다시 연 직후 1080×1484 → **t=143~187ms 에 inline 이 `"flex"` → `"none"`** → 상자 0×0 |
| ⓑ `__jzGen` 세대 가드는 «다시 열림» 을 안 센다 | **확인** | 닫힘 연출 세대 **3 → 다시 연 뒤 3**(한 칸도 안 오른다) |
| ⓒ 회피는 «연출이 끝날 때까지 기다리기» | **확인** | 창 = 0~110ms, 140ms 부터는 멀쩡 |

핵심은 **«다시 열린 쪽은 한 번도 틀린 적이 없다»** 는 것이다 — `#bPet` 은 `on` 이고
`#panel` 의 **규칙 height 는 내내 1484px** 로 맞았다. 가린 것은 규칙이 아니라 **inline 한 값**이다.

그리고 `__jzBusy` 가 서 있는 동안 MutationObserver 는 «다시 열림» 자체를 **한 번도 안 본다**(probe410 [3-b]) —
즉 여는 연출도 안 걸리고, 늦게 오는 `offC` 만 남아서 덮어썼다.

## 2. ⚠ 등재문이 명령한 «사용자 도달성» — 답은 **«손가락으로는 안 난다»** 였다

등재문은 «⚠ 사용자 도달성부터 재라 — 탭 두 번 빠르게 누르기로 실제 손가락에서 나는지 먼저 찍을 것» 이라고
못박았다. 그래서 실제 클릭으로 두 경로를 전부 쟀고, **둘 다 안 났다.**

* **2탭 경로**(✕ → 가이드 미션 배너 `#tuto` → `gmHero`) — 지연 10칸 전부 정상.
  뿌리는 **기하**다: 닫히는 시트가 하단 1484px 를 차지하고 **배너 자신(y=1779)을 덮는다.**
  연출이 도는 동안 그 탭은 시트가 먹으므로 **창 안에서 배너를 누르는 것 자체가 불가능**하다.
  ⚑ 1회차에 이 축이 «10칸 전부 안 열림» 으로 나와 하마터면 «경로가 없다» 로 읽을 뻔했다 —
  원인은 다른 것이었다. 부팅 세이브는 스킬이 **이미 장착돼 있어** 그 미션이 완료 상태였고,
  `gmGo()` 는 `gmReady()` 면 이동이 아니라 **수령**을 한다. `S.eqSkill = []` 로 미완을 만들고서야 잰 값이 위의 것이다.
* **3탭 경로**(영웅 ✕ → 영웅 → 서브탭) — 탭바는 안 덮이지만 **손가락 세 번이 창(≈140ms)보다 길다.**

⇒ **이 결함은 «빠른 두 번 탭» 이 아니라 «코드가 닫자마자 여는 경로» 에서 난다.**
그 경로는 가정이 아니다 — **저장소의 자 하나가 실제로 여기에 걸려 있었다**:
`verify51.js` [2차] 가 `closeAll` 뒤 **250ms 를 기다려** 비켜 가 있었고(403·404 가 그렇게 적어 뒀다),
이번에 그 대기를 **걷어냈다**(§4). 앞으로 딥링크·가이드 이동·자동 열기 같은 경로가 늘면 그대로 사람 앞에 나온다.

## 3. 처방 — «되돌릴 값을 아예 안 만든다»

등재문의 처방 후보는 셋이었다(ⓐ offC 에서 «누가 다시 열었나» 확인 · ⓑ 여는 경로가 닫힘을 취소 · ⓒ 열 때 `__jzT` 클리어).
**셋 다 안 골랐다.** ⓐ 는 **원리적으로 못 푼다** — 닫는 쪽이 쓴 `display:flex` 와 여는 쪽이 쓴 `display:flex` 는
**문자열이 같아서** 값만 봐서는 누가 썼는지 가를 수 없다. ⓑ·ⓒ 는 여는 경로마다 손을 대야 하고, 여는 경로는 하나가 아니다.

대신 **질문을 없앴다**: 닫힘 연출이 «보이게» 하는 손잡이를 **inline style 에서 클래스로** 옮긴다.

```
.jz-df{display:flex!important}  .jz-db{display:block!important}  .jz-dg{display:grid!important}
```

`jzClose` 는 이제 `jzDispOn(el, disp)` 로 클래스를 붙이고, 뒷정리는 `jzDispOff(el)` 로 **뗄 뿐**이다.
**inline display 를 한 번도 안 건드리므로 되돌릴 값이 없다** — 닫은 쪽이 적은 `none` 도, 그 사이 연 쪽이 적은
`flex` 도 그대로 살아남는다. `!important` 가 필요한 이유는 이기려는 상대가 **inline `display:none`** 이기 때문이다.

그 위에 «다시 열림» 을 세대 가드에 태우는 한 겹을 더 얹었다. 이제 jz 가 닫는 동안 inline 을 안 쓰므로,
`__jzBusy` 중에 들어오는 **inline 변화는 예외 없이 «바깥이 연 것»** 이다 — 그래서 MutationObserver 가
그것만 골라 `el.__jzCancel()` 을 부르고(늦게 오는 `offC` 무력화) 여는 연출로 넘긴다.
`offC` 와 `__jzCancel` 은 **같은 뒷정리(`done()`)** 를 부른다 — 갈래가 둘로 벌어지지 않게.

⚠ **345 를 안 깨뜨리는 순서** — `jzShellBack()` 은 **여전히 맨 앞**이다. 껍데기 판별은 «그 클래스만 도로
붙였을 때 뜨는가» 를 computed display 로 묻는데, 강제 표시를 먼저 걸면 **무엇을 붙여도 뜬다** 로 읽혀 통째로 망가진다.

### 안 한 것

* `dunRunProg`·`syncPanel`·여는 경로 **0줄**. 여는 쪽은 내내 옳았다(§1).
* 허용 오차·대기 시간을 **한 칸도 안 넓혔다.** 오히려 `verify51` 의 대기 250ms 를 **뺐다**.
* 레이아웃 0px · 밸런스 0줄 · `KEY` 안 올림(세이브에 닿지 않는다).

**무르게 푼 수리가 아님을 세 겹으로 못박았다.**

1. **[R] 되돌림 시험** — 수리 두 자리를 되돌린 사본에서 지연 **0/20/60/120ms 가 전부 0×0**, 200/400ms 는 멀쩡.
   (⚠ 경계에는 단언을 안 세웠다 — 창은 `jzSheetOut .13s` 가 정하고 rAF 두 번이 이미 그 안을 먹는다.
   1회차에 120ms 에 단언을 세웠다가 회차마다 뒤집혔다. 344·372·392 교훈대로 **창 한복판에서만** 묻는다.)
2. **[2] 불변식** — 닫는 내내 inline 이 `"none"` 그대로임을 30표본으로 단언한다(«되돌릴 값이 없다» 의 직접 증거).
   그러면서 **[2-b] 연출 도중 상자는 살아 있다** — 강제 표시가 실제로 일한다(둘을 같이 안 물으면 «그냥 안 보이는 것» 과 못 가른다).
3. **[3] 음성항** — 그냥 닫으면 그대로 닫히고(0×0 · `display:none`), 강제 표시 클래스가 **한 개도 안 남는다**(누수 0).

**[A] SCOPE 가 이 수리의 유일한 낡을 자리를 지킨다** — 클래스는 display 값을 **표로** 갖는다(flex·block·grid).
실측 분포는 flex×9 · block×13 이고, 새 오버레이가 표 밖 display(예: `table`)로 뜨면 닫힘 연출이 그 120ms 동안
**다른 배치로** 축소된다. 그 순간 [A] 가 빨개진다.

## 6. 다음 세션에게

* **오버레이를 새로 만드는 세션에게** — 그 오버레이가 `display:table`·`inline-flex` 처럼 표 밖 값으로 뜨면
  `verify410` [A] 가 빨개진다. **`JZ_DSP` 표와 CSS 규칙에 한 줄을 같이 더하는 것**까지가 그 작업의 범위다.
* **`#panel` 을 inline display 로 여닫는 자리는 `syncPanel()` 한 곳뿐이다**(probe410 [5] · 22개 중 1개).
  다른 오버레이를 inline 으로 여닫게 만들지 마라 — 그러면 이 결함의 사촌이 그 자리에 생긴다.
* **닫힘 연출 중에 무언가를 «누르게» 하고 싶은 세션에게** — §2 가 잰 대로, 닫히는 시트는 **자기 아래 것을 계속 덮는다**.
  연출 중 탭이 통과해야 하면 `pointer-events` 를 따로 손봐야 한다(이번에는 손대지 않았다 — 그것이 이 결함을
  사람에게서 가려 주고 있던 방패이기도 하다).
