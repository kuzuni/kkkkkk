## 3. 재발 방지

`docs/PROGRESS.md` «병렬 세션 규칙» 1 끝과 `docs/claims/README.md` 에 명문화:

> **새 작업을 등재할 때 번호는 «화면별 상태» 표의 마지막 번호 + 1 이다 — 이미 쓰인 번호는 절대 재사용하지 않는다.**

네 쌍이 다 «주인 보고/지시가 한꺼번에 쏟아진 2026-08-27» 에 생겼다. 여러 워커가 같은 시각에
«표 끝 번호» 를 각자 읽고 각자 +1 하면 같은 번호가 나온다 — 규칙만으로는 완전히 못 막고,
**push 가 rebase 로 붙을 때 자기 번호가 이미 쓰였는지 다시 보는 것**까지가 실제 방어다(표 스캔 1줄).
