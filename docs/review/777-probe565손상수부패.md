## 4. 무르게 풀지 않았다 — [R] 되돌림 시험 4항 신설

파생만 남기면 «그 항이 통째로 사라져도 초록» 이 된다(LESSONS **522-③**). 776 §4 방식대로
**같은 술어를 옛 값·어긋난 값 위에서 돌려** 그 항이 실제로 무엇을 잡는지 못박는다.

```

                                              :: 옛 13000,19000,21000 vs 오늘 8250,9750,10250
ok [R2] ★ 곡선 계수를 손으로 적는 자는 «판이 밀리면 반드시» 썩는다   :: 7750+500·[1,4,5] = 8250,9750,10250
ok [R3] ★ 한 칸이라도 한 칸 어긋난 상수로 굳으면 [1] 술어가 깨진다   :: 어긋난 사본 8251,9751,10251
ok [R4] ★ [1] 과 [2] 는 서로 다른 것을 잰다 — 상자 10연이 곡선을 이기는 판에서는 하한 술어만 살아남는다

```

**[R1] 은 옛 계수(11000/2000)를 그 자리에서 다시 계산해 «옛 상수가 어디서 왔는지» 까지 못박는다** —
`fnIdx.map(i => 11000 + 2000*i)` 가 정확히 `13000,19000,21000` 이다. 즉 빨갰던 것은 값이 아니라
**낡은 계수**였음이 자 안에서 산수로 증명된다.

**[R4] 가 «자리를 안 비웠다» 는 증거다** — [1] 과 [2] 가 같은 값을 찍는 것은 «지금 곡선이 이기고
있어서» 일 뿐, 상자 10연이 곡선을 넘는 판에서는 [1](하한)은 초록, [2](= 곡선)는 **빨강이 되는 것이
옳다**. 그래서 [2] 를 지우지 않았고(333·310), [1] 도 [2] 의 사본이 아니다.
