## 1. 지시와 그 해석

원문: «룰렛 승급전 길라잡이 팝업에 닫기 버튼 없애기 / 룰렛 돌리기 버튼이나 승급전 도전 버튼
같은 거 퀘스트 팝업에 일괄 받기 버튼처럼 크고 폰트도 그런 식으로 통일성 있게. 폰트도 좀 크고»

두 축이다. ① **닫기 제거** ② **주 행동 버튼을 22 규격으로**.

**등재문(2026-08-27)의 «현행» 서술 한 곳이 실제 코드와 달랐다**(LESSONS 264-① 재확인) —
등재문은 «승급전·길라잡이는 공용 `popup()` 으로 뜬다» 고 적었지만, `openPromo()` 는 **자기 마크업에
`#pclose` 를 직접 달고 있다.** `popup()` 경로인 것은 길라잡이와 «승급 **성공**» 팝업이다.
제목으로 갈랐다 — 지시 대상은 `🏅 승급전`(openPromo)이고, `🏅 승급 성공!` 은 다른 화면이라 뺐다(§5).

## 2. 바꾼 것 (index.html 6곳)

1. **CSS 신설 `.ifbtn.pbtn`** — 104 공용 베벨 부품 `.ifbtn` 을 그대로 쓰되 «모달 본문 흐름» 용으로
   `position:relative;width:100%` 로 되돌리고, 22 규격(`height:130` · `--gb-bw:7` · `radius:43`)과
   라벨(`46.6px` · `top:4.5` · `scaleX(.973)` · 스트로크·그림자 토큰)을 `.qs-all` 과 같은 식으로 적었다.
   **`.gbtn`(26px) 은 한 줄도 안 건드렸다** — 지정하지 않은 버튼까지 같이 커지는 것이 등재문이
   경고한 사고다(243 함정).
2. **룰렛** — `#rouClose` 삭제 · `#rouBtn` 을 `.ifbtn pbtn` + 라벨 `<b>` 로.
3. **승급전** — `#pclose` 삭제 · `#pgo` 를 `.ifbtn pbtn` 으로.
4. **`popup(title, html, opt)`** — `opt.noOk` 옵션 신설. **길라잡이 호출부에만** `{noOk:true}`.
   함수 안의 [확인] 을 통째로 지우면 약관·고객지원·랭커 상세·승급 성공·notify 폴백까지
   닫는 버튼이 사라진다.
5. **내 정보 [승급전 도전]**(`#promoBtn`) — 주인이 이름을 댄 자리라 같은 규격으로.
6. **`rouBtnTx()` 신설 + `#modal.rou-spin` 차단 규칙 확장** — §3.

## 3. ★ 이 작업에서 «부품을 바꾸면 같이 깨지는» 자리 2개

- **라벨을 `<b>` 로 감싸는 순간 `btn.textContent = …` 가 규격을 지운다.**
  `spinRoulette`/`roulFinish` 는 회전 중·정지 후 라벨을 `textContent` 로 갈아 끼운다 — 그러면
  `<b>` 가 통째로 날아가 «큰 버튼에 26px 맨몸 글씨» 가 된다(46.6px 은 `.pbtn>b` 에만 걸린다).
  `rouBtnTx(btn, t)` 한 곳으로 모았고, 게이트 **F3/F6** 이 «라벨을 바꾼 뒤에도 fs 46.6» 을 단언한다.
- **181 의 회전 중 차단 규칙이 클래스 이름으로 걸려 있었다.**
  `#modal.rou-spin .gbtn{pointer-events:none}` — 버튼을 `.pbtn` 으로 바꾸는 순간 이 방어가
  통째로 뚫려 «회전 중 재터치 → 흔들림·소리·캡션»(181 ②)이 되살아난다. 선택자에 `.ifbtn` 을
  더했고 게이트 **G1** 이 회전 중 `pointer-events:none` 을 직접 읽는다.
