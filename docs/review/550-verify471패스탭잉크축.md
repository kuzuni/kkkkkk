### 1-3. 14.5 는 기하로 닫힌다 (`probe550` [3])

`scale` 의 축은 패널 중심이므로 **패널 하단의 탭은 «패널 높이 × (1−s)/2» 만큼 위로 올라가 보인다**.

가로도 같은 식으로 설명된다 — 탭 우변 489, 패널 중심 540 ⇒ `(540−489)×.015 ≈ 0.8` = 등재문의 `inkR` **0.8**.

## 2. 처방 — 시간이 아니라 **상태**로 닫는다

`tools/probe471.js` 는 `settle()`(유한 애니는 `finish()` · 무한 애니는 0프레임에 `pause()`)을 이미
갖고 있었지만 **잉크 루프 안에서만** 불렀다. 그래서

* **상자**(`collect`) = 장면 대기가 끝난 순간 → 애니 한복판일 수 있다
* **잉크**(클립 3장) = `settle()` **뒤** → 항상 멎은 상태

두 축이 **다른 프레임을 봤다.** [F] 가 재는 «어긋남» 은 그 차를 그대로 받아 적은 값이다.

⇒ **드레인을 `collect` 앞으로 옮겼다**(두 축 공통). 한 번 세우고 끝내지 않고 **도는 유한 애니가 0이 될
때까지 반복**한다 — 늦게 시작하는 애니(§1-4)도 다음 바퀴에 잡히기 때문이다.

```js
const drain = async (tries = 12) => {
  if (NODRAIN) return -1;
  for (let i = 0; i < tries; i++) {
    await settle();
    await page.evaluate(() => new Promise(r => requestAnimationFrame(() => requestAnimationFrame(r))));
    const live = /* 도는 «유한» 애니 수 */;
    if (!live) return i;
  }
  return tries;
};
```

**제품은 한 줄도 안 고쳤다.** `jzPgIn` 은 결함이 아니라 60/491 쥬시 규약이 요구한 등장 연출이다 —
결함은 «연출 중에 자를 댄 것» 이다.

## 3. 무르게 풀지 않았음 — 세 겹

⚠ 등재문이 명시적으로 막은 길: **«허용치 3 을 올려서 초록으로 만들면 반려»**. **한 칸도 안 넓혔다**
(3 은 그대로 · [A] 의 ±2 · [F] 잉크 호스트의 ±2 도 그대로).

1. **[전제] «자가 안 흔들린다» 신설** — 자가 **같은 호스트를 다시 재서** 스스로 증언한다.
   `collect` 뒤에 한 번 더 드레인하고 27자리 전부의 상자를 재읽어 `mv`(top·right·w·h 최대 변화)를 싣고,
   게이트가 `mv ≤ 0.5px` 를 단언한다. 실측 **27자리 전부 0**.
   ⚠ **«도는 애니 수 = 0» 으로 묻지 않았다** — 관계 없는 자리에서 유한 애니가 끊임없이 나고 지므로
   그 수는 늘 0이 아니다(드레인 직후에도 `live` 가 3으로 읽힌다). 그것으로 단언했으면 **자가 자기를
   플레이키하게 만든다**(344 규칙). 물어야 할 것은 «같은 값이 다시 나오는가» 하나다.
2. **[R] 되돌림 시험 신설** — 자에 손잡이 둘(`P471_NODRAIN` = 수리 전 자로 되돌린다 ·
   `P471_FORCEANIM` = 등장 애니를 0프레임에 얼려 최악을 **결정적으로** 만든다)을 두고, 그 사본에서
   같은 호스트가 실제로 줄어드는지를 본다: **수리 후 289×166 ↔ 드레인 없음 285×164.**
   ⚠ 자연 경합(4/5회)에 기대면 되돌림 시험 자신이 플레이키해진다 — 그래서 **얼려서** 결정적으로 만들었다.
3. **[R] 두 번째 항** — 수리 후 값이 «멎은 상자» = CSS 선언값 `.ps-bar>div{height:166px}` 와 같은지
   단언한다(**166.0**). 드레인이 애니를 «끝» 이 아닌 아무 데나 세우면 여기가 빨개진다.
