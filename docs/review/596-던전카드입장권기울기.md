```css

  transform:rotate(-18deg) scale(1.00248);transform-origin:50% 50%}
```

- **각도는 04 세부에서 그대로 가져왔다**(`.dgd-tki` 의 `rotate(-18deg)`) — 새 상수·새 각도 0개.

## §7 아트 몫으로 남는 것

세로 **−3.62%**(48.19 vs ref 50)와 종횡 **+3.76%** 는 배율·각도로는 못 메운다 —
우리 티켓 아트의 잉크 종횡이 **1.765** 이고 ref 티켓은 그보다 **세로로 두툼**하기 때문이다
(같은 −18° 에서 ref 처럼 1.28 이 나오려면 잉크 종횡이 **1.635** 여야 한다 —
`r = (1.28·cos18 − sin18) / (cos18 − 1.28·sin18)`).
**04 세부도 정확히 같은 값**(−3.8% · 1.328)이므로 이것은 두 자리의 공통 아트 몫이고,
371 처방(«답은 배율이 아니라 글리프 교체»)의 자리다. 발주 시 **입장권 아트의 목표 잉크 종횡은 1.635**(지금 1.765 — 세로를 약 8% 두껍게).
