  **하드 스톱 그라디언트 한 줄**로 만든다(요소를 더 만들지 않는다).

### 렌더 버그 3건 (캡처로는 «디자인이 이상하다» 로만 보인다)

1. **`.ps-eg` 에 `position` 이 없어 컬럼 바깥 하이라이트·외곽 테 4줄이 통째로 안 그려졌다.**
   `.ps-tk` 의 자식이라 `.ps-r>*{position:absolute}` 가 안 걸렸다. F 의 **1순위 지적**(«4개 줄 전부 100% 누락»)이 이것이다.
   요소를 만들어 넣었다고 그려지는 게 아니다 — **부모가 다르면 position 규칙도 다시 봐야 한다.**
2. **수령완료 칸에 인라인 `--fill/--rim` 이 남아 «인라인 > 클래스» 로 `.dn` 의 수령완료 색이 죽었다.**
   E·F 가 각각 «명암 2.64배 밝음» / «3.2배 밝음» 으로 독립 검출했다. 처방은 CSS 특이도 싸움이 아니라
   **renderPass() 가 수령완료면 인라인을 아예 안 붙이는 것**이다.
3. **`<s>` 는 취소선 요소다.** 자물쇠·체크처럼 «글자» 를 담은 `<s>` 에 **순백 72×5 막대**가 그려져
   **프리미엄 칸 12개 전부에서 칸 우측 경계를 24px 침범**했다. E 가 3순위로 정확히 짚었고(F 는 «72×5 밝은 판» 으로 목격만 했다),
   원인이 «자물쇠 아트» 가 아니라 **`text-decoration` 기본값**이라 아트 교체로는 영원히 안 없어졌을 결함이다.
   → `#psw s{text-decoration:none}`. **의미 없는 태그로 도형을 만들 때는 그 태그의 기본 스타일을 먼저 지워라.**

### 좌표 오기 3건

4. **헤더 배지 `top` 에 ref 절대 y 를 넣었다** — 패딩박스 원점(frame 569) 기준이어야 하는데 84px 아래로 내려가
   헤더 하단 검정에 잘렸다(E 1·2순위: «보이는 높이 −72%»). 03 규칙(«절대 배치 자식의 기준은 padding box»)의 재현이다.

   그리고 내부의 어두운 코어 링은 ref 에 **없다**(세로 그라디언트 한 겹뿐).
6. **보상칸이 ref 대비 +2px**, 아이콘이 **15px 떠 있고** 잉크가 7~10% 작았다.
