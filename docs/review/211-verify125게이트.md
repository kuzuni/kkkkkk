## 1. A1 판정 — 🎟 «쿠폰» 은 화폐가 아니다 → 게이트의 제외 대상

남은 4곳:

| 위치 | 코드 | 정체 |
|---|---|---|
| `index.html:20893` | `art:'🎟'` | 151 이용권 «전투 효율 증가» 카드의 **아트 자리**. 형제 값이 `'▶'`(광고 제거)·`'⏳'`(오프라인 보상) |
| `:21821` | `notify('🎟 사용할 수 없는 코드입니다')` | 쿠폰 — 잘못된 코드 토스트 |
| `:21822` | `notify('🎟 이미 사용한 코드입니다')` | 쿠폰 — 중복 사용 토스트 |
| `:21825` | `notify('🎟 ' + curIc('dia') + …)` | 쿠폰 — 획득 토스트 |

**등재문의 «`curIc('tkRelic')` 로 옮기면 되는지» 는 아니다.** 125 가 통일한 화폐는 7종이고
그중 «입장권» 3종(`cur-ticket-gold/dia/relic.svg`)은 게이트 자신의 **H1** 이 «던전 6개의 입장권» 으로
못 박은 **던전 입장권**이다. 쿠폰 코드(`CF_CODES`)는 그 어느 것도 아니다 — 여기서 🎟 을 `curIc('tkDia')`
로 바꾸면 **던전 입장권 아이콘을 쿠폰 알림에 붙이는 오표기**가 된다.

그리고 이 자리들이 «화폐를 표시하는 자리» 가 아니다:

- `:21825` 의 **실제 지급물인 다이아는 이미 같은 줄에서 `curIc('dia')`** 로 나간다.
  즉 이 줄의 화폐 자리는 125 기준으로 **이미 통일돼 있고**, 🎟 은 «쿠폰» 이라는 **말머리 장식**이다.
- `:21821`·`:21822` 는 수량이 아예 없는 실패 안내다.
- `:20893` 은 [3] «아트 자리 규칙» 이 말하는 교체 예정 자리표다.

→ ALLOW(비재화 줄 목록)에 네 줄을 등재했다. **`index.html` 은 고칠 것이 없다.**
A2(허용 목록 부풀기 방지)는 `allowHits(18) ≤ ALLOW.length + 4` 라 15→19 로 늘어도 여유가 남는다(18 ≤ 23).

## 2. D1 판정 — «63×63» 이 게이트가 든 낡은 값이다

실측(1080×2280, `.cbox i > img.cic`):

| 재화 | rect | 상자(computed) | img transform |
|---|---|---|---|
| gold | **65.3 × 65.3** | `width/height:65.2969px` | `none` |
| dia | **73.08 × 63** | `width/height:63px` | `matrix(1.16, 0, 0, 1, 0, 0)` |

63×63 은 **컴포넌트 기본값**(`.cbox i>.cic`, index.html:216)이고, A3 2차 폴리시 라운드가 **화면(`#top .curs`)에서만**
재화별로 거기서 **의도적으로** 벗어난 것이다. 근거가 코드 주석과 측정표 양쪽에 남아 있다:

- **gold (A3 9회차)** — 자산 링(`stroke-width:4`)이 두꺼워 노란 코어가 55 로 나온다(ref 57).
  상자를 `63 × 57/55 = 65.3` 으로 키워 코어를 ref Δ0 으로 맞췄다. 비평가 4인(U·V·W·X)이 임계 스윕까지
  붙여 **같은 값**을 냈고, 외곽도 65.3 이라 ref 실측 64~65 에 오히려 더 가깝다.
  («실루엣 63 을 지켜야 한다» 던 7회차 판단은 그때 뒤집혔다.)
- **dia (A3 6회차)** — `cur-dia.svg` 의 마름모가 viewBox 64 안에서 가로를 덜 채운다. 상자는 63×63 그대로 두고
  **이미지 자신에** `scaleX(1.16)` 을 걸었다(`<i>` 에 걸면 `.cbox i:has(>.cic){transform:none}` 이 죽인다 — 125 교훈 4).
  → rect 가 73.1×63. 등재문의 «종횡비가 깨져 있다» 는 **깨진 게 아니라 잉크 가로를 되돌린 결과**다.
  `docs/measure/A3-상단HUD.md` §아트 필요 «보석 아이콘» 행이 이 override 를 이미 문서화하고 있다
  («자산이 고쳐지면 그 override 를 **지워야 한다**»).

결정적으로 **A3 는 이 두 값이 들어간 뒤(r10)에 비평가 2인(Y·Z)에게 ①~④ 9/8/9/9 를 받고 ✅ 통과**했다.
레퍼런스 대조를 통과한 쪽은 현재 CSS 다. 게이트만 `measure/A3` 의 명목값에 멈춰 있었다.

### 고친 내용

- **D1** 을 «둘 다 63×63» → **재화별 확정값**(`gold 65.3×65.3` · `dia 73.1×63`, 허용 ±2)으로 바꿨다.
- **D1b 신설** — 두 override 의 **기전**까지 본다(gold = 상자 크기 · dia = 이미지 `scaleX`).
  rect 만 재면 기전을 바꿔치기해도 안 걸린다(아래 N3 이 그 증거다).
- 반올림을 정수 → 0.1px 로 올려 65.2969/73.08 이 로그에 그대로 보이게 했다.

D2(`<i>` 에 옛 scaleX 잔존 금지)는 부모 `<i>` 를 보는 항목이라 그대로 두고 손대지 않았다.
