### ⓓ — 그리기 층 (166 특이성 함정, 이 계열 다섯 번째)

`<s class="bdg">` 에 걸리는 `display` 규칙을 CSSOM 으로 전수해 캐스케이드 승자를 골랐다:

| 특이성 | 선택자 | display |
|---|---|---|
| (1,0,1) | `#trw s` (9492 — `#trw i,#trw em,#trw b,#trw u,#trw s`) | `inline-block` ← **승자** |
| (0,2,0) | `.stab > .bdg` | `none` |
| (0,3,0) | `.stab.alert > .bdg` | `block` |

ID 급 한 줄이 클래스 급 두 줄을 **둘 다** 이긴다 ⇒ `.alert` 는 아무 힘이 없었다.
`.alert` 를 **강제로 뗀** 상태에서도 닷이 `display:block · 27×27 · 면적 729` 로 그려졌다(`[B-R1]`).

> **이것이 주인이 본 그림의 절반 이상이다.** 단련석이 0 이어서 판정식이 «소등» 이라고 말해도
> 화면에는 빨간점이 떠 있었다. 즉 **판정식만 고쳤으면 주인 눈에는 아무것도 안 바뀐다.**

### ⓑ — 판정 층

`temperAlert()` 의 첫 항 `(Math.floor(S.tstone)||0) >= TEMPER_PT_COST` 는
`TEMPER_PT_COST = 1`(18878) 이므로 사실상 **«단련석을 1개라도 들고 있는가»** 다.
단련석은 던전에서 계속 들어오니 상시 참이고, 전환해 봐야
`temperUpOk(k) = temperPts() >= temperCost(k)` 를 만족하는 축이 없으면 **누를 것이 없다.**

`temperSegCost(s) = (s+1)(s+2)/2` 라 1레벨 비용이 1 → 3 → 6 → 10 … 으로 커지므로
**어긋남은 시간이 갈수록 넓어진다**(레벨이 오를수록 «단련석 몇 개» 로는 아무것도 못 산다).

| 케이스 | tstone | pts | 최소 비용 | 옛 판정 | 현행 | 진실(전환 후 가능?) |
|---|---|---|---|---|---|---|
| ① | 0 | 0 | 1 | 소등 | 소등 | 없음 |
| ② | 1 | 0 | 1 | 점등 | 점등 | 가능 |
| ③ | 0 | 1 | 1 | 점등 | 점등 | 가능 |
| **④** | **1** | **0** | **3** | **점등** ✗ | **소등** | **없음** |
| ⑤ | 2 | 1 | 3 | 점등 | 점등 | 가능 |
| ⑥ | 3 | 0 | 3 | 점등 | 점등 | 가능 |

옛 식이 진실과 어긋나던 칸 **1/6** → 현행 **0/6**.

### ⓑ 판정식 (31958~)

```js
const temperAlert = () => {
  const pts = temperPts() + Math.floor((Math.floor(S.tstone) || 0) / TEMPER_PT_COST);
  return TEMPERS.some(t => pts >= temperCost(t.k));
};
```

등재문 권장식 그대로 — **전환과 투자를 한 판정으로 합쳤다**(두 벌 금지, 203 «표기층» 교훈).
`floor(use / TEMPER_PT_COST)` 는 `temperCharge`(18923)가 실제로 주는 그 수라 **식이 두 벌이 아니다.**

지시대로 지킨 것:
* ② 31790 주석의 «다이아 회수는 상시 가능하므로 뺀다» — **그대로**(`verify519` [1-f]·[4-c]·[4-d]).
