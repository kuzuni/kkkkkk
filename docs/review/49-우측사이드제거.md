## 2. `drawFac()` — DOM 없이도 에러 없게

지시서가 «시설 타이머 갱신 로직은 DOM 이 없어도 에러 없게 정리(**기능 자체는 보존 여부 미정 — 표시만 제거**)» 라고
했으므로 **계산 로직은 보존**하고 그리기만 널 가드로 막았다. 계산부를 `facLeftText()` · `facFreeCount()` 로 떼어 놨으니
나중에 다른 화면(메뉴·설정 등)이 그대로 가져다 쓸 수 있다.

```js
function drawFac(){
  const tm = $('facTm'), bg = $('facBg');
  if(!tm && !bg) return;          /* 49 — 배너가 없는 현재 기본 화면에서는 아무것도 안 한다 */
  if(tm) tm.textContent = facLeftText();
  if(bg) bg.textContent = facFreeCount();
}
```

`drawFac()` 는 `tick` 계열에서 매 프레임 계열로 불린다(구 6390행). 널 가드 없이 두면 `$('facTm')` 가 `null` 이라
**첫 프레임에 `TypeError` 로 게임 루프가 죽는다** — 이번 작업에서 가장 놓치기 쉬운 지점이었다.

## 5. 남은 문제

없음. 다만 참고로:

- 우측 컬럼이 사라지면서 **행 그리드 주석의 «좌우 공통» 서술이 무의미**해져 좌측 기준으로 다시 썼다.
  A2 측정표(`docs/measure/A2-사이드아이콘.md`)의 우측 항목(§1 이벤트·특권 · §2 시설 배너)은 **역사 기록으로 남긴다** —
  레퍼런스 스크린샷 자체에는 그대로 있고, 측정값을 지우면 나중에 «왜 없앴는지» 를 되짚을 수 없다.
- 시설 카운터(`facFreeCount()`)가 세던 «오늘 남은 무료 입장 횟수»는 이제 **어느 화면에도 표시되지 않는다.**
  기능 보존 여부는 주인 지시가 «미정» 이라 계산 함수만 남겨 뒀다. 표시가 다시 필요해지면 52(메뉴)·55(설정) 쪽에 붙이면 된다.
