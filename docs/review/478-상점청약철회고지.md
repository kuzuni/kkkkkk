### ⚑ 띠가 스크롤 밖이라 «리스트 하변» 을 같이 올리지 않으면 헛초록이 된다

띠를 얹기만 하고 리스트를 그대로 두면 **rect 로는 겹침 0** 이다(띠는 리스트 «위» 에 뜬다).
그런데 사람이 끝까지 굴리면 **마지막 카드가 띠 밑으로 들어간다.** 470 이 «스크롤로 닿는 밖»
조항이 없어 같은 화면이 스크롤 위치로 초록도 빨강도 됐던 자리와 **같은 함정**이다.
⇒ 게이트 **[D1]** 은 «리스트를 `scrollHeight` 까지 굴린 뒤» 마지막 항목 하변이 띠 상변 위인지 묻는다.

## §3 부품은 하나다 (166 «한 곳» 규약)

탭마다 노드를 만들지 않았다. `#shopw` 안에 `.shop-legal` **한 개**를 두고,
켜고 끄는 것은 CSS 한 줄이다:

```css
#shopw:has(.shp-list.coin) .shop-legal,#shopw:has(.shp-list.pass) .shop-legal{display:block}
```

같은 파일이 이미 `#shopw:has(.shp-list.coin)::before`(6110)로 이 문법을 쓰고 있어 새 관행이 아니다.
소환 탭에서는 `display:none` 그대로 = **주인 원문이 지목한 두 탭에만** 뜬다(게이트 [A2]).

### ⚠ 함정 하나 — 스코프가 취향이 아니라 특이성이다

껍데기 리셋 `#shopw i,#shopw em,#shopw b,#shopw u,#shopw s{display:inline-block;text-decoration:none}`
는 **1-0-1** 이라 `.shop-legal i`(0-1-1) · `.shop-legal u`(0-1-1)로는 **못 이긴다.**
그대로 뒀으면 두 줄이 한 줄로 붙고 «더보기» 밑줄이 안 그려졌다 —
**429 가 `.ol1~.ol5` 에서 «?» 만 민짜로 그려진» 것과 같은 스코프 함정**이다.
⇒ `#shopw .shop-legal i` · `#shopw .shop-legal u` 로 스코프를 올렸다.
밑줄이 실제로 그려지는지는 rect 가 아니라 **찍힌 픽셀**이 답한다 → §5.

## §4 문구는 한 곳에서만 온다 (333 교훈)

띠 2줄도 팝업 본문도 **같은 상수 `LEGAL_WITHDRAW`** 를 읽는다.
두 벌로 적으면 한쪽만 고쳐지고 그게 곧 게이트 부패다(333 이 `verify149` 에서 겪은 자리).

```js
const LEGAL_WITHDRAW = [ /* '' = 빈 줄(문단 나눔) · 앞의 '*' = 주인 원문의 <color=#FFCC44>(노랑) */ ];
const LEGAL_BAND = [LEGAL_WITHDRAW[0], LEGAL_WITHDRAW[1]];   /* 띠 2줄 = 본문 첫 문단 그대로 */
```

주인 원문의 유니티 표기를 **표기 규약째** 옮겼다:

| 주인 원문 | 저장소 표현 | 렌더 |
|---|---|---|
| `/` (줄바꿈) | 배열의 다음 칸 | 문단 **안**이면 `<br>` |
| `/ /` (빈 줄) | `''` 칸 | 문단 나눔 → `<p>` + `p+p{margin-top:20px}` |
| `<color=#FFCC44>…` | 줄 앞의 `*` | `<p class="y">` = `#FFCC44` + 검정 테 3px |

게이트 **[B2][B3][F3][F4]** 가 **상수 ↔ DOM** 을 글자 단위로 대조한다(문단 11개 전부 일치).
**[R3] 되돌림 시험** — 띠 문구를 «7일 → 8일» 로 한 글자 바꾸면 그 대조가 **깨진다**(원복도 같이 확인).

⚠ 문단 안 줄바꿈을 살린 이유: 메일 안내가 **두 줄 한 문단**이다
(«… 메일 접수하실 수 있으며,» / «메일 접수 시 …»). 문단으로 쪼갰으면 20px 이 벌어져 다른 글이 된다.

### ⚑ 등재문 한 칸 정정 — «본문이 길어 세로 스크롤» 은 실측과 다르다

등재문은 «본문이 길어 팝업 본문은 **세로 스크롤**» 이라고 처방했는데, 실측은
**`scrollHeight 1063 = clientHeight 1063`** = **스크롤이 안 걸린다**(A5 `.mbox{max-height:min(1497px,100%)}`
안에 11문단이 다 든다). 그대로 «스크롤바가 있다» 를 단언했으면 **영원히 빨간 게이트**가 됐을 것이다.

⇒ 자를 **뜻**으로 다시 적었다 — 물어야 할 것은 «스크롤바» 가 아니라 **«잘리는 데가 없다»** 다:
① 지금은 넘침 0 · ② 그릇이 `overflow-y:auto`(길어지면 받는다) ·
③ **실제로 길게 만들면** 스크롤이 생기고 팝업은 여전히 프레임 안(423 규약).
③ 이 없으면 ①·② 는 «그릇이 놀고 있는» 것과 구별이 안 된다.
