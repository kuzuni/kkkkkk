### 산수 (두 갈래 · 상자가 상한에 걸리는지가 기울기를 가른다)

`.cl` 높이 1543 · 띠 = `168 … frameH − 276` · `translateY(−42)` · 깃발탭 오버행 149.

- **상한 밖**(`frameH − 444 < 1543`, 즉 frameH < 1987): 상자가 띠를 꽉 채운다 → **여유 = Δ − 11** (상수)
- **상한 안**(frameH ≥ 1987): 상자가 1543 에 걸려 가운데 정렬 → **여유 = (frameH − 2009 + Δ)/2**

Δ = 0(수리 전)이면 앞은 **−11 고정**, 뒤는 1998 에서 −5.5 · 2009 에서 0 — **실측과 정확히 일치한다.**

### 처방 — 415 의 `--pfsh` 와 같은 **연속 흡수항** (제품 1자리)

```css
#collw{padding-bottom:calc(276px + clamp(0px, 2009px - var(--frameh, 2280px), 11px))}
```

`Δ(h) = clamp(0, 2009 − h, 11)`:

| 구간 | Δ | 여유 |
|---|---|---|
| h ≤ 1998 | 11 | 상한 밖 ⇒ 11 − 11 = **0** |
| 1998 < h < 2009 | 2009 − h | 상한 안 ⇒ (h − 2009 + 2009 − h)/2 = **0** |
| h ≥ 2009 | **0** | 상한 안 ⇒ (h − 2009)/2 ≥ 0 · **선언이 안 붙은 것과 같다** |

⚑ **왜 상수 11 을 그냥 더하면 안 되나** — 패딩은 «가운데 정렬» 의 입력이라(LESSONS 351-③)

1. **«등재문의 실측이 맞다» 와 «등재문의 판정이 맞다» 는 다른 말이다.** 여기서 10줄 표는 소수점까지

   대신 **축을 하나 더 돌린 것**이 결함을 냈다.
4. **부분 수리는 «어디까지 갚았는지» 를 반드시 적어야 한다.** 390 은 11 과 26 을 **이름으로 부르며**
   갚았지만 그 보정이 `.shortf` 안에만 들어간다는 말은 안 적었다. 그래서 같은 규칙의 위·아래 두 끝이
   문턱 위에서 **둘 다** 살아남았다(436 · 447).
