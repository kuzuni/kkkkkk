## §3 고친 것

### ⓐ 모델 입구를 하나로 (`skillHits()`)

504 이전에는 **다섯 곳**이 같은 삼항 사슬을 각자 손으로 베껴 적고 있었다 —
`stat.dps` · `verify260` [C] · `verify484` [B] · `verify86` · `sim197`.
`verify484` [A1] 이 «게이트 모델 = 제품 모델» 을 **소스 정규식으로** 확인하는 방어까지 두어야 했던
이유가 그것이다. 이제 사슬이 없다:

```js
const skillHits = s => s.id === 'multi' ? Math.min((s.hits || 1) + Math.floor(oLv('multi')/2), 9)
                                        : (s.hits || 1);
```

* 단위: `cd > 0` 이면 «발동 1회당 타격 수», `cd = 0` 인 지속형이면 «초당 타격 수».
  ⇒ 옛 모델의 `dmg * 3` 에 박혀 있던 **3 도 손으로 적은 상수**였다(실측 orbit 6.65 · aura 9.4).
* `multi` 만 예외 — 발수가 강화 Lv 로 3 → 9 까지 자란다. 레벨 축이라 484·504 의 밖이다.
* 게이트 넷은 이제 이 함수를 **부른다**(베껴 적지 않는다). 402 의 «사본을 지운 것이 핵심» 과 같은 처방.
