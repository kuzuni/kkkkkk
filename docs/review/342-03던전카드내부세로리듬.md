## 1. ⚑ 본체 — «자리가 하나 틀렸다» 가 아니라 **«높이와 자리가 같이 틀렸다»** 였다

등재문의 처방은 한 줄이었다: «타이틀 baseline **+5~6px 하향**(둘이 동시 해소)».
그대로 따랐으면 **한 축은 닫히고 다른 축이 반대편으로 넘어갔을 것**이다.

재현이 축을 둘로 갈랐다:

```
던전명 잉크   상변 +39 / +41   (ref +44)   → −3~5px «위»
              높이  48 /  46   (ref 51/50) → −6~8%  «짧다»
              하변 = 상변 + 높이 = +87 / +87  (ref +95 / +94)  → −7~8px
알약 상변 +121 은 ref 와 Δ0 이므로 간격이 34 (ref 26~27)
```

- `top` 만 **+8** 내리면 간격은 닫히지만 잉크 상변이 **+47~49**(ref 44)로 3~5px 넘어간다.
- `top` 만 **+5** 내리면 상변은 맞지만 간격이 **29~30**(ref 26~27)으로 남는다.

**한 손잡이로 두 축을 못 맞춘다.** 그래서 순서를 뒤집었다 — **높이를 먼저 세우고 자리를 잡는다**:

1. `font-size 56 → 60` — 잉크 높이 47(평균) → **50.4** = ref 50.5. 스트로크는 `1em` 비례라
   바깥 4.48 → **4.8** 로 따라온다(측정표 §3-3 «외곽선 4~5px»).
2. `top 40 → 44` — 잉크 오프셋 평균이 0 이라 박스 top 이 곧 잉크 상변이다 → **+44** = ref.
3. 그 결과 잉크 하변이 **94.0** 으로 내려와 간격이 **26~27 = ref** 로 **저절로** 닫힌다.

`height`·`line-height` 도 60 으로 같이 올렸다(라인박스 = 폰트 크기 규약 유지).

## 2. ⓑ — **«288» 은 레퍼런스의 상수가 아니라 «결과» 였다**

등재문 ⓑ 는 «칩 필 bbox 는 Δ0 이므로 한글 라벨 잉크가 −20% 좁아진 만큼 우측이 빈 것» 이라 읽었고,
그건 **재현으로 확인됐다**(면 92..380 = ref Δ0 · 라벨 잉크 −19.8% · 여백 87 ↔ ref 52).
그런데 «면이 옳고 글자가 틀렸다» 는 결론은 측정표를 한 칸 더 보면 무너진다:

- §3-4 는 **잠금 카드(3·4·5)의 알약 우단을 «미확정»** 으로 남겼다.
- §3-4-2 는 그 라벨 잉크 우단을 **473 · 474 · 562 · 615**(절대)로 적어 뒀다.
  카드1·2 의 알약 우단은 **429** 다.

⇒ **레퍼런스의 캡슐은 고정폭이 아니다. 글자를 감싸고 자란다.**
카드1 의 288 은 `58`(아이콘 자리) + `잉크 177` + `여백 52` = **287** 의 **결과값**이고,
우리는 그 결과값만 상수로 박아 두고 있었다. 그 상수가 두 병을 같이 낳았다 —
짧은 라벨은 오른쪽이 비고(87px), 긴 라벨은 캡슐 밖으로 새서 **90 이 `--psx` scaleX 로 눌러야** 했다.

처방은 등재문 AP 안 그대로 **텍스트 shrink-wrap + 좌우 패딩 고정**이다:

```css
.dnc .pill { box-sizing:border-box; padding:0 51px 0 58px; white-space:nowrap }  /* min-width:288 삭제 */
.dnc .pill>i { display:inline-block; height:46px; line-height:46px; font-size:34px }  /* position:absolute → 흐름 안 */
```

- 라벨을 **흐름 안**에 둔 것이 핵심이다 — 절대배치면 캡슐이 글자를 못 잰다(그게 `--psx` 를 부른 원인).
- `font-size 30 → 34` 는 잉크 **높이**를 ref 에 맞춘 것이다(25 → 30 · ref 28~29).
  **폭은 끝까지 안 밀었다** — 늘어난 잉크폭이 여백을 87 → 50 으로 데려오고, 남은 폭 −8% 는 서체 몫이다.
- `--psx` 는 **선언째 걷어냈다**(CSS 1줄 · DUN_UI 데이터 8자리 · 출력부 2자리).
  캡슐이 글자를 감싸므로 «눌러 넣을» 이유 자체가 사라졌다. **죽은 데이터를 남기지 않았다.**

결과: 알약 폭이 라벨 길이를 따라 **272 / 300 / 325 / 326** 네 종류가 됐다(ref 도 카드마다 다르다).
자리(좌변 92 · 상변 121)와 높이(46)는 **8장 전부 Δ0** 로 그대로다.

## 3. ⓒ — ①② 는 같은 병, **③ 은 기각**

**ⓒ-① 문구가 −5.5px 위 · ⓒ-② 어절 간격**: §1 과 **똑같은 병**이었다 —
잉크 상변 +220(ref +223) 이면서 잉크 높이 37(ref **41**). 같은 순서로 고쳤다:
`font-size 45 → 50`(잉크 37 → 41.1) 뒤 `top 211 → 214`(`.lk` inset 8 → 카드+222 → 잉크 상변 **+223**).
어절 간격은 `word-spacing:9px` 로 벌렸다 — `letter-spacing` 을 건드리면 **글자 사이가 같이** 벌어져
advance 가 ref(40px/자)를 넘는다.

**ⓒ-③ «잠금 문구 우변이 액자 좌변과 3~5px» — 기각한다. 레퍼런스가 그 요구를 안 한다.**

| | 문구 잉크 우단(카드기준) | 액자 좌변(카드기준) | 클리어런스 |
|---|---|---|---|
| **ref** 카드3 | **697** (절대 747, §3-7-3) | 643 (§3-8) | **−54** |
| **ref** 카드5 | **704** (절대 754) | 643 | **−61** |
| 우리(수리 전) | 642 | 643 | +1 |
| 우리(수리 후) | **671** | 643 | −28 |

레퍼런스는 문구가 액자를 **54~61px 밟고 지나간다**(잠금 딤 위에 얹히는 글자라 그래도 읽힌다).
«3~5px 로 좁다» 로 보였던 것은 클리어런스 문제가 아니라 **문구가 ref 보다 작아서 왼쪽에 웅크리고
있던 것**이고, ⓒ-① 로 잉크 높이를 ref 로 세우자 우단이 642 → **671** 로 나아가 ref 쪽(697)에
가까워졌다. **같은 수리가 닫는다** — 오버레이 센터를 옮기거나 폭을 클램프할 이유가 없었다.
(등재문이 제안한 두 처방은 **둘 다 ref 에서 멀어지는** 방향이다.)

가로 중심은 수리 전후 모두 카드+491(ref **489**)로 Δ2 였다 — 원래 정상이었다.
