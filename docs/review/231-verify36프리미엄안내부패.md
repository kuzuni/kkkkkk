## 1. 원인 — 옛 단언은 두 조건 다 죽어 있었다

```js
/* 옛 단언 (tools/verify36.js [4]) */
const m = document.getElementById('modal');
const shown = getComputedStyle(m).display !== 'none';
const t = (m.textContent || '');
return { shown, prem: t.indexOf('프리미엄') >= 0 };
...
if (lockPop.shown && lockPop.prem) ok('프리미엄 미구매 상태에서 프리미엄 칸 → 안내 팝업');
```

| 조건 | 상태 | 왜 |
|---|---|---|
| `shown`(모달 표시) | **항상 false** | 149 가 `notify()` = `fxToast` 로 뒤집었다. `passClaim` 은 모달 경로를 안 탄다 |
| `prem`(본문에 «프리미엄») | **항상 false** | 모달이 안 뜨니 `#modal` 본문은 직전 팝업의 잔재이거나 빈 값이다 |

등재문의 `got {"shown":false,"prem":false}` 가 **둘 다 빈 값**인 비대칭이 그 표시였다(LESSONS 230-①).
현행 안내(index.html 23613 `passClaim`)는 이것 하나다:

```js
if(c > 0 && !passPrem()){ notify('🔒 <b>프리미엄 패스</b>를 활성화하면 받습니다'); return false; }
```

즉 «막는 것»·«이유를 말하는 것» 둘 다 **살아 있었고**, 죽은 것은 «어디에 그리는가» 뿐이었다.

## 2. 고친 것 — `tools/verify36.js` [4] (index.html 0줄)

옛 항목 1개를 **4개**로 갈랐다. 코드 경로가 여럿이면 단언도 여럿이어야 한다(230-④ — 옛 단언은
«막혔는가» 를 아예 안 물어서, 가드가 통째로 사라져도 그 항목 하나만 빨개졌을 것이다).

| 항목 | 무엇을 묻나 |
|---|---|
| `프리미엄 잠금 전제 — 미구매 상태` | 재기도 전에 프리미엄이 켜져 있으면 이 절 전체가 무의미하다 |
| `프리미엄 칸 수령 차단` | 다이아·수령키 개수·칸의 `.dn` 이 **전부 불변** |
| `잠금 안내 토스트 노출` | `#fxl .fx-toast` 문구가 «무엇을 · 어떻게 하라» 를 말하는가 |
| `잠금 안내는 팝업이 아니다` | `#modal.on` 이 아니어야 한다 — 149 되돌림 감시(230-③) |

세부 관례 3가지:

- **기대 문구는 런타임 계산**(185-①). 리터럴 «프리미엄 패스» 를 박지 않고 화면의 두 라벨에서 뽑는다 —
  헤더 `#psw .ps-hdr b.p i`(«프리미엄») 과 구매 버튼 `#psBuy .t1 i`(«프리미엄 활성화»). 뒤에서 앞을 빼면
  «활성화» 가 남는다. 안내는 이 둘을 **모두** 포함해야 한다. 문안이 다듬어져도 «무엇을 활성화하라는가» 는 남는다.
- **기다리지 않는다**(230-③). `click → passClaim → notify → fxToast → appendChild` 가 한 동기 흐름이라
  같은 `evaluate` 안에서 그 자리에서 읽으면 퇴장 시각(760/1060ms)에 아예 안 걸린다.
- **재기 전에 비운다**(230-②). `fxToast` 는 `stack > 3` 이면 조용히 드롭한다 — 앞 절의 토스트가 남아 있으면
  정작 재려는 안내가 태어나지 않아 «안내 없음» 오진이 된다. 측정 뒤 뒷정리도 같이 한다.

부수로 `V36_SRC` 환경변수를 붙였다 — 되돌림 시험이 **사본을 새로 열어** 돌리기 위한 자리다(LESSONS 191).
평소에는 저장소의 `index.html` 그대로다.

## 3. 되돌림 시험 — `tools/neg231.js` 신설

`index.html` 사본의 **그 한 줄만** 갈아 끼우고 `verify36` 을 통째로 돌려, «어느 항목이 빨개지는가» 를 본다.
값어치는 `want` 가 아니라 `not` 에 있다(230-④) — 서로 다른 절을 때린다는 증명이다.

| 시험 | 갈아 끼운 것 | 빨개져야(want) | 그대로 초록(not) |
|---|---|---|---|
| N1 | 안내를 통째로 제거 | 토스트 노출 | 전제 · **차단** · 팝업 아님 |
| N2 | 문구에서 «프리미엄»·«활성화» 제거 | 토스트 노출 | 전제 · 차단 · 팝업 아님 |
| N3 | 149 되돌림 — `notify` → `popup` | 토스트 노출 · **팝업 아님** | 전제 · 차단 |
| N4 | 가드 자체를 무력화 | **차단** · 토스트 노출 | 전제 · 팝업 아님 |

N3 만이 «팝업 아님» 을 빨갛게 하고, N4 만이 «차단» 을 빨갛게 한다 — 네 단언이 항등식이 아니라는 증거다.
N1·N2 는 같은 한 줄을 다르게 뒤집는데 **같은 항목 하나만** 빨갛다(«안내가 없다» 와 «안내가 아무 말도 안 한다» 는
사용자에게 같은 손해다).
