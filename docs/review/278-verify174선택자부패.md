## 3. 고친 것

1. **선택자 3개를 파일 상단 한곳으로** — `PT_SLOT` / `PT_UNEQ` / `PT_FREE`.
   여섯 자리에 흩어져 있던 문자열이 각각 따로 썩던 것을 막는다.
2. **§10 은 클릭 «전에» 뱃지 개수를 단언한다.** 0개면 30초를 기다리는 대신 그 자리에서 빨개지고
   즉시 종료한다(`p.click(…, {timeout:5000})` 로 타임아웃도 30초 → 5초).
3. **§5 에 «실제로 잰 슬롯 수» 단언 신설.** 절 전체가 «단언 0건» 으로 사라지는 것을 구조적으로 막는다.
   — 이번 부패의 진짜 교훈은 여기다: `forEach` 로 도는 절은 **몇 개를 잡았는지를 먼저 단언**해야 한다.
4. **§10 «빈 칸이 잠금» → «빈 칸이 [+]»** (272 사양). 덤으로 `.sk-slot.lock` 이 **0인지**도 같이 단언해
   «펫 칸에 자물쇠가 서면 272 역행» 을 양방향으로 못 박았다.
