## 3. 처방 — 등재문 ⓑ(축을 듀티로), 단 «틱을 분모로 삼는 축은 어떤 변형이든» 폐기

- **1차 시도(tm50)는 실측으로 기각했다** — 틱별 최대의 중앙값으로 옮기고 8회를 돌리자 7회 PASS 뒤
  1회에서 B1 rune 이 **tm50 0.974**(틱별 꼭대기 포착 7/17 = 0.41)로 빨갰다. 부하 스파이크가 틱당
  표본을 2~3장으로 줄이면 꼭대기 포착률이 반토막 나고, 중앙값도 분포째 끌려 내려간다.
  **같은 나쁜 실행에서 restPct 는 초록이었다**(≥0.12) — 페인트가 타임라인을 고르게 표본하는 한
  듀티(전체 비율)는 fps 가 줄어도 기대값이 안 변하고, 틱 분모 축은 변형(비율이든 중앙값이든) 무관하게 fps 를 탄다.
- **[B1]** = restPct ≥ **0.12**(원본 0.245~ / 무력화 ≤0.036) **그리고 omax ≥ 0.995** — «완전히 원래 크기»
  프레임은 듀티가 아니라 **실재**로 묻는다(원본 매 실행 1.0 도달 · 무력화 train/temper ≤0.959).
- **[B2]** = 왕복 에피소드 **ep ≥ 4**(원본 최악 7 / 무력화 ≤1 — 무력화의 1 은 재렌더 노드 교체 순간의
  표류 프레임 한 장) — «틱마다 왕복» 의 페인트 쪽 증거를 틱 분모 없이 세는 축. 틱마다 부품이 불리는 것
  자체는 [A5]·[A6] 정적 축이 이미 진다.
- **[R1]·[R2] 를 같은 두 축으로** — 334 규약(되돌림은 본문과 같은 자): 무력화 사본 restPct ≤ 0.05 · ep ≤ 2,
  원복 restPct ≥ 0.12 · ep ≥ 4. 구 틱 비율(cycRatio)은 판정에서 빼고 **진단으로 계속 찍는다**.
- ⚠ ep 문턱은 HOLD_MS 2400(틱 13~18개)에 물려 있다 — 홀드를 늘리면 무력화 쪽 표류 프레임도 같이
  늘어나므로 DEAD_EP 를 같이 다시 재야 한다(자 안에 주석으로 박음).
- 문턱은 분리폭 실측의 **양쪽에서 먼 자리**로 골랐다(ⓒ «실측 폭 아래로 내리기» 가 아니다 —
  무력화 사본이 전 축에서 문턱의 절반 이하라 «왕복이 통째로 사라져도 초록» 은 성립하지 않는다).
