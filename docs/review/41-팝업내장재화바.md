## 0. 먼저 확인한 것 — «정말 메인 HUD 와 다른가»

지시서가 «형태가 다르다» 고만 적혀 있어 **먼저 픽셀로 확인**했다. 결론: 다르다(측정표 §0).

| 프로필 플레이트 | 있음(x0~468) | **없음** — x0~496 전 구간 전이점 0개 |
| 본체 톤 | 단색 `#42362A` | **하드 2단** `#42362A`(ref y93~143) + `#3A2E22`(147~183) |

그리고 **03 과 14 의 바는 서로 픽셀 동일**(y80~200 에서 차이 픽셀 0, 숫자 문자열 제외)이라
**공용 컴포넌트 `.pcb` 1개**를 두 페이지가 같이 쓴다.

### 구조 결정 — 왜 page-local `top:-104px` 인가

레퍼런스에서 이 바는 화면 **최상단 스트립**(ref y87~191 = 프레임 3~107)을 차지한다.
그런데 `#dunw`·`#relicw` 는 `top:104px` 로 잡혀 있고, 그 좌표계 위에 **기존 측정값이 전부 얹혀 있다**.
페이지 top 을 0 으로 내리면 03·14 의 모든 자식 좌표를 다시 써야 한다(회귀 위험).
→ 페이지는 그대로 두고 **바만 `top:-104px; height:108px`** 으로 위로 올려 프레임 0~107 을 덮었다.
아래 4px 은 레퍼런스의 «바 하단 검정 테두리 6px»(ref 186~191) 중 페이지 영역으로 넘어오는 몫이다.

`#relicw` 는 `overflow:hidden` 이라 이 바가 통째로 잘렸다 → **클립을 `#relicBody`(inset:0, 같은 박스)로 이관**했다.
`#dunw` 는 원래 `overflow` 지정이 없어 그대로다.
