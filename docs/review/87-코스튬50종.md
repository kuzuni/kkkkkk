## 2. 설계 판단 3가지 (다음 세션이 «지시 위반» 으로 되돌리지 않게)

1. **등급은 6단계다(8단계 아님).** 85 가 `GRADE` 를 8단계로 늘렸지만 초월·불멸은 **장비 전용**이고
   README 등급 절도 «스킬·펫·유물·코스튬은 신화가 최고» 라고 못박는다. 87 지시문의 배분표도 6등급이다.
   → `verify87 §1` 이 «코스튬에 g≥6 이 없다» 를 게이트로 걸어 둔다.
2. **구 6종의 «능력치» 는 보존, «틴트» 는 새로 뽑았다.** 지시 ①은 *id·능력치* 보존이고,
   지시 ②는 *색상환을 고르게 나눈 틴트 체계*를 요구한다 — 둘을 같이 만족시키려면 색은 새 체계를 따라야 한다.
   다만 **전설·신화의 첫 칸(av4 금 `#ffb648` · av5 신성 `#ff8fa0`)은 옛 색 그대로** 뒀다:
   그 둘은 이미 «금 · 신성» 계열이라 새 체계와 어긋나지 않고, 최상위 코스튬은 외형 각인이 가장 세다.
3. **틴트 파라미터는 눈대중이 아니라 탐색으로 골랐다.** 처음엔 «색상 간격만 벌리면 된다» 고 보고
   stride 11 + 흔들림 없음으로 짰는데 쌍별 최소 ΔE 가 **3.3**(av7↔av14, 둘 다 연녹)이었다.
   Lab 에서 «색상 11° 차이»는 밝고 저채도인 구간에서 사실상 같은 색이다.
   stride · 등급 밴드(s/l) · 명도/채도 흔들림을 격자 탐색해 **최소 ΔE 10.3 / 등급 안 11.0** 을 얻었다
   (`COS_STRIDE=19`, `COS_LADL=[-14,0,14]`, `COS_LADS=[-20,0,20]`, 밴드 s 58→100 · l 68→77).

## 4. 밸런스 검산 (④ «과도하지 않게»)

- 전부 보유(50종) 시 — **공격 ×159.8 · 체력 ×52.0 · 골드 ×17.1**, 총 구매 비용 **💎10,511,300**.
- 확장 전(6종 전부 보유)은 공격 ×16.4 였다. 종 수가 8배가 되는데 배수는 **9.7배**에 그치도록
  신규 44종의 기준 효과를 등급 밴드별로 낮게 잡았다(일반 +1.0% ~ 신화 +20%. 구 6종은 값 보존이라 훨씬 세다).
- 게이트가 «공격 ×1000 미만 · 체력 ×300 · 골드 ×100 미만» 을 상한으로 지킨다(verify87 §3).

## 5. 성능 — 왜 카드만 `lite` 틴트인가

`tinted('knight', color)` 는 아틀라스(927×254 ≈ **0.94MB**)를 **색마다 통째로** 캐시한다.
격자 50칸이 각자 다른 색이므로 그대로 두면 캐시가 **약 47MB** 로 불어난다(모바일에서 위험).
그래서 카드 캔버스(96×96)만 `drawHeroTo(..., {lite:true})` 로 **그린 자리에서** 같은 연산
(`multiply` → `destination-in`)을 한다. 연산이 같아 색은 전투와 **픽셀 단위로 동일**하고
(verify87 §5 — 다른 픽셀 0), 메모리는 50×96×96×4 ≈ **1.8MB** 다.
착용 슬롯·08 상세·전투·79·80 은 기존 `tinted()` 경로 그대로다.
