## 2. 본체 — «발원 표시를 안 찍는다» 로는 **안 꺼진다**

가장 짧아 보이는 처방(21789 의 `fxAt(…, 'combat')` 한 줄 삭제)은 **연출을 없애는 게 아니라 더
나쁜 자리로 옮긴다.** 표시가 없는 증가분은 `fxSrc` 가 «마지막으로 누른 버튼»(창 1200ms)을
**추측**으로 집어 **UI 발**로 만들고, UI 발은 `#fxl`(z60 = 모든 팝업 **위**) + 딤 위 알약 복제까지 켠다.
이것이 158·518·578 이 세 번 겪은 바로 그 자리다(주인 원문 «쌩뚱맞은 곳에서 골드 이펙트가 터진다»).

⇒ 판정을 «표시를 찍느냐» 가 아니라 **«이 증가분은 연출을 안 한다»** 로 옮긴다.

```js
const fxMute = fxMap(0);
function fxSilent(cur, n){ if(n > 0 && fxMute[cur] != null) fxMute[cur] += n; }
```

`fxWatch` 가 델타에서 **먼저** 뺀다. **여기가 유일한 자리다** — 아래 `fxAcc`/`fxHold` 는 `fxFly` 를
부르기 **전에** 걸리므로, `fxFly` 안에서 되돌리면 비행만 안 나고 **HUD 숫자는 2초를 붙잡힌 채
나중에 튄다**(홀드 프레임 33~37% 가 그 값이다). 지금 자리에서는 묶음·홀드·롤링 어디에도 안
들어가 숫자가 그 프레임에 바로 오른다 — 실측 홀드 **0%** · 역행 **0** · 창 끝 잔차 **0**.

### 2-b. 1회차에 실제로 걸린 함정 — **부동소수 잔재가 «획득» 으로 읽힌다**

토큰을 빼고 나면 `d` 가 0 일 것 같지만, 같은 값을 다른 순서로 더하고 뺀 뒤에는 ulp 급 찌꺼기가 남는다.
`fxFly` 를 후킹해 잡은 실측값이 **`n = 4.085620730620576e-14`** 이고, 그 묶음이 그대로
**코인 두 개**로 났다(층 `fxl` — 발원이 없으니 UI 발로 승격까지 됐다).

```js
if(d > 0 && d <= Math.abs(v) * 1e-9) d = 0;
```

⚠ **문턱은 상수면 안 된다** — 후반 골드는 1e25 라 ulp 자체가 1e9 급이다. 보유량에 비례시킨다.
(게이트 `verify592` [A8] 이 이 조건을 문장째 묻는다.)

## 3. 스위치는 «한 표» — 자리를 다시 찾지 않게

`fxAt(…, 'combat')` 이 찍히는 자리는 소스 전체에 **셋뿐**이고 셋은 서로 다른 사건이다.

```js
const FX_COMBAT_FX = { kill:false, stageClear:true, waveBonus:true };
```

| # | 자리 | 사건 | 기본값 |
|---|---|---|---|
| ⑴ | `killEnemy` 21803 | 적이 죽어 떨어지는 골드 | **꺼짐**(주인 지시) |
| ⑵ | 23300 | 스테이지 클리어 보너스 | 켜짐 |
| ⑶ | 23328 | 파도 전멸 보너스 | 켜짐 |

⑵⑶ 은 «적이 죽을 때» 가 아니라 «스테이지가 끝날 때» 다 — **475 가 격파와 ⑵ 사이에 1초를 넣어 둔 것**
자체가 둘이 다른 사건이라는 제품의 선언이다. 주인이 지목한 것은 ⑴ 하나이므로 ⑴만 껐고, 나중에
«그것도 빼라» 가 왔을 때 자리를 세 군데 다시 찾지 않도록 판정만 한 표로 모았다.

### 6-b. `verify77` [D] — 여기는 **실제로 빨개졌다**

종전 [D] 는 «상점을 연 채 10초 동안 `#fxlc` 에 연출이 0건이면 실패» 였고, 그 연출을 대 주던 것이

**표본**을 없앴는가» 는 다른 일이다. 뒤쪽이면 고칠 곳은 제품이 아니라 **표본**이고, 표본을 바꾼 뒤에는
