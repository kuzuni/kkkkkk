## 2. 뿌리 — 한 줄이 두 상황을 같은 침묵으로 삼킨다

`offlineReward()`(`index.html`)의 `if(sec < 60) return;` 한 줄이다. 이 `sec` 은 이미 **세 축으로
잘린 뒤**의 값이라, 60초 미만이 되는 이유가 둘이다:

- **ⓐ** 자리비움 자체가 60초 미만 — 알릴 것이 없다. **침묵이 정답이다.**
- **ⓑ** 자리비움은 몇 시간인데 **하루 예산 잔량이 0** 이라 0 으로 잘렸다.
  유저 쪽에서는 «아무 일도 안 일어났다» 로만 보인다.

`claimOffline` 에는 이미 «오늘 오프라인 보상 한도를 모두 받았어요» 토스트가 있었지만
**그 자리는 광고 배수(×1.5) 반려 전용**이라 ⓑ 는 한 번도 그 말을 못 들었다.
⚑ **199 25회차가 예산을 1,440 → 660분으로 내려 «처음 눈에 보이게 됐을 뿐»**,
분기 자체는 예산제를 도입한 199 3회차 이후 내내 있었다.

## 3. 처방 — «자른 축을 이름으로 묻고 ⓑ 만 말한다»

```js
const away = (Date.now()-lastTime)/1000;                     /* 자르기 전 자리비움 */
const room = Math.max(0, OFF_DAY_CAP_MIN - (S.daily.offMin || 0));
let sec = Math.min(away, OFF_CLAIM_CAP_H * 3600, room * 60);
if(sec < 60){
  if(away >= 60 && room * 60 < 60) notify(OFF_CAP_MSG);
  return;
}
```

⚠ **«away ≥ 60 && sec < 60» 으로 뭉뚱그리지 않았다.** 지금은 자르는 축이 둘뿐이라 두 식이
동치지만, 나중에 자르는 축이 하나 더 늘면 뭉뚱그린 식은 **그 축이 자른 것까지 «예산 소진» 이라고
거짓말한다.** 자른 축을 이름(`room`)으로 물어야 그 거짓말이 구조적으로 안 생긴다
(`verify842` [A6] 이 이 형태를 못박는다).

### 3-1. 팝업이 아니라 토스트다 — 등재문 ⓐ 를 정정했다 (위임 규약 채택)

등재문의 처방 후보는 «ⓐ 잔량 0 일 때도 **팝업**을 열고 «오늘 한도 소진 · 내일 다시» 를 적는다 ·
ⓑ 사이드/HUD 진입점에 소진 상태를 표시» 였다. 둘 다 안 골랐다.

| 안 | 대가 |
|---|---|
| ⓐ 팝업 | **149 와 정면으로 부딪힌다** — ««다이아 부족» 류 **단순 안내가 팝업으로 뜸 → 토스트로 교체**(방치형 게임 관례)» 가 주인 지시로 이미 닫힌 축이다. 게다가 `#offw` 는 «시간·골드·[받기]·[1.5배 받기]» 를 그리는 **보상 표**라 잔량 0 으로 열면 «0시간 0분 · 0골드 + 아무것도 안 주는 버튼 둘» 이 된다. 그것을 안 보이게 하려면 팝업에 **새 상태 하나**를 만들어야 하는데, 안내 한 줄에 새 UI 상태를 다는 것이 곧 149 가 없앤 그 «안내성 팝업» 이다. |
| ⓑ 진입점 표시 | **표시할 진입점이 없다.** `offlineReward()` 를 부르는 곳은 부팅 한 곳뿐이고(`index.html` 부트 블록), 사이드/HUD 어디에도 오프라인 보상 버튼이 없다 — `sideAlert()` 8축(attend·roul·mail·quest·promo·coll·pass·bless)에도 오프라인 축은 없다. **없는 버튼에 상태를 달 수는 없다.** |
| **채택 — 토스트(`notify`)** | 149 «단순 안내는 토스트» 그대로. 문구는 등재문이 시킨 대로 **`claimOffline` 의 그 문구를 재사용**하되, 사본을 만들지 않도록 상수 `OFF_CAP_MSG` 한 곳으로 뽑았다(402 «표 두 벌»). |

⚑ **`fxToast` 가 아니라 `notify` 다.** `fxToast` 는 토스트가 4장 쌓이면 **조용히 드롭한다** —
부팅 직후는 이용권 일일 보석·자동 축복·도감 안내가 같이 뜨는 자리라 실제로 찰 수 있고,
**조용한 드롭이 바로 이 작업이 잡는 결손**이다. `notify`(206)는 큐를 타고 자리가 나면 띄운다.

**되돌림 방법**: `offlineReward` 의 `if(sec < 60){ … }` 를 `if(sec < 60) return;` 로 되돌리면 끝이다
(`verify842` §R 이 그 사본을 실제로 만들어 빨개지는지까지 확인한다).

### 3-2. 안 건드린 것 — 299 레드닷 짝

등재문의 «**299 레드닷 규약과 짝** — 레드닷이 «지금 누를 수 있다» 를 약속하므로 소진 상태에서
