소환 비용 통화는 **다이아**다(`doSummon` → `summonCost`/`payFor`). 클릭 전후로
`dia 500000 → 500000` · `S.summons 0 → 0` · 보유 스킬 `1 → 1` 로 **전부 불변**.

> ⚠️ **골드는 판정에 쓰면 안 된다.** 유휴 루프가 계속 굴려 클릭과 무관하게 줄어든다.
> 무클릭 대조군(0.5s)에서 **골드만 −55** 로 같은 폭 드리프트, 다이아·소환수는 불변임을 확인했다.
> 처음 이 스크립트는 골드로 판정해 «소환 발생» 오탐 1건을 냈다 — **아이들 게임에서 «상태 불변»을
> 검사할 때는 유휴 루프가 건드리는 값을 빼고, 무클릭 대조군으로 드리프트를 먼저 재라.**
