## 2. 왜 «타원 반경»(등재문 ⓐ)이 안 되는가 — 산수 한 줄

이 상자는 **아래변이 세로 인셋 0**(449 가 닿는 면을 위해 그렇게 뒀다)이다. 타원 반경은
«상자의 두 변에 접하는 사분타원» 이라, `23px 30px` 를 주면 호가 **알약 바닥(y=84)까지 끌려
내려간다** — 우리가 원하는 원(검정 링 안쪽 윤곽 = r23 · 중심 (W−30, 54))은 y=77 에서 끝나는데
그 원은 상자의 아래변에 닿지 않으므로 **어떤 반경 쌍으로도 못 만든다.**
재현이 그 값을 그대로 냈다(띠가 D 로 안 남고 베벨이 가장 바깥이 된다).

## 3. 왜 «층» 인가 — 한 상자를 두 면이 공유한다

```
  가운데 칸 :  윤곽 ┃ K7(링) ┃ D7 ┃ B7 …   ← ::before 사방 7 인셋 · r23   (동심)
  닿는  면  :  윤곽 ┃        ┃ D7 ┃ B7 …   ← ::before 가로 0 · 세로 0 · r30 (동심 · 449)
  반대  면  :  윤곽 ┃ K7(링) ┃ ??           ← 같은 상자를 쓰는데 세로가 0 이라 어긋난다
```

세로 인셋은 **한 상자를 두 면이 공유**한다 — 닿는 면은 0, 반대 면은 7 이어야 하므로
`::before` 하나로는 둘을 동시에 만족시킬 수 없다. 의사요소는 `::before`·`::after` 둘뿐이고
`::after` 는 이미 검정 링이 쓰고 있다.

**그런데 `box-shadow` 의 스프레드가 «상자를 하나 더» 만들어 준다.**
`inset 0 -7px 0 7px` 의 그림자 상자는 «패딩 상자를 사방 7 인셋»(반경도 30→23 으로 따라 준다)
= **가운데 칸 `::before` 의 바로 그 상자**다. 그래서 같은 띠가 같은 자리에 생긴다.
남는 것은 «사방 7 짜리 고리» 가 하나 더 깔리는 것뿐인데, 그 자리는 **검정 링(첫 항)이 통째로 덮는다.**

⚑ **스코프가 공짜다** — 끝 칸의 `::after` 는 `--pill-mask`(378·409)가 이미 «반대 면 기둥 하나» 만
남긴다. 닿는 면에는 이 층이 **통째로 없으므로** 449 는 손댈 수 없다.
`V462_NEAR=1 node tools/probe462.js` 로 닿는 면 5곳 × 2코너 × 6각도를 A ↔ W 로 대조했고
**한 칸도 안 바뀌었다.**

⚠ **배경이 아니라 그림자다.** 등재문 ⓑ(«`::after` 배경에 코너 타일»)는 `verify409` **[8-Δ]**
(«::after 배경을 껐다 켜도 아래 코너 Δ0»)를 이관해야 성립한다고 등재문 자신이 적어 뒀다.
그림자로 그리면 그 항이 **그대로 참**이고(배경은 여전히 위 코너 고리 둘뿐), `verify462` **R3** 이
«배경을 꺼도 아래 코너 Δ0» 을 직접 재서 못박는다.

## 6. 자를 만들다 잡은 함정 셋

1. **셀렉터 목록에 의사요소를 붙일 때는 쉼표마다 붙이고 블록은 한 번만 적는다.**
   1회차 첫 실행에서 **네 변종이 소수점까지 같은 값**으로 나왔다 —
   `sel.split(',').map(s => s + '::after{…}').join(',')` 가 `a::after{…},b::after{…}` 라는
   **통째로 무효인 CSS** 를 만들고 있었다. 「값이 안 변한다」 보다 「**전부** 안 변한다」 가 신호다.
2. **주입은 «핀» 으로 박아야 한다.** 10 상점(`renderShop()`)은 틱마다 `.on` 을 상태에서 다시 그려,
   rect 는 끝 칸인데 **찍힌 픽셀은 셸**인 순간을 만든다(칸3 이 통째로 `S`/`R` = 바 배경·셸 림으로
   읽혔다). 한 번 켜는 것으로 부족해 16ms 간격으로 계속 되켠다.
3. **호스트 진입은 «한 번 · 칸 여럿»** 이다. «10 상점 칸1» 과 «10 상점 칸3» 을 별도 호스트로 두면
   두 번째 진입의 `goTab('hero')` 가 이미 열린 상점을 덮어, 알약 좌표에 **영웅 화면 픽셀**이 찍힌다.
   (449 §5-1 의 같은 함정 — verify449 는 그래서 «호스트 1회 · 칸 여럿» 꼴이다.)

## 7. 곁다리 등재 — **465** (`.stab-sep` 이 활성 끝 칸 위를 지난다)
