# 484 — 스킬은 «같은 등급 안에서는 같은 세기, 등급이 오를 때만 ×3»

> 세션 `sess-1558-7451` (루틴 워커 D) · 2026-08-30 · **1회차 · 472·485 와 한 세션**
> 지시서 [3]-**(가)** — «DPS 표가 평평한가» 라는 산술 명제라 비평가 없음.

## 1. 주인 원문

> «스킬은 dps로 쳤을때나 뭐나 같은 등급끼리 더 쎌필요없고 등급 바뀔때마다 더 쎼져야함. 3배정도 더 쎼지면 될듯»

## 2. 재현이 절반을 끝냈다 — **등급 축은 이미 옳았다**

`skillDmg = stat.dmg × m × gWear(g) × lvWear(Lv)` 에서 **`gWear` 가 이미 등급당 ×3** 이다
(197 `GRADE_JUMP`). ⇒ 지시의 «등급 바뀔 때마다 3배» 는 **한 줄도 안 고쳐도 이미 참**이었고,
남은 일은 «같은 등급끼리» 쪽뿐이었다. `verify484` C1 이 실피해로 재서 2.991~3.001 을 확인한다.

수리 전 등급 안 기본 DPS(`m × hits / cd`, 지속형은 `m × 3`):

## 3. 무엇을 고쳤나 — **`m` 27개뿐**

기준선 **`SK_DPS_REF = 1.84`** = 27종 기본 DPS 의 산술 평균 **1.8377** 을 소수 2자리로.

⚑ **평균을 고른 이유**: 등급 평균이 1.335~2.423 으로 흩어져 있어 어느 한 등급을 기준으로 삼으면
나머지 다섯 등급이 통째로 밀린다. 평균은 총량 이동을 최소화한다.

⚑ **등급마다 다른 기준선을 쓰지 않았다**: 등급 축 ×3 은 `gWear` 가 내므로, 등급별 기준선이
다르면 인접 등급 실비가 3.0 에서 벗어난다(주인 지시 위반). ⇒ **기준선은 전 등급 하나.**

`m = REF × cd / hits` (지속형 cd 0 은 `m = REF / 3`), 소수 3자리 반올림. 반올림 오차 최대 **0.078%**.

**cd · 발수(`hits`) 선언 · 범위 · 발사체 수 · 속도 · 관통 · 수명 · 연출은 한 글자도 안 바꿨다**
(주인 지시 «개성은 모양, 세기는 동일»). `verify484` D1·D2·D3 가 27종 전수로 못박는다.

⚠ `multi` 의 발수는 강화 Lv 로 3→9 까지 자란다. 티어 축의 자는 **Lv1 기준 3발**인데 이것은 484 가
새로 만든 규약이 아니라 **23494(장비·스킬 공용 «세기» 자)가 이미 쓰던 값**이다. Lv 로 자라는 발수는
«등급 안 세기» 가 아니라 레벨 축이라 이 지시 밖이다.
