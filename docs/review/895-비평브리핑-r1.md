# 895 1회차 비평 브리핑 — 10 이용권 카드 «2000% / 가치» 배지

## 무엇을 보는가

10 상점 «이용권» 탭 카드 **우상단의 분홍 별판 배지** 안, 노란 두 줄
(윗줄 «2000%» · 아랫줄 «가치») **하나만** 본다. 카드의 다른 부분(리본·알약·아트·노치)은
**다른 번호**(885·923·904 등)가 잡고 있으니 지적하지 마라.

## 좌표 규약 (⚠ 이 화면만 다르다)

- 레퍼런스 `docs/ref/151-이용권-카드.png` 는 **전체 화면 스크린샷이 아니라 카드 2장만 잘라 낸 504×705**
  이미지다. 그래서 **«프레임 y = 레퍼런스 y − 84» 변환은 이 작업에 해당하지 않는다.**
- 견줌은 **«카드 하나» 단위**로, **카드 폭을 1 로 놓은 비율**로 한다.
- 우리 캡처는 1080 폭이고 ref 카드 → 우리 카드 환산 계수는 **K = 2.0628** 이다
  (ref px × 2.0628 = 우리 px).
- ref 위 카드 = **배너형**, 아래 카드 = **불릿형**. 우리 캡처의 `c1`(noads) 이 배너형,
  `c2`(abless)·`c3`(offplus) 가 불릿형이다.

## 채점 축

지시서 [3] 대로 ①요소 배치 ②상대 크기 비율 ③여백·간격 ④정렬·그리드 ⑤색·명암 ⑥폰트 크기 비율
각 10점, **최저 항목 점수가 당신의 점수**다. 통과 판정은 **①②③④** 만으로 한다.
⑤⑥ 은 기록만 남긴다 — 단 **크기·bbox·비율에 관한 지적**(잉크 높이·폭·획 두께)은 ②·⑥ 비율 항목이므로
반드시 적어라. **색·아트 내용·서체 «모양»(획 끝 마무리, 글자꼴)은 감점 사유로 쓰지 마라.**

지적은 **«몇 px 어긋남 / 몇 % 큼»** 처럼 수치로만. 두루뭉술한 총평 금지. **후하게 주지 마라.**
각 지적에 **자기 신뢰도(상/중/하)** 를 붙이고, **어떻게 쟀는지**(무엇을 무엇으로 나눴는지) 한 줄 적어라.

## ⛔ 이미 닫힌 자리 — 다시 열지 마라 (열면 회차만 태운다)

1. **[1-g]/[1-h] 윗줄 글자 «폭»** — 833 3회차가 윗줄 다섯 글리프를 열 덩이로 갈라
   **글리프 폭 합은 이미 ref +1.5%** 임을 쟀다. 부족분은 전부 «글자 사이» 였고 답은 `letter-spacing`
   (2.9 → 5.2)이었다. **«글자가 좁다/넓다» 를 `font-size` 나 `scaleX` 로 처방하라는 지적은 받지 않는다.**
2. **기울기 +15°** — 885 4회차가 «각도를 가정하지 않는 자» 로 ref 를 직접 재 **+14.5~15.0°** 를 냈고
   우리도 +15.0° 다. 4인 연속 «맞다».
3. **강체 회전** — 두 줄은 **같은 점**을 돈다. 줄마다 따로 도는 것처럼 보인다는 지적은 자로 기각됐다.

## ⚑ 이번 회차가 바꾼 것 (당신이 확인해야 할 것)

**아랫줄 «가치» 하나만** 줄였다 — `font-size` 36 → **31** · 검정 획 7 → **5px** ·
상자 `top` +0.5px. 근거는 895 가 세운 자(`tools/scan895.py` — ref 와 우리를 같은 방법으로 잰다):

| 축 (우리 px 환산) | ref | 수리 전 | 수리 후 |
|---|---|---|---|
| 아랫줄 잉크 두께(베이스라인 수직) | 23.26 | 27.22 (**+17.0%**) | 23.14 (**−0.5%**) |
| 아랫줄 잉크 길이(베이스라인 방향) | 52.32 | 58.96 (**+12.7%**) | 51.46 (−1.7%) |
| 아랫줄 검정 획(밖으로 나온 몫) | 2.06 | 3.00 (**+45.4%**) | 2.00 (−3.1%) |
| 두 줄 «빈 띠» | 9.28 | 8.94 | 9.00 (−3.0%) |
| 노랑 AABB 높이 | 90.76 | 94.00 (+3.6%) | 92.00 (+1.4%) |

**윗줄은 한 칸도 안 건드렸다.** 윗줄 잉크 두께는 여전히 ref +6.0% 인데, 폭은 이미 맞아 있어
(위 «닫힌 자리 1») **손잡이가 없다** — 우리 서체가 ref 보다 «좁고 높다» 는 뜻이고 지시서 [3] 이
감점에서 뺀 서체 축이다. 이 잔차를 지적해도 좋지만 **처방으로 `font-size`·`scaleX`·`scaleY` 를
제시하지는 마라**(닫힌 자리를 되돌린다).

## 당신이 답할 것 (순서대로)

- **Q1** 아랫줄 «가치» 가 이제 ref 아랫줄과 **같은 덩치**로 읽히는가? 아니면 이번에 **너무 작아졌는가**?
  (수치로 — ref 카드폭 대비 아랫줄 잉크 높이·폭의 비를 양쪽에서 재라)
- **Q2** 두 줄 사이 **빈 띠**가 ref 와 같은가? 아랫줄이 줄면서 «위로 떠 보이거나» «아래로 처져 보이지» 않는가?
- **Q3** 아랫줄 검정 테두리 두께가 ref 와 같은가? (ref 는 아랫줄 테두리가 윗줄의 **절반**이다)
- **Q4** 배지 **블록 전체**(두 줄 덩어리)가 분홍 별판 안 제자리에 앉아 있는가? — 판 중심 대비 어긋남 px.
- **Q5** ①②③④ 각 점수와, 그 점수를 정한 **단 하나의 최저 근거**.
