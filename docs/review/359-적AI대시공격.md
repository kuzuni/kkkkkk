## 2. 처방과 그 이유

### ⓐ 평시 속도 — `BOSS_CHASE` 1.08 → **0.94**
358 이 플레이어 이속을 상수 `PLAYER_SPEED = 115` 로 굳혔으므로 이 비는 **영구히 «살짝 느림»** 을 뜻한다
(0.85~0.95 재량 구간의 위쪽 — 「살짝」에 가장 가깝고, 대시가 메워야 할 몫도 가장 작다).
상수의 **뜻이 바뀌었다**: «붙는 수단» → «평시 걸음». 붙는 일은 이제 대시가 한다.

### ⓑ 대시 — 상태 세 개짜리 기계 (쿨다운 → 예고 → 돌진)
```
DASH.boss = { cd0:1.2, cd1:2.0, tel:0.30, dur:0.34, spd:3.6, min:60,  max:470 }
DASH.mob  = { cd0:5.0, cd1:8.0, tel:0.42, dur:0.26, spd:2.6, min:120, max:380 }
```
* **예고(tel)** — 제자리(`spd = 0`)에서 자세를 잡고, 바닥에 «조여드는 원 + 조준선»(FX_W0 가는 선,
  63 낙하 예고와 같은 문법)을 그린다. 원이 몸통에 닿는 순간이 돌진 시작이다.
* **잠금** — 예고가 끝나는 **그 프레임**의 플레이어 방향으로 방향을 잠근다. **유도하지 않는다** —
  유도하면 피할 수 없는 공격이 되고, 66/172 가 재는 «진행 방향 정렬» 의 뜻도 흐려진다.
* **돌진(dur)** — 잠근 방향으로 `stat.speed × spd`. 조향(스월)·분리 힘을 전부 무시한다.
* **피해** — **새 경로 없음.** 시작 조건에 `e.cd <= 0`(접촉 공격이 준비된 상태)을 넣어 «못 때릴 대시» 는
  아예 안 나가게 했고, 닿으면 종전 접촉 판정이 때린다. 실측 대시 10회 ↔ 공격 11회로 거의 1:1 이다.
* **초기화는 이동 루프에서 게으르게** — 개체가 `makeEnemy` 만으로 태어나지 않기 때문이다
  (172 의 표: 승급 수호자·아레나는 `enemies.push` 직접 스폰). 한 곳에서 세우면 경로가 몇 개든 안 빠진다.

### ⓒ ⚑ 보스 `min` 은 **사거리(76px)보다 아래**여야 한다 — 1회차의 결함
처음에 `min:110` 으로 두었더니 `probe359` 가 **«보스가 76~96px 띠에서 맴돌며 대시도 접촉도 못 한다»**
를 찍었다(30초 공격 27 → **4회**). 평시 걸음이 0.93배라 카이팅(59) 앞에서 그 띠가 정확히
«닿지는 못하고 대시 창에도 안 드는» 사각이었다. `min` 을 60 으로 내려 «못 닿으면 곧 달려든다» 로
만든 뒤 9~11회로 돌아왔다. **대시의 아래끝은 사거리에서 정해야 한다 — 거리 숫자로 고르면 사각이 생긴다.**

### ⓓ 돌진 중 겹침은 «자기가 통째로» 물러난다 (verify257 회귀에서 발견)
257 의 위치 해소는 **절반씩** 미는데, 그 값은 «걸음»(프레임당 1.8px) 전제다. 프레임당 6.9px 로
파고드는 돌진 앞에서는 한 프레임에 다 못 풀어 잔차가 쌓였다 — `verify257` [6]④ 가
**«97% 아래 12프레임 연속»**(허용 2)으로 잡았다. 돌진하는 쪽만 `push` 를 전부(×1)로 바꿔
그 프레임 안에 반지름 합으로 떨어지게 했다. **미는 것은 자기 자신뿐**이라는 257 규약은 그대로다.
