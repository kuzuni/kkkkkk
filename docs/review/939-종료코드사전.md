| 호출 방식 | 수리 전 부모 코드 | 부모가 찍는 줄 |

⚑ **뿌리가 한 자리가 아니었다.** 전수(`tools/*.py` 105자 + `pxdiff41.py`)를 세니 같은 병이 **세 자 다섯 자리**였다
(`scan885e` 2 · `scan122` 2 · `scan892` 1). 등재는 하나만 지목했지만 **처방은 자리가 아니라 «사전» 이라야**
다음 자에서 똑같이 재발하지 않는다(936 의 «처방을 한 자에 적어 두면 나머지는 몇인지조차 모른다»).

## §2 처방 — 갈래 ⓐ·ⓑ 를 둘 다 채택했다(위임 규약)

등재문의 갈래: ⓐ 측정 실패를 **3 이나 1** 로 내린다 · ⓑ 게이트에 항을 세워 **자가 코드 2 를 자기 실패로 못 쓰게** 한다.

- **ⓐ 를 «3» 으로 골랐다.** 1 은 안 된다 — `--gate` 규약이 **0/1** 이라 «비가 과녁을 벗어났다»(FAIL)와
  «★ 를 못 찾았다»(못 쟀다)가 같은 값이 되어 885 채점 회차의 판정이 흐려진다. 3 은 아무 규약도 안 쓰던 값이다.
- **ⓑ 도 같이 했다.** ⓐ 만 하면 «지금 세 자» 만 낫고, 다음에 자를 만드는 워커가 같은 `sys.exit(2)` 를 또 적는다.
- 사전은 **한 곳**에 둔다 — `tools/pydep937.py` 의 `EX_ENV=2`/`EX_SELF=3` 와 `tools/pydep937.js` 의 같은 두 값.

```
0 = 통과 · 1 = 오류/FAIL(게이트 판정 포함)
2 = 환경에 없음  — 부트스트랩 need() 만 낸다
3 = 자가 못 쟀다(측정 실패 · 사용법 · 입력 없음) — 자가 fail() 로 낸다
```

바꾼 자리(제품 0줄 · 자·부품 6파일):

| 파일 | 무엇을 |
|---|---|
| `tools/pydep937.py` | 사전 `EX_*` + 공용 `fail(what, todo)` — stderr 에 «무엇이 안 됐는지 — 할 일» 한 줄 + 코드 3 |
| `tools/scan885e.py` | 측정 실패 2자리 → `fail(...)`. 도크에 종료 코드 절 신설 |
| `tools/scan122.py` | 사용법 2자리 → `fail(...)` |
| `tools/scan892.py` | 입력(캡처) 없음 1자리 → `fail(...)` |
| `tools/pydep937.js` | 코드 **3 도 옮긴다**(안 옮기면 부른 게이트가 스택 트레이스+코드 1 = 다시 «없는 자») · 코드 2 인데 **환경 말투가 아니면** 자식의 말을 옮기고 3 으로 내린다 · `available()` 사설 프로브의 3 → 1 |
| `tools/verify937.js` | 이관 — `[B8]` 인구조사 한 항 + 면제 목록에 `verify939`·`probe939` |

⚠ **`py()` 에서 «읽을 수 있는가» 와 «이미 화면에 나왔는가» 는 다른 물음이다.** `execFileSync` 는
`stdio` 를 안 적으면 자식 stderr 를 **부모로 흘리면서 동시에 `e.stderr` 에 담는다**(실측). 처음엔 이 둘을
한 깃발(`e.stderr != null`)로 묶었다가 `verify937` **[R5]**(«같은 안내문이 두 번 나오지 않는다»)가
**2회**로 빨개졌다 — 그 자가 이 실수를 그 자리에서 잡았다. ⇒ `shown`(= `opts.stdio` 미지정)과
`readable`(= 자식의 말을 손에 쥐었다)을 갈라 적고, **옮겨 적을 줄이 이미 흘러간 그 줄이면 안 찍는다.**
