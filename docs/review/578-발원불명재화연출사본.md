## 4. ★ 본체 — 근거가 더 약한 쪽이 더 높은 층을 얻고 있었다

문제는 «누가 띄웠나» 가 아니라 **«어디에 띄웠나»** 다. `fxFly`(34678) 의 층 판정은 518 이 세운 것이다:


그런데 판정이 `from.tap` **하나**에 걸려 있어서, **추측조차 못 한 묶음**(`fxAccSrc` 스냅샷이 `null` —
`fxWatch` 36549 주석이 스스로 «발원 불명 → fxFly 가 종전대로 **화면 중앙 기본값**» 이라고 적어 둔 그 자리)은
`combat` 도 `tap` 도 거짓이라 **가드를 통째로 비켜 갔다.**

⇒ 그 묶음은 `#fxl`(**z60 = 모든 팝업 위**)에 `.ui` 로 뜨고, 자리는 `fxFly` 의 폴백

## 5. 수리 — 둘이다

### ⓐ 제품 (`index.html` `fxFly`) — 판정을 «추측인가» 에서 «근거가 있는가» 로

```js
const guess  = !combat && (!from || !!from.tap || !fxPt(from));
const buried = guess && (fxCovered() || (from && from.el ? fxOverlaid(from.el) : false));
```

**518 의 축을 새로 만들지 않고 넓히기만 했다.** 타이밍·개수·소리·경로는 한 값도 안 바뀐다
(아래 계산이 전부 `combat` 만 본다 — 518 이 세운 구조 그대로).

⚠ **메인 화면은 한 값도 안 바뀐다** — `fxCovered()` 가 거짓이라 종전대로 `#fxl` + `.ui` 다
(`verify578` [D2]·[D3] · `verify518` [D2] 회귀 초록).

### ⓑ 자 (`tools/cap491.js`) — 하네스가 «없는 사건» 을 만들지 않는다

되돌림은 장면의 사실이 아니라 하네스의 사정이다. 값을 되돌린 **뒤에 감시자의 기준선을 같이 옮겨**
이 되돌림만 조용하게 만든다(제품 판정은 한 줄도 안 건드린다 — 진짜 획득은 그대로 연출된다):

```js
S.tstone = 1e6; ... ; if (typeof fxSeen === 'object' && fxSeen) fxSeen.tstone = S.tstone;
```

같은 이유로 **장면 시작 전 «재고 채우기»**(`S.gold = 1e18; … S.tstone = 1e6`)에서도 기준선을 맞춘다 —
안 맞추면 1번 장면(`rune`)에 같은 사본이 얹힌다(probe578 [B/down+60] 이 실제로 그 자리다).

그리고 **층을 비우는 두 자리가 둘 다 `#fxl`·`#fxlc` 를 같이 비운다.** 6·8회차는 `#fxl` 만 비웠는데
같은 `+n` 이 발원에 따라 `#fxlc` 로도 가므로 한 층만 비우면 다른 층에 남는다.
