### 결론 먼저

1. **등재문 그대로다 — `--rw-mb-seat` 4 → 0.** 바는 이제 받침 상면을 파고들지 않고 **닿기만** 한다.
   다섯 프레임 전부 얹힘 **+3.94 → 0**, 바가 **3.94px(= 4·rwc) 위**로 올라간다.
2. **두 문턱은 둘 다 초록이다** — 879 4회차가 «그려진 자» 로 옮긴 뒤의 값으로:
   그려진 격자↔바 **46.90 → 42.96**(행 간 25.6 의 **×1.68**, 문턱 1.5) · 바 **100.0%**(문턱 85%).
   886 이 «clear 0 은 ×1.35 또는 82.7% 라 반드시 깨진다» 고 적은 것은 **상자 자** 위의 산수였다.
3. **배율은 안 움직인다.** `RW_MB_FL` 이 12 → 16 이 되어 니치 예산이 4 줄지만, 꼬리를 뺀 예약
   (`RW_MB_GAP` 20.47)이 만든 여유 안이다: 1600 (139.1 − 16 − 20.47)/98 = **1.047 ⇒ min 이 1**.
   1회차 이전과 같이 다섯 프레임 전부 배율 1 이고 **바 크기·폭·중심은 Δ0px** 이다.
4. ⚑ **곁다리 하나를 이 회차가 잡았다** — `verify867` **[2] 가 879 4회차의 이관을 못 받은 쌍둥이**였다
   (분자는 격자 **상자** 하변, 분모는 **그려진** 행 간 25.6). 문턱이 ×1.0 이라 1600 이 **1.12 로 간신히**
   초록이었을 뿐이고, 바가 4px 올라가자 **0.97 로 넘어가 빨개졌다.** 같은 자로 다시 재면 ×1.68 이다.
   ⇒ `verify879` [2]·[2e] 와 **한 벌로** 이관했다(§3).
5. 되돌림은 상수 둘을 4 로 되돌리면 된다(CSS `--rw-mb-seat` · JS `RW_MB_SEAT` — **반드시 같이**).

### §5 안 건드린 것 (다음 세션이 다시 열지 않게)

- **`--rw-mb-seat` 을 «여유 손잡이» 로 쓰지 마라**(886 의 경고 · 등재문이 다시 못박았다).
  0 과 4 말고 다른 값을 넣을 자리가 아니다. 예산이 필요하면 니치·꼬리·문턱 쪽을 열어야 한다.
- **`clear 12`(867 이 말한 «받침 위 12») 의 기각은 그대로 살아 있다** — `verify886` [5] 가
  사본으로 ×1.22 / 92.5% 를 찍는다. 910 이 무효로 만든 것은 **clear 0** 하나뿐이다.
- **`verify867` [2b] · `verify879` [2b]**(위 간극 > 아래 간극 ×1.5)는 **안 건드렸다.** 둘 다 상자 자로
  재고 있고 1600 이 **1.57:1** 로 초록이다(전 2.42:1 — 분자가 3.94 줄고 분모가 3.94 늘어 여유가 얇아졌다).
  ⚠ **다음에 이 자리를 만지는 세션은 이 항을 먼저 보라** — 그려진 자로 재면 2.73:1 이라 여유가 넉넉하고,
  상자 자로는 문턱까지 **0.07** 뿐이다. 지금 고치지 않은 이유는 «빨갛지 않은 자를 이번 작업의 범위로
  끌어들이지 않는다» 이고, 고칠 때는 **두 자를 같이** 옮겨야 한다(§4 의 교훈).
- **배율(`--rw-mbs`)·니치 예산식·문턱 셋은 한 글자도 안 바꿨다.** 바뀐 것은 상수 둘이다.
