# 38 — 패널 오버레이화 (열려도 메인 화면 무영향) · 실측 기록

세션 `sess-1658-26076` (2026-08-24). 지시서 [3]-**(가) 기계적 작업**으로 처리 —
레퍼런스 대조가 필요 없는 **구조 변경**이므로 **비평가를 띄우지 않았다.**
검증은 `문법 검사 + 헤드리스 실측(요소 이동 0px · 콘솔 에러 0 · 넘침 0) + 픽셀 대조` 로 했다.

## 1. 버그

`#panel` 이 `#app` 의 **flex 흐름 안**(`flex:none;height:844px`)에 있어서, 탭을 열면
`#stagearea{flex:1}` 이 그만큼 줄었다. `syncPanel()` 끝의 `resizeCanvas()` 가
`layoutSide()` 를 다시 돌려 **사이드 아이콘이 위로 밀리고 세로로 찌그러졌다.**

수정 전 실측 (1080×1920, 탭 «영웅» 열기):

| 요소 | 닫힘 | 열림 | Δ |
|---|---|---|---|
| `#stagearea` h | 1636 | 792 | **−844** |
| `#view` h | 1636 | 792 | −844 |
| `#battlefoot` top | 1559 | 715 | −844 |
| `#tuto` top | 1418 | 574 | −844 |
| `#sideL` top / h | 176 / 811 | 164.75 / 542.16 | −11.25 / **−268.84 (−33%)** |
| `#sideR` top / h | 337 / 371.97 | 272.39 / 248.67 | −64.61 / −123.30 |

**07 스킬 시트(1484px)** 는 더 심했다 — `#stagearea` 1636 → **152**,
`#sideL`·`#sideR` 높이가 **0** 이 되어 사이드 아이콘이 통째로 사라졌다.

측정한 요소 16종 기준 **탭 1개 열 때마다 33건**이 움직였다.

## 2. 수정 (3곳, index.html)

1. **`#panel` 을 오버레이로** — `position:absolute;left:0;right:0;bottom:180px;z-index:9`
   (`flex:none` 제거). `bottom:180` = 탭바 높이. 다른 껍데기(`#dunw`·`#shopw`·`#relicw`·`#eqw`)가
   이미 쓰는 것과 같은 값이다.
   - `z-index:9` 근거 — 캔버스 위 오버레이(스테이지 헤더·배틀풋 z3, 사이드 z5)와 상단 HUD(z6) **위**,
     딤/다이얼로그/전체화면 껍데기(z28~40) **아래**. 07 시트가 이미 쓰던 z9 와 같은 값이라
     시트 딤이 HUD 를 덮는 동작이 그대로 유지된다.
2. **`#panel:has(#bSk.on)` 의 `position:relative` 제거** — 베이스가 `absolute` 가 됐으므로
   `relative` 를 남기면 오버레이가 다시 흐름으로 돌아간다. `z-index:9` 는 그대로 둔다.
3. **`syncPanel()` 끝의 `resizeCanvas()` 호출 제거** — 개폐가 `#stagearea` 높이를 바꾸지 않으니
   불필요하고, 부르면 캔버스 버퍼 재할당 + `layoutSide()` 재배치가 일어나 지시 위반이 된다.
   (`ResizeObserver` 는 `#stagearea` 를 계속 관찰하지만 크기가 변하지 않으므로 발화하지 않는다.)

**바꾸지 않은 것**: `#tabbar`(흐름 유지) · `fit()` · `resizeCanvas()` · `layoutSide()` 본문 ·
패널 내부 레이아웃 · 저장 구조(KEY 유지).

## 4. 넘기는 것 / 주의

- **패널이 열리면 `#tuto`(튜토리얼 배너)·`#battlefoot` 이 시트에 가린다.** 흐름에서 뺐으니
  당연한 결과이고 «메인 화면 요소는 움직이지 않는다» 는 지시대로다. 레퍼런스의 바닥 시트도 같다.
- `bottom:180px` 은 탭바 높이 하드코딩이다. **탭바 높이를 바꾸는 작업(A1 개정 = 24번)** 이
  180 을 건드리면 `#panel`·`#dunw`·`#shopw`·`#relicw`·`#eqw` 5곳을 같이 고쳐야 한다.
- 9:16 보다 넓은 화면은 `frameH` 가 1600 으로 clamp 되므로 스킬 시트(1484 + 탭바 180 + HUD 104
  = 1768)가 프레임 위로 넘친다. 수정 전에는 flex 가 캔버스를 0 으로 눌러 «캔버스 소멸» 이었고
  지금은 시트 상단이 `#app{overflow:hidden}` 에 잘린다 — **넘침 검사에서 «프레임 밖 요소 0건»**
  (시트가 프레임과 겹쳐 있으므로) 이고 메인 화면 영향도 0 이라 38 범위에서는 통과 처리했다.
  시트 자체를 짧은 프레임에 맞추는 건 **07 구간** 일이다.
