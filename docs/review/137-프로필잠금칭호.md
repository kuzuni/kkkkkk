# 137 — 19 프로필 «잠금 칭호» 자물쇠가 이름 정중앙을 덮는 버그

작업 단위 137 (T1 버그) · 2026-08-26 · `sess-0055-6926` 워커 D · 1회차로 종결.
지시서 [3]-**(가) 기계적/버그 수정** 절차 — 레퍼런스 배치를 «맞추는» 작업이 아니라
«글자가 가려지는 결함» 을 없애는 작업이라 비평가 루프 없이 **실측 + 게이트**로 검증했다.

## 1. 증상과 원인

잠긴 티어 7칸 전부에서 자물쇠가 칭호 이름의 가운데를 덮어 1~2자가 읽히지 않았다.

```
.pf-lk{position:absolute;left:50%;top:22px;width:28px;height:32px;margin-left:-14px}
.pf-bn{position:absolute;left:26px;top:11px;width:298px}   /* 안에서 이름은 가운데 정렬 */
```

`.pf-card` 폭이 350 이므로 자물쇠 중심 = `350/2` = **175**,
배너 안에서 가운데 정렬된 이름의 중심도 `26 + 298/2` = **175**.
두 중심이 **글자 길이와 무관하게 CSS 상 항상 같은 점**이라, 이름이 자물쇠(28px)보다
길기만 하면 반드시 가운데가 가려진다. 수정 전 실측(`node tools/verify137.js --broken`):

| 칭호 | 자물쇠 x(카드상대) | 글자 잉크 x | 겹침 |
|---|---|---|---|
| 실버 | 161..189 | 156..194 | 28px |
| 골드 | 161..189 | 157..193 | 28px |
| 플래티넘 | 161..189 | 137..213 | 28px |
| 다이아 | 161..189 | 146..204 | 28px |
| 마스터 | 161..189 | 146..204 | 28px |
| 그랜드마스터 | 161..189 | 118..232 | 28px |
| 챌린저 | 161..189 | 146..204 | 28px |

7칸 전부 28px — 자물쇠 폭 그대로다. 즉 «가끔 겹친다» 가 아니라 **항상 자물쇠 폭만큼 가린다.**

## 2. 레퍼런스 재측정 — 등재 당시 전제는 틀렸다

등재문(PROGRESS 137 행)은 «레퍼런스는 자물쇠가 배너 위에 겹치지 않는다 →
`docs/ref/19-프로필-팝업.jpg` 를 다시 재서 자물쇠 자리를 잡을 것» 이라고 적었다.
그래서 **먼저 레퍼런스를 다시 쟀다** — `tools/scan137.py`(신설).
배너 안쪽(베벨·검정 외곽 제외)에서 «흰 덩어리»(자물쇠)와 «잉크»(글자) 열 투영을 따로 낸다.

```
ref#3: 자물쇠 x(카드) 164..186 중심 175.0 · 글자 덩어리 131..161 · 189..218 (중심 174.5)
ref#4: 자물쇠 x(카드) 164..186 중심 175.0 · 글자 덩어리 117..161 · 189..205 · 215..232
ref#5: 자물쇠 x(카드) 164..186 중심 175.0 · 글자 덩어리 130..161 · 189..218
ref#7: 자물쇠 x(카드) 163..186 중심 174.5
```

열별 원자료(`python3 tools/scan137.py dump 3`)를 보면 왼쪽 글자 덩어리는 **자물쇠 좌변에서
정확히 끊기고**(…160, 161 부터 white 13→27) 오른쪽은 자물쇠 우변 바로 다음(189)부터 다시 시작한다.
글자가 자물쇠를 **피해 배치된 것이 아니라 자물쇠에 잘려 있는 것**이다.

즉 **레퍼런스도 자물쇠를 카드 중심에 두고 칭호와 겹친다.** 측정표 `docs/measure/19-프로필팝업.md`
§5-4 «흰색 몸통 28×32 (카드 중앙 배치)» · §5-3 «청회 등급 텍스트는 옐로 계열(자물쇠에 부분 가림)»
과도 일치한다. 등재문이 제시한 «배너 우측 바깥» 은 레퍼런스에 존재하지 않고, 애초에 자리도 없다 —
배너 우변 324, 카드 우변 350 이라 바깥 여유가 **26px 뿐**이고 자물쇠 몸통은 28px 다.

**결론: 베낄 «안 겹치는 자리» 는 레퍼런스에 없다. 이 수정은 레퍼런스 모사가 아니라
의도된 이탈이며, 그 사실을 여기와 측정표 §5-4 에 남긴다.**

## 3. 처방 — 글자는 그대로, 자물쇠만 배너 오른쪽 안쪽으로

등재문의 두 선택지 중 «배너 위 오버레이 + 이름 좌측 정렬» 계열을 택하되,
**이름은 건드리지 않았다.** 이유:

- 이름 중심 174.5 는 측정표 §5-3 의 레퍼런스 실측값이고, 19 화면은 이미 ①~④ 8 로 통과한 화면이다.
  글자를 왼쪽으로 옮기면 «통과한 좌표» 를 7칸 전부에서 깨뜨린다.
- 자물쇠는 28×32 아이콘 하나뿐이라 옮겨도 잃는 것이 작고, **크기·세로 위치는 레퍼런스 그대로** 둘 수 있다.
- 우리 칭호가 레퍼런스보다 길다(최장 «그랜드마스터» 6자, 잉크 114px). 이름을 왼쪽으로 밀면
  긴 칭호가 배너 좌측 테이퍼(14px)로 다시 밀려 나간다.

```css
/* 전 */ .pf-lk{left:50%;  top:22px;width:28px;height:32px;margin-left:-14px; …}
/* 후 */ .pf-lk{left:276px;top:22px;width:28px;height:32px;                  …}
```

자리 근거(카드 상대 좌표):

| 항목 | 값 |
|---|---|
| 자물쇠 | **276..304** (w28, 중심 290) — 크기·`top:22` 는 레퍼런스 그대로 |
| 최장 칭호 «그랜드마스터» 잉크 우변 | 232 → **여유 44px** |
| 배너 우변 | 324 → **안쪽 20px** |
| 자물쇠 위·아래 끝 행에서의 배너 우변 | 육각 테이퍼 14px · 배너 반높이 28.5 · 끝 행 거리 17.5 ⇒ `324 − 14×17.5/28.5` ≈ **315** → 자물쇠 우변 304 가 그 안쪽 |

즉 자물쇠 네 모서리 전부가 배너 면 위에 앉는다(테이퍼 밖으로 튀지 않는다).
