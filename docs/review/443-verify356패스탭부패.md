## 6. 교훈

1. **«목록을 손으로 고쳤다» 는 수리는 그 목록이 다시 뒤처지는 것을 못 막는다.** 397 이 네 줄을 고쳤고
   428 이 그중 한 줄을 다시 죽였다. 402 의 «표가 아니라 id 파생» 이 그대로 여기서도 답이었다.
2. **«resolve 되는가» 는 «빠진 게 없는가» 가 아니다.** 목록형 스코프에는 자가 **두 방향** 필요하다 —
   유령(적힌 게 죽었다)과 사각지대(산 게 안 적혔다). 후자는 영원히 초록이라 아무도 안 본다.
3. **무음 실패를 고칠 때는 대체 경로도 소리를 내야 한다.** 파생이 «못 읽으면 빈 목록» 이었다면
   무음의 자리만 옮긴 것이다 — 그래서 던지게 했고, [R8]-ⓑ 가 그것을 지킨다.
4. **한 줄이 빨간 동안 나머지가 초록인 것 자체가 결함일 수 있다.** 수리 전 [A]·[B] 는 «전 화면을 봤다» 는
   얼굴로 초록이었지만 한 화면을 두 번 세고 한 화면을 안 본 값이었다.
