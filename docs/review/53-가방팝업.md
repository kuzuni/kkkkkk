### 2회차에 정정한 측정 오독 — 칸 크기

| | 1회차(오독) | 2회차(정정) |
|---|---|---|
| 칸 크기 | 149 × **159** | **148 × 147** |
| 세로 pitch | **171** | **170** |

칸 중앙 열(x=200)에서 쟀더니 **수량 숫자의 검정 외곽선**(y1156..1157)이 칸 아래 테두리로 잡혔다.
수량은 칸 아래 테두리에 **걸쳐서 ~9px 삐져나온다**. 가림 없는 열(x=410)에서 재면 **999..1145 = 147**.
→ LESSONS 22-① / 04-② «가림 없는 열을 골라 재라» 가 세 번째로 재발했다.

### 2회차에 정정한 딤 계수

1회차는 **02 기본 메인 화면**과 비교해 α = .61 을 냈는데, 02 는 **배경 상태가 다르다**(STAGE·배너 구성).
배경이 같은 상태인 **40 (보스 재도전)** 과 비교하면 휘도비 0.457 로 화면 전역에서 균일 → **α = .545**.
→ 딤 계수는 «아무 레퍼런스» 가 아니라 **배경 상태가 같은 레퍼런스**와 비교해야 한다.

### 2회차에 잡은 CSS 함정 — padding box

탭 스트립을 `.bg53` 기준 `left:85px; margin-top:12px` 로 놨는데 **x +8 · y −7.5** 로 어긋났다.
`.bg53` 은 `border:8px` 이고 **절대배치 자식의 기준은 border box 가 아니라 padding box** 다(LESSONS 03).
→ `left = 151 − 74 = **77**`, `margin-top = 12 + 8 = **20**`.

## 기능 (T3 «기능 연결은 가능한 범위에서»)

레퍼런스의 가방은 **«소모품 · 재화» 2탭**이고 활성 탭이 «재화» 다. 2탭 구조를 그대로 가져오고 내용만 우리 데이터로 매핑했다 — **둘 다 실제 게임 상태를 읽는다(«준비 중» 없음).**

| 탭 | 내용 | 소스 |
|---|---|---|
| **재화** (기본 활성) | 골드 · 다이아 · 유물석 · 마일리지 · 스탯 포인트 + 보유 아이템 재료 | `S.gold/dia/relic/mileage/sp` · `S.own` |
| **소모품** | 던전 입장권 5종 · 상자별 무료 소환권 3종 · 룰렛 남은 횟수 | `S.daily.dun` · `S.daily.freeSum` · `S.daily.spins` |
