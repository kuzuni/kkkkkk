## 2. 뿌리 — 플레이어만 «살아 있는 프레임» 을 뽑는다

`verify243` §1 은 «서 있는 자세에서 스프라이트가 자기 그림자 위에 서는가» 를 잰다. 표본을 고르는 방식이 셋인데
**플레이어 하나만 다르다**:

| 대상 | 표본 | 성질 |

| 적 6종 | `A.a[T.walk][0]` | 제품이 `ETYPE` 에 선언한 **쉬는 자세**에 고정 |
| 펫 3종 | `A.a[sp.anim][0]` | `PET_SP` 가 선언한 **쉬는 자세**에 고정 |

## 3. 처방 — 표본을 «제품에게 묻는다»(368·393 과 같은 모양)

자세를 손으로 박지 않는다. 제품이 «안 움직일 때» 스스로 거는 그 호출을 그대로 걸고, 무슨 프레임이
그려지는지 **제품에게 묻는다**:

```js
const sav = { anim:player.anim, akey:player.akey, at:player.at, afps:player.afps, aloop:player.aloop };
setAnim(player, 'knight', 'idle', 8, true); player.at = 0;   /* index.html 20443 · 33796 과 같은 호출 */
const fn = curFrame(player) || A.a.idle[0];
Object.assign(player, sav);                                   /* 재는 것 말고는 아무것도 안 바꾼다(§3 규약) */
```

- `setAnim` 은 **같은 애니면 곧장 되돌아간다**(16615) — 그래서 `player.at = 0` 을 따로 준다. 안 주면
  이미 `idle` 이던 실행에서만 위상이 남아 **또 표본이 흔들린다**.
- 새 상수 **0개**. `'idle'` 이라는 이름조차 제품 코드(20443 `else setAnim(player,'knight','idle',8,true)`)에서
  가져온 것이고, 실제 프레임 이름은 아틀라스가 말한다.
- 적·펫과 **규칙이 같아졌다** — 셋 다 «제품이 선언한 쉬는 자세의 0프레임».

## 4. 무르게 풀지 않았음 — 세 겹

허용치는 **한 칸도 안 넓혔다**(3% / 8% 그대로). 표본만 제자리에 놓았고, 그것이 «자를 푼 것» 이 아님을
게이트 안에서 세 항이 못박는다:

| 항 | 내용 | 값 |
|---|---|---|
| `§1 플레이어 표본 = …쉬는 자세의 0프레임` | 다음 세션이 `curFrame(player)` 로 되돌리면 **곧바로 빨개진다** | `idle/frame0000` |
| `§1 되돌림 — knight xo 를 빼면 …` | 243 수리 전 상태(`xo=0`)로 되돌리면 같은 항이 허용을 크게 넘는다 | **Δx −124.5 > ±12.9** |
| `§1 되돌림 뒤 원복` | 되돌림 시험이 제품을 더럽히지 않았다 | 0.5 → 0.5 |

⚠ **334 의 갈림길** — 처방 ②(허용치를 넓힌다)를 골랐으면 «스프라이트가 자기 그림자 옆에 선다» 는
243 의 소유권이 통째로 사라진다. 처방 ①(표본을 제자리에)은 그 뜻을 그대로 두고 **재는 자리만** 옮긴다.
되돌림 −124.5 는 그 뜻이 살아 있다는 증거다(수리 전 기사 249px 과 같은 급).
