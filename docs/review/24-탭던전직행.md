작업 세션 `sess-1814-7310` (2026-08-24). **기계적 작업**이므로 지시서 [3]-(가) 대로
**비평가를 띄우지 않고** grep 잔여 + `node --check` + 헤드리스 전수 실측으로만 검증했다.

### 제거 1줄 — 이게 실제 버그였다

```js
/* 삭제됨 */ $('tabbar').addEventListener('click', closeDungeon, true);
```

던전이 «사이드 아이콘으로만 여는 페이지» 이던 시절의 정리 코드다. **캡처 단계**라 `goTab` 보다
먼저 돌아 던전을 닫아 버리고, 그 뒤 `goTab('adv')` 이 «닫혀 있음»을 보고 **다시 연다** —
재클릭 토글이 죽는다. 1차 헤드리스 실측에서 `[던전탭 재클릭(닫힘)] dunw=true` 로 잡혔다.
다른 탭으로의 이동은 `goTab` 각 분기의 `closeDungeon()` 이 이미 처리하므로 리스너는 불필요하다.

> **교훈**: «어떤 UI 를 탭이 소유하게» 바꿀 때는 그 UI 를 정리하던 **캡처/전역 리스너**가
> 남아 있는지 먼저 grep 하라. 캡처 리스너는 핸들러보다 먼저 돌아 토글 상태를 뒤집는다.
