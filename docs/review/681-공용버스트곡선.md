## §2 처방 — 등재문 ①②를 둘 다, 단 ② 는 «미루기» 가 아니라 «뒤로 몰기»

```
0%   translate(0,0)      scale(.34)  α1     ← ① 탄생 팝
11%  translate(.13d)     scale(1)    α1
52%  translate(.78d)     scale(1)    α1     ← 42회차의 «퇴장 ≥180ms» 경계 — 한 값도 안 건드린다
76%  translate(.89d)     scale(.82)  α.86   ← ② 알파를 뒤로 몰고 그만큼 더 줄인다
90%  translate(.95d)     scale(.66)  α.55
100% translate(d)        scale(.5)   α0
```

**등재문 처방 ②(«페이드 시작을 52% → 70% 로 미룬다»)는 그대로 쓰면 안 된다** — 그러면 퇴장 폭이
182 → 114ms 로 줄어 **42회차가 닫은 자리**(«퇴장 50~90ms 는 «동시 전멸» 로 읽힌다» — 비평가 BG·BH
2인 공통)로 되돌아간다. 같은 목적(«꼬리가 빈 껍데기가 아니게»)을 퇴장 폭을 **182ms 그대로 둔 채**
달성하는 길이 알파를 뒤로 모는 것이다: α 1 → .86 → .55 → 0 으로 몰면 α≤0.35 구간만 96.9 → 27.9ms 로
줄고, 그 구간의 크기도 .62 → .5 라 «큰 얼룩이 오래 남는» 그림이 사라진다.

**안 건드린 값(남의 자들이 그 위에 서 있다)**
- 수명 `.38s`/`FXSPARK_MS` 380 — `verify660` [E2]·`verify666` [G] 가 읽는다.
- 52% 고원 경계·이동 계수 `.78d` — 42회차가 «퇴장 ≥180ms» 를 그 위에서 계산했다.
- 끝 scale 은 **.5 아래로 안 내렸다** — 16회차가 «.38 은 중간 프레임이 12px 로 읽힌다» 로 올린 값이고
  이 곡선은 26px 구슬과 44~47px 아이콘이 **같이** 탄다.
- **어느 지점도 scale 1 을 안 넘는다**(오버슈트 금지) — 619 13·14회차의 가둠(`sz/2 + FXB_INPAD`)이
  «최대 크기 = sz» 를 전제로 상자를 좁혀 뒀다. 넘기면 잉크가 액자를 샌다.
- 전용 봉투 `fxRlic`(753 유물 획득 알)은 `animation-name` 으로 갈라져 있어 **불변**이다.
