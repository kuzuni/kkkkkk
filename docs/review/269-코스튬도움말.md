## 1. 무엇을 옮겼나 — «일반 설명» 과 «이 칸 하나의 수치» 를 가른 선

슬롯 상세(`showCosDetail`)의 `.sk-db` 설명 박스에는 성격이 다른 두 가지가 섞여 있었다.

| 구 문장 | 성격 | 처리 |
|---|---|---|
| «보유한 코스튬은 보유 효과가 영구 적용되고, 착용하면 외형이 바뀝니다» | 코스튬 **일반** | → [?] 도움말 |
| «보유 효과는 10개마다 한 계단씩 커집니다» | 코스튬 **일반** | → [?] 도움말 |
| «강화석으로 최대 Lv. 500까지 (효율 곡선은 모든 코스튬이 동일)» | 코스튬 **일반** | → [?] 도움말 |
| «강화 효과 Lv. n — 공격 +x · 체력 +y · 골드 +z» | **이 칸 하나** | 상세에 **남김** |
| «(미보유) ⟨조건⟩ 시 지급됩니다» | **이 칸 하나** | 상세에 **남김** |
| «(미보유) 받으면 보유 효과가 영구 적용되고 … 키울 수 있습니다» | 코스튬 **일반** | → [?] 도움말 |

등재문의 «그 두 블록을 제거(**그 자리는 개별 코스튬 정보만 남긴다**)» 를 이 선으로 읽었다.
`.sk-sl`·`.sk-db` 를 **통째로 지우지 않은 이유**는 기하다 — `.sk-ct` 는 bottom 340, `.sk-ow` 는 top 604 이라
두 블록을 빼면 그 사이가 **264px 짜리 빈 구멍**이 된다(08 껍데기 `.skd` 는 800×701 고정). 그래서
자리·크기는 1px 도 안 건드리고 **글자만** 바꿨다(게이트 [F] 가 스킬 세부와 픽셀 동일을 매 실행 재측정).

라벨도 «코스튬 설명» 이 아니다:

- 보유 칸 → **«강화 효과»** · 본문 = 지금 Lv 의 수치 + `Lv. 500` 까지 갔을 때의 수치(둘 다 `COS_LV` 에서 나온다)
- 미보유 칸 → **«획득 방법»** · 본문 = `cosReqText(a)`(= 어느 승급전이 주는가)

## 3. 도움말 팝업 — «설명만 있는 팝업»

A5 공용 `popup(title, html)` 을 그대로 쓴다 → 딤 탭·[확인] 두 길로 닫힌다(게이트 C12·C13).
전용 껍데기를 새로 만들지 않았으므로 `closeModal()` 의 클래스 목록도 안 건드렸다.

본문은 5문단이고 **수치는 전부 상수에서 읽는다** — `COS_STEP_EVERY`(10개마다 한 계단) ·
`COS_MAXLV`(Lv. 500). 상수를 고치면 설명이 따라간다(게이트 C9·C10 이 이 연결을 붙잡는다).

글씨는 **35px**. `.mbody p` 는 24px 인데 **A5 공용이라 못 건드린다**(265 가 같은 벽을 만났다) —
179·265 와 같은 처방으로 이 팝업 전용 래퍼 `.cos269`(특이도 0-2-1)만 키웠다. 48px 은 179 승급전
전용 배율이라 쓰지 않았고, 265 가 22 퀘스트 급으로 잡은 35px 에 맞췄다. 5문단이 `.mbox` 상한을
**144px 남기고** 들어간다(게이트 C11).

### ⚠ [G] 에서 잡은 «뜨고 지는 FAIL» 의 정체 (게이트 쪽 함정)

262 식으로 «읽고 → 손 떼고 → 다시 읽기» 를 하면 **두 읽기 사이에 홀드가 한 번 더 tick** 해서
Lv 가 1 오른 채 비교된다(실측: 3회 중 2회 FAIL, 대기 시간을 250→400ms 로 늘리자 재현률이 올라갔다).
262 가 보려는 것은 «**같은 레벨에서** mdLive 가 통짜 재렌더와 같은 글자를 쓰는가» 이므로,
`clearTimeout(upHold.timer)` 로 **타이머만 얼리고**(`end()` 를 안 부르니 통짜 재렌더도 안 난다)
같은 틱 안에서 라이브 표기와 `showCosDetail(id)` 재렌더 표기를 나란히 읽게 고쳤다 — 이후 6회 연속 PASS.
같은 모양의 단언이 `tools/verify262.js` §8 에도 있다(**그 파일은 안 건드렸다** — 내 구간이 아니고
지금 38/38 PASS 다). 거기서 같은 증상이 뜨면 이 처방을 그대로 옮기면 된다.

## 6. 안 건드린 것 (근거)

- **`popup()` 의 [확인] 버튼** — 267(룰렛·승급전·길라잡이 [닫기] 제거)이 그 함수를 만지는 작업이고
  **다른 세션이 선점 중**이다(`docs/claims/267.lock`). 도움말은 «닫는 길이 있어야» 하는 쪽이라
  그대로 두는 것이 맞다. 267 이 `noOk` 같은 변형을 넣더라도 이 팝업은 대상이 아니다.
- **07 스킬·26 펫 세부 팝업의 «스킬/펫 설명»** — 지시는 코스튬 한 화면이다. 같은 `.sk-sl`·`.sk-db`
  구조를 쓰지만 손대면 268 의 «네 계열 픽셀 동일» 을 내 쪽에서 깨는 셈이 된다.
- **`.mbody p`(24px)** — A5 공용. 팝업 글씨 일반 확대는 267 계열의 몫이다.
- **`.sk-db` 박스 자체** — §1 의 기하 이유로 남겼다. 이 자리를 정말 비우려면 `.sk-ow` 를 위로
  올리고 두 번째 알약 행을 새로 만들어야 하는데, 그러면 08 껍데기가 계열마다 갈라진다(268 이 방금 모은 것).
