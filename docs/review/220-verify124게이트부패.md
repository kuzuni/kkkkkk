## 2. 원인 — 153 이 «즉시 보석» 의 목적지를 지갑에서 우편함으로 옮겼다

`index.html` 21102행(`grantPass()` 꼬리):

```js
/* 153 — 권한(위)은 즉시, **재화(아래)는 우편함**으로 간다. 쿠폰·즉시 보석은 «상점 구매품» 이다. */

  sendMail({ t:'🛒 이용권 구매 보상 — ' + p.n, c:p.once || 0, m:p.cp || 0,
    b:'상점에서 구매하신 이용권의 지급 보상입니다. 보관 기간은 없습니다.' });
```

`buyPass()` 는 `S.dia -= p.dia` 로 **정가만** 빼고, 팝업 문구도 이미 153 을 반영해
«우편함으로 지급» 이라고 말한다(21159~21161행). 즉 **구매 순간의 순차감 = 정가 75,000 이 정상**이고,
`once` 10,000 은 우편을 수령해야 들어온다.

게이트의 기대식은 그 이전 세계의 것이었다:

```js
/* 151 — 구매에 «즉시 보석 지급» 이 붙었으므로 순차감은 정가 − 즉시분이다 */
return { … cost: d0 - S.dia, price: p.dia - (p.once || 0), … };
```

`p.once` 를 **가격 할인**으로 읽은 식이다. 151 시점에는 `grantPass()` 가 `S.dia += p.once` 로
즉시 입금했으므로 순차감이 실제로 65,000 이었고 그때는 맞는 식이었다. 153 이 그 한 줄을
`sendMail()` 로 바꾸면서 **기대값만 과거에 남았다.** 149·150 이 «안내의 그릇» 을 바꿔 놓은
214·215·217·218 과 완전히 같은 계열이고, 여기서 바뀐 것은 **«지급의 목적지»** 다.
