### 남긴 것 · 다음 세션에 넘기는 것

1. **「포기하기」 버튼은 설계 확정 6번 «글»에는 없다** — 레퍼런스 39 에 실측 좌표로 있어서 넣었고,
   동작은 지시된 실패 경로(스테이지 유지 + 파밍 + 재도전)를 그대로 탄다. 주인이 원치 않으면
   `#bossGv` 의 DOM·CSS·리스너 3곳만 지우면 된다(다른 로직에 얽혀 있지 않다).
2. **40 재도전 대기 상태에서는 스테이지 진행바가 안 보인다** — 레퍼런스가 그렇다. 파밍 중
   «몇 마리 잡았는지» 피드백이 사라지는 건 의도된 재현이다.
3. **중앙 해골 노드의 색**은 02 자산(검정→시안→네이비 링)을 비율 확대해 재사용했다.
   ref 40 은 시안 그라디언트(#4EFFF9→#40AEE1)라 **색이 다르다** — ⑤ 색은 통과 기준이 아니라 남겨 뒀다.
4. **`S.bossFarm` 은 `KEY` 를 올리지 않았다.** 옛 세이브는 `load()` 의 기본값 병합으로 `false` 가 들어간다.
5. **보스 체력바는 «보스전 중»에만 뜬다.** 승급전(`promo`)은 자기 진행바(`prT`)를 그대로 쓴다 — 안 건드렸다.
