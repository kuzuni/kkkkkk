(384 가 «세로 한복판은 그라데이션이 이미 같은 값을 칠한다 · 바뀌는 것은 코너뿐» 이라고 못박아 뒀으므로
`::before` 를 코너 기둥으로 잘라도 **직선 구간은 Δ0** 이다 — 다만 그 «Δ0» 을 먼저 **재서** 확인할 것).

⇒ **지금 구조(의사요소 2개, 마스크 하나)로는 D1 을 회수하면 384 를 깬다.** ref 의 코너는
«검정 링 **안쪽 윤곽**을 따라 세 띠가 감기는» 그림인데(ref 위 코너 `K8 B9 F…` ↔ 아래 `K8 D8 F1 B1`

**사방 7 인셋**해야 하고, 그러면 **직선 구간의 단면**(베벨 0..7 · 면 7..71 · 베벨 71..78 · 띠 78..85)이
통째로 7px 안으로 밀린다 — 384 가 «세로 한복판 단면 Δ0» 으로 지킨 바로 그 값이다.
**손잡이가 하나 더 필요하다**(세 번째 층). 그것이 409 의 남은 반쪽이고, **이 세션은 거기서 멈춘다.**

법선으로 환산하면 ref 는 **0~45° 가 등폭 7 이고 60° 부터 내려간다**(60° 5.5~6.4 · 70° 5.7 · 75° 3.9 · 88° ~1).

4회차 우리 것은 dx 28 까지 7 을 끌고 가다 마스크 경계(x=30)에서 0 으로 잘렸다: 그 절벽이 네 비평가가
네 회차에 걸쳐 짚은 **«3×7 사각 노치»** 다.

### 14-3. 처방 — **인셋 그림자 한 쌍의 «구멍» 을 옮긴다** (제품 CSS 3줄)

인계 3번(«알파가 아니라 기하»)을 만족하는 길이 CSS 안에 있었다. 인셋 그림자의 구멍은
«상자를 (dx,dy) 밀고 spread 만큼 오므린 것» 이므로, **오프셋과 스프레드를 나눠 주면 구멍의 코너 중심이 옆으로 밀린다**:

```
box-shadow: inset  d 0 0 s #000,
            inset -d 0 0 s #000;     d + s = 7
```
구멍의 코너 중심 = **(30 + d, 30)** · 반경 **23 + d** ⇒ 검정 두께 `t(α) = 30 + d·cos α − √(d²cos²α + 529 + 46d)`
* `d=0` 이면 1~4회차의 **동심 등폭 링**(t ≡ 7)
* `d=7` 이면 384 이전의 **가로 평행이동 밴드**(t = 7·cos α)
* 그 사이가 테이퍼다. **한 식이 세 경우를 다 덮는다.**

**d 는 4 를 골랐다.** 후보를 ref 곡선에 맞춰 재 보면:

| d | 0° | 30° | 45° | 60° | 75° | 88° | ref 대비 오차합 | `verify409` [5](60°≥4.5 · 75°≥3.5) |
|---|---|---|---|---|---|---|---|---|
| 3 | 7.0 | 6.64 | 6.21 | 5.63 | 4.94 | 4.27 | 5.87 | 통과 |
| **4** | **7.0** | **6.53** | **5.98** | **5.22** | **4.32** | **3.30** | **5.06** | **전 면 통과** |
| 5 | 7.0 | 6.44 | 5.76 | 4.84 | 3.71 | 2.62 | 5.46 | **일부 면 미달**(실측 60° 4.0 · 75° 3.0) |
| ref | 7 | 7 | 7 | ~5.75 | 4.2 | ~1 | — | — |

d=5 가 접선은 더 낫지만 **[5] 가 면에 따라 빨개진다.** [5] 는 «7·cos α 밴드가 되살아났는가» 를 지키는
유일한 항이라 인계가 «반드시 남기라» 고 못박은 자다 ⇒ **그 항을 한 칸도 안 넓히는 가장 깊은 테이퍼**가 d=4 다.

### 14-4. 같이 옮긴 것 둘 (같은 전제 위에 서 있던 층들)

* **`::before`(가로 세 띠) 상자 → 좌·우 7 · 상·하 3 · r27.** 4회차가 이 상자를 «검정의 안쪽 윤곽» 으로
  정의했는데, 5회차가 그 윤곽을 바꿨으니 상자도 따라간다(4회차가 384 의 상자를 옮긴 것과 **같은 논증**이다).
  안 옮기면 테이퍼가 벗겨 낸 자리에 부모 그라데이션의 **채움면**이 뜬다(60° 위 코너에서 1.2px).
* **바닥 베벨 `inset 0 -14px` → `-15px`.** 상자가 세로로 4px 자라면서 «어두운 띠 뒤 베벨» 이 30° 에서
  5.5 → 4.5 로 내려갔다(MIN_BEV 5.0 미달). 1px 되돌리니 **5.5~8.0**(ref 6~7) 이고 어두운 띠는 **6.0 그대로**다.
  ⚠ 처음엔 세 띠를 통째로 4px 밀었다가(`-11/-18/+11`) 어두운 띠가 **9~10** 으로 부풀었다 — 되돌렸다.
  상자의 바깥 윤곽이 이미 테이퍼를 따라가므로 **띠는 제자리에 두는 것이 맞다.**

### 14-7. ⚑ **되돌렸어도 이 회차가 남긴 것 — 다음 세션은 여기서 시작하라**

1. **ref 곡선이 확정됐다(세 자 · 두 비평가 독립 일치).**
   **0~60° 는 등폭 7.0 · 70° 5.7 · 75° 4.2 · 78° 2.9 · 86° 2.0 · 90° ~1.0**, 그리고 **접선을 넘어
   dx 38 까지 꼬리**가 있다(DE [E]: dx 30 → 1.42 · 32 → 1.37 · 34 → 1.31 · 36 → 0.54 · 40 → 0.05).
   1~4회차 게이트 [2]가 요구하던 «0~75° 등폭» 은 **ref 자신이 통과 못 한다.**
2. **«오프셋+스프레드» 족은 이 곡선을 못 만든다 — 증명 끝.**
   `inset ±d 0 0 s`(d+s=7) 한 쌍의 구멍은 코너 중심 (30±d, 30) · 반경 23+d 이라
   `t(α) = 30 + d·cos α − √(d²cos²α + 529 + 46d)` 다. **d 가 커질수록 전 각도에서 얇아진다** —
   0~60° 를 7 로 두면서 60~90° 만 떨어뜨리는 d 가 **존재하지 않는다**(합집합·교집합도 안 된다:
   합집합 = 작은 d, 교집합 = 큰 d 를 그대로 준다). 알파 페이드는 §13-3 이 이미 기각했다.
   ⇒ **남은 길은 4회차 인계가 적어 둔 ⓒ SVG 마스크뿐이다.** 코너는 고정 30×30 타일이므로
   `mask-image: url("data:image/svg+xml,…") 0 0/30px 30px` 를 코너 4개에 얹고, 직선부는
   `linear-gradient` 를 30px 폭 타일로 좌·우에 놓으면 된다(폭이 %인 것은 문제가 안 된다).
   목표 곡선은 위 1번. **꼬리(dx 30~38)를 위해 마스크 기둥을 30 → 38px 로 넓혀야 한다**(DE 2위).
3. **곁다리 결함 셋이 드러났다 — 그중 하나는 4회차의 버그다.**
   ⓐ **`::before` 의 마스크 기준이 7px 어긋나 있다**(DE 6위). 상자가 `left:7px` 인데 마스크가
   `#000 0 30px` 라 «알약 x 0~30» 이 아니라 **«7~37»** 을 덮는다. 4회차 이후 내내 그랬고, 직선부는
   부모 그라데이션이 같은 색을 칠해 안 보였을 뿐이다. 5회차가 상자를 세로로 옮기자 **dx 36→37 에
   2.55px 수직 계단**으로 드러났다. 올바른 값은 **23 = 30 − 7**. ⇒ **462** 로 등재.
   ⓑ·ⓒ «위 코너 베벨 +51%»·«아래 코너 검정↔띠 틈 5.25px» 는 **내 상자 이동의 부수효과**라
   되돌리면서 같이 사라졌다(DE 3·4위). SVG 마스크로 다시 상자를 옮기는 세션은 그때
   `inset 0 7px` → `inset 0 (7−세로인셋)` · `inset 0 -7px` → `inset 0 -(7+세로인셋)` 로 같이 옮길 것.
4. **자 두 개가 남았다** — `tools/probe409c.py`(열 두께 · 바닥값 뺀 검정 픽셀 수 · 셸과 안 섞인다) 와,
   DE 가 쓴 **[E(dx)] = «열 dx 의 검정 깊이 − 직선부(dx 120)의 같은 값»**(= «코너가 더 얹은 검정»).
   접선 **너머**(dx>30)를 잴 수 있는 자는 **[E] 뿐**이다 — 꼬리를 채점하려면 그 자를 써라.
5. ⚠ **비평가에게 줄 캡처를 채점 직전에 다시 찍어라.** DE 7위: 내가 준 cap 3장은
   437·450(셸 테두리 7.91 · 검정 립 1.5px)이 들어오기 **전** 그림이라 «셸 테두리 −28%» 가
   ② 감점에 섞여 들어갔다. DE 가 현 트리로 재렌더해 «코너 기하는 동일» 을 확인해 준 덕에
   1~6위 지적은 살아남았지만, 그 확인이 없었으면 감점의 출처를 못 갈랐다.
