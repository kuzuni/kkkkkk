## 4. 처방 — 세로는 한 값도 안 건드리고 **가로만** 늘렸다

1. **라벨**(`buildSlots()`): `'<div class="lvv2">' + oLv(id)` → `'<div class="lvv2">Lv. ' + oLv(id)`.
   접두는 **07 시트 `.sk-slv` 가 쓰는 문자열 그대로**다(«Lv. » — 새 표기를 만들지 않았다).
2. **그릇**(`.lvv2`): 원 → **알약**. `width 43.5 → 88` · `border-radius 50% → 20.05px`(= 높이의 절반이라
   **양 끝은 여전히 원**) · `white-space:nowrap`.
   - 88 의 근거: 안쪽 82 = 최장 «Lv. 100» 잉크 69.66 + 좌우 6.17(≥6).
   - **자릿수와 무관하게 고정 폭**이다(735 규약 — 레벨이 오를 때 그릇이 출렁이면 안 된다).
     실측 Lv1/Lv10/Lv100 상자 **88×40.09 셋 다 동일**.
   - 88 < 슬롯 지름 118 ⇒ 알약이 **자기 슬롯 가로 폭 안**(44.8..132.8 ⊂ 27.5..145.5)에 머문다.

   716 의 등급색 토큰(`--f`/`--r`) · 쿨타임/활성/미해금 상태 신호. 세로는 A4 §3 규격 그대로다.

### 위임 규약 채택 — «Lv.100» 이냐 «Lv. 100» 이냐

주인 원문은 붙여 쓴 «Lv.100» 이고, 저장소에는 두 표기가 **50 : 51** 로 섞여 있다.
결정 대기로 회차를 세우지 않고(2026-09-01 위임 규약) **«Lv. »(07 시트 표기)를 채택**했다.

다시 다른 말이 된다** — 그러면 [B2] 같은 항을 세울 수조차 없다.
**되돌림**: `buildSlots()` 의 `'Lv. '` 한 곳을 `'Lv.'` 로 고치면 끝이다(그릇은 8px 더 남는다 —
