## 1. 증상과 원인

주인 보고: «스테이지 클리어했을 때 메시지가 심하게 이상하게 나옴».

화면 중앙에 이렇게 떴다:

```
STAGE CLEAR! <img class="cic" data-cur-ic="dia" src="assets/ui/cur-dia.svg" alt="">+80
```

`showMsg()` 는 **캔버스 텍스트 싱크**다 — `draw()` 끝에서 `ctx.strokeText/fillText(msgTxt, …)`
(index.html ~16460) 로 **문자열을 글자 그대로** 그린다. HTML 파서가 없으니 태그도 글자다.

그런데 작업 **125**(화폐 아이콘 통일)가 `curIc()` 를 «이모지 한 글자» 에서
**`<img …>` HTML 문자열**(index.html ~12229)로 바꿨고, 스테이지 클리어 경로

```js
S.dia += d; msg += ' ' + curIc('dia') + '+' + d;      // index.html ~15536 (수정 전)
```

가 그 문자열을 **캔버스 싱크로 그대로 흘려보냈다**. 125 가 잡아 둔 함정 목록
(review/125 §2 — textContent 자리 5곳 · 모달 제목)에 **캔버스는 없었다**. DOM 이 아니라서
125 의 게이트 F1(«화면 텍스트에 아이콘 마크업 0건» 스윕)도 캔버스는 못 본다.

## 2. 고친 것 — index.html 한 곳

```js
/* 94 — 골드는 58 코인 비행이 보여 주므로 문구에서 뺐다. 다이아만 짧게 붙인다.
   160 — 여기는 **캔버스 텍스트 싱크**다(showMsg → ctx.fillText). … */
let msg = 'STAGE CLEAR!';
if(first){
  const d = 35 + Math.floor(S.stage*3.6);
  S.dia += d; msg += ' 다이아 +' + fmt(d);
}
```

**왜 💎 로 되돌리지 않았나** — 그게 원래 형태(`msg += ' 💎+' + d`)였지만, 125 의
«화폐는 정해진 이미지 1종» 원칙상 소스에 화폐 이모지를 다시 넣으면 `verify125` **A1**
(«주석 뺀 소스에 화폐 이모지 0건»)이 즉시 FAIL 한다. 캔버스에는 이미지도 이모지도 못 쓰므로
지시서 표의 처방대로 **아이콘 없이 낱말 + 수치**로 갔다. 낱말 «다이아» 를 넣은 이유는
`+81` 만으로는 무엇이 81 인지 알 수 없기 때문이다(골드는 58 코인 비행이 따로 보여 준다).
`d` 도 다른 표기와 맞춰 `fmt()` 를 태웠다.

문구 길이는 «STAGE CLEAR! 다이아 +81» 22자 — 94 의 폭 클램프(`MSG_MAXW` 500 논리 px)
안이라 축소도 «…» 자르기도 걸리지 않는다(실측 잉크 x 180..899 / 폭 719, 프레임 1080).

## 3. 전수 조사 — 캔버스 싱크가 여기뿐인가

지시서 표의 «`showMsg`/`fxToast` 등 텍스트 싱크에 `curIc()` 를 넣는 호출이 더 있는지 전수 grep» 이행:

| 싱크 | 개수 | curIc 유입 | 판정 |
|---|---|---|---|
| `ctx.fillText/strokeText` | **2곳뿐** (`nums` 데미지 숫자 ~16425 · `msgTxt` ~16460) | `nums` 는 `fmt(v)` 만(~14551) · `msgTxt` 는 **여기 1건** | 고친 뒤 0건 |
| `showMsg()` 호출부 | 9곳 | 8곳은 문자열 리터럴, 1곳이 이 `msg` | 고친 뒤 0건 |
| `fxToast(txt)` | `el.innerHTML = txt` (~23281) | 유입되지만 **innerHTML 이라 무해**(125 가 의도한 경로) | 정상 |
| `fxDelta(el, txt)` → `d.textContent` | `trDeltaTxt()` 는 `.cv i` 의 **textContent** 를 읽는다 → 마크업이면 `''` | 마크업 유출 불가 | 정상 |
| `jzFx(cls, ms, txt)` → `d.textContent` | 호출부 인자는 `'BOSS'` 리터럴 | 없음 | 정상 |
| `jzWhy()` · 모달 제목 · `.textContent =` 전반 | — | `grep -E "textContent *= *[^;]*(curIc|\.ic\b)"` **0건** | 정상 |

즉 **캔버스가 마지막 남은 구멍이었고, 그 구멍의 유일한 유입점이 이 한 줄**이었다.

## 4. 게이트 — `verify94` 는 이 버그를 **놓친 게 아니라 죽어 있었다**
