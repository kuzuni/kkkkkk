## 1. 무엇을 지웠나 — 폐지 자리는 **두 곳**이었다

162 가 «보스 격파 = 스테이지 클리어» 로 바꾼 뒤로, «클리어 보상» 은 한 자리가 아니라 두 자리에
흩어져 있었다. 등재문이 짚은 그대로다.

| # | 자리 | 지웠던 코드 | 스테이지 12 클리어 시 실측 |
|---|---|---|---|
| ⓐ | 클리어 블록 `if(stageWin){…}` (`index.html` ~16485) | `const first = S.stage >= S.best;` … `const d = 35 + Math.floor(S.stage*3.6); S.dia += d; msg += ' 다이아 +' + fmt(d);` | 💎 **+81** (= 35 + ⌊13×3.6⌋) |
| ⓑ | `killEnemy()` (`index.html` ~15540) | `if(e.tk === 'boss' && S.stage >= S.best) S.dia += 250 + S.stage*25;` | 💎 **+550** (= 250 + 12×25) |
| | | **합계** | 💎 **+631 → 0** |

`first` 는 ⓐ 말고 쓰는 곳이 없어 선언째 삭제했다(`grep '\bfirst\b'` — 남은 것은 CSS `:first-child`
와 `#fxHand`·트레일 렌더의 동명이인 지역변수뿐).

**남긴 것**: 클리어 골드 보너스 `bonusG = eGold(S.stage-1) * 12 * stat.goldMul`(클리어마다) ·
`killEnemy()` 의 처치 골드 `S.gold += g`. 즉 **전투 보상은 골드만** 남는다.

문구는 «STAGE CLEAR!» 한 낱말로 줄었다 — `let msg` → `const msg` (더 붙일 것이 없다).
실측 잉크 bbox **x 327..748 / y 873..924**(캔버스 1080×1996) — 이전 «STAGE CLEAR! 다이아 +81» 의
x 180..899 에서 좁아졌고 94 폭 클램프 안이다.

두 자리 모두에 **되돌림 방지 주석**을 박았다(LESSONS 184-② — «폐지» 지시는 호출부까지 지우고
그 자리에 왜 지웠는지를 남긴다. 다음 세션이 «심심하다» 며 되살린다).
