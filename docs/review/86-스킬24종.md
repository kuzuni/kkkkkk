## 1. 무엇을 했나

13종(등급별 2/3/2/3/2/1) → **24종(4/4/4/4/4/4)**. 신설 11종 = 일반 +2 · 고급 +1 · 희귀 +2 ·
영웅 +1 · 전설 +2 · 신화 +3 (지시서 ① 배분 그대로).

**기존 13종은 id·등급·`cd`·`m`·발동 코드를 한 글자도 바꾸지 않았다.** `castSkill()` 의
`switch(s.id)` 13개 분기는 그대로 두고 **`default:` 하나만 추가**해 신설분을 `castGeneric()` 으로
보낸다 — 구 세이브(`S.own`·`S.eqSkill`)가 참조하는 값이 전혀 흔들리지 않는다.

### 신설 11종

기존 13종의 계열을 세고 부족한 칸만 채웠다(예: 영웅은 이미 범위·도트·흡혈이 있어 공격형 1종만 추가).

### 신설 코드

- **`castGeneric(s, dmg)`** — `t` 필드로 네 타입만 처리한다. `proj`(투사체: `k` 그리기 종류 ·
  `n` 발수 · `sp` 속도 · `spread` 부채각 · `ring` 전방위 · `pierce` 가산 · `col` · `slow`) ·
  `chain`(무작위 n명 즉발, bolt 재사용) · `area`(제자리 범위 폭발, holy 재사용) · `buff`.
  **새 그리기 코드는 0줄** — `k` 는 기존 `slash`/`shuri`/`ice` 만 쓴다(지시서 ② «파라미터만 다르게»).
- **`sbuf` / `addSbuf` / `sbufTick` / `sbufClear`** — 전투 중에만 사는 휘발 버프.
  **저장하지 않는다**(전투 시작 = 0, 부활 시 초기화).
  `sbAtk()`·`sbRate()`·`sbDef()`·`sbRegen()` 네 지점에서만 곱한다:
  ① `castSkill()` 의 `dmg`(→ 기존 13종에도 그대로 먹는다) ② 자동 발동 `rateMul`
  ③ `player.hp -= e.dmg * stat.defMul` ④ 재생 `stat.regen*dt`.
  회전검·신성 오라(지속 스킬)의 `skillDmg` 에도 `sbAtk()` 를 곱했다.
- **전투력에는 넣지 않았다.** `bonus()` 캐시에 넣으면 HUD 전투력이 초 단위로 요동친다.
  보조 5종은 `sup:1` 로 `stat.dps` 합산에서 제외했다(직접 피해가 없으므로 부풀림 방지).
  대신 `power()` 는 `m` 을 그대로 쓰므로 자동장착 순서에서 사라지지 않는다.
- **버프 중복 발동 방지** — 남은 시간이 절반 넘게 남았으면 `castGeneric` 이 `false` 를 반환해
  쿨을 낭비하지 않는다(자동 발동 루프가 0.25초 뒤 재시도).

### 딸려 온 수정 (지시서 ④⑤)

- **04 스킬 격자**: 24장 = 5열 × **5행**. 열 pitch 190 · 행 pitch 220 은 **유지**하고,
  격자 패널(`.sk-gp` 1000×680 · top 387)은 레퍼런스 기하 그대로 둔 채 **안쪽만 세로 스크롤**로
  바꿨다(`overflow-y:auto` + 절대배치 카드가 세우지 못하는 스크롤 높이를 `.sk-gsp` 스페이서로 세움).
  → `.sk-tot`(1085) · `.sk-btn`(1158) 의 y 가 밀리지 않아 **04 레이아웃 점수(8)에 영향 없음**(실측 확인).
- **21 도감** `COLL.skill.tiers` need 3/5/7/9/11/13 → **6/10/13/17/20/24**(마지막 = 전 종 수집).
  `S.coll.skill` 은 «받은 단계 수» 카운터라 구 세이브가 이미 받은 보너스는 그대로 유효하다(75 와 같은 처리).
- **11 확률 팝업**: 코드 수정 0줄 — `BANNERS.skill.list = SKILLS` 를 그대로 읽어 24종을 자동 표기한다.
- **README**: «스킬 13종» → «24종 — 6등급 × 등급당 4종».

## 3. 기능 체크 표 (헤드리스 전투 20초 실측 · `--table` 재생성)

각 스킬 **하나만** 보유·장착한 상태로 적 8마리를 세우고 `step(1/60)` 을 1,200회
(= 게임 내 20초) 돌려 «발동 → 무엇이 바뀌는가» 를 실측했다.

| 스킬 | 등급 | 눌렀을 때(발동 시) 무엇이 바뀌는가 | 실측 |
|---|---|---|---|
| 돌팔매 (`stone`) | 일반 | 적에게 직접 피해 | ✅ 투사체 16발 발사 |
| 기합 (`vigor`) | 일반 | 스킬 피해 증가 버프 | ✅ 스킬 피해 버프 최대 **+18%** |
| 치유의 빛 (`mend`) | 고급 | 체력 회복 + 재생 버프 | ✅ 재생 **+120%** · 체력 64 → 160 |
| 꿰뚫는 화살 (`arrow`) | 희귀 | 적에게 직접 피해(관통) | ✅ 투사체 28발 발사 |
| 신속의 축복 (`haste`) | 희귀 | 스킬 발동 속도 버프 | ✅ 발동 속도 **+30%** |
| 서리 연쇄 (`frost`) | 영웅 | 적에게 직접 피해 + 둔화 | ✅ 번개 40회 명중 |
| 폭풍의 칼날 (`gale`) | 전설 | 전방위 직접 피해 | ✅ 투사체 96발 발사(12방향 × 8회) |
| 수호의 결계 (`ward`) | 전설 | 받는 피해 감소 + 회복 | ✅ 받는 피해 **−35%** · 체력 64 → 160 |
| 천벌의 창 (`lance`) | 신화 | 적에게 직접 피해(관통) | ✅ 투사체 27발 발사 |
| 창세의 폭발 (`nova`) | 신화 | 광역 직접 피해 | ✅ 범위 폭발 6회 |
| 광란 (`rage`) | 신화 | 스킬 피해 + 발동 속도 2축 버프 | ✅ 피해 **+40%** · 속도 **+25%** 동시 |

추가 확인 2건:
- **버프가 기존 스킬에도 먹는다** — `addSbuf('atk', 0.40)` 후 `검기` 투사체 `dmg` 가 21.7 → 30.4 (×1.40).
- **버프는 만료된다** — 0.5초 버프에 1초를 태우면 `sbuf.atk === 0`.
