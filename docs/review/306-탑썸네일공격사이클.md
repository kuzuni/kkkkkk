### 4. 등재문이 «재지 않고 남겨 둔» 우려 — 재어 보니 기우였다

> ⚠ 72 가 안 고친 이유: `tower` 는 `.dnc.rd`(97 «슬롯을 꽉 채운다», `fit:0`) 경로라
> 창을 좁히면 97 의 단언과 충돌할 수 있다 — 재지 않고 건드리지 않았다.

**충돌하지 않는다. 채움% 가 99% → 99% 로 그대로다.**

이유는 아틀라스 표에 이미 적혀 있다 — 좁혀 낸 `_3`·`_4` 는 **가로만** 큰 프레임이고
(194·262 vs 115~131), **세로는 131~133 으로 6장이 전부 같다.** 슬롯을 채우는 축(세로)이
안 줄었으므로 `fit:0` 경로의 채움률도 안 줄어든다. 줄어든 것은 «칼을 뻗은 가로» 뿐이다.

같은 이유로 `TH_INKC` 에는 항목을 **더하지 않았다** — `thPaint` 가
`inkC: rd ? null : TH_INKC[…]` 라 `.dnc.rd` 경로는 중심 보정표를 아예 안 읽는다
(`verify72 [1-4]` 도 액자 8장만 대조한다. 실제로 259/259 PASS 로 확인).
