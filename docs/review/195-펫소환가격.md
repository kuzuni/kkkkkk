## 1. 무엇이 틀려 있었나

73 ④(2026-08-25, 주인 지시)가 소환가를 «10회 1,000 · 30회 3,000» 으로 통일할 때 지시가
«펫·유물은 현행 유지» 였다. 그래서 통일은 `flat:1` 이라는 **배너 플래그**로 갈렸고, 펫만
플래그 없이 `cost:250` 으로 남았다:

```
summonCost(b, n) = round(BANNERS[b].cost × n × ((n ≥ 10 && !B.flat) ? 0.9 : 1))
```

= 펫은 **가격도 2.5배(250 vs 100)이고 산식도 달랐다**(10연 이상 0.9 할인을 혼자 받았다).
실제 값은 1회 250 · 10연 **2,250** · 30연 **6,750** 으로, 다른 네 배너의 100 / 1,000 / 3,000 과
**세 자리 전부** 어긋나 있었다. 106(2026-08-26)이 펫 상자를 상점에 넣으면서 이 차이가
«같은 화면 카드 5장 중 한 장만 다른 가격» 으로 눈에 보이게 됐고, 이번 지시가 그것을 정리한 것이다.

## 2. 고친 것 (index.html — 실질 1줄)

```diff
- pet: { n:'펫', ic:'🐾', cost:250,          g8:1, cur:'dia', coll:'pet', list:PETS }
+ pet: { n:'펫', ic:'🐾', cost:100, flat:1, g8:1, cur:'dia', coll:'pet', list:PETS }
```

나머지는 전부 **주석 정정**이다(73 이 «펫 현행 유지» 를 근거로 적어 둔 3곳: `BANNERS` 머리주석 ·
`summonCost` 머리주석 · `UI-REFERENCE` 2곳). 이 주석들이 살아 있으면 다음 세션이 «예외가 설계다» 로
읽고 되돌린다 — 값보다 주석이 오래 산다.

**표시·차감 경로는 한 줄도 안 고쳤다.** 73 이 세 소비처(10 상점 카드 `.cost` · 12 결과 팝업
`#sumB10c/#sumB30c` · 부족 판정 `.lack`/`disabled`)를 전부 `summonCost()` 한 함수로 모아 놨기 때문에
상수 하나로 다섯 곳이 같이 움직였다. 하드코딩된 «2,250 / 6,750» 문자열은 소스 전체에 **0건**이었다(실측).

### `summonCost` 의 0.9 분기는 지우지 않았다

이제 `flat` 이 아닌 배너가 하나도 없으므로 0.9 가지는 **죽은 코드**다. 그래도 지우지 않은 이유:
유물(89 가 `BANNERS.relic` 을 폐기하고 `#relw` 균등 소환으로 옮겼다)이 배너로 돌아오거나 새 배너가
생길 때의 **기본값**이고, 지우면 산식이 «전부 정가» 한 갈래로 굳어 다음 지시가 코드 구조를 다시
건드려야 한다. 대신 `verify195 A4`·`verify73 §1` 이 «지금은 그 가지를 타는 배너가 0개» 를 못박는다 —
누가 몰래 예외를 다시 만들면 게이트가 그때 운다.

## 6. 새 게이트를 만들며 잡은 함정 2개 (게이트 쪽 결함 — 제품 무관)

1. **`[data-shsum="pet"][data-shn="10"]` 은 두 칸을 문다.** `.b1`(무료 10연)에도 `data-shn="10"` 이
   붙어 있고 거기에 `data-shfree` 가 더해질 뿐이다. 먼저 잡히는 쪽이 `.b1` 이라 **차감 0 이 «통과처럼»**
   보였다(첫 실행 D1 FAIL — 차감 0 인데 +10). 유료 칸은 `.b2` 다.
   → 상점 카드를 클릭으로 미는 게이트는 **반드시 `.b2`/`.b3` 로 집을 것.**
2. **무료 횟수 차감은 `doSummonFree()` 가 아니라 호출부(카드 클릭 핸들러)가 한다.**
   함수를 직접 부르면 `freeLeft` 가 안 줄어 «무료가 안 준다» 는 잘못된 결론이 난다(첫 실행 F2 FAIL).
   → 무료 경로도 클릭으로 가야 한다.
3. (곁가지) 구 세이브는 `S.guide.idx` 가 0 = «스킬 1회 소환» 미션이라 **73 ③ 이 펫 소환을 막는다.**
   가격을 보려는 절에서 차단에 걸려 차감 0 이 났다(첫 실행 H2 FAIL). 가이드를 끝낸 상태로 맞춘 뒤 쟀다
   — 차단 자체는 `verify73 §4` 몫이다.

## 7. 밸런스 메모 (195 범위 밖 — 199 몫)

펫 소환이 **2.25배 싸졌다**(10연 2,250 → 1,000). 다이아 지출 대비 펫 획득 속도가 그만큼 빨라지고,
106 이 만든 펫 보유 효과가 곱연산(전 종 Lv1 기준 공격력 ×19.9)이라 **초중반 파워 곡선이 앞당겨진다**.
주인 지시가 «가격을 같게» 이지 «펫을 비싸게 유지» 가 아니므로 값은 지시대로 내렸고, 도달 곡선 재측정은
**199 최종 밸런스 라운드**(착수 조건 = 다른 todo 전부 구현 후) 몫으로 남긴다. 197(파워 커브 계단식)이
착용효과를 다시 만지므로 그 뒤에 재는 것이 맞다.
