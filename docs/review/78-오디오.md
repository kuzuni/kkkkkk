### 구현 (index.html 맨 끝 «78» 절 + 훅 22곳)

- `AudioContext` 경로('ctx'): master(볼륨)→sfx/bgm 게이트 게인. fetch+decodeAudioData 버퍼 22개.
  **file:// 폴백('el')**: `location.protocol` 로 선분기(fetch 를 시도만 해도 콘솔 CORS 에러가 남아 smoke 가 깨진다
  — 1회차에 실제로 밟은 함정) → `<audio>` cloneNode 재생. README «별도 서버 불필요» 유지.
- 첫 사용자 제스처(pointerdown 캡처)에서 초기화+resume. 같은 SFX 30ms 디바운스(`auLast`), 피치 ±5%
  (ctx: playbackRate / el: playbackRate + preservesPitch=false).
- BGM: 루프 + **페이드 1초**(ctx: linearRamp / el: 50ms 볼륨 스텝). 팝업·탭 전환에서 끊지 않음.
  보스전: `cineBossIn → bgmSet('boss')`, `cineBossKill`/`failBoss → bgmSet('main')`.
- 55 설정: 토글·볼륨 핸들러에 `auApply()` — **즉시 반영**(이전에는 저장만 됐다). `sndOn()` 게이트는 재생 직전마다 읽는다.

### 기능 체크 표 (헤드리스 실측 — http 서버 + 실제 게임 데이터)

| 재화 비행 | `fxFly(null,'gold',500)` | `coin:8`(묶음별 디바운스) |
| 룰렛 (29) | `roulSpinTo(1)` 실회전 3.9s | `rtick:50 · rstop:1` + **다이아 실지급 확인** |
| 소환 결과 (12) | `doSummon('skill',10)` 실소환 | `flip:4`(카드 팝 동기) + 다이아 차감 |
