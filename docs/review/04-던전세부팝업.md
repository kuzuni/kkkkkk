주 편집 구간: `#dgdw` / `.dgd-*` (신설) · `openDunDetail()` (신설)
측정표: `docs/measure/04-던전세부팝업.md`

채점 규칙: 비평가 2명 독립, 항목 6개(①배치 ②크기비율 ③여백 ④정렬 ⑤색·명암 ⑥폰트비율) 각 10점,
**최저 항목 점수 = 그 비평가의 점수**, 두 명 중 **최저가 9 이상이면 통과**.
비평가에게는 매 회차 「레퍼런스 1080×2340 / 캡처 1080×1920, 가로는 1:1, 세로는 고정 요소만 비교,
전투 캔버스 높이 차이는 감점 금지」와 「PIL 픽셀 스캔으로 실측할 것」을 명시했다.

## 회차별 점수

| 회차 | 비평가 A | 비평가 B | 최저 | 주요 지적 |
|---|---|---|---|---|
| 1 | 5 | 6 | **5** | 입장권 알약 폭(측정표 추정 164 → 실측 199), 화살표 종횡비(0.77 vs 0.94)·외곽선 두께·우화살표 색, 실루엣 판 형상·높이, 리본 노치 깊이 |
| 2 | 6 | 7 | **6** | 실루엣 판 상단 뿔 부재, 티켓 초록 명도, 리본 반투명도 부족, 배너 그라디언트 명암 방향 |
| 3 | 7 | 7 | **7** | 버튼 채움 폭(테두리 6→8px), 자물쇠 크기, 크림 상단 코너 라운드, 프레임 내부 높이 |

## 3회차 → 4회차 조치

- **크림 본체 상단 코너**: `border-radius:27px` 가 4모서리에 걸려 헤더 접합부가 13px 파였다. ref 는 직각 → `0 0 27px 27px`.
- **하단 버튼**: 바깥 249×120 은 맞는데 채움이 237×106(ref 234×104) 이었다 → 테두리를 8px 균일로.
- **자물쇠**: 🔒 이모지는 **몸통이 금색이라 금색 버튼 위에서 형태가 사라진다**(어두운 획 12×15밖에 안 잡힘). ref 실측(외곽 77×70·크림 몸통 #FEF9B7·검정 외곽선)대로 **CSS 로 직접 그렸다** → 외곽 bbox 77×70 @ (353,1637) 로 ref 와 완전 일치.
  ⚠️ 버튼에 `border:8px` 이 있어 절대배치 자식의 기준점이 8px 밀린다(패딩 박스 기준). left/top 에서 8 을 빼야 맞는다.
- **리본**: ref 는 좌측 (5,39,24) → 우측 (17,74,39) 로 **좌→우 밝아진다**. 단일 알파 대신 가로 그라디언트(`.82 → .46`)로 교체.
- **배너 측면 비네트는 넣었다가 철회**했다. ref 좌측 밴드 전체 평균은 (38,140,96) 으로 어둡지 않고, **어두운 건 리본이 얹힌 구간뿐**이었다. 비네트를 넣으니 좌측 밴드가 (21,77,50) 으로 과도하게 어두워져 되돌렸다.
- **`-webkit-text-stroke` 를 줄여도 흰 획은 굵어지지 않는다.** `paint-order:stroke fill` 이면 채움이 스트로크 안쪽 절반을 덮으므로 **흰 잉크 면적은 스트로크 두께와 무관**하다. 비평가의 «획이 −31% 가늘다» 는 지적은 **레퍼런스의 좁고 두꺼운 게임 서체가 없어서 생기는 것**이며 스트로크 조정으로는 회수 불가다(A1 이 이미 남긴 한계와 같은 원인). 스트로크 축소는 검정 외곽선 두께를 ref 에 맞추는 효과만 있어 그만큼만 반영했다.

### ⚠️ 비평가 오독 기록 (지적을 그대로 반영하면 오히려 멀어지는 것들)

이 저장소의 A5 교훈(«비평가에게 우리가 아는 수치를 섞어 물어 신뢰도를 재라»)이 그대로 재현됐다.
**2회차 비평가 A 의 신뢰도 보정 5개 중 3개가 틀렸고, 그 위에 세운 지적 3건은 채택하지 않았다.**

| 비평가 주장 | 자가 픽셀 스캔 결과 | 판정 |
|---|---|---|
| 하단 버튼 233×98 / gap 67 | ref·cap **양쪽 다 249×120 / gap 50** (완전 동일) | 오독 — 미채택 |
| 실루엣 판 하단폭이 +85~107px 과대 | 폭 프로파일 y1125~1275 전 구간 Δ0~6px | 오독 — 미채택 (단 y1110 의 뿔 부분은 실제 차이라 수정함) |
| 리본 빨강 텍스트가 어두운 벽돌색 | ref·cap 양쪽 다 **(250,113,108)** 동일 | 오독 — 미채택 |
| 티켓 초록이 칙칙함 | ref (173,240,117) vs cap (74,146,43) — **사실** | 채택 → `filter` 보정 |
| (B) 리본이 너무 투명함 | ref 내부평균 (27,61,36) vs cap (36,87,64) — **사실** | 채택 → 알파 .38→.58 |
| (B) 배너 초록 과채도 | ref 전체평균 (45,145,90) vs cap (40,139,98) — **사실**, 게다가 명암 방향이 반대(ref 는 가운데가 밝고 위·아래가 어둡다) | 채택 → 그라디언트 재작성 |

**교훈**: 비평가 지적은 반영 전에 반드시 **자가 픽셀 스캔으로 재확인**할 것. 특히 «신뢰도 보정» 문항의 답이 이전 회차나 측정표와 어긋나면 그 회차 지적 전체를 의심해야 한다.

## 1회차 → 2회차 조치 (자가 픽셀 스캔으로 검증 후 반영)

- **입장권 알약**: 측정표는 티켓 아이콘에 좌측이 가려 `314,164×45` 로 추정했으나, `#736757` 색 마스크를 직접 스캔하니 **`278,1539 199×51`** 이었다. 실측값으로 교체(측정표 §11 «확신도 낮음»에 이미 예고됨).
- **난이도 화살표**: 이모지 글리프가 세로로 길어 종횡비 0.77(ref 0.94)·외곽선 10px(ref 7px) 이었다. `font-size 88→79`, `-webkit-text-stroke 12→9`, `<i>` 에 `scaleX(1.19)` 로 폭 회복 → 실측 64×68 로 ref 와 1~2px 일치.
- **실루엣 판**: clip-path 를 ref 폭 프로파일(위 2/3 폭 180, 아래 1/3 이 턱처럼 좁아짐) 실측대로 다시 그림 → 180×174 로 ref 와 0~1px 일치.
- **리본 좌측 ◀ 노치**: 실측 깊이 23~27px 확인 → clip-path 노치 21→27.
- **배너**: 테두리 5→6px, radius 12→9, 평균색 ref(45,144,89)에 맞춰 그라디언트 밝기 상향.
- **입장권 아이콘 색**: 🎟️ 이모지는 적색인데 ref 는 초록(158,255,53) → `filter:hue-rotate` 로 보정.
- **버튼 문구**: 최상층에서 우화살표가 비활성이던 문제와 무관하게, 문구를 층 상태에 따라 «소탕/도전» 으로 바꾸던 것을 레퍼런스대로 **항상 «도전»** 으로 통일(소탕은 내부 처리).
