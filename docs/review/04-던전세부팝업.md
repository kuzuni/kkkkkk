## 5회차 — 최종 (통과 기준 9 미달, 5/5 소진)

### ⚠️ 이번 회차의 가장 큰 교훈 — **캡처 상태가 레퍼런스와 다르면 비평은 통째로 무효다**

첫 캡처를 **엉뚱한 던전(황금 동굴 8층)** 으로 떠서 비평가 2명에게 보냈다.
레퍼런스는 **보석 던전 3층**이다. 그 결과 받은 지적이 전부 «내용 차이» 였다:

| 비평가 지적 | 실제 원인 | 올바른 캡처로 재측정 |
|---|---|---|
| (B) 리본 텍스트가 **+26px(+16%) 넓다** | 문자열이 달랐다(`황금빛 대낮 상태` vs `어두운 밤 상태`) | **162 vs ref 161 — Δ1** |
| (B) 자물쇠가 **+35% 크다**(48→65) | 크림색 마스크로 «채움» 만 쟀다. JPEG(ref)는 좁은 마스크에 작게 잡힌다 | 외곽선 포함 outer bbox **ref 75×69 / cap 77×70 — Δ≤2** |
| (A) 타이틀 폭·문구 불일치 | 던전 이름이 달랐다(`황금 동굴` vs `수정 광산`) | 잉크 높이 44/44, advance 45.8/45.8 — **Δ0** |
| 우 화살표가 캡처에 **없음** | 8층=최고층이라 `dgdNext` 가 비활성(opacity .38) | 3층으로 맞추니 **63×67 vs 64×68** |

→ **캡처는 반드시 레퍼런스와 같은 상태(같은 던전·같은 층)로 만들고 나서 비평가에게 보낼 것.**
   상태가 다르면 비평가는 문자열·아트 차이를 «레이아웃 오차» 로 보고한다.

### 채택한 지적 1건 — 입장권 알약 높이 (실제 버그, 1회차 자가 스캔 오독)

5회차 비평 B 의 최저 항목 2개(② 크기비율 8 · ③ 여백 8)가 **모두 이 한 값**에서 나왔다.

| | ref | 구현(수정 전) | 수정 후 |
|---|---|---|---|
| 알약 높이 | **44~45** | 51 (Δ7) | **45** (Δ1) |
| radius | 22 (=높이/2) | 25 | **22** |
| 알약 하단 → 버튼 상단 gap | 29 | 23 (Δ4) | **29** (Δ0) |

**1회차의 자가 스캔이 51 로 읽은 것이 원인이다.** 알약 좌측을 티켓 아이콘이 덮고 있어
전체 bbox 를 잡으면 아이콘의 안티에일리어싱 행까지 물려 49~51 이 나온다.
**아이콘을 피한 x400 / x430 / x440 열**에서 스캔하면 ref 가 일관되게 **44** 다.
측정표 §6 의 `45` 가 처음부터 맞았고, 1회차가 그걸 «실측으로 교체» 하며 덮어쓴 것이 회귀였다.

> **교훈**: 다른 요소에 가려진 도형은 **전체 bbox 로 재지 마라.** 가림이 없는 열/행을 골라 스캔해야 한다.
> (05 의 «세로 1열 스캔만으로 단정하지 마라» 와 같은 계열의 함정이다)

### 미채택 2건 — 자가 픽셀 스캔으로 반증

| 비평가 주장 | 자가 검증 | 판정 |
|---|---|---|
| (A) 리본 좌측 노치가 **Δ12~33px 밀렸고 좌우 대칭 V 가 깨졌다** | 리본은 **반투명**이라 뒤 배너 아트가 비친다. 던전이 다르면 아트도 다르다. `.dgd-bn` 을 흰색으로 평탄화하고 자식을 숨겨 **리본 실루엣만** 스캔하니 행별 좌측 끝이 `262→257→251→245→242→247→253→259→262` — ref `264→259→253→246→241→247→254→261→264` 와 **전 행 Δ≤2px, 대칭 V 정상** | **오독 — 미채택** |
| (A) 티켓 아이콘 ref 41×39 → cap 47×35 (Δ6×4) | 사실이나 🎟️ **이모지 글리프 종횡비 한계**다. `rotate(-18deg)` + `hue-rotate` 로 이미 보정한 상태이며 아트 리소스 없이는 회수 불가 | **사실이나 아트 한계** |

**리본 검증에 쓴 방법(다른 화면에도 그대로 쓸 것)**: 반투명 요소의 형상을 잴 때는
**뒤 레이어를 단색으로 평탄화한 프로브 캡처**를 따로 떠라. 배경이 비치는 채로 스캔하면
뒤 아트의 어두운 픽셀이 그 요소의 윤곽으로 잡힌다.

### 남은 문제 (9 미달 사유 — 아트 리소스 없이는 회수 불가)

레이아웃은 사실상 픽셀 일치이며, 남은 감점은 **전부 이모지 대체 + 게임용 한글 서체 부재**로 수렴한다.
A1(6)·A2(5)·A3(6)·A4(7)·01(5)·02(5)·05(7) 과 **동일한 천장**이다.

1. **티켓 아이콘** 🎟️ — ref 41×39 vs 47×35. 이모지 종횡비 고정이라 회전·색보정으로만 근사.
2. **보석/자물쇠/보상 아이콘** — 이모지 대체. 자물쇠는 CSS 로 직접 그려 outer 를 맞췄으나 내부 형상은 근사.
3. **텍스트 획 두께** — ref 의 좁고 두꺼운 게임 서체가 없어 잉크 폭·획이 미세하게 다르다.
   `paint-order:stroke fill` 이면 흰 잉크 면적은 스트로크 두께와 무관하므로 스트로크 조정으로 회수 불가(4회차 결론).

## 4회차 → 5회차 조치

- **리본 문구의 어절 공백이 사라져 있었다** — `letter-spacing:-4px` 때문이다. **01 화면이 이미 남긴 교훈이 그대로 재발했다**
  («음수 letter-spacing 을 넣으면 어절 공백과 소수점이 통째로 사라진다»). 자간을 0 으로 되돌리고 폭은 `scaleX(.91)` 로만 맞췄다.
  → 어절 런이 ref 와 같은 3+3 덩어리로 복원(공백 gap 11px), 총 잉크폭 162 vs ref 161.
- **실루엣 판 윤곽을 행별 폭 프로파일로 다시 그렸다.** ref 는 상단이 평면이 아니라 **돔**(y1105 폭 9 → y1110 68 → y1115 168)이고
  하단은 폭 11 까지 뾰족하게 맺힌다. y1108/1115/1125/1185/1240/1260 전 구간 Δ≤4px 로 일치시켰다.
- **화살표 외곽선**: ref 편측 7.5px. `-webkit-text-stroke` 는 안팎 절반씩이라는 통설과 달리 이 글리프에서는
  9px→편측 5px, 15px→편측 13.5px 로 **비선형**이었다. 실측 보간으로 **10px** 확정(전체 82×86 vs ref 79×85, 흰 채움은 64×68 로 완전 일치).
- **리본 면색**: ref 는 좌 (5,39,24) → 우 (17,74,39) 로 밝아진다. 가로 그라디언트를 `.84 → .32` 로 재조정(전체 평균 Δ≤5).
- **체크박스 갈색**: ref (126.4,91.4,69.1) → 구현 (125.9,90.1,68.3) 으로 일치.

## 3회차 → 4회차 조치

- **크림 본체 상단 코너**: `border-radius:27px` 가 4모서리에 걸려 헤더 접합부가 13px 파였다. ref 는 직각 → `0 0 27px 27px`.
- **하단 버튼**: 바깥 249×120 은 맞는데 채움이 237×106(ref 234×104) 이었다 → 테두리를 8px 균일로.
- **자물쇠**: 🔒 이모지는 **몸통이 금색이라 금색 버튼 위에서 형태가 사라진다**(어두운 획 12×15밖에 안 잡힘). ref 실측(외곽 77×70·크림 몸통 #FEF9B7·검정 외곽선)대로 **CSS 로 직접 그렸다** → 외곽 bbox 77×70 @ (353,1637) 로 ref 와 완전 일치.
  ⚠️ 버튼에 `border:8px` 이 있어 절대배치 자식의 기준점이 8px 밀린다(패딩 박스 기준). left/top 에서 8 을 빼야 맞는다.
- **리본**: ref 는 좌측 (5,39,24) → 우측 (17,74,39) 로 **좌→우 밝아진다**. 단일 알파 대신 가로 그라디언트(`.82 → .46`)로 교체.
- **배너 측면 비네트는 넣었다가 철회**했다. ref 좌측 밴드 전체 평균은 (38,140,96) 으로 어둡지 않고, **어두운 건 리본이 얹힌 구간뿐**이었다. 비네트를 넣으니 좌측 밴드가 (21,77,50) 으로 과도하게 어두워져 되돌렸다.
- **`-webkit-text-stroke` 를 줄여도 흰 획은 굵어지지 않는다.** `paint-order:stroke fill` 이면 채움이 스트로크 안쪽 절반을 덮으므로 **흰 잉크 면적은 스트로크 두께와 무관**하다. 비평가의 «획이 −31% 가늘다» 는 지적은 **레퍼런스의 좁고 두꺼운 게임 서체가 없어서 생기는 것**이며 스트로크 조정으로는 회수 불가다(A1 이 이미 남긴 한계와 같은 원인). 스트로크 축소는 검정 외곽선 두께를 ref 에 맞추는 효과만 있어 그만큼만 반영했다.
