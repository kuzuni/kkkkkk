## 4. 처방 — 항을 눌러 초록으로 되돌리지 않았다

**`=== 5` 를 `=== 8` 로 고치는 것은 오답이다.** 그렇게 풀면 던전이 하나 늘 때마다
같은 자리가 **다섯 번째로** 뒤처진다. 그리고 이 항이 지키려던 뜻은
「입장권이 5종」이 아니라 **「단련석(절망의 탑 보상)이 입장권 목록에 끼어들지 않는다」** 다
(328-330 «이관이 본체» 교훈).

### 갈아 끼운 모양 — 한 항 → **세 항**

| 자리 | 항 | 묻는 것 |
|---|---|---|
| [A] | `!hasTkTstone && tstoneAsTicket.length === 0` | 어느 던전도 **단련석을 권종으로 안 쓴다** |
| [A] | `tkKeys === dunTkKeys` (집합 일치) | **여분의 입장권 0장** — 숫자를 손으로 안 적는다 |
| [I] | 탑 카드 2장 `img.cic` **0장** · «없음» | **그린 것**으로도 못박는다 (125 H3 식) |

세 번째가 있는 이유는 402 의 교훈이다 — 선언만 보면 «카드는 옛 사본을 그린다» 를 놓친다
(402 에서 `DUN_UI[].tk` 사본이 정확히 그랬다).

### 무르게 풀지 않았음 — 되돌림 시험 ⓕ 신설 ([H])

```js
const g0 = !CUR_ICON.tkTstone && same();     /* 손대기 전 = 초록 */
CUR_ICON.tkTstone = CUR_ICON.tstone;         /* 일부러 끼워 넣는다 */
const red = !!CUR_ICON.tkTstone && !same();  /* 두 항 다 빨강 */
delete CUR_ICON.tkTstone;                    /* 원복 */
out.f = g0 && red && !CUR_ICON.tkTstone && same();
```

단련석 입장권을 심으면 **두 항이 둘 다** 빨개지고, 원복하면 초록이다.
⚠ 대조의 요점: **옛 «키가 5개» 상수는 이 조작을 하면 6 이 되어 여전히 빨갛고, 조작을
안 해도 8 이라 빨갰다** — 뜻과 무관하게 빨간 자였다.
