## 3. 365 — 무엇을 지웠고 왜 id 를 재사용하지 않았나

구 6칸: a1 보석(dia 100) · a2 공물(rel 50) · a3 골드 상자(goldMul 200) · a4 아티팩트 상자 열쇠(rel 10) ·
a5 아티팩트 강화석(rel 30) · a6 일반 펫 소환 열쇠(freePet 1).
**a2·a4·a5 가 셋 다 같은 유물조각**이었고 a3·a6 은 재화가 아니라 다른 화면의 기능이었다 —
레퍼런스 이름만 보고 매핑한 잔재다. 주인 목록대로 넷으로 갈아 끼웠다:

| id | 이름 | 수량 | 보상 키 | cap |
|---|---|---|---|---|
| a1 | 보석 | ×100 | `dia` | 5 |
| a2 | 유물 | ×50 | `rel` | 5 |
| **a7** | 스킨 강화석 | ×50 | `stone`(194 코스튬 강화석) | 5 |
| **a8** | 단련석 | ×50 | `tstone`(210 단련 포인트) | 5 |

⚑ **새 칸의 id 를 `a3`~`a6` 으로 재사용하지 않은 것이 이 작업에서 가장 조용한 결정이다.**
`S.daily.adBuy` 는 상품을 **id 로만** 기억한다. a3 을 «스킨 강화석» 에 다시 쓰면, 오늘 골드 상자를
이미 받은 세이브는 새 상품을 **처음부터 소진 상태로** 연다. `verify365` [G] 가 구 세이브
(`adBuy:{a1:0,a2:1,a3:0,a4:0,a5:1,a6:0}`)를 실제로 열어 `a1:0 a2:1 a7:5 a8:5` 를 단언한다.
죽은 키(a3~a6)는 `load()` 에서 지운다(204 `delete b.daily.dun` 과 같은 처방). 기준은 «지금
`COIN_ADS` 에 없는 id» 라 목록이 또 바뀌어도 그 줄은 안 바뀐다.

### 보정값(fs/sx/qx)을 어디까지 옮겼나

`fs`·`sx` 는 **레퍼런스 잉크에서 역산한 값**이라 문자열이 바뀐 칸에 새로 맞추면 «레퍼런스에 없는
수치를 지어내는 것» 이 된다(173 · LESSONS 05-2). 그래서:

- a2 는 «공물» → «유물» 로 **같은 2글자** — 그대로 둔다.
- a7·a8 은 ref 대응 문자열이 없어 **fs/sx 를 아예 안 준다**(CSS 폴백 35.5px / 1 = 무보정).
  356(«아이콘 비균등 스케일 금지») 정책과도 정합이다.
- `qx`(×N)만은 **같은 문자열 «×50» 의 이미 측정된 값**(a2 의 1.24)을 그대로 쓴다. 지어낸 값이
  아니라 같은 글자열의 같은 보정이고, 안 주면 폴백 1.3 이라 **나란히 놓인 두 칸의 ×50 이 서로 다른
  폭**으로 렌더된다.

⚠ 이 «안 주는 칸» 때문에 렌더가 한 줄 바뀌었다 — 예전엔 여섯 칸이 전부 값을 들고 있어서
`';--fs:' + a.fs + 'px'` 를 무조건 이어 붙였는데, 그대로 두면 `--fs:undefinedpx` 가 박혀
**CSS 폴백조차 못 탄다**(LESSONS 15 계열). 있는 칸만 적도록 가드를 넣었다.

### 격자 — 3열 2행 → 2열 2행

칸 크기(278×309)와 pitch(가로 290 · 세로 319)는 **한 값도 안 건드렸다.** 3열 격자는
x111 ~ 969 로 프레임 중심 540 에 대칭이었으므로 2열도 같은 중심에 맞춘다:

```
2열 폭 = pitch 290 + 칸 278 = 568   →   좌열 x = 540 − 284 = 256 · 우열 = 546
```

행은 그대로다(689 / 1008). **6칸도 4칸도 «2행» 이라 아래 §6 배너·§7 리본 좌표가 안 밀린다** —
`verify365` [F] 가 `.cn-a2t` top 1404 · `#cnDiaRb` top 1698 을 못박아 이것을 감시한다
(두 값은 6칸 시절 커밋과 글자 그대로 같다. `git show ff3d462:index.html` 로 대조했다).

## 4. 366 — 하루 5회

`cap` 만 5 로 올리면 끝이다. 잔여는 `adLeft()` 가 «없는 키 → cap 폴백» 이라 **세이브 이관이 없다**
(등재문 진단 그대로). 버튼 «(n/5)» 표기 · 레드닷 판정(잔여 > 0) · 자정 리셋은 전부 기존 경로가
따라온다 — `verify365` [B][D][E] 가 셋을 각각 잰다.

**수량은 안 줄였다.** 지시가 «횟수를 늘려라» 이고 366 비고가 «cap 5 는 고정, 개당 수량만 재량» 이라
기존 급(보석 ×100 · 유물 ×50)을 그대로 두고 새 둘을 같은 급(×50)으로 맞췄다.

| 상품 | 1회 | 하루 최대 | 비교 기준 |
|---|---|---|---|
| 보석 | 100 | **500** | 아레나 승리 20 · 월별 우편 급 |
| 유물 | 50 | **250** | 유물 던전 1판 |
| 스킨 강화석 | 50 | **250** | 강화석 던전 1층 270 · DPS 측정장 60 · 아레나 40 |
| 단련석 | 50 | **250** | 단련석 던전 1층 105 |

던전 1~2판 급이라 «룰렛·출석과 같은 급» 이라는 13 의 원래 밸런스 위치를 벗어나지 않는다.
**밸런스 계수는 0줄 변경** — 조정이 필요하다는 판단이 서면 그때 값만 만지면 된다(cap 은 지시가 5로 고정).
