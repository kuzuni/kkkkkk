# A5 — 팝업 모달화(레퍼런스 규격) · 비평 기록

작업 단위: **A5** (공용 팝업 껍데기를 레퍼런스 규격으로 — 갈색 헤더 바 + 베이지 본문 + 굵은 외곽선, 화면 중앙)
주 편집 구간: `#modal` · `.mbox` · `.mhead` · `.mbody` · `showModal()`
측정표: `docs/measure/A5-모달.md`

채점 규칙: 비평가 2명 독립, 항목 6개(①배치 ②크기비율 ③여백 ④정렬 ⑤색·명암 ⑥폰트비율) 각 10점,
**최저 항목 점수 = 그 비평가의 점수**, 두 명 중 **최저가 9 이상이면 통과**.
비평가에게는 매 회차 「레퍼런스 1080×2340 / 캡처 1080×1920, 가로는 1:1, 세로는 고정 요소만 비교,
전투 캔버스 높이 차이는 감점 금지, 모달 **안의 콘텐츠**(퀘스트 행 내용·아이콘 아트)는 감점 대상이 아니고
**껍데기**(외곽선·헤더 바·제목·닫기 버튼·본문 배경·여백)만 채점」을 명시했다.

## 구조 변경 (회차 채점 이전)

레퍼런스의 모달은 **헤더 바와 본문이 분리된 2단 구조**인데, 기존 구현은 `.mbox` 한 덩어리에
`<h2>` 를 그냥 흘려 넣는 방식이라 헤더 바를 만들 수 없었다. 그래서 먼저 DOM 을 갈랐다.

```
#modal > .mbox > .mhead ( h2#mtitle + button.mx )
                > .mbody#mbox   ← 스크롤 영역
```

호출부 10곳이 전부 `$('mbox').innerHTML = ...; $('modal').classList.add('on')` 패턴이었으므로
`showModal(html)` 하나로 모았다. 넘어온 html 앞머리의 `<h2>제목</h2>` 를 정규식으로 떼어
헤더(`#mtitle`)에 담고 나머지를 본문에 넣는다 — **호출부의 기존 계약을 그대로 유지**했다.
`$('mbox')` 는 이제 본문 영역이므로 호출부의 `$('mbox').querySelectorAll(...)` 도 그대로 동작한다.
