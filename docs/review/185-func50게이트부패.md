## 2. 왜 이런 게 생기나 — 원인은 «기대값을 손으로 적어 굳혔다»

7건 중 **5건이 «데이터·문구·개수를 리터럴로 박아 둔» 단언**이다(`['av2','av3','av4','av5']` · `'???'` · `'💎'`).
게이트가 감시하는 것은 «기능이 도는가» 인데, 저 리터럴들은 **기능이 아니라 그때의 데이터 스냅샷**이다.
그래서 87 이 코스튬을 6종 → 50종으로 늘리자 **기능은 멀쩡한데 게이트만 빨개졌고**, 빨간 게이트는
아무도 안 보게 되어 §7 의 진짜 크래시가 **몇 작업이나 가려져 있었다**.

→ 이번 복구의 원칙: **기대값을 게임 데이터에서 런타임에 계산한다.** 다음에 코스튬이 100종이 돼도 안 죽는다.

```js
const lkGot  = (await page.$$eval('#bCos .sk-card.lk', e => e.map(x => x.dataset.cosit))).sort();
const lkWant = (await S(page, 'AVATARS.filter(a => !S.avatars[a.id]).map(a => a.id)')).sort();
eq('미보유 카드 = AVATARS − 보유', lkGot, lkWant);
```

같은 이유로 §4 의 대상 코스튬도 `av5` 고정에서 **런타임 선택**으로 바꿨다 —
«미보유 + `cosReqOk` 충족 + `cost > 0`» 이라야 «다이아 부족» 가드에 닿는다.
조건 미달 코스튬을 누르면 87 ③ 의 «🔒 조건» 안내가 **먼저** 나가 엉뚱한 것을 재게 된다(가드가 2단이다).
