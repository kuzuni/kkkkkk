## 남은 문제 (아트 리소스 없이는 회수 불가)

1. **캐릭터 일러스트가 이모지 대체다.** 레퍼런스는 카드1 «햄지+국자» **466×255**, 카드2 «매옹이+뒤집개» **389×351** 짜리
   가로로 넓은 일러스트인데, 이모지는 가로세로가 같이 커져 **가로로 넓은 아트를 재현할 수 없다**(A1 에서 얻은 교훈과 동일).
   두 회차 모두 ② 상대 크기 비율이 이 한 항목 때문에 6 에 묶였다.
2. **카드 배경 실루엣 무늬가 규칙적이다.** 레퍼런스는 개체마다 회전·크기가 달라 «타일 이미지» 가 맞고
   CSS `repeat`(pitch 152)은 눈에 띄게 규칙적이다(측정표 §2-2·§6-3 7번).
3. **서브탭 3·4번 라벨 문자열 미확정.** 픽셀상 잉크 폭은 3글자(101)·4글자(146)인데 자물쇠가 가운데를 가려 복원 불가다.
   기획서(`UI-REFERENCE.md` §292)의 «동료 · 기타»(각 2글자)를 따랐으므로 잉크 폭이 각각 **101→68 / 146→68** 로 짧다.
   **실제 문자열이 확인되면 교체할 것.**

## 다른 화면에도 쓰이는 교훈

- **`clip-path` 와 `filter` 를 같은 요소에 주지 마라.** 렌더 순서가 «filter → clip-path» 라
  clip-path 가 drop-shadow 외곽선을 **통째로 잘라낸다**(검은 외곽선이 102px 만 남았다).
  외곽선 filter 는 **부모 요소**로 올릴 것.
- **이모지 아이콘은 색까지 틀린다.** ❤️ 는 단색 빨강(244,67,54)이라 레퍼런스의 «분홍 + 초록 `+`» 와 아예 다르고,
  ⚔️ 는 «교차된 검 2자루» 라 «검 1자루» 와 형태가 다르다. **면적비·축 각도를 실측해 CSS 로 그리면 회수된다**
  (하트·검 모두 면적 오차 2% 이내로 맞췄다). 자물쇠(`.sk-lock`)와 같은 접근이다.
- **알약형 요소의 높이를 둥근 끝에서 재면 짧게 나온다.** 서브탭 바를 x=1000(끝)에서 재면 93,
  직선 구간 x=650 에서 재면 97 이다. 비평가가 «3px 짧다» 고 한 것은 이 때문이었다.
- **레퍼런스는 JPEG 라 단일 픽셀 표본을 믿으면 안 된다.** 슬롯 초록은 같은 열에서 148~159 로 흔들린다.
- **모서리 radius 는 «행별 인셋» 을 `r−√(2rd−d²)` 로 피팅하면 정확히 나온다.** 눈대중이나 첫 행 인셋(AA 오염)으로 재지 말 것.
