## §2 처방 — 사본을 지우고 `tools/pwlaunch.js` 한 곳으로

A4·127 선례 그대로다. 루트에서는 상대 경로가 `./tools/pwlaunch` 다.

```js
const { pw, launch } = require('./tools/pwlaunch');
const { chromium } = pw();
…
const browser = await launch(chromium);
```

- 6개(`29`·`41`·`42`·`43`·`44`·`75`): `require('playwright')` 2줄 치환 + `chromium.launch()` → `launch(chromium)`.
- `verify25`: 같은 치환에 더해 **자기 폴백 블록 9줄을 삭제**했다. 남겨 두면 사본이 둘이 되어 다시 어긋난다
  (이 저장소가 겪은 병이 정확히 그것이다 — `pwlaunch.js` 머리말). 폴백이 사라지면서 쓰이지 않게 된
  `const fs = require('fs')` 도 같이 걷었다(`fs` 참조 잔여 0건).

부수 효과 하나가 **의도된 것**이다: `pwlaunch.launch()` 는 entry 가 `verify*.js` 일 때 `settle291.armBrowser`
(입장 연출 정착 장치)를 같이 심는다. 루트 게이트 7개도 이제 `tools/*` 게이트 44개와 **같은 정착 규약**을 받는다.
