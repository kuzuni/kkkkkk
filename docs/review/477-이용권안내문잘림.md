## §2 처방 — 등재문 ⓐ (총론 한 줄 + 카드별 대체가)

두 갈래 중 ⓐ 를 골랐다.

- **ⓐ 채택** — 하단은 **총론 한 줄**만: «결제 미연동 — 구매 시 💎 다이아로 대체 결제됩니다».
  각 카드의 대체가는 **그 카드**의 가격 버튼 위 `.pvd` 로 옮긴다.
  정보가 «그 카드» 것이고, **하단 줄이 이용권 수에 안 딸리게 된다**(뿌리를 끊는다).
- **ⓑ 기각**(줄바꿈 2~3줄) — 잘림은 없어지지만 **뿌리는 그대로**다(이용권이 늘면 3줄 → 4줄로 계속 자란다).
  게다가 하단 줄은 `top` 절대배치라 줄이 늘 때마다 `pageH`·서브탭 여유를 같이 손봐야 한다.

### 자리를 고른 것은 취향이 아니라 기하다

`.pvd{right:72px; bottom:145px; width:308px}` — **가격 버튼(`.pvc>.bt` right 72 · w308 · bottom 31 · h101)과 같은 폭·같은 우 여백**.

| 왜 이 자리인가 | 값 |
|---|---|
| 세로 앵커가 **bottom** 이라 카드 높이가 달라도 버튼과의 간격이 상수 | 버튼 상변 = bottom−132 · `.pvd` 하변 = bottom−145 ⇒ **13px** (불릿형 690 · 배너형 534 둘 다 같다) |
| 리본2(`.rb2` bottom 66..138)와 세로로 안 만난다 | `.pvd` 상변 bottom−179 ~ 하변 bottom−145 ⇒ rb2 상변보다 **7px 위** |
| 리본1 금색 판·수량(x 316..447 / 356..447)과 가로로 안 만난다 | `.pvd` x **649..957** |
| 일러스트 판(`.art`)과 안 만난다 | 불릿형 여유 **72px** · 배너형(ban1) 여유 **37px** |

⚠ **버튼 «안» 두 줄은 이미 한 번 실패한 자리다** — 151 이 시도했다가 원화 글자와 겹치고 검정 테를 뚫었다
(렌더 28541 주석). 그래서 버튼 **밖**이다.

⚠ **보유 중(`own`) 카드에는 안 붙인다** — 버튼이 «이용 중» 으로 바뀌어 살 수 있는 상태가 아니다.
`.pvd` 는 원화 버튼과 **같은 분기**에서 나온다(둘이 갈라지면 «이용 중» 옆에 가격이 남는다).
