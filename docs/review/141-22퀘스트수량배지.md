## §1. ★ 측정표에 적힌 «.364» 를 그대로 넣었으면 이번에도 틀렸다

등재 문구와 측정표 §5-2 는 목표 배율을 **.364** 로 적어 뒀다. 그 값의 출처는

```
font-size = 잉크 높이 27 ÷ 0.70     (0.70 = «숫자는 잉크 = 캡하이트» 가정)
          = 38.5  →  38.5 / 106 = .364
```

인데, **0.70 은 서체 교체 «전» 의 값**이다. 지금 서체(Jua)로 우리 화면에서 직접 재면:

| | fs | 흰 채움 높이 | 잉크비 |
|---|---|---|---|
| 우리 실측 | 24.91 | **20** | **0.803** |

→ ref 잉크 높이 27 을 내려면 `fs = 24.91 × 27/20 = ` **33.6** = 106 × **.317** 이다.
`.364` 를 넣었으면 잉크가 **31** 이 돼 −26% 가 **+15%** 로 부호만 바뀌었다.

이것은 126 §9-6 이 이미 경고한 함정과 **같은 함정**이다 — 거기는 한글 라벨의 `ink/0.93`,
여기는 숫자의 `ink/0.70`. **측정표의 «환산 상수»(잉크비)는 전부 옛 서체 것이라 다시 재기 전에는
쓰면 안 된다. 재는 것은 ref 가 아니라 «우리 렌더» 다** — ref bbox 는 이미 맞게 적혀 있다.

## §2. 폭은 `font-size` 로도 `scaleX` 로도 혼자 안 맞는다 — 자간이 빠져 있었다

fs 를 33.6 으로 올려도 폭이 안 맞는다. 두 손잡이가 필요한 이유는 **ref 숫자열이 우리보다
«글자가 넓은 것» 이 아니라 «글자 사이가 벌어져» 있기 때문**이다.

| | 2자리 `50` | 3자리 `100` | 자당(=한 자 늘 때 증가분) |
|---|---|---|---|
| ref | 46 | 67 | **21.0** |
| 우리 (fs 33.6, sx 1, ls 0) | 39.2 | 52.3 | **13.1** |

자당이 13.1 → 21.0 이어야 하는데 2자리 총폭은 39.2 → 46 이면 된다. 비율이 서로 다르다
(1.60 vs 1.17) — 그래서 **한 손잡이로는 두 표본을 동시에 못 맞춘다.**
단일 `scaleX` 최선값 1.28 로는 2자리 **+1.8%** / 3자리 **−1.7%** 로 갈린다.

`scaleX` s 와 `letter-spacing` L 을 연립으로 풀면

```
s(39.2 + L)  = 46          →  L = 8.8px (= .262em)
s(52.3 + 2L) = 67          →  s = 0.958
검산: 자당 = s(13.1 + 8.8) = 21.0 = ref ✔
```

즉 답은 «글자를 늘리는 것» 이 아니라 **«글자는 거의 그대로(×0.96) 두고 자간을 벌리는 것»** 이었다.
`text-indent` 는 53 `.bg53-c>b.ifq` 와 같은 이유로 같이 넣는다 — `letter-spacing` 은 **마지막 글자
뒤에도** 붙어서 가운데 정렬을 L/2 만큼 왼쪽으로 민다. `text-indent:L` 이 그것을 되돌린다(실측 §3).

## §3. ⚠ 1× 캡처로는 이 연립식을 못 푼다 (도구 교훈)

처음 두 회는 답이 **3px 씩 오락가락**했다. 원인은 식 자체다:

```
25·L = 67·A₂ − 46·A₃      →   dL/dA₂ = 67/25 = 2.68
```

**A₂(2자리 자연 잉크폭)의 ±1px 오차가 L 에서 ±2.7px 로 증폭**된다. 1× 캡처의 ±0.5px 양자화만으로도
답이 «s 1.15 / L 3.4» 와 «s 0.96 / L 8.8» 사이를 왔다 갔다 했다(둘 다 그 회차 측정에는 «정답» 이었다).

→ `tools/ink141.js` 를 **deviceScaleFactor 3** 으로 찍게 했다(±0.17px). 그러자 5행이 전부 같은 값으로
붙었고 답이 한 번에 수렴했다. **연립으로 두 손잡이를 푸는 자리는 1× 로 재지 마라.**

같이 겪은 두 번째 오염 — **B(대상 숨김) 캡처가 한 장이면 그 프레임만의 떨림이 통째로 «잉크» 가 된다.**
회차마다 «잉크 폭 106 / 84 / 82» 같은 값이 무작위 행에서 튀었다(106 = 프레임 폭 전체).
B 를 **두 장** 찍어 «둘 다에서 사라진 픽셀» 만 잉크로 세게 하니 사라졌다. (m126ink 의 N 두 장과 같은 처방을
B 쪽에도 해야 한다 — A 쪽만 막으면 반만 막은 것이다.)
