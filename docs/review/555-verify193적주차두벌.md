### 2. 고친 것 — 주문을 **한 벌**로 접었다 (546-④)

같은 파일 안에 «적을 세운다» 가 두 벌이었다. 130행은 507 이 이미 고쳤고(`sp·dashT·dashD·dashCd`),
[2b]·[3] 의 표본 여섯 자리는 507 **이전**의 `e.sp = 0` 하나로 남아 있었다.

* 페이지에 헬퍼를 **한 번만** 얹는다 — `window.park = e => { e.sp = 0; e.dashT = 0; e.dashD = 0; e.dashCd = 1e9; }`
  (`p.goto` 직후 · 이 파일은 goto 가 한 번뿐이고 reload 가 없어 전 절이 같은 것을 읽는다).
* 부르는 자리 **7곳** — 130행(주 루프) + 등재문이 센 여섯 자리(266 setup · 334 레이저 · 345 화염병 ·
  360 드론 연사 · 362 드론 만료 · 400 [3]ⓐ 곡선탄).
* 남은 `e.sp = 0` 은 **주석과 [2b-p2] 대조군뿐**이다(`grep 'sp = 0'` 로 확인) — 다음 세대가 `park(` 로 셀 수 있다.

⚑ **부수 효과 — 표본 다섯 자리가 «처음으로» 주차됐다.** `setup()` 이 한 번만 park 하면
`dashCd = 1e9` 는 프레임마다 `dt` 씩만 줄므로 그 표본이 끝날 때까지 유효하다. 그래서
매 프레임 주차를 **아예 안 걸던** 곡선탄·나선탄·주변 참격·반사탄·도약 연쇄탄 다섯 표본도
같이 닫혔다(등재문이 센 여섯 자리보다 넓다).
