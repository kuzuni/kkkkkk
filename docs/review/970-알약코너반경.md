## 1. ⓐ — ±1.3 은 오차막대가 아니라 **버그**였다

`probe352.radius()` 의 두 호출이 서로 다른 규칙을 쓰고 있었다:

```
radius(ref7, 292, 551, 2027, 'ref')   ← 셸 바깥 상변 2021 + 6
radius(cap7, 291, 551, 1967, 'cap')   ← 셸 바깥 상변 1960 + 7
```

437(2026-08-30)이 ref 테두리를 **7** 로 확정했는데(`K7 · B7 · F63 · B7 · D7 · K6(+AA)`) **이 리터럴만 안 따라왔다.**
직접 세로 단면이 그것을 못박는다 — 자를 안 믿어도 되는 증거다:

| | x420 세로 단면 (클래스 / 최대휘도) | 검정 런 | ⇒ 알약 상변 |
|---|---|---|---|
| ref | `PPRKKKKKKKSSSSSSSVVVVV` · `… 154 6 1 0 0 1 3 35 96 99 …` | y **2021..2027** (7행) | **2028** |
| cap | `PPPKKKKKKKSSSSSSSVVVVV` · `… 240 0 0 0 0 0 0 0 99 99 …` | y **1960..1966** (7행) | **1967** |

⇒ ref 원점을 **2028** 로 모았다. 눈금 **30.6 → 29.6**, 968 의 모델 역산으로 과녁 **32.65 → 31.62**.
리터럴 1px 이 과녁을 1.03px 옮기므로 968 이 «± 1.3» 이라고 적은 폭은 **통째로 이 한 글자**였다.

⚠ 958 2회차·968·970 이 **세 번 연속** 같은 얼굴을 만났다 — «두 자를 섞은 짝». 교훈은 LESSONS 에 적었다.

## 2. ⓑ — 원점을 고쳐도 자는 여전히 틀린다 ⇒ **원점에 면역인 자**

대조군이 그렇게 말한다. 참값이 CSS 선언으로 **rx 30** 인 우리 캡처를 옛 자가 **28.1** 로 읽는다(−1.9).
뿌리는 좌표 규약 둘이다 — ① 깊이를 `d` 로 쓰는데 행 y 의 표본 중심은 `y+0.5` 라 참깊이는 `d+0.5` ·
② `pill_l` 이 손으로 적은 정수다(cap 참값 DOM 290.75 ↔ 리터럴 291). 둘 다 같은 방향으로 깎는다.

`tools/probe970.py` 는 그래서 **원점 셋(상변·좌변·우변)을 그림에서 부분 화소로 찾고**(368 처방 —
«자리를 상수에서 빼고 제품에게 묻는다») 깊이를 표본 중심으로 잡는다. 손 값은 «어디쯤부터 훑을까» 뿐이다.

**그래도 남는 것이 원점의 정밀도**다. 그래서 한 겹 더 갔다 — 원점이 e 만큼 틀리면 인셋이 전부 `ins + e` 로
**같이** 밀리므로, 같은 그림 안 **두 깊이의 차**를 쓰면 e 가 소거된다. 그 차는 여전히 rx 에 1차라

```
rx_ref / rx_cap  =  [ins_ref(d1) − ins_ref(d2)] ÷ [ins_cap(d1) − ins_cap(d2)]
```

이고 **원점·원 모델·좌표 규약 셋 다 안 쓴다**. 등재문 ⓑ 가 «자기 직선부 대비 비율» 로 노린 상쇄를 원점까지 넓힌 꼴이다.

### 그 면역이 실제로 일한다는 증거 — 좌·우가 만난다

면역 자에서는 사라진다**:

| 자 | 좌 ⇒ rx | 우 ⇒ rx | **좌우 갈림** |
|---|---:|---:|---:|
| 절대 인셋 비율(원점 의존) | 34.51 | 39.92 | **5.41 px** |
| **인셋 «차» 비율(원점 면역)** | **30.94** | **31.47** | **0.53 px** |

`verify970` **[R1]** 이 그 대비를 되돌림 시험으로 든다(면역을 걷어내면 좌우가 4px 넘게 갈린다).

## 4. ⓒ — 그래서 제품을 **안 옮겼다**(위임 규약 채택)

과녁 **31.3 ~ 31.6** 은 선언 **30** 과 **1.3 ~ 1.6** 떨어져 있다. 그런데:

1. **그 차가 오차막대 안쪽이다.** ref 쪽 사분위 폭이 **±1.9** 라 구간 29.5~33.4 이 **30 을 품는다.**
   크리스프 짝에서 ±0.25 이던 자가 ref 에서 ±1.9 로 벌어지는 것은 JPEG 경사면 몫이고, 그것은 이 자로 더 못 줄인다.
2. **같은 양을 «눈» 으로 잰 표본과 어긋나지 않는다.** 352 비평가 5인 평균이 **30.2** 다.
   등재문 ⓒ 는 «표본을 늘려 30.2 와 갈라라» 였는데, 늘려 보니 **새 과녁이 30.2 를 품는다** — 가를 것이 없다.
   LESSONS **352-⑤**(«소수 쪽으로 값을 옮기지 마라 · 같은 양을 잰 표본 수로 판단하라»)가 못박은 자리가 정확히 여기다.
3. **대가가 크다.** rx 를 옮기면 409 가 **18회차**에 걸쳐 세운 코너 장치 넷이 같이 움직이고

   `.stab-c4::before{border-radius:30px}`) 게이트 넷을 이관해야 한다.
   **오차막대 안쪽 1.4px 을 위해 18회차짜리 기하를 다시 세우지 않는다.**
