## 채점 축 (각 10점 · **최저 항목 점수가 그 비평가의 점수**)

1. **① 타이밍** — 길이·이징. 프레임 사이 변화량이 «터진다» 로 읽히는가, 아니면 등속·계단으로 읽히는가.
2. **② 크기 비율** — 알 지름이 호스트(버튼)·발원 아이콘 대비 적절한가. 너무 커서 그릇을 먹거나, 너무 작아 판독이 안 되는가.
3. **③ 위치·경로** — 알이 **어디서 나와 어디로 가는가**. 발원(재화 아이콘)에서 나오는가 · 온 원으로 퍼지는가 · 한쪽에 뭉치거나 빈 부채가 있는가 · 궤적이 «원» 인가 «직사각형» 인가.
4. **④ 가독성·일관성** — 아래 숫자·라벨을 가리지 않는가 · 두 씬이 **같은 어휘**로 읽히는가 · 09·12·17 의 기존 연출 톤과 어긋나지 않는가.

**통과선 = ①~④ 최저 8.** «연출 없음» 은 무조건 0 이다.

## 지적 규격 (엄수)

- 지적은 **수치로만** — «몇 px · 몇 % · 몇 도 · 몇 배». 두루뭉술한 총평 금지.
- **지적마다 어떻게 쟀는지 밝혀라** — 어떤 프레임(#n)·어떤 마스크/열창·어떤 기준점. (A1 10~12회차 사고: 계측 정의가 다르면 «2인 일치» 도 틀린다.)
- 각 축마다 **1순위 결함 하나**를 고르고, 처방을 **한 낱말~한 줄**로 적는다.
- 색·아트 내용·서체 «모양» 은 감점 사유로 쓰지 마라. 크기·위치·비율·타이밍만 본다.

## 배경 — 이 작업이 무엇을 쫓고 있는가 (등재문)

씬 A(요소 대상)의 알이 **제 몸길이만큼도 안 움직인다**는 지적으로 시작된 행이다.
등재 당시 실측: 알 하나의 총 이동 **24.0px**, 그 알의 최대 지름 **41px** ⇒ **0.59 몸길이**.
같은 곡선을 타는 씬 B(점 대상)는 **265.6px / 28px = 9.5 몸길이** — 몸길이당 이동량이 **16배** 차이였다.
⇒ 「터진다」 가 아니라 「제자리에서 커졌다 꺼진다」 로 읽힌다는 것이 이 행의 결함이다.

## 앞 회차가 이미 **닫은** 것 — 다시 1순위로 올리지 마라 (근거 없이는)

각각 비평 2인이 독립으로 확인해 준 자리다. 여전히 결함으로 보이면 **수치와 계측법을 붙여서** 적어라.

1. **발원 원반 안에서 끝나는 알 = 0/10** (4회차엔 3~6알이 원반 안에서 죽었다).
2. **「53」(훈련 숫자) 가림 0.0%** · **호스트 상자 이탈 0px**(잉크가 액자에 닿지 않는다 — 여유 5~17px).
3. **발원 정합** — 알이 실제로 **코인 아이콘**에서 나온다(역투영 오차 2.2px).
4. **「53」 섹터를 비우는 것은 결함이 아니다** — 5회차 두 사람(DF·DG)이 각각 계산해 «비우는 쪽이 정답» 이라고 지지했다.
5. **씨앗 각 «쓸 수 있는 호 위에 등간격 재파종» 은 이미 두 판 다 만들어 재고 기각했다**(7회차). 굴림이 막힌 방향의 알을 경계 **바로 바깥**에 앉히고 있고, 등간격은 그 알을 반 피치 **안쪽**으로 물린다(빈 각 1안 +18° · 2안 +3.8°). 같은 처방을 다시 내려면 **왜 앞 판정이 틀렸는지**를 수치로 적어라.
6. **끝점 융합 회피**(끝점이 이미 앉은 끝점을 안 밟게)도 8회차가 만들어 재고 기각했다(최소 간격 불변 0.13 지름 · 산포 ×2.89 → ×2.97 악화).
