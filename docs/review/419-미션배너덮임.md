**작업 중(2026-08-30, sess-0646-17631 워커 C · 1회차).**

눈은 이미 말했다 — 407 을 낳은 351 6회차에서 비평가 3인(BY·BZ·CA)이 **각자 1순위로** 짚은 자리다.

## 1. 등재문 확인 — 값은 그대로 재현됐고, **축은 갈아 끼워야 했다**

338 규칙대로 처방 전에 재현부터 했다.

**ⓐ 등재문의 값은 그대로다.** `node tools/probe351.js` 전수(45화면 × 2해상도):

```
[351] 1600 에서만 생긴 결함 21건 · 화면 8/45   (그중 covers:tuto 17건 · 화면 7개)
```

등재문의 «17건 · 화면 7개» 와 화면·부품·px 가 **한 건도 안 틀리고** 같다
(`side:attend` 150·150·150 · `side:roul` 150·150·69·3 · `side:promo` 150·150·117 ·
`side:bless` 150·150 · `menu:mail` 150 · `menu:bag` 150·150 · `prof:19` 88 · `prof:20-스펙` 137).

**ⓑ 그런데 D7 의 «겹침 px» 로는 이 결함의 모양을 말할 수 없다.** 겹침 150px 은 두 그림을 구별 못 한다 —

* 배너가 **통째로** 상자 뒤로 들어간다 → 사람 눈에는 «배너가 없다». 깨져 보이지 않는다.
* 배너가 **일부만** 덮여 오른쪽에 노란 **토막**이 삐져나온다 → **깨져 보인다.**

407 이 고친 것은 뒤쪽이었다(배너 [진행중] 버튼 잉크 87.5% 덮임 = 나머지가 보였다).
⇒ `tools/probe419.js` 를 신설해 겹침 px 대신 **«배너의 보이는 면적 %»** 와 **«오른쪽 토막 폭»** 을 쟀다.
(덮는 상자의 «불투명» 판정·클리핑 접기는 D7 과 **글자 그대로 같은 필터**를 쓴다 — 같은 자리를
다른 자로 재면 값이 안 붙는다.)

### 1-2. ⚑ 등재문이 못 본 두 가지 — **자의 차분이 삼킨다**

**① 결함은 «1600 전용» 이 아니다.** `menu:mail`·`prof:19`·`prof:20`·`menu:conf` 는 **2280 에서도**
배너를 13~48px 물고 있다(보임 93.3 / 74.4 / 75.2 / 89.4%). D7 의 key 는 `covers:tuto` 하나라
**2280 에도 같은 key 가 있으면 차분에서 소거된다** — `menu:mail` 이 세 상자 중 하나만 세진 이유,
그리고 **`menu:conf` 가 전수 21건 어디에도 안 나오는 이유**가 그것이다(2280 10.6% ↔ 1600 69.1%).
⇒ **`menu:conf` 는 등재문에 없지만 같은 결함·같은 뿌리·같은 처방이다.** 여기서 같이 닫는다.
한 자리만 남기면 «설정 팝업만 배너를 토막 낸다» 는 **새 예외**가 선다(427 이 «유물석 던전만 층»
을 안 남긴 것과 같은 이유).

**② 문턱을 `.shortf`(1842)로 잡으면 안 된다.** 겹침의 시작점은 1842 **위**다 —
`menu:bag` 은 1920 에서 이미 15.7% · `side:bless` 는 1920 에서 **86.1%** 가 덮인다.
`.shortf` 로 가르면 **9:16(1920)에서 결함이 그대로 남고** 1842 를 지나는 순간 배너가 **튄다**.

## 2. 뿌리 — 407 과 같고, **호스트가 다르다**

배너는 하단 앵커(`#tuto{bottom:171}` + `#tabbar{height:180}` + `height:150` ⇒ 상변 = 프레임 하변 − 501),
팝업·시트는 가운데 정렬이다. 프레임이 1px 짧아지면 배너는 1px 올라오는데 상자 중심은 0.5px 만
내려가므로 **차이가 프레임 감소의 절반 속도로 벌어진다**(407 §2 의 산수 그대로).

다른 것은 **상자의 덩치**다. 407 의 `#ciw>.ci` 는 813px 짜리 «작은 다이얼로그» 라 하단 여백만
늘리면 됐지만, 여기 여섯은 **전체 높이 시트·공용 모달**이다.
