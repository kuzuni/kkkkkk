## 1. 이 환경엔 PIL 도 png 디코더도 없다 → `scan21.js`

23·33·41 세션이 쓰던 `scan*.py` 는 PIL 이 필요한데 이 컨테이너엔 없다(23 비고에도 같은 메모).
`node_modules` 에도 pngjs·jimp·sharp 가 없다. 그래서 **크로미움 자체를 스캐너로** 썼다 —
`--allow-file-access-from-files` 로 띄운 페이지에서 `file://` 이미지를 캔버스에 올리고 `getImageData` 를 읽는다.
레퍼런스 JPEG 와 우리 PNG 를 **같은 코드로** 스캔하므로 임계값 편차가 안 생긴다.

```
node scan21.js <이미지> <x0> <y0> <x1> <y1> ink <r> <g> <b> <tol>   # 색 마스크 bbox
node scan21.js <이미지> <x0> <y0> <x1> <y1> light|dark <임계>        # 밝은/어두운 잉크 bbox
node scan21.js <이미지> <x0> <y0> <x1> <y1> px                       # 영역 평균색 (단면 스캔용)
```

## 4. 함께 잡은 버그 — 51 계열 «짧은 프레임에서 깃발탭이 프레임 밖으로»

`node tools/smoke.js` 가 **1920×1080 · 1024×768** (둘 다 frameH 1600 으로 clamp)에서
`collTabs bottom +147 / +105` 로 검출했다. 원인은 **깃발탭이 모달 «상단» 기준 `top:1534px` 절대**였던 것 —
`.cl` 이 `max-height:100%` 로 눌리면 탭만 그 자리에 남아 프레임을 뚫는다.

- `.cl-tabs{top:1534px}` → **`{top:auto;bottom:-156px}`** (모달 하단 앵커. 기준 프레임 값은 동일)
- `.cl-body{height:1416px}` → **`{top:111px;bottom:1px}`** (리스트도 상자를 따라 줄게 — 안 그러면 모달 밖으로 흘러 탭을 덮는다)

**교훈**: «모달 밖으로 나가는 장식» 은 반드시 **그 모달의 하단 앵커**로 붙인다. 상단 절대로 붙이면
상자가 눌리는 순간 장식만 남는다. `smoke.js` 의 잘림 검사 id 목록에 `#collw .cl`·`#collw .cl-tabs` 를 추가하고,
화면비 루프에서 21 을 열도록 했다(이 화면이 «모달 아래로 삐져나오는» 유일한 껍데기라서).
