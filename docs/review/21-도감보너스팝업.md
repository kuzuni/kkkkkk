## 1. 이 환경엔 PIL 도 png 디코더도 없다 → `scan21.js`

23·33·41 세션이 쓰던 `scan*.py` 는 PIL 이 필요한데 이 컨테이너엔 없다(23 비고에도 같은 메모).
`node_modules` 에도 pngjs·jimp·sharp 가 없다. 그래서 **크로미움 자체를 스캐너로** 썼다 —
`--allow-file-access-from-files` 로 띄운 페이지에서 `file://` 이미지를 캔버스에 올리고 `getImageData` 를 읽는다.

```
node scan21.js <이미지> <x0> <y0> <x1> <y1> ink <r> <g> <b> <tol>   # 색 마스크 bbox
node scan21.js <이미지> <x0> <y0> <x1> <y1> light|dark <임계>        # 밝은/어두운 잉크 bbox
node scan21.js <이미지> <x0> <y0> <x1> <y1> px                       # 영역 평균색 (단면 스캔용)
```

## 7. 다음 세션에게 — 교훈 4개 (다른 화면에서도 그대로 재발한다)

1. **`#id 요소` 리셋은 `.class>요소` 규칙을 이긴다(ID 특이성).** `#collw i{display:inline-block}` 하나 때문에
   `.clb-bdg>i.l{display:block}` 이 통째로 무시돼 뱃지가 «Lv./숫자» 2단이 아니라 한 줄로 붙어 있었고,
   카드 아이콘도 인라인이 됐다. **오버레이 안에서 display 를 바꾸려면 같은 ID 를 붙여 특이성을 맞춘다.**
2. **`filter` 는 `clip-path` «전에» 적용된다.** 깃발·리본처럼 `clip-path` 로 모양을 내는 요소에
   `drop-shadow` 로 외곽선을 주면 **클립이 그림자를 잘라내 한 픽셀도 안 나온다.**
   외곽선은 **클립이 끝난 래퍼**에 걸어야 한다.
3. **전역 클래스 이름 충돌을 의심하라.** 카드 아이콘 `<i class="ci">` 가 33 재화정보 팝업의
   `.ci{width:598px;height:813px}` 를 그대로 먹어 상자가 598px 로 카드 밖까지 흘렀다.
   짧은 클래스명(`ci`·`cd`·`cb`)은 **화면 접두어를 붙일 것**.
4. **비평가 지적은 «항목» 만 받고 «수치» 는 자체 스캔으로 다시 낸다.** 이번 8명 전원이
