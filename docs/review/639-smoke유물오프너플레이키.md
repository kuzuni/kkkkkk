## §2 재현 — `tools/probe639.js` 신설

### ⚠ 부하 모델을 한 번 틀렸다 — 브라우저 «안» 의 부하는 부하가 아니다

1회 시도는 같은 브라우저에 페이지를 3장·8장 더 띄우는 방식이었고 **8/8 전부 통과**했다(재현 실패).
배경 탭은 rAF 가 스로틀링돼 **CPU 를 안 태운다**. 등재문이 본 부하는 스윕 = **별개 node+chromium 프로세스**다.
`node tools/verify*.js` 6개를 실제로 띄우자 **그 자리에서 재현됐다.**

| 부하 | 메인 fps | 89 유물 fps | smoke 경로 실패 |
|---|---|---|---|
| 없음 | 43.6 | 9.79 | **0/6** |
| 브라우저 안 8장 | 10.31 | 2.65 | **0/8** ← 부하가 아니었다 |
| **프로세스 6개** | 16.99 | **2.24** | **5/8** |

### ⚑ 본체 — «아직 안 그려졌다» 가 아니라 «왕복이 굶었다»

죽는 순간 그 셀렉터를 페이지 안에서 물었더니 **매번 이렇게 나왔다**:

```
{"n":1,"w":254,"h":49,"x":805,"y":31,"disp":"flex","vis":"visible","op":"1","pe":"auto"}
```

노드는 **붙어 있고 · 보이고 · 상자가 있고 · pointer-events 도 살아 있었다.**
즉 «유물 페이지가 알약을 아직 안 그렸다» 가 **아니다**. `page.click` 은 셀렉터 resolve → 액션어빌리티 →
히트테스트 → 입력 디스패치로 렌더러를 **여러 번 왕복**하는데, 그 화면이 2.2fps 라 왕복 하나하나가
프레임을 기다린 것이다. `force:true` 는 가시성·안정성 검사를 끌 뿐 **왕복 자체를 없애지 못한다.**

⇒ **ⓑ 는 뿌리가 아니다.** 멈춤이 길어지면 새 상한도 같이 넘는다 — 실제로 처방 ⓐ 의 클릭이
**3276·3924·3763·4091ms** 를 쓴 회차가 있었다. 3000 을 5000 으로 올렸어도 그 회차들은 죽었을 것이다.
ⓐ 는 **왕복을 한 번으로 줄이므로** 상한을 안 넘는 게 아니라 **상한에 안 걸린다.**

## §3 처방 — ⓐ, 그리고 이 파일의 선례

`tools/smoke.js` 는 **이미 열 곳이 페이지 안 클릭**이다
(`o.hero`·`o.dun`·`o.tr`·`o.cos`·`o.rel`·`o.prof`·`o.coll`·`o.quest`·`o.legal`·`o.shop` — LESSONS 50-①).
일반 `o.sel` 경로만 마지막으로 `page.click` 에 남아 있었다. **새 방식이 아니라 안 따라온 한 곳이다.**

```js
async function clickIn(page, sel) {
  await page.waitForSelector(sel, { state: 'attached', timeout: 6000 });
  await page.$eval(sel, (el) => el.click());
}
```

⚠ **«붙었는지» 대기는 안 뺐다** — 오프너가 통째로 사라진 것은 여전히 빨개야 한다(§R2).
빼도 되는 것은 «액션어빌리티» 뿐이고, 그건 `force:true` 가 이미 포기한 값이라 **잃는 커버리지가 0** 이다.

## §4 ⚑ 무르게 풀지 않았다 — `want` 항을 같이 세웠다

페이지 안 클릭은 히트테스트를 안 거치므로 **«클릭은 던졌는데 아무것도 안 열린»** 경우가 생길 수 있다.
그런데 [2] 의 통과 조건은 **«콘솔 에러 0» 과 «NaN 문자열 0» 둘뿐**이라 — 그 둘은
«아무 일도 안 일어났다» 를 **통과로 읽는다.** 처방만 넣고 끝냈으면 **플레이키한 빨강을 조용한 초록으로 바꾼 것**이 된다.

⇒ 오프너에 `want`(«누르면 무엇이 켜져야 하는가»)를 신설하고 `cur:*` 셋에 `#ciw.on` 을 달았다.
셋 전부가 실제로 `#ciw` 를 연다는 것은 **전수로 확인했다**(gold·dia·relic **3/3**) — 안 여는 오프너가 하나라도
있었으면 이 항이 남의 자리를 빨갛게 만들었을 것이다.

⚠ **`want` 의 예산은 3000 이 아니라 6000 이다.** 조이면 방금 고친 병이 이 항으로 **옮겨 붙는다**
(부하에서 팝업이 늦게 열린다). 삼켜진 클릭은 **예산이 얼마든 영원히 안 열리므로** 넉넉해도 이빨은 안 빠진다.
