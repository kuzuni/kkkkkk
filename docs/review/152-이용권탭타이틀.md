## 2. 원인 — 빌려온 좌표가 «무엇을 피한 값» 인지 안 읽었다

124(이용권 탭)는 13(재화 탭)의 부품을 그대로 빌려 쓴다. 그 주석이 명시하고 있다:

> 레퍼런스에 없는 «우리 게임 설계» 라 13(재화 탭)의 부품을 그대로 빌려 쓴다:
> 껍데기 `.cn-wrap`(높이만 다름) · 타이틀 `.cn-ti` · 밴드 `.cn-hl/.cn-hd` · 리본 `.cn-rb` … 새 좌표계를 만들지 않는다.

그런데 `.cn-ti` 의 값은 **범용 타이틀 규칙이 아니다.** 13 의 §2 주석이 출처를 적어 놨다:

```
/* §2 `재화 상점` 타이틀 — 잉크 x686 y335(local 143) 268x65, 중심 819.5, #FFF8AA */
.cn-ti{left:670px;top:139px;width:301px;height:78px;text-align:center}
```

**13 좌측의 배너 아트(`.cn-bn` — 🎁 + 보석 3개)를 피해 오른쪽에 앉힌 레퍼런스 실측치**다.
이용권 탭에는 `.cn-bn` 자체가 없다 — **피할 대상이 사라졌는데 좌표만 따라왔다.** 이것이 ⓐ.

ⓑ 는 같은 뿌리의 두 번째 결과다. 박스 폭 301px 은 «재화 상점» 잉크 **268px** 에 맞춘 값인데,
«이용권 상점» 잉크는 **319px** 로 **51px 더 길다**(글자 수가 하나 더 많다).
→ 301px 박스에 못 들어가 공백에서 줄바꿈 → 2줄 → 78px 박스 밖으로 넘침.

**한 원인(빌린 박스가 이 페이지·이 글자에 안 맞음)에서 증상 두 개가 나왔다.**

## 3. 처방 — 이 페이지의 나머지가 이미 쓰고 있던 규칙에 맞춘다

이용권 페이지의 다른 부품은 **전부 프레임 중앙 540** 이었다. 타이틀만 그 규칙 밖에 있었다.

| 부품 | 좌표 | 중심 |
|---|---|---|
| 밴드 글자 `.cn-hd>i` | 전폭 `left:0;right:0;text-align:center` | 540 |
| 리본 `.cn-rb` | `left:227;width:627` | 540.5 |
| 안내문 `.pv-nt` | `left:66;width:948` | 540 |
| 기간 바 `.pv-bar` | `left:111;width:858` | 540 |
| 하단 문구 `.pv-bt` | `left:111;width:858` | 540 |
| **타이틀 `.cn-ti`** | **`left:670;width:301`** | **820.5 ← 혼자 튐** |

**수정은 CSS 한 줄**(index.html §124 블록 안, `.cn-wrap.pv{height:1180px}` 바로 아래):

```css
.cn-wrap.pv>.cn-ti{left:0;width:1080px}
```

- 전폭으로 열면 `text-align:center`(13 원값 그대로)가 잉크를 **540 정중앙**에 놓는다 → ⓐ 해소
- 폭이 1080 이라 319px 잉크가 접힐 이유가 없다 → **1줄** 로 돌아온다 → ⓑ 해소
- **13 의 `.cn-ti` 원값은 한 글자도 안 건드렸다.** 그쪽 치우침은 레퍼런스가 요구하는 값이고
  **내 작업 구간이 아니다**(병렬 세션 규칙 3). 자손 선택자로 `.pv` 페이지에서만 덮었다.
