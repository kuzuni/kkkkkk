### 뿌리 — 표본이 «속도가 0 인 상태» 를 만들지 못한다

옛 [E] 는 `player.vx/vy` 를 **세 프레임 내내 0 으로 박고** 마지막 프레임의 `player.anim` 을 읽었다.
그런데 `step()` 은 매 프레임 자동 이동 AI(59 ④ «적이 없으면 천천히 중앙 복귀»)로 속도를 **다시 계산**한다:

```
player.vx += ((mx/ml)*sp - player.vx) * Math.min(1, dt*9)      /* sp = stat.speed * mmag */
```

`dt*9 = 0.15` 이므로 박아 둔 0 은 **한 프레임 만에 `0.15 × stat.speed` 로 되밀린다**
(230 × 0.15 = 34.5 — 실측과 소수점까지 같다). 그 잔여는 `stat.speed` 에 **정확히 비례**하는데
460 의 갈림값 `MOVE_EPS` 는 **25 고정**이다. ⇒ **580**(`SPD_SC` = 2)이 115 를 230 으로 올린 순간
잔여가 임계 위로 올라섰다.

**460 도 580 도 잘못한 게 없다.** 플레이어 속도를 표본 안에 **암묵적으로 박아 둔 쪽이 자다** —
368 이 «자리를 상수에서 빼고 제품에게 물어라» 로 닫은 것과 같은 꼴이다.
