2. ★ **우리에게만 있는 잉여 레이어** — 젬 주위의 **갈색 소프트 드롭섀도**(폭 6px, `.ri` 기본 `filter`).

   어두워지는 그라디언트» 로, H 는 «하드 톤 스텝이 소프트 그라디언트로 대체됨» 으로 각각 검출했다.
3. ★ **숫자·라틴 글리프 폭이 전 구간 −17~25%.** 한글은 맞는데(«션» ref 24 vs 우리 25) 숫자만 무너진다:
   `200` −24% · `(0/10)` −23% · `[미션-227]` −17.5% · 하이픈 −38%.
   그 여파로 L1 중심이 10px 왼쪽으로 이탈하고 자간이 −25~39% 로 좁아진다.

그 밖에 — `200` 검정 외곽선 ref 4.5px vs 우리 2px(−55%) · 본문 외곽선은 반대로 ref 2px vs 우리 3px(+50%,

- **2회차** — 세 줄과 아이콘의 잉크 «폭» 을 ref bbox 에 맞췄다.
  높이를 먼저 ref 에 맞춘 뒤(`font-size`) 폭만 `scaleX()` 로 채우는 방식:
  L1 `font-size 29→28 + scaleX(1.25)` · L3 `27→23 + scaleX(1.5)` · `200` `scaleX(1.32)` · 💎 `scaleX(.77)`.
  L1 은 ref 중심 793.5 에 맞춰 +9px 이동. → **전 항목 Δ≤4px.**

  → 이 회차에 **회귀 게이트 `node tools/verify32.js` 신설** (아래 §5).

### 4-2. 이 회차에 밟은 함정 — **`filter:drop-shadow()` 는 연쇄하면 안 된다**

컨투어를 처음엔 `drop-shadow` 4개를 **연쇄**해서 만들었다. 그런데 **각 단계가 «앞 단계의 결과»(그림자 포함)를
다시 번지게 해서 오프셋이 합산**된다(5+5+4+4 = 18px) — 보상칸이 통째로 검게 메워졌다(프레임 안 검정 3028px).
`text-shadow` 의 콤마 목록은 전부 **원본 글리프**에서 그려지므로 합산되지 않는다. 다른 화면의 아이콘
아웃라인에도 그대로 해당된다.

## 7. 5회차 — 글리프 «종류별» 보정

한 줄을 통째로 `font-size` + `scaleX` 로 맞추는 방식으로는 ⓐ~ⓔ 를 동시에 못 잡는다
(숫자를 키우면 한글이 같이 커지고, 폭을 줄이면 숫자가 같이 줄어든다).
→ `drawTuto()` 가 줄을 **글리프 종류별 태그로 감싸서** 내보내게 바꿨다. 문자열은 전부 우리 소유다.

```
L1  <b>[</b><i>미션</i><s>-</s><em>227</em><b>]</b>      b=대괄호 i=한글 s=하이픈 em=숫자
L3  <b>(</b><em>0</em><s>/</s><em>10</em><b>)</b>        b=괄호   s=슬래시 em=숫자
L2  … <em>10</em> …                                      (61 이 이미 숫자를 <em> 로 감싸 두었다)
```

그리고 종류마다 **`font-size`(크기) · `top`(baseline) · `scaleX`(폭) · `margin`(상쇄)** 을 따로 준다.
`transform` 은 레이아웃 폭을 바꾸지 않으므로 **줄어든/늘어난 만큼 좌우 margin 으로 상쇄**해야 글자 사이가 벌어지지 않는다.
값은 `node tools/probe32.js <캡처> runs` 의 **글리프 열 런**(측정표 §2-3 형식, 런마다 잉크 상·하단 포함)으로 3회 반복해 맞췄다.

## 12. ★ M 의 «`paint-order` 누락» 진단은 틀렸다 — 두 수법을 실제로 해 보고 픽셀로 반증했다

M 은 «L2 채움이 절반인 것은 `-webkit-text-stroke` 가 중앙정렬이라 안쪽을 잠식했기 때문이고

1. **`paint-order` 는 이미 걸려 있었다.** 베이스 규칙 `#tuto .tt`(628행)가 이미 주고 있고 `.todo` 는
   stroke «폭» 만 덮어쓴다. 그래도 혹시나 해서 `.todo` 에 명시적으로 넣고 캡처해 비교하니
   **잉크 화소 1517 → 1512 로 무변화**였다.
2. **«같은 색 스트로크로 살찌우기»(4365행 `--fat` 수법)도 안 먹는다.** `-webkit-text-stroke` 를
   `currentColor` 로 돌리고 폭을 스윕한 결과:

| 스트로크 | 잉크 화소 | 잉크 bbox | 획 중앙값 |
|---|---|---|---|
| 5px #000 (현행) | 1250 | 216×24 | 3.0 |
| 2px currentColor | 1250 | 216×24 | 3.0 |
| 4.5px currentColor | 1254 | 216×24 | 3.0 |
| 5px currentColor | 1284 | **219×29** | 3.0 |
| 6px currentColor | 1402 | **219×30** | **2.0** |
| **ref** | **2217** | **217×26** | **5.0** |
