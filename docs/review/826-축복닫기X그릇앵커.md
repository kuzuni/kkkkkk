> 지시서 [3]-**(가)** — 레퍼런스 대조가 아니라 «✕ 가 무엇에 매달려 있는가» 라는 구조 명제다. 비평가 없음.

## 1. 등재문을 재현으로 셋으로 갈랐다 (338 규칙)

등재문(754 8회차 · 비평가 CJ·CK 2인 독립 일치)은 세 문장을 적었다. `tools/probe826.js` 를 신설해
**수리 전 트리 사본**에서 각각을 픽셀로 되물었다.

| 등재문 | 재현 결과 |
|---|---|
| ① «1841 에서 ✕ 가 그릇 상변보다 **63.5px 위**로 떠 딤에 얹힌다» | **이미 닫혀 있었다.** 등재(14:43Z) 뒤 **821**(21:28Z)이 `#app.shortf #blsw .bls{margin-top:0}` 한 줄로 그릇을 가드 126 에 못박아, 지금은 그릇 126 ↔ ✕ 134 로 ✕ 가 **그릇 안**이다 (`probe826` [A1]) |
| ② «경계에서 **Δx −426 · Δy +1479**» | **참이다.** 인접한 1841 ↔ 1842 에서 다시 재면 **Δx −426 · Δy +1440**(등재문의 1479 는 1841 을 인접하지 않은 1920 과 견준 값) (`probe826` [B1]) |
| ③ «요소별 개별 앵커 — 754 규약 ② 위반» | **참이고 이것이 남은 본체다.** 821 은 **증상**만 껐고 커플링(가드 126 ↔ 프레임 상수 134)은 그대로였다 |

⚑ **③ 을 «말» 이 아니라 «기계» 로 만든 것이 이 회차의 핵심이다.** 「✕ 가 프레임에 붙어 있다」는
**그릇을 움직이면 ✕ 가 안 따라온다**는 뜻이다. `probe826` [C] 가 821 의 한 줄을 뗀 사본에서 그것을 직접 만든다:

```
[C] 수리 전 트리 + 821 제거 — 그릇만 움직이고 ✕ 는 제자리인가
    1600 : bls 141.5 · ✕ 134 · Δ  -7.5
    1841 : bls 197.5 · ✕ 134 · Δ -63.5      ← 등재문 ① 의 63.5px 이 그 자리에서 되살아난다
```

그릇 상변은 프레임을 타는데(141.5 → 197.5) **✕ 상변은 두 프레임에서 같은 값(134)** 이다.
821 이 없으면 등재문 ① 이 그대로 돌아온다 — 즉 ① 은 «고쳐진» 것이 아니라 **한 줄에 기대고 있었다**.

## 2. 무엇을 고쳤나 — 좌표계 하나

✕(`.bls-x`)를 `#blsw`(`inset:0` = **프레임 좌표계**)의 형제 자식에서 **`.bls` 의 자식**으로 옮기고,
두 자리를 모두 **그릇의 패딩 상자 기준**으로 다시 적었다.

| | 수리 전 | 수리 후 | 그려지는 자리 |
|---|---|---|---|
| 짧은 프레임(<1842) | `#blsw` 기준 `top:134;right:45` | `.bls` 기준 `left:848;top:0` | 897 / 134 — **Δ0px** |
| 긴 프레임(≥1842) | 흐름 자식(`margin:5 0 auto` + `top:16`) | `.bls` 기준 `left:422;top:1440` | 471 / `.bls`+1448 — **Δ0px** |

- 흐름에서 빠진 **143px**(margin-top 5 + 높이 138)은 `#app:not(.shortf) #blsw{padding-bottom:289px}`(= 146 + 143)이 낸다.
  남는 높이가 다시 `frameH − 1842` 가 되어 중앙정렬 식이 수리 전과 **글자 그대로 같다**.
  (안 내면 남는 높이가 143 늘어 그 절반을 위쪽 `auto` 가 먹어 팝업이 **71.5px 내려간다** — `verify826` [R-d] 가 2280 에서 345 → 416.5 를 직접 잰다.)
- ✕ 가 모든 프레임에서 흐름 밖이 됐으므로 마지막 흐름 자식은 늘 스트립이다 ⇒ `.bls-promo{margin-bottom:auto}` 를 **기본값**으로 올렸다.
  754 가 `.shortf` 에만 걸어 둔 같은 선언은 이제 그 사본이라, 지우지 않고 «사본» 이라고 적어 남겼다(무엇을 왜 되돌렸는지의 기록).

**실측 — 프레임 6종 전부 Δ0px** (`verify826` §2 · `probe826` [E2]):

```
      1600      1841      1842        1920        2280        2600
✕  134..272  134..272  1574..1712  1613..1751  1793..1931  1953..2091   (수리 전과 전부 동일)
그릇  126       126       126         165         345         505
```

수리 후 같은 [C] 를 다시 하면(`probe826` [E1]) 그릇이 141.5/197.5 로 움직여도 ✕ 가 **149.5/205.5 로 8px 아래에 붙어 따라온다.**

## 3. 안 고친 것 — «경계의 자리 갈아타기» 는 351 의 설계다

등재문 ② 의 점프(Δx −426 · Δy +1440)는 **없앨 수 없다.** 1600 에서 ✕ 를 스트립 아래 자리로 되돌리면

```
가드 126 + 팝업 1157 + 21 + 스트립 249 + ✕ 138 + 아래 가드 16 = 1707 > 1600
```

라 간격을 0 으로 줘도 안 들어간다 — `probe826` [D1] 이 실제로 그 사본을 만들어 **✕ 하변 1712 > 프레임 1600(넘침 112px)** 을 찍는다.
그래서 351 이 148px 를 회수하려고 ✕ 를 코너로 올렸고, 423 이 그 빈 자리를 스트립에게 물려줬다.
점프를 없애려면 351 의 회수와 등재문 자신이 «깨면 안 된다» 고 적은 ④(1920·2280·2600 Δ0px)를 동시에 버려야 한다.
⇒ **826 이 고칠 수 있는 것은 «두 자리를 무엇에 매다는가» 였고, 그것을 고쳤다.**
`verify826` 머리말에 이 판단을 적어 뒀다(다음 세션이 같은 자리를 «미완» 으로 다시 잡지 않게).

## 6. 교훈

1. **«증상을 껐다» 와 «뿌리를 고쳤다» 는 다르다.** 821 은 그릇을 못박아 63.5px 을 지웠지만,
   그것은 «두 상수를 손으로 맞춰 둔 상태» 였다. 한 줄만 떼면 되살아나는 초록은 초록이 아니다.
2. **구조를 고치는 수리는 «값이 안 변한다» 가 성공 신호다.** 이 회차의 제품 5자리는 픽셀을 하나도 안 옮겼다
   (6종 Δ0px). 그래서 §R 이 없으면 이 게이트는 **아무것도 안 지키는 자**가 된다 — [R-a]~[R-d] 넷이 그 자리다.
3. **DOM 을 옮기면 «자식을 세는 자» 가 조용히 눈이 먼다.** `verify414` 의 `coverAny` 가 그랬다.
   `#blsw.children` 을 세던 표 셋 중 둘은 초록을 유지한 채 뜻만 잃었을 것이다.
4. **되돌림 사본은 «짝» 을 같이 옮겨야 한다.** `verify821` 의 문턱 이동 사본에서 배웠다 —
   조건이 다른 두 규칙이 한 뿌리를 나눠 가지면, 사본을 만들 때 하나만 옮기는 것이 곧 새로운 결함이다.
