## 2. 뿌리 — «은닉» 은 기능이 아니라 **강제 0/«???» 한 겹**이었다

세 자리 전부, 값을 만드는 식은 이미 미보유에서도 옳은 값을 낸다. 화면이 그것을 **덮어쓰고** 있었다:

```
own ? ownVal(cur) : 0          ← 식은 1.84% 를 주는데 0 으로 눌러 적는다
own ? it.n : '???'             ← 이름은 있는데 가린다
own ? fmtB(petDmg(it)) : '—'   ← petDmg 는 펫 레벨을 아예 안 타는데(481) 가린다
!own ? '아직 획득하지 못했습니다…' : <실설명>   ← 상태문이 실설명 **자리를 차지**한다
```

⇒ 처방은 **강제 0/대체문을 걷어내는 것**뿐이다. `oLv(id)` 가 미보유에서 0 이므로 같은 식이
그대로 «Lv. 0 일 때의 값» 으로 떨어지고, 그 값은 바로 위 «Lv. 0» 칩·진행바 «0/n» 과
**서로 맞는 말**이다 — 거짓 신호가 아니다. **346 이 코스튬에서 `cosLvOf`=0 으로 이미 한 것과 같은 길**이고,
그래서 미보유 전용 상수나 분기를 새로 만들지 않았다(402 «표 두 벌» 부패 예방).
