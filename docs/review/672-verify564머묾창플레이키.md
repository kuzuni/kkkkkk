## 3. 뿌리 — 자의 «창» 이 제품의 «국면» 과 어긋나 있다

[E] 는 표본 창을 **`btn.click()` 전** 에 찍은 벽시계 `t0` 기준으로 잡았다:

```
const H = { a: FX3_SPREAD*1000, b: (FX3_SPREAD + FX3_HOLD_F)*1000 };   // 220 .. 340ms
const t0 = performance.now();  btn.click();
… if (t >= H.a && t <= H.b) { /* 잰다 */ }
```

그런데 코인 자신의 시계는 `f.st = performance.now()` 로 **스폰 순간**에 시작하고, 스폰은 클릭 처리 +
렌더 뒤라 **18~29ms 늦다**. 국면 경계는 그 시계로 `f.sd` (0.22s) ~ `f.ha` (0.34s) 다.
⇒ 두 창이 지연만큼 어긋나, [E] 창의 **앞 1~3 표본이 아직 «퍼짐»(a) 국면**에 걸린다.

퍼짐 중인 코인은 **버튼(= 라벨이 있는 자리)에서 슬롯으로 가는 중**이라 배치값에서 최대 45.9px
떨어져 있다. 그런데 문턱 `FX3_KOM − FX3_BSFX` 는 **머묾 국면에서만 성립하는 하한**이다
(«배치는 구멍 밖 = `KOM` · 부유는 ±`BSFX`» 라는 산수). 국면이 다른 표본에 그 문턱을 대면
**틀린 자로 재는 것**이고, 퍼짐 표본이 하필 라벨 근처에 걸리는 실행만 빨개진다 = 플레이키.

**«경계에 앉아 있다» 는 등재문의 읽기는 결과였지 원인이 아니었다** — 0.4px 는 배치가 마침
`fx3Eject` 로 구멍 가장자리에 앉아 있던(644 이전 기하) 덕에 작아 보였을 뿐이고,
같은 결함의 폭은 아래 §4 에서 **최대 22.9px** 까지 벌어진다.

## 5. 처방 — 문턱이 아니라 창 (제품 0줄)

`tools/verify564.js` 의 [E] 를 다시 썼다. **문턱(`FX3_KOM − FX3_BSFX`)은 한 칸도 안 내렸다.**

1. **창을 제품 자신의 국면으로** — `fl.sd ≤ fl.t < fl.ha` 인 코인만 센다. 국면 밖(퍼짐·흡수)은
   세지 않고 **개수만 보고**한다(무엇을 안 셌는지 보이게).
   ⚠ 국면 판정에 `performance.now() − fl.st` 가 아니라 **`fl.t` 를 쓴다** — 지금 화면에 그려진 자리를
   만든 값이 그것이라, 두 개를 섞으면 프레임 한 칸만큼 또 어긋난다.
2. **y 대역 필터 폐지** — 제품의 keep-out 은 코인 y 를 안 보므로(밴드 y 대역에 걸리는 글자를
   가로로만 뺀다) 그 필터는 자를 **무르게만** 했다. 실제로 «라벨 y 대역에 코인 없음» 으로
   **n/a 초록**이 나던 자리다(9회 실행 중 1회 관측).
3. **좌표계 통일** — 코인 중심·라벨 상자를 둘 다 **프레임 좌표**로 환산해 프레임 단위 문턱과 잰다.
   종전은 뷰포트 px 를 프레임 문턱과 비교했다(s = 1 이라 값은 같았지만 자가 축척에 묶여 있었다).
4. **범위를 조용히 안 좁힌다** — keep-out 은 «밴드 배치» 의 규칙이라 `fl.bnd` 만 재는데,
   **밴드 밖 코인이 하나라도 있으면 세어서 빨갛게** 만든다(현재 실측 0개).
5. **자가 라벨을 스스로 잰다** — 제품의 `fx3TextX` 를 그대로 믿지 않고 Range 로 따로 재고,
   **제품 keep-out 원본과의 차 `dLab < 0.5px`** 를 같이 단언한다(실측 0.00).
6. **표본 0 이면 빨강** — 머묾 국면을 한 번도 못 본 실행은 관측이 아니다.
7. **허용오차는 고른 값이 아니라 «잰 값»** — 제품은 자리를 `translate(x.toFixed(1)px …)` 로
   **0.1px 격자에 양자화**해 그린다. 배치가 가장자리에 앉는 기하에서는 설계값이 문턱과 **정확히
   같으므로**, 그 격자 몫(±0.05)을 안 빼면 자가 0.05px 짜리 칼날 위에 선다. `probe672` [8] 실측
   최대 부족분 **0.001px** — 격자 상한 안이다. **문턱 자신은 불변.**

## 6. 무르게 풀지 않았음 — `[R3]` 되돌림 시험 신설

[R]·[R2] 는 «밴드 산수» 를 되돌리는 자라 **[E] 의 관측 경로를 한 번도 안 쓴다** — [E] 를 다시 쓴 이번에는
