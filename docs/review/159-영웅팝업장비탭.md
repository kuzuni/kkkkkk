## 1. 증상과 원인

기본값은 **이미 `heroTab='eq'`** 였다(전역 `let … heroTab = 'eq'` · `DEF()` 의 `heroTab:'eq'`).
그런데 서브탭을 옮길 때마다 세이브에 남기고(`heroSubGo()` 의 `S.heroTab = k`), 부팅 때 되살렸다:

```js
/* 폐기 전 */
heroTab = (S.heroTab === 'eq' || HEROBODY[S.heroTab]) ? S.heroTab : 'eq';
```

그래서 «기본값이 장비» 라는 말과 달리 **실제로는 마지막에 본 탭이 계속 부활**했다.
게다가 부활 경로가 둘이었다 —

| 경로 | 왜 장비가 아니었나 |
|---|---|
| **재열기**(닫았다 다시 열기 · 다른 탭 갔다 오기) | `goTab('hero')` 는 `curTab`·`panelOpen` 만 세우고 `heroTab` 은 **안 건드린다** → 전역에 남은 마지막 값이 그대로 |
| **재접속**(리로드) | 위의 복원 한 줄이 세이브에서 되살림 |

즉 «기본값을 고치는» 문제가 아니라 **«기억하지 않게 만드는»** 문제였다. 두 경로를 각각 끊어야 한다.

## 2. 고친 곳 (index.html 4곳 · 순 −1줄)

| # | 위치 | 변경 |
|---|---|---|
| ① | `goTab()` 일반 경로(~21993) | `if(k === 'hero'){ heroTab = 예약값 또는 'eq'; }` — **여는 순간 리셋** |
| ② | `gmHero(sub)`(~17322) | `heroTab`/`S.heroTab` 직접 대입 → **`heroSubReq = sub` 예약**(신설 `let heroSubReq = null`) |
| ③ | `heroSubGo(k)`(~21940) | `S.heroTab = k` **삭제** (전역 `heroTab` 만 갱신) |
| ④ | `DEF()`(~13741) · 부팅 복원(~24378) | 세이브 키 `heroTab` **폐기** · 복원 한 줄 **삭제** |

### ① 리셋을 «여는 순간» 에 둔 이유

`goTab()` 의 일반 경로는 **같은 탭 재클릭(= 닫기)이 바로 위에서 `return` 한 뒤**다.
그래서 이 지점에 도달한다는 것은 «닫혀 있던 영웅을 연다» 또는 «다른 탭에서 영웅으로 온다» 뿐이고,
**열려 있는 동안의 서브탭 이동(`heroSubGo`)은 이 경로를 아예 타지 않는다.**
덕분에 «열 때는 장비 / 열려 있는 동안은 자유» 가 분기 하나로 갈린다 — 별도 플래그가 필요 없다.

### ② 가이드 미션만 예외인데, 그 예외를 «예약» 으로 만든 이유

`gmHero('sk')` 는 미션이 지정한 서브탭으로 열어야 한다(73 ①). 옛 코드는 `heroTab = sub` 를
**먼저 세우고** `goTab('hero', true)` 를 불렀는데, ①이 들어오면 그 값이 곧바로 덮인다.

순서를 뒤집어 `goTab()` **뒤에** `heroSubGo(sub)` 를 부르는 방법도 있었지만 버렸다 —
장비 시트(`#eqw`)가 한 번 떴다가 곧바로 스킬 시트로 갈리므로 **60 쥬시의 개폐 감시(`jzOpen`/`jzClose`)가
같은 틱에 두 번 물린다.** 96 ②가 «장비 탭만 아래에서 다시 등장» 을 없애려고 `jzHush()` 까지 넣은 자리라
같은 증상을 되살릴 위험이 있다.

그래서 **목적 서브탭을 `heroSubReq` 에 예약**하고 `goTab()` 이 그 1회만 존중하게 했다.
전환이 한 번뿐이라 연출도 한 번이다. 예약값은 **쓰는 즉시 비운다** — 남아 있으면 다음 수동 진입이
장비가 아니게 된다(게이트 «예약은 1회만» 항목이 이걸 지킨다). 모르는 값이 들어오면 장비로 떨어진다.

### ④ 세이브 키 폐기 — KEY 인상 없음

`S.heroTab` 은 이제 **아무도 읽지 않는다.** 구 세이브(`v4`)에 남아 있는 키는 그대로 실려 다니다가
다음 `save()` 때 사라진다(44 교훈 2 «없으면 기본값» 의 역방향 — 키가 있어도 안 읽으면 무해).
그래서 **`KEY` 를 올리지 않았다.** 게이트가 `heroTab:'cos'` 를 박은 구 세이브를 심고 `load()` 한 뒤에도
장비로 열리는지 직접 확인한다.

`eqTab`(06 시트 **안**의 무기/방어구 탭)은 **건드리지 않았다** — 그건 시트 내부 상태라 별개다.

## 5. 다음에 이 자리를 만질 때

1. **«기본값이 X 다» 와 «열 때 X 로 시작한다» 는 다른 말이다.** 이 작업의 지시는 후자였고,
   전자는 이미 참이었다. 상태를 **저장하는 곳**과 **되살리는 곳**을 먼저 세어라 — 여기선 둘(전역 잔존 · 세이브 복원)이었다.
2. **서브탭을 새로 늘리면 `HEROBODY` 에만 넣으면 된다.** `goTab()` 의 리셋은 `'eq'` 를 상수로 쓰고
   예약값 검증에 `HEROBODY` 를 쓰므로, 칸이 늘어도 이 분기는 안 고쳐도 된다.
3. **남의 게이트 2개(`verify79`·`verify74`)가 아직 `S.heroTab = …` 을 쓴다** — 페이지 컨텍스트에서
   죽은 키 하나를 더 다는 것뿐이라 **무해해서 손대지 않았다**(둘 다 같은 줄에서 전역 `heroTab` 도 세우고,
   `verify79` 17/17 · `verify74` PASS 로 확인했다). 그 게이트를 다음에 고칠 사람은 그 대입만 지우면 된다.
4. **«열 때 초기화» 를 다른 팝업에도 붙일 거면 `goTab()` 이 아니라 각자의 `open*()` 에 넣어라.**
   03·10·89·23 은 `goTab()` 초입에서 각자 페이지 함수로 빠지므로 이 분기에 도달하지 않는다.
