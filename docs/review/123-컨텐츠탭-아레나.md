## 설계 결정 5건 (다음 세션이 되돌리지 않게)

1. **`data-dsub` 키는 안 바꿨다.** 지시가 «텍스트·측정표·README 만» 이라고 허용했고, 키를 바꾸면
   `smoke.js` 의 2단계 오프너 수집(`#dunSub [data-dsub]`)·`verify46`·`fnchk97`·`cap97`·`verify72` 가 동시에 깨진다.
   화면에 «레이드» 글자는 0곳이다(verify123 [1] 이 고정).

2. **아레나는 30 던전 런의 «상태» 를 재사용하되 HUD 는 새로 짰다.**
   `#app` 에 `dunrun` + **`arn`** 을 같이 붙인다 → 상단 HUD·탭바 숨김 · ◀ 나가기 노출 · 배속 버튼 위치까지
   30 의 규칙을 그대로 타고, `#app.arn` 이 `#dunHud` 를 내리고 `#arnHud` 를 올린다.
   **30 의 CSS 선택자에 `,#arnTm` 식으로 끼워 넣지 않았다** — 남의 구간을 건드리게 되므로 값을 다시 적었다
   (타이머는 28/30 과 같은 규격: 원판 Ø66 + 용두 36×21 + 흰 숫자 fs68/stroke9).

3. **상대는 «플레이어 스프라이트를 쓰는 특수 적» 이다.** `ETYPE.arena` 의 atlas/scale/r 을
   플레이어(`drawFrame('knight', …, 1.0)` · `player.r 16`)와 같게 맞췄다. 색 구분은 적 렌더에 추가한
   **`e.tint` 경로**(플레이어의 `tinted()` 와 같은 경로)로 한다 — 틴트가 없는 기존 적 5종은 `img = null` 이라
   렌더가 한 줄도 안 바뀐다.

4. **카드 팔레트는 폐기된 r120 의 보라를 물려받았다.** 처음에는 슬롯 규격과 함께 카드2 의 노랑을 썼는데,
   `fnchk97` [2]가 «잉크가 배경보다 어두우면 안 된다» 를 잡아냈다 — 기사 잉크 휘도 **60.8** vs 노랑 배경 **98.2**.
   보라(65.2)로 옮기니 두 칸(102.2 / 60.8) 다 산다. **기하는 카드2 값 그대로**(296×289 / 52).

5. **썸네일은 `drawHeroTo` 가 아니라 `drawSpriteTo` 로 그린다.**
   look(코스튬 아바타) → 틴트라는 **데이터 경로는 80 과 같지만**, `drawHeroTo` 는 «씬에 발밑을 앉히는» 앵커라
   카드 슬롯 위쪽에 **109px 공백**이 남았다(verify72 [5] 가 잡았다). 카드 아트 자리는 97 의 «잉크 rect 를
   슬롯에 꽉 채운다» 규칙이므로 `drawSpriteTo` 가 맞다. 남은 여백 3.4/6.3px 은 아틀라스 프레임의 투명 1px 이다
   (idle[0] rect 44×46, 잉크 (1,1)~(42,45) — 실측).

## 밸런스 (아레나)

| 값 | 식 | 근거 |
|---|---|---|
| 상대 전투력 | `내 cp × rnd(0.8, 1.2)` | 주인 지시 ④ 그대로 |
| 상대 HP | `상대 전투력 × 0.70` (`ARENA_HP_K`) | 30 던전의 `DUN_DMG_K` 1.2 = «cp 와 같은 상대의 30초 누적 피해/cp» 다. 0.70 이면 **동급 상대가 ~17초에 눕는다**(제한 30초의 58%) — 이기는 게 기본이되 시간 초과 패배가 실제로 나온다 |
| 상대 평타 | `내 최대 HP × 0.030 × (상대 cp / 내 cp)` (`ARENA_DMG_K`) | 접촉 쿨 0.9초라 «계속 붙어 맞는» 최악에도 30초에 최대 HP 의 ~99%. 카이팅(59 AI)하면 훨씬 덜 맞는다 |
| 보상(승) | `골드 = eGold(최고 스테이지) × 40` · `💎 20` | «준비 중» 없이 확정 소액(주인 지시 ④). 골드만 스테이지 곡선을 타 성장해도 의미가 유지된다 |
| 보상(패) | 승리의 **1/5** (`골드/5` · `💎 4`) | 참가 위로금 — 30 던전 실패가 보상 0 인 것과 달리 «대전» 이라 빈손으로 내보내지 않는다 |

승 = 상대 HP 0 · 패 = 내 사망(`player.dead > 0`) 또는 시간 초과 · **◀ = 중단**(전적·보상 없음).
전적은 `S.arena = {w, l}` 에 남고 카드 우측 캡슐(«전적 (승-패)»)·04 세부 팝업에 반영된다.
아레나 중에는 스테이지가 오르지 않고, 끝나면 진입 직전 스테이지·최대 HP 로 복귀한다.

> ⚠ **`player.hp = 0` 만으로는 패배가 재현되지 않는다.** 다음 프레임의 체력 재생이 곧바로 되살린다.
> 실제 사망 경로는 `hp <= 0` 과 함께 `player.dead = 2.4` 가 켜지는 것이라 판정도 `player.dead > 0` 을 본다
> (verify123 [7] 이 이 상태를 만들어 검사한다). 18 패배 화면은 아레나 중 `openDefeat()` 초입에서 막아
> 결과 팝업과 두 겹으로 뜨지 않게 했다 — **자동 부활 진행 자체는 그대로**다.
