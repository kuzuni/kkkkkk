## 2. 뿌리 — «앵커가 둘» (56 절전과 같은 꼴)

* 팝업 `#ciw` = **세로 중앙** 앵커 (`padding:126px 0 234px` + flex center + `translateY(17px)`)
* 배너 `#tuto` = **하단** 앵커 (`bottom:171` + `#tabbar{height:180}` + `height:150` ⇒ 상변 = **H − 501**)

둘이 마주 보고 다가온다:

```
팝업 하변 = 126 + (H − 126 − 234 − 813)/2 + 813 + 17 = 369.5 + H/2
겹침      = (369.5 + H/2) − (H − 501)               = 870.5 − H/2
```

⇒ **겹침이 0 이 되는 프레임은 정확히 H = 1741** 이고, 1600 에서 70.5 다(자가 잰 값과 일치).
프레임이 1px 짧아질 때 배너는 1px 올라오는데 팝업 중심은 0.5px 밖에 안 내려가므로
**차이가 프레임 감소의 절반 속도로 벌어진다** — 이것이 «마주 보고 다가온다» 의 산수다.

## 3. 처방 — 하단 여백 한 겹 (`index.html` 1자리 · 새 상수 0개 · 새 축 0개)

```css

정리하면 위 한 줄이 된다. **1801 = 여백 30 을 얹은 교차점**이다.

정리하면 놀라운 성질이 하나 나온다 — H ≤ 1801 에서

```
