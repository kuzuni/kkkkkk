`renderWpn()`(index.html ~34080)이 행마다 **고정 열 수**로 돌고 있었다:

```js

…
for(let c = 0; c < WPN_COLS; c++){
  const real = items[c] || null;      /* ← 모자라면 null = 잠금 더미 */
```

이 «남는 칸은 잠금 더미로 채운다» 는 **05 레퍼런스의 띠 구조를 흉내 내려고** 75 이전에 들어온 규약이고,
당시에는 «등급당 무기 1종» 이라 **모든 행**이 1종 + 더미 4였다. 75 가 «등급당 여러 종» 으로 가면서
1~7등급은 정확히 5종이 되어 더미가 0칸이 됐고, **더미가 남은 자리는 1종뿐인 불멸 행 하나**였다.
그 4칸이 주인 눈에 «불멸 아이템 5개» 로 읽혔다.

**처방**: 열 수를 «5» 로도 «1» 로도 못 박지 않는다 — **그 등급이 실제로 가진 종 수**가 정한다.

```js
…
items.forEach((real, c) => { …          /* real 은 항상 실물 — 더미 분기 없음 */
```
