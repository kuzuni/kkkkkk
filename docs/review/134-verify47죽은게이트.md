## 4. 게이트를 짜면서 잡은 것 2개

**(가) 프레임 스케일.** 03·10 은 전체화면 페이지가 `transform:scale()` 로 앉는다. 그래서
`getBoundingClientRect()` 는 프레임 px 가 아니다 — 바 h 99 가 **97.5** 로, 칸 폭 391 이 **385.1** 로 나온다.
옛 47 은 단일 시트라 이 문제가 없어 rect 를 그대로 판정했다. 새 게이트는 바마다
`rect.width / offsetWidth` 로 스케일을 구해 **프레임 px 로 환산한 뒤** 판정한다.
덤: 숨은 바는 `0 / 0 = NaN` 이 되는데, NaN 은 비교가 전부 false 라 **«Δ NaN 인데 통과»** 가 나올 수 있다
(실제로 초안이 그랬다). 스케일이 유한하지 않으면 «바 없음» 으로 잘라낸다.

**(나) «본문이 반응했다» 를 노드 존재로 검사하면 아무것도 검사하지 않는다.**
초안은 `!!document.querySelector('#bSk')` 로 봤는데 이 노드는 **늘 DOM 에 남아 있어** `true → true` 였다.
`["bSk","bPet","bCos","eqw"].filter(보이는 것)` 로 바꾸니 `["eqw"] → ["bSk"]` 처럼 **실제 교체**가 찍힌다.
