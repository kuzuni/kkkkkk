## 2. ⓒ «장비 탭만 아래에서 다시 등장» — jzHush()

```js
let jzQuiet = 0;
function jzHush(fn){ jzQuiet++; try { fn(); } finally { queueMicrotask(() => { if(jzQuiet>0) jzQuiet--; }); } }
```
60 의 개폐 감시 콜백에서 `if(jzQuiet){ if(vis) el.__jzLast = disp; continue; }` 로 **연출만 건너뛴다**
(보이기 상태 `__jzVis/__jzLast` 는 계속 최신으로 유지 — 안 그러면 다음 «진짜» 개폐가 어긋난다).

네 개의 서브탭 핸들러(`data-sktab`/`pttab`/`costab`/`eqtab`)를 `heroSubGo(k)` 하나로 모아
그 안에서만 `jzHush()` 를 건다. 영웅 탭을 **처음 열 때**는 `goTab()` 경로라 시트 등장 연출이 그대로 붙는다.

> **타이머를 쓰지 않은 이유(LESSONS 60-4 의 재확인).** MutationObserver 콜백은 «첫 변이가 기록된 시점»에
> 마이크로태스크로 예약된다. `jzHush` 안에서 변이가 나므로 그 예약이 먼저 잡히고,
> `finally` 의 `queueMicrotask` 는 **항상 그 뒤**다. `setTimeout(…, 0)` 도, 지속시간 상수도 필요 없다.

## 3. ⑤ 60 쥬시 — 탭 전환 팝

`.jz-st` = `scale: 1 → 1.06 → 1` 0.22s (③ 탭바 팝 `jzTi` 와 같은 곡선, 진폭만 1.12 → 1.06).
`transform` 이 아니라 **독립 변형 속성 `scale:`** 를 쓴다 — 라벨 폭 보정 `transform:scaleX()` 가 날아가지 않게(LESSONS 60-1).
영웅 시트는 바가 통째로 다시 그려지므로 **누른 노드가 아니라 rAF 뒤의 `.on` 칸**을 찾아서 건다.

뒤에 선언된 스태거 규칙이 통째로 이겨 서브탭 팝이 «1 → 1.06 → 1» 이 아니라 **«0.94 → 1.02»**(등장 연출)로 재생됐다.
`.jz-sb`/`jzSb` 로 개명해 해결. `animation` 은 목록 전체가 교체되므로 이름 충돌은 «둘 중 하나가 통째로
사라지는» 사고다(LESSONS 60-3 의 재발 — 이번엔 `!important` 가 아니라 **이름**이 원인이었다).
