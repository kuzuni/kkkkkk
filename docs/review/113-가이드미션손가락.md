## 3. 왜 이렇게 짰나 (다음 세션이 다시 파지 않도록)

**① `hint` 는 «셀렉터» 가 아니라 «요소를 돌려주는 함수» 도 받는다.**
지시서는 «셀렉터» 라고 썼지만, 실제 대상 절반은 **상태로 갈린다** — 무료 소환이 남았으면 `b1`,
아니면 `b2`; 스킬은 «미장착 + 보유» 첫 카드; 던전은 «잠금 아님 + 남은 횟수» 첫 카드.
CSS 셀렉터로 밀어 넣으면 `:has()` 중첩이 읽히지 않는 문자열이 된다. `gmHandGetter()` 가
문자열·함수·요소 셋 다 정규화하므로 **단순한 것은 문자열로**(`'#rouBtn'`, `'#rwBasin'`) 남겼다.

**② ⚠ `hint:` 는 참조를 «GUIDE 평가 시점에» 담는다 — 힌트 헬퍼는 전부 `function` 선언이어야 한다.**
`go:` 는 전부 화살표 안에 감싸여 있어(`go:() => gmShop(...)`) 지연 평가지만, `hint:gmHintTrain` 은
**그 자리에서 값을 읽는다.** GUIDE 는 라인 ~8790, 헬퍼는 ~11360 이라 화살표 `const` 로 두면
**로드 즉시 TDZ ReferenceError 로 게임이 통째로 죽는다.** 처음 작성분이 정확히 그랬고, 함수 선언
(호이스팅)으로 바꿔 닫았다. 앞으로 힌트를 추가할 때도 같은 규칙이다.

**③ 대상은 «지금 없어도» 된다 — 탐색 창(`GM_HAND_SEEK` 900ms)을 둔다.**
`gmHero('eq')` 처럼 패널 전환이 끼면 이동 직후 프레임에 대상 DOM 이 아직 없다. rAF 루프가
매 프레임 다시 찾고, 창을 넘기면 조용히 자멸한다. 덕분에 «렌더 타이밍» 때문에 힌트가 깜빡이는
경우가 없고, `renderTrain()` 이 카드 노드를 통째로 갈아끼워도 다음 프레임에 새 노드를 다시 잡는다
(LESSONS 50-① «재렌더에 진 클릭» 의 포인터 판 — **노드가 아니라 «찾는 법» 을 들고 있는다**).

**④ 대상 클릭 판정은 `closest()` 가 아니라 `composedPath()` 다.**
핸들러 안에서 재렌더가 돌면 `e.target` 은 떨어져 나간 노드라 `closest()` 가 null 이 된다
(LESSONS 74-⑥ 와 같은 함정). 경로는 디스패치 시점에 확정돼 있어 면역이다.

**⑤ `scrollIntoView()` 를 쓰지 않았다.** 프레임(`#wrap`)까지 같이 굴러 `fit()` 정렬이 흔들린다.
**스크롤 가능한 첫 조상만** 직접 굴린다(`gmHandScroll`). 107 «시트가 자동으로 위로 되돌아감» 과
같은 구간이라 조심스럽게 — 한 번만, 대상이 바뀔 때만 부른다.

**⑥ 회전과 «탭» 을 한 transform 에 섞지 않는다.** `#fxHand`(팁 앵커, 0×0) → `i`(손 상자 120,
회전·미러 담당) → `s`(탭 애니메이션만) 3단이다. 한 요소에 몰면 `.mir` 의 `scaleX(-1)` 이
키프레임 transform 에 통째로 덮여 미러가 안 걸린다.

## 4. 손가락 «아트» — CC0 에셋 대신 인라인 SVG 인 이유

지시서 ③ 의 1순위(Kenney CC0 «Cursor Pack» → `assets/ui/hand.png` + CREDITS 등재)를 먼저 시도했고,
**이 환경의 에이전트 프록시가 `kenney.nl:443` CONNECT 를 403 으로 거부**한다(2026-08-26 실측,
`recentRelayFailures: connect_rejected · policy denial`). 지시서가 정한 폴백대로 **인라인 SVG**로
직접 그렸다 — 외곽 7px 검정 + 흰 장갑 + 손목 띠, 게임 공통 UI 톤(다른 화면의 `-webkit-text-stroke`
검정 외곽과 같은 두께감). 이모지 👆 는 지시서대로 쓰지 않았다(플랫폼마다 글리프가 달라 방향·비율이 튄다).

**아트 필요** — 나중에 이미지로 교체할 자리:

| 요소 | w×h | 용도 | 현재 대체물 |
|---|---|---|---|
| 가이드 손가락 | 120×120 (잉크 ≈82×101) | «여기를 누르라» 포인터 | 인라인 SVG 손(흰 장갑·검정 외곽 7px) |

교체는 `fxHand()` 안 `hand.innerHTML` 의 `<svg>` 한 덩어리를 `<img src="assets/ui/hand.png">` 로
바꾸기만 하면 된다 — 팁(가리키는 점)이 상자 좌표 **(34, 10)** 에 오도록 맞출 것. CSS
`#fxHand>i{left:-34px;top:-10px}` 과 `.mir` 의 `left:-86px`(= 120−34) 이 그 값을 쓴다.
