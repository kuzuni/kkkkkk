## 4. 못 보는 것 — 초록이라 부르지 않는다

루틴 컨테이너의 클론은 **shallow** 다(실측 56 커밋 ≈ 3시간). `done()` 커밋의 부모가 이력 경계 밖이면
[정확 되돌림] 을 **잴 수 없다** — 그런 ID 는 조용히 넘기지 않고 **«부분검사»** 로 세어 요약줄에 찍는다
(현재 클론에서는 8건 전부 완전검사 · 부분검사 0). 되돌림 사고는 몇 시간 안에 일어나므로 shallow 창으로도 실전 커버리지는 충분하다.

**여전히 못 잡는 갈래**: 손으로 병합하다 **완료 행을 ✅ 는 남긴 채 새로 써서** 내용만 잃은 경우.
정확 되돌림도 아니고 표지도 살아 있어 두 자 모두 조용하다. 길이 비교로 넓히려다 **접었다** —
이 저장소는 «전문은 `PROGRESS-DONE.md` 로» 처럼 행을 **정당하게 줄이는** 관행이 있어 플레이키 게이트가 된다
(344·372 가 플레이키를 «버그» 로 등재하는 저장소다). 잡히는 두 갈래를 정확하게 잡는 쪽을 골랐다.
