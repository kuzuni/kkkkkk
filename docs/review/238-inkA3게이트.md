## 1. ①② — 게이트를 «폭을 잴 수 없는 캡처» 에 물렸다

`tools/capA3.js` 는 처음부터 **모드가 둘**이고, 그 사실이 파일 주석에 적혀 있었다.

- `A3_REFSTR=1`(**측정 전용**): `rankN`·`goldN`·`diaN` 을 **레퍼런스와 똑같은 글자**로 바꾼다

잉크 «폭» 은 글자 수가 같을 때만 비교된다. 등재는 `A3_REFSTR` **없이** 찍은 캡처로 게이트를 돌렸고,
글자 수 차이(3 vs 5 · 5 vs 6)가 그대로 «폭 −29.6% / −19.0% 결함» 으로 나왔다.

```
A3_REFSTR 없음 :  칭호/계급  71x19 → 50x17   −29.6 / −10.5   ← 「브론즈」
A3_REFSTR=1    :  칭호/계급  71x19 → 74x19    +4.2 /  +0.0   ← 「칭호 없음」(허용 6/8 안)
A3_REFSTR 없음 :  골드      116x25 → 94x25   −19.0 /  +0.0   ← 「39.2A」
A3_REFSTR=1    :  골드      116x25 →116x25    +0.0 /  +0.0   ← 「39.20A」(Δ0 정확)
```

높이 −10.5% 도 같은 것이다 — 「브론즈」에는 ref 「칭호 없음」의 「없」 받침처럼 아래로 내려가는 획이 없다.

## 2. ③ — 창이 **잘라 잰** 폭을 «scaleX 가 넓다» 로 읽었다

`A3_REFSTR=1` 로 다시 찍어도 전투력만 **+13.4%** 로 남았다. 여기가 진짜 함정이다.

`capA3.js` 는 전투력을 `fmt(1330000)` 으로 덮어쓰고 있었고, 주석은 「우리 `fmt()` 로 레퍼런스와 같은
문자열이 나오는 값을 넣는다」 고 적혀 있었다. **그 주석이 낡았다.**

| | 값 | 글자 수 |
|---|---|---|
| 레퍼런스 | `1.33B` | 5 |
| 화면이 실제로 찍는 것 (index.html:18328 `fmtB`) | `1.33B` | 5 |
| **하네스가 덮어쓰던 것** (`fmt`) | **`1,330,000`** | **9** |

작업 **150**(골드만 알파벳 단위 · 나머지는 쉼표)과 **188**(주인 정정 — 데미지·체력·**전투력**은 `fmtB` 로
알파벳 단위)이 표기 규약을 두 번 갈면서 `fmt` 와 `fmtB` 가 갈라졌는데, **화면은 `fmtB` 로 옮겨 갔고
하네스만 `fmt` 에 남았다.** 실측: `fmt(1330000)='1,330,000'` · `fmtB(1330000)='1.33B'`.

그래서 `inkA3.py` 의 전투력 창(측정표 ref bbox + pad 10 = **104px**)에 9글자짜리 문자열이 들어왔고,
창이 **글자를 잘라 낸 폭(93px)** 을 재서 「+13.4% · sx 배수 0.8817」 을 뱉었다. 창에 갇힌 값이라
`.pcp b` 를 아무리 손봐도 저 숫자는 안 움직인다.

`fmt` → `fmtB` 한 글자 고치자:

```
전투력 1.33B   82x23 → 93x23   +13.4 / +0.0   sx 0.8817   ← fmt  (9글자, 창에 잘림)
전투력 1.33B   82x23 → 82x24    +0.0 / +4.3   sx 1.0435   ← fmtB (5글자, 폭 Δ0)
```

**폭 Δ0.0%.** `scaleX(1.243)` 은 처음부터 정확했다.

> 교훈 — **«하네스가 화면과 다른 포매터를 쓰면, 게이트는 화면이 아니라 하네스를 잰다».**
> 15·122 회차의 「자를 안 댄 곳은 자동 무결점」 과 짝을 이루는 반대편 실패다: 여기서는 자를 댔는데
> **자가 딴 것을 재고 있었다.** 그리고 그 자의 눈금(`sx 배수 0.8817`)이 **친절하게 처방까지 가리켰다** —
> 계측이 틀리면 오답이 «수치로» 나오기 때문에 더 믿게 된다.
