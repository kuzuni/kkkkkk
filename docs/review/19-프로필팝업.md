  남지만 «몇 점이었는지·무엇이 기각됐는지»가 안 남는다.
- 렌더가 `S`(top-level `let/const`)를 읽는 표시 전용 화면은 localStorage 주입 없이
  `page.evaluate(() => { S.nick=…; openProfile(); })` 로 충분하다 (14번 교훈 ③의 예외 — load() 재실행이 필요 없는 경우).
