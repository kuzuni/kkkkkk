# 312 — `verify290` B2 가 항상 FAIL(14/15): 등재 예외 해시 2개가 이력 재작성으로 «객체째» 사라졌다

- 담당: sess-0817-28709 워커 A · 2026-08-28
- 티어: **T1 버그(게이트)** · 지시서 [3]-**(가) 기계적 작업 — 비평가 없음**
- `index.html` **0줄** (게이트·도구만)
- 회차: 1/5

## 1. 증상

```
FAIL B2 등재 예외가 실제 이력에 있다(죽은 예외 0건) — 8fcacb6✗ 이력에 없음 · 6e8a949✗ 이력에 없음

```

A·C·D 절은 전부 초록이다. **초록 줄이 먼저 답한다**(LESSONS §7153): `claim.js` 의 동작을 재는
A(6/6)·C(6/6)가 통째로 초록이므로 **선점 로직은 멀쩡하고**, 빨간 것은 «이력을 어떻게 가리키는가» 뿐이다.

## 2. 실측 — 창(窓) 문제가 아니라 **객체 소멸**이다

| 확인 | 명령 | 결과 |
|---|---|---|
| 객체 존재 | `git cat-file -t 8fcacb6…` | **없음**(`could not get object info`) |
| 〃 | `git cat-file -t 6e8a949…` | **없음** |
| 도달성 | `git merge-base --is-ancestor <h> origin/main` | 둘 다 **NO** |
| 창 포화 여부 | `git log --format=%H origin/main -- docs/claims/` | **36개** — `-n 400` 은 애초에 다 담는다 |

즉 «400개 창 밖으로 밀린» 것이 아니라 **저장소에 아예 없다.** 이 세션의 첫 `git pull` 도
`+ d8ac8c2...4add572 main -> origin/main (forced update)` 였다 — 주인 쪽 squash/force-push 로
이력이 재작성됐고, 두 사건은 squash 커밋 `2d707b1`(lock 다수를 한꺼번에 «생성» 한 커밋)에
녹아 사라졌다. **사건을 가리키던 예외 목록만 남아 빨갛다.**

## 3. 처방 — 예외의 열쇠를 «해시» 에서 **«사건 내용»** 으로

등재 행이 제시한 후보 ⓐ(재작성에 안 죽는 지문) + ⓑ(객체 존재로 소멸/부패 구분)를 **같이** 채택했다.
ⓒ(문서로 옮기기)는 «예외가 코드에서 안 보이면 더 쉽게 썩는다» 라 안 골랐다.

### ⓐ 지문 = `lock 파일 | 덮인 SID | 덮은 SID`

해시로 잠그면 squash·force-push **한 번**에 예외가 통째로 죽는다. 사건 내용은 재작성을 견딘다.
SID 는 세션마다 새로 나므로 **새 위반은 어떤 예외에도 절대 안 걸린다** — B1 민감도는 그대로다(N1·N2 로 실측).

### ⓑ B2 를 «죽은 예외» 가 아니라 **«부패한 예외»** 를 재는 항목으로

| 상태 | 조건 | 판정 |
|---|---|---|
| `matched` | 지문이 이력에 있다 | 초록 |
| `erased` | 지문도 없고 **등재 커밋도 `origin/main` 에서 안 닿는다** | 초록 + ⚠소멸 표기 |
| `rotten` | 지문은 없는데 **등재 커밋은 아직 닿는다** | **빨강** |

`rotten` 이 남아 있는 것이 핵심이다. B2 의 존재 이유(«예외 목록이 썩어 새 위반을 가리는 것을 막는다»)는
**커밋이 살아 있는데 스캔이 그 사건을 못 보는 경우** — 파서나 `-n` 창이 썩은 경우 — 이고, 그건 그대로 빨갛다.
그리고 `erased` 를 초록으로 두는 것이 안전한 이유는 구조적이다: **아무것도 안 맞는 예외는 아무것도 안 봐준다.**
지문 대조로 바뀐 뒤로 죽은 예외가 새 위반을 가릴 길이 없다(N5b 로 실측).

⚠ **B1(새 위반 0건)의 민감도는 한 줄도 낮추지 않았다.**

### 덤 — 파서 굳히기(우연에 기대던 자리)

`--- a/…` · `--- /dev/null` 헤더가 `^-(\S+)\s+(\S+)` 에 걸려 **파일 «생성» 이 덮어쓰기 모양**으로 보이고
있었다(실측 6건: `2d707b1` 의 122·292·294·297·58·72). 지금은 시각이 `NaN` 이라 뒤에서 걸러지지만,
**걸러 주는 것이 우연이면 언젠가 통과한다**(LESSONS §3630). 헤더 줄을 명시적으로 건너뛰게 했다.
거짓 양성·거짓 음성은 지금도 없었으므로 이건 회귀 수정이 아니라 굳히기다.
