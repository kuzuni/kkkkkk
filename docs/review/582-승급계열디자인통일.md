## 2. 처방 — «새 프레임을 그리지 않는다»

등재문 ①대로 **부품 승격**이다. 새 상자를 그리면 통일할 것이 하나 더 늘 뿐이다.

```css
:root{--slot-r:40px;--slot-k:5px;--slot-w:12px}
.slotfr{background:var(--f);border-radius:var(--slot-r);
  box-shadow:inset 0 0 0 var(--slot-k) #000,inset 0 0 0 var(--slot-w) var(--r)}
```

- `.sk-slot` 은 **프레임 선언을 통째로 내려놓고** 자리·크기만 남겼다(계산값 Δ0).
- 세 자리 마크업이 전부 `slotfr` 를 단다 — `class="sk-slot slotfr"`(6자리) ·
  `class="pr-rw-c slotfr"` · `class="pg-c slotfr"`.
- **색 리터럴은 부품 안에 한 자도 없다.** 면 `--f` · 림 `--r` 은 호스트가 인라인으로 준다:
  50 시트는 `COS_FILL`/`COS_RIM`, 179·182 는 `COS_FILL` + **그 코스튬의 틴트**(194 규약).
  ⚑ 여기에 색을 또 적었으면 402 가 잡은 «표 두 벌» 부패를 새로 만드는 것이었다.

**⑵ 톤 토큰** — 두 팝업이 각자 들고 있던 리터럴을 한 곳으로 모았다.

```css
:root{--pr-bx:#F7ECDA;--pr-bd:#C8B091;--pr-h:#B4571E;--pr-r:40px}
```

`.pr-rw` 와 `.pr182` 가 면·테두리·표제 색·radius 를 여기서 읽는다.
182 의 radius 는 **28 → 40** 이 됐다 — 2168 이 «같은 화면의 같은 보상 상자» 라고 적어 둔
뜻을 값으로도 맞춘 것이다(종전에는 톤만 같고 모서리가 갈려 있었다).
글자 크기는 안 따라간다 — 179 만 2배 본문이라는 2166 주석 그대로다.

### 2-1. ⚑ 그림은 한 픽셀도 안 줄이지 않았다

링이 12px 을 먹으므로 «안쪽» 이 좁아진다. 여기서 **캔버스를 줄이면 411·492 가 두 번에 걸쳐
올려 놓은 그림이 도로 작아진다**(주인이 «크게» 를 반복해서 지시한 축이다). 그래서 반대로 갔다 —
**칸이 링에게 내준 만큼을 칸이 되받는다.**

| 자리 | 칸 (전 → 후) | 그림 (전 → 후) |
|---|---|---|
| 179 `.pr-rw-c` | 150×189 → **174×189** (`padding:12`) | 캔버스 150×189 → 150×165 · **잉크 126×135 → 126×135 (Δ0)** |
| 182 `.pg-c` | 96×118 → **108×118** | 캔버스 css **84×84 → 84×84 (Δ0)** |

- 179 는 잉크가 135 인데 캔버스가 189 여서 **54px 이 남아 있었다** — 24 를 링에 내주고도 남는다.
  그래서 **높이는 안 늘렸다**(팝업 상자 높이 Δ0).
- 182 는 캔버스가 이미 y14..98 이라 링 안쪽(12..106)에 **그대로 든다** — 높이 Δ0 ⇒ **행 pitch Δ0**.
  폭만 +12 이고 5열 폭은 5×108 + 4×12 = **588 < 778** 이다(§1 [D] 의 상한 146 에 한참 못 미친다).
- 179 보상 줄은 `justify-content:center` 라 +24 는 줄 전체를 12px 씩 재배치할 뿐이고,
  남는 폭이 275.78 → **251.78** 로 여전히 넉넉하다(`verify582` F4·F5 가 겹침·잘림 0 을 못박는다).

### 2-2. ⚠ 곁다리 하나 — 429 와 같은 «스코프 구멍» 이 하나 더 있었다

182 코스튬 이름표 `<u class="ol1">` 은 외곽선 유틸의 스코프
`:is(#bSk,#bPet,#bCos,.stabs,.rl-help)` **밖**이라 **한 번도 외곽선이 안 걸려 있었다**.
종전에는 남색 면 위 틴트 글자라 티가 안 났지만, 이 행이 칸을 슬롯 프레임으로 바꾸면서
라벨이 «면 + 림» 두 색에 걸치게 되어 실제로 필요해졌다
(라벨 색을 `var(--r)` 로 두면 **림과 같은 색**이라 겹치는 5px 에서 글자가 사라진다).

⇒ ⓐ 라벨을 슬롯의 `Lv.n`(`.sk-slv`)과 같은 **흰 잉크**로, ⓑ 스코프 목록에 `.pr182` 를 더했다.
429 와 같은 이유·같은 처방이고 `:is()` 특이성은 인자 최대(`#bSk` 1,0,0)라 **다른 화면 계산값 Δ0** 다.

## 3. 결과 — 찍힌 픽셀

`verify582` [B] 가 다섯 자리(07·26·50·179·182)를 **한 장씩 찍어** 세로 단면을 읽는다.

```
07 스킬 슬롯   115×115 · r40 · #000000×5 → #AB7A5C×7 → #78553F
26 동료 슬롯   115×115 · r40 · #000000×5 → #AB7A5C×7 → #78553F
50 코스튬 슬롯 115×115 · r40 · #000000×5 → #AB7A5C×7 → #78553F
179 미리보기   174×189 · r40 · #000000×5 → #8AF6FF×7 → #78553F
182 획득 칸    108×118 · r40 · #000000×5 → #8AF6FF×7 → #78553F
```

- 두께 수열 **5/7** · radius **40** · 면색 **#78553F** 가 다섯 자리 전부 같다.
- ⚑ **림 «색» 은 일부러 안 묶었다** — 194 가 «림 = 그 코스튬의 틴트» 로 정해 둔 정보축이다.
  대신 [B8] 이 «같은 코스튬을 가리키는 179 와 182 의 림 색은 같아야 한다» 를 못박는다.
- ⚑ **프레임을 스케일하지 않았다** — 칸이 108 이든 174 이든 링은 5+7 이다.
  `box-shadow` inset 은 원래 안 스케일되고, 스케일하면 «같은 부품» 이 아니라 «비슷한 그림» 이 된다.
