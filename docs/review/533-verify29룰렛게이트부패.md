## §2 갈래 ⓐ — 라벨 표본: **표본을 새로 적지 않았다**

`[1]` 69행은 «골드»·«대박» 이라는 **옛 결과 문자열 두 개**를 찾고 있었다.
가장 짧은 수리는 그 둘을 «다이아»·«1,000» 으로 바꿔 적는 것이지만 **그러면 세 번째 부패를 예약**한다
(이 자리는 이미 155 가 한 번 옮겼고, 512·367 이 또 옮길 자리다 — 334 «시계가 사라져도 초록» 계열).

⇒ **표본을 안 적고 제품의 표에게 직접 묻는다**:

- `geo.want` = 페이지 안에서 읽은 `ROULETTE.map(r => ({ic:r.ic, tx:r.t, vl:roulLabel(r)}))`
- `geo.lbparts` = 렌더된 8칸의 `.rlt-ic` / `.rlt-tx` / `.rlt-vl`
- **칸마다 세 부품을 맞댄다**(8항 신설) + «자가 표를 읽었다» 1항

⚠ **함정 하나** — `r.ic` 는 글자가 아니라 **마크업**이다(`curIc('dia')` = `<img class="cic" …>`).
`textContent` 로 재면 늘 빈 문자열이라 **아이콘 칸만 `innerHTML`** 로 맞댄다(1회차에 8항이 전부 빨갛게 나와 잡았다).

### 그것만으로는 «사본» 을 못 가른다 → `[1c]` 되돌림 시험 신설

표를 렌더에 **복사해 둔 사본**이라도 위 8항은 초록이다. 그래서 표를 한 칸만 흔들어 원판이 따라오는지 묻는다:

```
[1c] 라벨 생성 되돌림 시험
  OK  표를 흔들면 라벨이 따라온다 — 센티널 «77,777» / 실측 «77,777»
  OK  되돌리면 라벨도 원복 (100 / 100)
```

## §3 갈래 ⓑ — `#rouClose` 즉사: **버튼이 아니라 «닫기 경로» 에게 묻는다**

110행이 읽던 `document.getElementById('rouClose').disabled` 에서 **노드가 267 에 지워져** `null.disabled` 로 절이 통째로 죽었다.
«회전 중에는 못 닫는다» 는 **뜻은 살아 있고 자리만 옮겼다**(455 → `closeModal()` 앞 `rouLocked()` 가드).
⇒ 자도 그 자리로 옮겼다 — 회전 중에 **`closeModal()` 을 실제로 불러** false 를 돌려주는지, 모달이 그대로 열려 있는지 본다.

```
[2] OK 회전 중 돌리기 비활성 + 닫기 잠금 (btn true · rouLocked true · closeModal false · 모달 유지 true)
```

### 양성항만 남기지 않았다 — `[3b]` 음성항 신설

«늘 false 를 돌려주는 `closeModal`» 로도 위 항은 초록이다. 그래서 **풀리는 쪽**을 같이 물었다.
잠금은 회전(3.6s)뿐 아니라 **지급 비행 창**(`ROUL_PAY_MIN` 300 ~ `MAX` 2000 · `fxFlies` 공중)까지 이어지므로
기다림 자체를 단언으로 썼다(안 풀리면 빨강):

```
[3b] 정지 후 닫기 잠금 해제
  OK 지급 비행이 끝나면 rouLocked() 해제 (458ms 뒤 false)
  OK 정지 후 closeModal() 이 실제로 닫는다 (true / 닫힘 true)
  OK 다시 열어 다음 절로 (true)
```
