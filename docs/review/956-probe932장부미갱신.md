## 2. ⚑ 이 작업의 본체 — 옛 `fix` 의 «두 자리만 다시 보면 된다» 가 틀렸다

장부의 옛 `fix` 는 이 상황을 **예고까지 해 두고** 처방을 이렇게 남겼다:

> 923 은 이 회차에 진행 중이라 소스가 또 바뀌면 [2-c] 가 다시 열린다 —
> 그때는 **위 두 자리가 여전히 «길이가 아닌가» 만** 다시 보면 된다.

그 말대로만 하면 이렇게 된다 — `.sum()` 계열이 하나도 안 늘어 **`i2` 가 그대로**이고
두 자리(L112 색 거리 · L302→L449 행 술어)도 그대로다 ⇒ «변한 게 없네» 하고 `sig` 한 줄만
베껴 넣으면 [2-c] 는 초록으로 돌아간다. **그 사이 자에는 얇은 축이 하나 더 생겨 있었다.**

`--band` 가 새로 재는 것은 **검정 띠 두께(곧은변 ≈10 우리 px)** — 이 장부가 존재하는
바로 그 종류의 축이다. `i` 는 «정수 걸음의 개수» 라 **부분 화소로 새 축을 만들면 안 움직인다.**
⇒ 신호가 움직였을 때 세야 하는 것은 옛 자리가 아니라 **늘어난 걸음**이다
(931 «손으로 적은 갈래는 자가 늘 때 아무도 안 센다»).

## 3. 판정 — **S(면역) 유지**, 단 근거가 하나 늘었다

`--band` 의 두 모서리가 **둘 다 부분 화소**다:

| 자리 | 걸음 | 처방 |
|---|---|---|
| 바깥 모서리 | `outer_x` — 덮개 적분 α = \|p−bg\|₁ / \|검정−bg\|₁ | ⓑ (923 4회차, 이미 면역) |
| 안쪽 모서리 | `inner_x` — 밝은 고원 V 의 50% 문턱 **선형 보간** `f = (g[i]−lvl)/(g[i]−g[i+1])` → `return i + f` | ⓐ (`scan895.py` 선례) |
| 두께 자체 | 두 부분화소 점구름의 **최소 유클리드 거리** `np.hypot(…).argmin()` | 화소 세기 0 |

실측이 그 결론과 같다(값이 소수로 나온다):

```
$ python3 tools/scan923.py --ref --band
    곧은변 띠 두께(우리px) 중앙값  10.31  (표본 40)   ← ref 배너
    곧은변 띠 두께(우리px) 중앙값  11.81  (표본 76)   ← ref 불릿
   칸 중앙값 9.43 / 9.57 / 9.80 / 10.04 / 10.06 / 10.11 / 10.29~10.34
```

ⓐ 는 W < 3.7 우리 px 에서 무너지지만(`verify932` [3-d]) 이 축은 ≈10 우리 px 이라
[3-e] 대역(W ≥ 3.7 에서 ±3%) 안이다. ⇒ **면역 판정은 유지된다.**

### ⚠ 면역인 것이 «그 값을 믿으라» 는 뜻은 아니다

`scan923.py` 헤더가 스스로 적어 둔 검정 상태를 장부 `fix` 로 옮겼다 — **ref 불릿 곧은변이
11.81 로 읽히는데 7회차 채점 2인은 둘 다 10.17~10.23** 을 냈고, 뿌리는 초록 카드 바깥의
그림자 램프(4 ref px)가 `outer_x` 의 \|Δ바탕\| 문턱을 바깥으로 미는 것이다.
그 편향은 **923 8회차 2단계 몫**이고 «부분 화소냐» 와는 다른 축이다.
이 장부가 S 라고 해서 그 값을 과녁으로 쓰면 안 된다(338 — 자를 못 믿으면 처방도 못 믿는다).
