## 3. 처방 — 리터럴을 걷어내고 «관계» 를 단언한다 (185-①)

§10 을 통째로 다시 썼다. 잠금은 지금 두 갈래다:

- **ⓐ 가이드미션(`gm`)** — `relic1`. 경계 **idx=gm−1 잠김 / idx=gm 해금**을 데이터에서 만든 숫자로 본다.
  라벨의 N 이 `DUN_UI.gm` 과 **같은지**까지 본다(89 처럼 키가 갈려도 라벨과 데이터가 같이 움직이는지).
- **ⓑ 이전 단 N층(`pre`, 90)** — `relic2~4`. 없어진 «수련·마왕» 단언을 **여기로 이사**시켰다.
  경계 `S.dun[pre.id] > pre.f` 를 위아래로 한 층씩 본다.

전제도 같이 박았다(185-③) — 전제가 무너지면 결론이 아니라 **전제 쪽이** 빨개진다:

- 모든 던전에 `DUN_UI` 항목이 있다
- gm 잠금 ≥1개 · pre 잠금 ≥1개 (둘 중 하나가 0 이 되면 그 갈래가 조용히 안 돌게 된다)
- 잠금 조건은 gm·pre 중 **정확히 하나**
- **`max(gm) ≤ 체인 길이`** ← 154 가 체인을 줄였을 때 «영영 못 여는 던전» 이 생기는 것을 잡는다.
  옛 «체인 21개» 리터럴이 감시하려던 것의 **진짜 알맹이**가 이것이다.
