## 좌표계

```
콘텐츠 좌상단 = 레퍼런스 y192      → local y = ref y − 192
헤드리스 캡처(1080x1920) 대응      → capture y = ref y − 88   (스크롤 최상단)
```
콘텐츠 총 높이 **1809**(ref 192~2000, 마일리지 리본 꼬리 끝까지). 뷰포트는 1482~1509 이라
**약 300~320px 을 스크롤이 흡수**한다(측정표 §9). 어떤 요소도 축소하지 않았다.

### 기능 연결 (레퍼런스 화면을 이 게임에 매핑)

- **광고 상품 6칸** = 하루 n회 무료 수령. `S.daily.adBuy` 에 횟수를 쌓고 **없는 키는 cap 으로 폴백**해
  세이브 마이그레이션 없이 동작한다(`dailyCheck()` 에서 날짜가 바뀌면 초기화).
  보석→💎100 · 공물→🔮50 · 골드 상자→🪙(스테이지 수입 200배) · 상자 열쇠→🔮10 · 강화석→🔮30 ·
  동료 소환 열쇠→펫 무료 소환 1회. 전부 일일 제한이라 룰렛·출석과 같은 급이며 밸런스 영향 없음.
- 수령 횟수가 0이 되면 그 칸이 **구매 완료**(오버레이 `rgba(0,0,0,.335)` + 띠 `rgba(0,0,0,.67)`)로 바뀐다 —
  레퍼런스 ① 칸이 정확히 그 상태다.
- **기존 기능 보존**: 원래 «재화» 탭은 기존 패널 상점(다이아 패키지·아바타·유물석 교환소)으로 튕겼다.
  이제는 진짜 페이지를 그리고, 그 기능들은 «평생 광고 제거» 배너의 **[이동] 버튼**으로 들어간다.

### 병합 사고 — **다른 세션과 같은 줄에 블록을 추가하면 주석 여는 줄이 사라질 수 있다**

1회차 지적의 절반(+59px 밀림)은 CSS 값이 아니라 **병합 사고**였다.
14번 세션과 내가 **같은 위치(`.shp-soon` 다음)에 각자 CSS 블록을 추가**했고, 두 블록 모두
`  /* ==========================================================================` 라는 **똑같은 첫 줄**로
시작했다. rebase 가 그 줄을 공통 context 로 보고 **한 번만 남기는 바람에** 내 블록의 여는 `/*` 가 사라졌고,
CSS 파서는 주석 본문을 셀렉터로 읽다가 **바로 다음 규칙 `.shp-list.coin{padding-top:0}` 을 통째로 삼켰다.**
그 한 줄이 죽어 상단 패딩 59px 이 남아 콘텐츠 전체가 59px 아래로 밀렸다.

- **문법 오류가 아니라서 콘솔 에러 0건이었다.** 헤드리스 실행·기능 테스트도 전부 통과했다.
- 자가 실측도 `getBoundingClientRect()` 기준이라 **요소끼리는 전부 정상**으로 나왔다(다 같이 밀렸으므로).
  잡아낸 것은 **캡처 픽셀을 프레임 절대좌표로 검증한 비평가 2명**이었다.
- 교훈 3가지:
  1. 병합 후에는 **CSSOM 에 내 규칙이 살아 있는지** 확인할 것 —
     `document.styleSheets` 를 훑어 `selectorText` 로 내 셀렉터를 찾으면 1초면 끝난다.
  2. 자가 검증을 `getBoundingClientRect` 로만 하면 **전체가 평행 이동한 오차는 절대 안 잡힌다.**
     캡처 PNG 에서 **프레임 절대 y** 를 한 번은 재라(예: «배너 파랑이 시작하는 행 = 104 인가»).
  3. 공용 파일에 블록을 추가할 때 **첫 줄을 남과 똑같이 쓰지 마라**(블록 제목을 첫 줄에 넣는 편이 안전하다).
