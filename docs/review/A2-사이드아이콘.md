## 남은 문제 (A2 를 이어받는 세션용)

규격 — 가장자리 여백 45 · 슬롯 100 · 아트 94×82 · pitch 134 · 레드닷 Ø31/Ø42 `#F22E52` ·
배너 234×105 `#511F14` + 금띠 7px + 우측 bleed 0 · pill 151×35 — 은 비평가 2명 모두 **레퍼런스와 일치** 판정.
남은 감점 사유는 아래 3가지이고 **전부 A2 코드 범위 밖**이다.

1. **아이콘이 이모지 폰트다.** 레퍼런스는 전용 일러스트 스프라이트라 슬롯을 꽉 채운다. 이모지는 정사각이라
   `scaleX(1.15)` 로 종횡비만 맞췄고, 이모지별 잉크 높이가 72~88 로 들쭉날쭉한 건 CSS 로 못 고친다.
   **아트 리소스가 들어와야 해결된다.**
2. **라벨 서체.** 레퍼런스는 굵은 광폭 디스플레이체(자당 advance 25.7). 시스템 굵은 폰트 + `scaleX` 로
   근사했으나 잉크 밀도가 부족하다. **웹폰트 도입 시 해소.**
3. **패널이 열려 있으면 캔버스가 681px 로 줄어 아트가 82 → 44 로 축소된다.** 레퍼런스는 콘텐츠가 전부
   모달이라 캔버스가 1931px. 체크리스트의 «콘텐츠를 모달로» 항목이 끝나면 **코드 수정 없이 자동 해소**
   (`layoutSide()` 가 캔버스 높이에 비례 — 9:19.5 에서 이미 레퍼런스 실측치와 정확히 일치).

또한 상단 HUD 의 `.pedge` 가 캔버스로 38px 내려와 1행을 가리던 문제가 있어,
`layoutSide()` 가 `#top` 자식들의 최하단을 실측해 «HUD 하단 + CLEAR» 로 첫 행을 배치하도록 해뒀다.
**A3 에서 `#top` 높이가 바뀌어도 사이드 아이콘은 자동으로 따라간다** — 이 로직은 유지할 것.
