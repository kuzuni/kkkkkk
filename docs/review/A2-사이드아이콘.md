## 이 작업에서 실제로 바꾼 것

### 1회차 — 행 그리드 재구성 (커밋 `c95187c`)

측정표 §0 의 «1·2·3행 y 가 좌우 동일» 을 **실제 행 그리드로** 구현했다.

| 행 | ref y | 캡처 y | 좌 | 우 |
|---|---|---|---|---|
| 1 | 260 | 176 | 라벨 없는 단독 아이콘(아트 101) | `#menub` 4분할 메뉴 버튼 |
| — | — | — | **gap 60** (라벨 그룹과 분리) | — |
| 2 | 421 | 337 | 패스칸 | 이벤트칸 |
| 3 | 556 | 471 | 퀘스트칸 | 특권칸 |
| 4 | 687 | 605 | 휴식보너스칸 | 시설 타이머 배너 |
| 5 | 820 | 739 | 도감칸 | — |
| 6 | 958 | 873 | 길드칸 | — |

- **기존 구조의 결함**: 6칸을 균등 pitch 134 로 깔고 있었다. 레퍼런스 1행은 라벨이 없고(셀 101)
  아래 gap 이 60 이라, 균등 pitch 로는 **2~6행이 전부 27px 위로 밀린다.**
- `#sideR` 은 1행을 정식으로 비우고 2행부터 시작하게 했다
  (`top: --itop + --isolo + --isgap`). 02 세션이 겹침 회피용으로 넣어 둔
  `#sideR{transform:translateY(한 행 pitch)}` 한 줄은 이 구조로 대체·제거했다.
- `SIDE.TOP` 을 **31 → 72** 로 정정했다. 31 은 폐기된 «캔버스 top 229» 기준값이다.
  A3 인수인계 메모의 «SIDE.TOP 을 올려라 / 초상화 플레이트와 16px 겹친다» 가 이걸로 해소된다
  (현재 플레이트 하단 142, 1행 아이콘 top 176 → **34px 여유**).
- `layoutSide()` 는 단독행(SOLO 101 + SGAP 60)을 분모에 포함해 비례 축소한다.

**실측 대조** (캡처 좌표): 176 / 337 / 471 / 605 / 739 / 873, 스택 bottom 987
→ 정답 176 / 337 / 472 / 603 / 736 / 874, bottom 988. **최대 오차 3px.**

### 2회차 — 잉크 실측 보정 (커밋 `fc4a639`)

1회차 비평(4/10 · 6/10)의 수치 지적을 **레퍼런스 픽셀을 직접 다시 재서** 검증한 뒤 반영했다.

| 지적 | 판정 | 조치 |
|---|---|---|
| 아이콘 잉크 크기가 칸마다 제각각(폭 60~115, 레퍼런스는 77~107) | **인정** | 아래 «이모지 잉크 보정» |
| 1행 잉크 중심이 95 가 아니라 102 (+7px) | **인정** | `.si` 박스 1.6배 확대 |
| 아이콘에 레퍼런스의 검정 외곽선이 없다(근흑 3.9~8.8% vs 12.8~29.3%) | **인정** | drop-shadow 4단 체이닝 |
| 라벨 외곽선이 2.5~3.2배 과중 | **인정** | 두께 .20 → .07 |
| 좌 라벨이 우 라벨보다 17% 작아야 한다 | **인정**(재측정으로 확인) | 좌 fs24 / 우 fs29 차등 |
| 배너 프레임이 카키 rgb(180,173,131) 여야 한다 | **반증** | 레퍼런스 y=760 x850..858 실측 = **#fab647**, 현재 CSS 와 동일 |
| 메뉴 레드닷이 Ø21 로 과대하다 | **반증** | 실측 채움 Ø31 · 외곽 Ø42 로 측정표와 일치 |
| 좌측 레드닷 4개가 레퍼런스에 없다 | **미채택** | 게임 알림 상태값이라 캡처 시점 문제. 레이아웃 사안 아님 |

#### 이모지 잉크 보정 (핵심)

이모지는 **글리프마다 잉크가 제각각**이다 (font-size 100 기준 실측, canvas `getImageData`):

| 글리프 | 잉크 폭 | 잉크 높이 | | 글리프 | 잉크 폭 | 잉크 높이 |
|---|---|---|---|---|---|---|
| 📅 | 100 | 103 | | 🏆 | 112 | 110 |
| 🎰 | 113 | 109 | | 🏅 | **69** | 113 |
| 📬 | 112 | 111 | | 🎁 | 104 | 112 |
| 📜 | 112 | 107 | | 👑 | 113 | 106 |
| 🏰 | 112 | 109 | | 🔒 | 74 | 106 |

한 벌의 `font-size`·`scaleX` 로는 절대 못 맞춘다. 그래서 칸마다 `--sf`(font-size 배율)·`--sx`(가로 배율)를
**측정표 §1-1 스프라이트 bbox 로 역산**해 인라인으로 박았다.

    sf = (목표높이 / 82) × (100 / 잉크높이)
    sx = 목표폭 / (잉크폭/100 × 82 × sf)

**🏅 → 🏆 교체**: 🏅 는 잉크 폭이 69 뿐이라 6행 목표 폭 107 을 맞추려면 `scaleX 2.04` 가 필요해
형태가 뭉개진다. 잉크 폭 112 인 🏆 로 바꿨다(의미도 «승급전» 에 맞는다).

> **[함정] 이모지 advance = font-size × 1.248.**
> 폭 100 박스에 넣으면 넘치고, 넘친 글리프는 가운데가 아니라 **좌측 정렬**돼 잉크가 우측으로 밀린다
> (PROGRESS «CSS 함정» 과 같은 현상). `.si` 를 `--ih × 1.6` 으로 넓게 잡아 해소했다
> (`.ibtn` 이 `align-items:center` 라 좌우로 균등히 넘쳐 중심이 맞는다).

#### 검정 외곽선

레퍼런스 아트는 전부 검정 외곽선 4~6px 을 두른다(측정표 §1-4). 이모지 소재만으로는 재현이 안 돼
`drop-shadow` 를 축방향으로 **4단 체이닝**했다(각 단계가 앞 결과에 다시 걸려 실루엣이 팽창한다).
색은 레퍼런스 근흑 픽셀 평균 **rgb(8,10,10)**.

| 아이콘 박스 내 근흑 픽셀 비율 | 레퍼런스 | 1회차 | 2회차 |
|---|---|---|---|
| 패스 / 퀘스트 / 휴식 / 도감 | 19.3 / 11.2 / 10.7 / 8.3 % | 3.9~8.8 % | 11.3 / 13.0 / 7.5 / 14.0 % |
| 이벤트 / 특권 | 12.6 / 8.0 % | — | 9.5 / 8.5 % |

#### 라벨 — 좌우 크기가 다르다

레퍼런스 흰 잉크 bbox 실측:

| | 패스(좌2자) | 퀘스트(좌3자) | 이벤트(우3자) | 특권(우2자) |
|---|---|---|---|---|
| 폭 × 높이 | 50 × **21** | 74 × **22** | 77 × **26** | 47 × **26** |

**좌측 라벨이 우측보다 약 17% 작다.** 측정표 §1-3 의 «잉크 높이 받침 유무 26~27 / 21~23» 은
좌·우를 섞어 본 것이다(퀘스트·이벤트 둘 다 받침이 없는데 22 vs 26).

잉크비 0.897(=27/30.1 실측)로 역산 → **좌 font-size 24 · 우 29**, 폭은 `scaleX` 좌 1.11 · 우 .914.
결과: 2행 라벨 잉크 **y509..529 로 레퍼런스와 완전 일치**, 이벤트 y507..532 일치, 특권 y641..667(+1).

외곽선 두께는 «라벨 영역의 근흑:흰 픽셀 비» 로 튜닝했다 — 레퍼런스 0.57~1.11 인데
`.20` 이면 1.38~2.88 로 2~3배 과중했다. **`.07` 에서 0.5~1.2** 로 붙는다.

## 검증

- 뷰포트 6종(1080×1920 / 390×844 / 412×915 / 768×1024 / 1024×768 / 360×640) × 패널 개폐 2종
  → **콘솔 에러 0 · 요소 겹침 0 · 프레임 밖 잘림 0.**
- `battlefoot` 침범 0, `#menub` ↔ `#sideR` 1행 여유 61px.
- 세로가 짧은 1024×768(가로) 에서만 비례 축소가 걸린다(`--ih` 81.13). 6칸 전부 들어간다.

## 남은 문제 (아트 리소스 없이는 회수 불가)

1. **이모지는 스프라이트가 아니다.** `--sf/--sx` 로 잉크 bbox 는 맞췄지만, 레퍼런스 아트의
   «가로로 넓은 일러스트 + 두꺼운 검정 외곽선 + 내부 명암» 자체는 재현되지 않는다.
   ⑤ 색·명암이 9점에 도달하려면 실제 아트가 필요하다 (A1·A3·A4 와 같은 결론).
2. `scaleX` 로 폭을 맞추면 글리프가 가로로 늘어난다. 6행(🏆 sx 1.222) 이 가장 눈에 띈다.
3. 라벨 서체가 레퍼런스의 «좁고 높은 게임용 한글 서체» 가 아니라, 폭을 맞추면 자폭 배분이
   레퍼런스와 다르다(2자 −4.6% / 3자 +3.6% 트레이드오프). A1 비고 2 와 같은 한계.
4. **이모지를 교체하면 `--sf/--sx` 를 반드시 다시 재야 한다.** 재측정은 `canvas getImageData` 로
   글리프 잉크 bbox 를 뜬 뒤 위 공식에 넣으면 된다.
