## 6. 넘기는 것 · 교훈

**넘기는 것 2개**
1. **작업 45**(카테고리 탭 4→2)가 «특별·일일주간» 을 지울 때, smoke 오프너는 `data-cat` 을 훑으므로
   자동으로 2개만 남는다 — 수정할 필요 없다.
2. **결제를 붙일 때는 `grantDiaPack(p)` 만 호출**하면 된다(다이아·쿠폰·`S.cnt.paid`·저장·재렌더가 그 안에 있다).
   `#shopList` 의 `[data-diabuy]` 분기에서 팝업을 결제 SDK 호출로 갈아끼우는 것이 전부다.
   `window.devBuyDia` 는 **디버그 메뉴가 생기면 그쪽으로 옮길 것**(지금은 전역 함수뿐이다).

**교훈 2개 (LESSONS 로 올림)**
1. **살아 있는 페이지에서 localStorage 를 고친 뒤 reload 로 마이그레이션을 검사하면 안 된다.**
   게임 루프가 5초마다 자동 저장(`if(saveT > 5) save()`)하므로, `delete d.mileage` 와 reload 사이에
   메모리의 옛 값이 그대로 다시 쓰인다 — 1회차 검증이 «마이그레이션 실패» 로 **오진**했고 틀린 건
   구현이 아니라 **검사 절차**였다(43 교훈 1 «내가 쓴 assert 도 기준을 먼저 확인하라» 의 재현).
   `context.addInitScript()` 로 **페이지 스크립트보다 먼저** 세이브를 심으면 결정적이다.
2. **필드 하나 추가에 KEY 를 올리지 마라.** `load()` 가 `Object.assign(DEF(), d)` 구조면 새 스칼라
   필드는 기본값이 자동으로 남는다. KEY 를 올리면 전 진행도가 날아간다. 대신 옛 세이브가 `null`·문자열을
   갖고 있을 때를 위해 **`Number.isFinite` 한 줄**로 못박는다(그래야 `S.mileage` 가 NaN 으로 새지 않는다).
