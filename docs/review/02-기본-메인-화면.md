## 0. 좌표계 정정 (이 회차의 핵심 발견)

A2 측정표는 전투 캔버스 top 을 **229**(좌측 프로필 플레이트 하단)로 잡았지만,
**전체 폭 기준 상단 HUD 바 하단은 188** 이다(A3 측정표 §19 와 일치. 좌측 플레이트만 38px 더 돌출).

프레임(1080×1920)의 `#stagearea` 는 y=104 에서 시작하고 `#top` 높이가 104 이므로,

| | 레퍼런스(2340) | 프레임(1920) |
|---|---|---|
| 전투영역 top | 188 | 104 |
| 전투영역 bottom | 2160 | 1740 |

- 상단 고정 요소 → `stagearea 기준 top = ref_y − 188`
- 하단 고정 요소 → `stagearea 기준 bottom = 2160 − ref_bottom`

229 를 쓰면 상단 요소가 전부 **41px 아래로** 내려간다. 이후 세션은 **188** 을 쓸 것.

### 레퍼런스에 없어서 **끈** 것

| 요소 | 처리 |
|---|---|
| 진행바 안 `n / m` 숫자 | `#stinfo .kbar span{display:none}` — 값 갱신은 유지 |
| 미션 배너 안 진행바 | `#tuto .tp{display:none}` — 진행 수치는 미션 문구 뒤 `(p/goal)` 로 표기 |
| 스테이지 헤더의 `최고 N` | `chapN` 을 `STAGE n` 한 줄로. 최고기록은 프로필 모달에 있다 |
| **플레이어 HP 바** (`#hpwrap`) | `display:none` **한 줄**로 숨김. 레퍼런스 02 에 없으며(측정표 §6, A4 측정표 §66 동일 결론), 켜 두면 좌하단 마을 라벨·우하단 미션 배너와 **세로로 겹친다**. 요소와 JS 갱신은 그대로 두었으므로 되돌리려면 그 한 줄만 지우면 된다 |

> **A4/battlefoot 담당자에게**: `#hpwrap` 은 내 구간이 아니라 CSS 한 줄로만 껐다. 정식 제거·이전은 그쪽에서 판단할 것.
