## 1. 무엇이 문제였나

`gradeProbs(b)` 는 표의 가중치 `p1` 을 **총합으로 재정규화**한다. 그래서 표에 적힌 «3%» 는
화면에 보이는 확률이 아니다 — 만렙 가중치 총합이 **1.09** 라 실효는 `0.03 / 1.09 = 2.752%`,
**지시의 27.5배**였다. «표의 숫자» 와 «플레이어가 겪는 확률» 이 어긋나 있었던 것이 사고의 원인이다.

## 2. 고친 것 — 상수를 «목표 실효 확률» 로 뒤집었다

`index.html` `GRADE_ROLL_EQ`(§ 소환 레벨 확률표):

```js
const TRANSCEND_P1   = 0.06;     /* 초월 가중치 — 115 에서는 미변경(② 제안만) */
const IMMORTAL_P_MAX = 0.0010;   /* ★ 불멸 «목표 실효 확률» @ 만렙 = 0.10% */
const IMMORTAL_P1 = IMMORTAL_P_MAX * (GRADE_ROLL.reduce((a, g) => a + g.p1, 0) + TRANSCEND_P1)
                    / (1 - IMMORTAL_P_MAX);
```

- 만렙(t=1)에서 `w = p1`, 실효 `= p1 / (Σ다른행 + p1) = T` → **`p1 = T·Σ다른행 / (1 − T)`**
- `Σ다른행 = 1.00(6행 표) + 0.06(초월) = 1.06` → `p1 = 0.001 × 1.06 / 0.999 = 0.00106106…`
- **손으로 적은 값이 아니다.** 6행 표나 초월 가중치가 바뀌면 식이 자동으로 따라간다
  (LESSONS 106-1 «값이 식을 따라야 한다». 게이트 `A3` 이 이 등식을 직접 단언한다).
- **해금 Lv75 유지** — 75→100 구간은 `t^0.9` 로 0 → 0.10% 단조 상승(Lv90 = 0.0649%).

## 4. 표기 — `fmtProbPct` 신설 (지시 ③)

옛 `fmtPct(v, d)` 는 «뒤 0 제거» 라 이번 변경에서 **두 가지가 실화**가 됐다:

| 입력 | 옛 `fmtPct(v,2)` | 새 `fmtProbPct(v)` |
|---|---|---|
| 0.10 | `0.1` | **`0.10`** |
| 0.001 | **`` (빈 문자열!)** | **`<0.01`** |
| 5.6547 | `5.65` | `5.65` (불변) |
| 5 · 30 | `5` · `30` | `5` · `30` (불변) |

규칙: **1% 미만은 소수 둘째 자리 고정**, **0.005% 미만은 «<0.01»**, 1% 이상은 종전 그대로.
적용처는 11 확률 팝업의 등급 헤더 하나다 — 아이템별 행은 종전대로 `toFixed(5)`(등급 확률을 종 수로 나눈 값이라 자리수가 더 필요).

> **«12 결과» 는 손댈 것이 없었다.** 지시 ③ 이 «11 팝업·12 결과의 표시» 라고 했지만,
> 12 소환 결과 팝업(`showSummonResult`)은 **확률을 한 곳도 표시하지 않는다**(아이템 칸 + 개수뿐).
> 확률 문자열을 만드는 곳은 저장소 전체에서 `renderProbInfo` 하나다(`grep fmtPct` 로 확인).

## 7. ② 초월(7등급) 만렙 실효 ≈1% — **제안만. 변경하지 않았다**

지시 ②: «초월도 불멸과의 간격을 위해 만렙 실효 ≈1% 로 낮출지 담당이 **표로 제안만**(변경은 주인 확인 후)».
지금은 초월 5.655% : 불멸 0.100% = **57:1** 이라 «초월은 흔하고 불멸만 극단» 인 모양이다.
1% 로 낮추면 10:1 이 되어 «상위 2등급이 한 계단씩» 이 된다.

바꾼다면 코드는 상수 두 줄로 끝난다(§2 와 같은 역산 구조):

```js
const TRANSCEND_P_MAX = 0.0100;   /* 목표 실효 */
const IMMORTAL_P_MAX  = 0.0010;
/* Σ6행 = 1.00 · 총합 X = 1/(1 − 0.010 − 0.001) = 1.011122
   → 초월 p1 = 0.010111 · 불멸 p1 = 0.001011 */
```

| 등급 | 현재(115 적용 후) | **제안 (초월 1%)** | 차이 |
|---|---|---|---|
| 일반 | 4.712% | 4.945% | +0.23%p |
| 고급 | 14.137% | 14.835% | +0.70%p |
| 희귀 | 28.274% | 29.670% | +1.40%p |
| 영웅 | 23.561% | 24.725% | +1.16%p |
| 전설 | 14.137% | 14.835% | +0.70%p |
| 신화 | 9.425% | 9.890% | +0.47%p |
| **초월** | **5.655%** | **1.000%** | **−4.65%p** |
| 불멸 | 0.100% | 0.100% | — |

- **밸런스 영향**: 초월 장비는 «불멸 합성 재료»(85 — 초월 5개 → 불멸 1종)라 초월을 1/5.7 로 줄이면
  **불멸 합성 루트가 사실상 막힌다**(소환 직접 획득 0.1% 와 합성 루트가 동시에 좁아진다).
  낮출 거면 «초월 → 불멸» 합성 필요 개수도 같이 봐야 한다 — **주인 확인 없이는 손대지 않는다.**
- 담당 의견: **현행(5.655%) 유지 권장.** 지시는 «불멸 0.1%» 였고 그건 달성됐다. 초월까지 함께 조이면
  체감 난이도가 곱으로 오른다.
