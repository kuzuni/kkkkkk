## 1. 뿌리 — 814 가 «별도 행» 으로 넘긴 자리

814(8~11회차)가 코스튬 [강화] 플래시 워시 밑에서 무너지던 두 값 줄을 두 손잡이로 회수했다:
`--flash-keep`(값 줄을 워시 «위» 로 다시 그림) · `--flash-k` .70(워시 세기 눌러 «앉은 면» 이 뜨는 것 억제).
그 결과 «n/500» 봉우리 대비가 **2.30~2.63 → 3.59:1** 로 올라 목표 ≥3.5 를 넘겼다 — 다만 **여유가 0.09**.

814 §4-8-1 이 그 마지막 여유를 **명시적으로 878 로 넘겼다**:

> ⚠ «n/500» 의 4.5:1 은 이 행 밖이다 — 무연출 바 색(122,126,157) 자체가 3.73~3.92:1 이라
> 워시를 0 으로 해도 못 넘는다(2인 각자 확인). 여기 목표는 «정지와 같아지는 것» 이고,
> 그 이상은 **바 색을 바꾸는 별도 작업**이다.

878 은 그 «남은 손잡이 하나» = **바 자신의 색**이다.

## 2. 실측 (probe814c · verify878 · 찍힌 픽셀 대비비)

* 목표를 «4.5» 가 아니라 **«최악 프레임 ≥3.5 를 여유로»** 로 잡은 것은 814 EA·EB 처방 그대로다 —
  무연출이 5.59 로 올라 814 가 «구조적 불가» 라 한 4.5 도 정지 상태에선 넘겼다(verify878 [D]).

## 3. 처방 — 바탕 두 스톱만 f≈.87 로 누른다, **#bCos 로 가둬서**

```css
/* index.html, .sk-bar 규칙 바로 뒤 */
#bCos .sk-bar{background:linear-gradient(180deg,#70718B 0 21px,#5F6784 22px)}
```

* top #8182A0(129,130,160) → **#70718B**(112,113,139) · bot #6E7798(110,119,152) → **#5F6784**(95,103,132).
  두 스톱을 같은 계수 f≈.8675 로 눌렀다(휘도 ∝ f^2.4 라 top 대비 3.73 → 4.83, bot 4.49 → 5.59).
* ⚠ **`.sk-bar` 는 07 스킬(#bSk)·26 펫(#bPet)·50 코스튬(#bCos) 공용이다.** 플래시(`--flash-*`)는
  **#bCos 에만** 걸려 있고, 스킬·펫 바는 무연출이라 어둡게 할 이유가 없다 → **#bCos 로 가뒀다**
  (411·664 계열 «공용 부품은 스코프로 가른다»). 공용 원본 규칙(#8182A0/#6E7798)은 **한 글자도 안 건드렸다**
  (verify878 [B]).
* 채움색(`.sk-bar>i` 앰버 · `.up>i` 초록)·조건 톤(`.sk-bar.rq`)은 그대로 — **바탕만** 눌렀다.
* 기하·bbox·pitch **Δ0px**(색만 바꿨다).

## 4. 되돌림 시험 (verify878 [R])

옛 공용 색을 #bCos 에 도로 얹으면(`!important`) 봉우리가 **3.59 로 내려간다**(지금 4.23 · Δ0.65).
814 의 두 손잡이만으로도 3.5 는 «겨우» 넘으므로, 878 이 산 것은 «3.5 를 넘는 것» 이 아니라
**«실측 흔들림·DPR 뽑기를 견디는 여유»** 이고, 그 여유를 지탱하는 게 «바 색» 임을 이 항이 못박는다
(863·338 «문턱에 붙인 항은 다음 손잡이에 바로 빨개진다» 계보 — Δ≥0.40 + [C2] 여유선 3.80 밑을 같이 물었다).
