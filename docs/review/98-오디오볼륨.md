## 1. 측정 방법 (ⓐ)

`node tools/aud98.js` — 신설. 재생하지 않고 `decodeAudioData` 로 디코드해 잰다.
지시서가 경고한 대로 `chrome --dump-dom --virtual-time-budget` 은 decode 완료를 기다리지 않으므로
**playwright `page.evaluate`** 로 await 했다(`--json` 옵션 · `W98=<ms>` 로 창 길이 변경).

측정치는 3종:

- **peak** — 절대 최대 진폭. 클리핑 판정에 쓴다.
- **전체 RMS** — 파일 전체 평균. 꼬리 무음이 긴 파일(`victory` 4.4s, `toggle` 0.62s)에서 **과소평가**된다.
- **창 100ms RMS** — 가장 시끄러운 100ms 구간의 RMS. **게인 산정 기준으로 이걸 쓴다.**
  SFX 는 «한 방» 이라 사람이 듣는 크기는 전체 평균이 아니라 이 피크 구간이다.
  전체 RMS 로 잡으면 `victory`(전체 −22.2 / 창 −16.1) 를 6 dB 더 키워 버린다.

> **BGM 만 전체 RMS 로 판정한다.** 40~70초 연속음이라 «가장 시끄러운 100ms» 가 아니라 평균이 체감 레벨이다.

## 2. 게인 산정식 — 피크 실링이 있다

```
g = min( 10^((목표 − 창RMS)/20) ,  10^((−1 − peak)/20) )
                 ↑ 목표 도달              ↑ 피크 실링(−1 dBFS)
```

뒤 항이 **이 작업에서 가장 중요한 발견**이다. 부스트가 필요한 5종은 원본 피크가 이미 −1 dBFS 근처라
목표까지 올리면 **클리핑(왜곡)** 한다 — 특히 `tap.ogg` 는 피크 −1.51 / 창RMS −26.69 로 **크레스트 25 dB** 짜리
아주 짧은 클릭이라, 목표 −18 을 맞추려면 +8.7 dB → 피크 +7.2 dBFS 로 심하게 깨진다.

→ 그 5종(`tap`·`toggle`·`flip`·`rtick`·`rare`)은 **실링에서 잘리고 목표에 미달하는 것이 정상**이다.
클릭류는 어차피 RMS 가 아니라 피크로 지각되므로 체감상 문제 없다. 게이트도 이 5종은
«목표 초과만 아니면 통과» 로 따로 본다(`verify98.js` §B `피크실링` 표시).

**원본 파일을 리노멀라이즈하면** 실링을 풀 수 있지만 이 환경에 ffmpeg·soundfile 이 없고,
78 이 받아 둔 CC0 원본을 재인코딩하면 `CREDITS.md` 대조·용량 예산(verify78 §A)이 흔들려 하지 않았다.
→ **남은 개선점**으로 아래 §6 에 적는다.

### BGM 게인이 0.35~0.45 가 아니라 0.20 인 이유 (ⓒ 편차 — 주인 확인 필요)

지시는 «기본 게인 ≈ 0.35~0.45», 그 괄호 안 근거는 «실측 BGM RMS 로 SFX 평균보다 8~10 dB 낮게» 였다.
게이트 조건도 «SFX 평균 대비 −8 dB 이하» 다. **실측하니 두 값이 어긋난다:**

- SFX 평균(전투 반복음 3종 제외 17종, 적용 후 창RMS) = **−18.68 dBFS** → 기준선 **−26.68**
- BGM 원본 전체 RMS 는 −13.99 / −14.14 (요즘식 라우드 마스터) → −26.68 을 맞추려면 게인 **0.23**
- 0.35 를 쓰면 −23.1 로 **기준선보다 3.6 dB 위** = 게이트 불합격

→ **수치 근거이자 게이트 조건인 «−8 dB» 쪽을 따랐다**(0.20, 실제 −9.3 dB 아래).
0.35~0.45 는 실측 전 어림값으로 보인다. 주인이 «그래도 0.35» 라고 하면 게인만 바꾸고
게이트 §C 기준을 완화하면 된다 — 한 줄 수정이다.

## 4. `coin` 발화 억제 (ⓓ)

`fxFly()` 가 **킬마다 · 알약(골드/다이아)마다** 부른다. 30ms 디바운스로는 사실상 무제한이었다.

- 이름별 최소 간격 테이블 `AU_MIN = { coin:150 }`(기본 `AU_MIN_DEF = 30`) 신설
- → 이론상 상한 **6.67회/s**. 같은 프레임에 들어오는 골드·다이아 두 알약은 **1회만** 운다(두 번째가 150ms 안이라 잘림)
- `hit` 은 무적 0.4s 라 최대 2.5회/s → 지시대로 **게인만** 낮췄다(−12.8 dB)

게이트 실측:

| 조건 | 호출 | 실제 발화 | 발화율 |
|---|---|---|---|
| 연속 두들기기 40회 / 1.33s | 40 | 8 | **6.02회/s** ≤ 7 ✅ |
| 헤드리스 전투 60초(실사용) | 19 | 19 | **0.32회/s** ≤ 7 ✅ |

> 전투 60초 쪽이 호출=발화인 것은 1스테이지 킬 간격이 150ms 보다 길기 때문이다.
> **상한을 증명하는 것은 두들기기 쪽**이다(호출률과 무관하게 6.67회/s 에서 잘린다).
