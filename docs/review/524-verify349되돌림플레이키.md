## 2. 뿌리 — 유령 이름 하나 (`closeDefeat`)

`verify349` 의 `reset()` 은 표본마다 화면을 치운다.

```js
['closeDunClear', 'closeDefeat', 'closeModal', 'closeDungeon', 'closeSummonResult']
  .forEach(fn => { try { if (typeof window[fn] === 'function') window[fn](); } catch (_) {} });
```

**`closeDefeat` 는 제품에 없는 이름이다 — `index.html` 에 0건**(`probe524` §3 이 매 실행 못박는다).
나머지 넷(그리고 형제 자들이 쓰는 `closeRelw`·`closeTrain`)은 전부 실재한다. 유령은 이 하나다.
`typeof … === 'function'` 가드가 그 사실을 **조용히 삼켜**, 18 패배 화면을 치우는 팔은
**한 번도 돈 적이 없다**(LESSONS 353-① «0 이면 그 장치는 그 자리에 없는 것과 같다»).

남은 보호는 계측 블록의 hp 되채움 하나뿐인데,

```js
/* 죽어서 18 패배 화면이 버튼을 덮는 것만 막는다(74 규약) — 루프 자체는 **돌린다** */
setInterval(() => { … S.hp = maxHp(); }, 200);
```

이것은 **«죽는 순간» 과의 경주**다. 한 번 지면 `#defw.on`(z39 · `inset:0` · 반투명 딤)이
룬 버튼을 통째로 덮은 채 **굳고**(끄는 것은 클릭 리스너뿐이다), 그 뒤 표본은 **전부 «0회»** 로 읽힌다.

⇒ [R1b](`v ≥ 5`)와 [G] 양성항(`aimBad === 0`)이 **같이** 빨개진다. 등재문의 «22~24/24» 가 정확히 그 모양이다
