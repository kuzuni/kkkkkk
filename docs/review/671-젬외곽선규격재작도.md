## 2. 처방 — 몸통은 한 자도 안 건드렸다

바꾼 것은 «검정 테를 **어떻게** 두르는가» 하나다.

| | 수리 전 | 수리 후 |
|---|---|---|
| 검정 테 | 몸통 path 에 `stroke 4` straddle | 몸통의 **1.0714배** 자리에 **따로 깐 실루엣 path** + `stroke 4` 라운드 조인 |
| 몸통 | `fill` + 그 stroke | `fill` 만 (stroke 없음) |
| 면 분할선 | 몸통 위에 그대로 | **몸통으로 클립**(`clip-path="url(#diaBody)"`) |
| viewBox | `2 2 60 60` | `0 0 64 64` (= 새 잉크 bbox) |

산수: 실루엣 = 몸통 56 × 1.0714 + 4 = **64** · 색 잉크 = 몸통 **56** ⇒ 56/64 = **.875 (두 축 모두)**.
`M20 4h24l16 18-28 38L4 22z` (몸통 path)·색·면 분할 좌표는 **한 자도 안 바뀌었다** —
`verify144` 의 경로 술어와 `verify671` [A] 가 그것을 못박는다. 644 의 불변식
«viewBox == 잉크 bbox» 도 그대로다(실루엣이 0..64 를 정확히 채운다).

**그 다음이 이 작업의 본체다** — 아트가 등방이 되자 **같은 상자가 같은 잉크를 낸다**:

- `.cbox i>.cic` (HUD) 59.06 → **65.3**
- `.pcb-d>i>.cic` (41 재화 바 · 03·10·89 공용) 59.06 → **65.3** = 바로 위 `.pcb-g` 와 **한 값**

⇒ 65.3 × .875 = 잉크 **57.1**(ref 색 잉크 56×57) · 실루엣 **65**(ref 64×65) — **둘 다 ref 쪽으로 갔다.**
같은 프레임 안 덩치 비 **1.106 → 1.000**(411·356 눈금 ≤1.05).

⚠ **`.pcb-p` 57 은 안 내렸다** — 644 가 «측정표 41 §3 의 선언이 처음으로 참이 된 자리» 로 남긴 것이고,
