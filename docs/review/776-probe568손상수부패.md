## 3. 처방 — 등재문 ⓐ(제품 역산), ⓑ 는 필요 없었다

등재문의 갈래 ⓑ(«verify76 쪽까지 같이 본다»)는 **오늘 트리에서 이미 닫혀 있다** — `verify76` 은 30/30 PASS 이고

```js

/* 새 판 */ eq('[1] ① 76 이 «값» 으로 묻던 그 자리가 그대로 재현된다 — 손 상수가 아니라 max(498 곡선, 목걸이 10연) 하한',
```

## 4. 무르게 풀지 않았다 — [R] 되돌림 시험 4항 신설

파생만 남기면 «그 항이 통째로 사라져도 초록» 이 된다(LESSONS **522-③**). 774 §4 방식대로,
**같은 술어를 옛 값·어긋난 값 위에서 돌려** 그 항이 실제로 무엇을 잡는지 못박는다.

```
ok [R1] ★ 옛 손 상수 21,000 은 오늘 술어를 통과하지 못한다 — 그것이 이 항이 빨갰던 이유   :: 옛 21000 vs 오늘 10250
ok [R2] ★ 곡선 계수를 손으로 적는 자는 «판이 밀리면 반드시» 썩는다 — 오늘 곡선은 제품 역산으로만 맞는다  :: 7750+500·5 = 10250
ok [R3] ★ idx5 를 한 칸 어긋난 상수로 굳히면 [1]① 술어가 깨진다 (= 그 항이 실제로 값을 잰다)  :: 어긋난 사본 10251
ok [R4] ★ [1]① 과 [2]① 은 서로 다른 것을 잰다 — 상자 10연이 곡선을 이기는 판에서는 하한 술어만 살아남는다
```

**[R4] 가 «자리를 안 비웠다» 는 증거다** — 두 항이 같은 값을 찍는 것은 «지금 곡선이 이기고 있어서» 일 뿐,
상자 10연이 곡선을 넘는 판에서는 [1]①(하한)은 초록, [2]①(= 곡선)은 빨강이 **되는 것이 옳다**.
그래서 [2]① 을 지우지 않았고(333·310), [1]① 도 [2]① 의 사본이 아니다.
