## 2. 2·4번이 «부수 피해» 인 기전 — 자가 자기 발을 밟고 있었다

옛 §6 은 한 `evaluate` 안에서 입장을 **두 번** 했다:

```js
startDunRun(DUNGEONS[0], 1);          // ① «막힌다» 표본 — 665 이후로는 성공한다
const blocked = !dunRun;              //   ⇒ false ⇒ 1번 빨강

                                      //   ⇒ battleLocked() 가 «던전 → 던전» 을 막아 **조용히 무산**

```

⚑ **`mid.run` 이 초록인 것이 함정이었다** — `!!dunRun` 은 ① 이 세운 낡은 런을 보고 참이라
«들어갔다» 로 읽힌다. 실제로는 안 들어갔다. 수리에서 **런을 접고**(`endDunRun` + `dunRun = null`)
다시 재는 것으로 이 헛초록까지 같이 없앴다.

## 4. ⚑ 등재문의 처방 한 조각은 채택하지 않았다 — 관측되지 않기 때문

⇒ 관측 안 되는 것을 단언하면 «이미 참인 것을 굳힌 게이트»(338 이 잡은 그 모양)가 된다.
