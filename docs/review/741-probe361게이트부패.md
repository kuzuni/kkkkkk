## 3. ⓐ — 「가로를 키웠는데 빨간 항이 없다」의 산수

옛 N1 은 `scaleX(SX × 1.15) = scaleX(0.842 × 1.15) = scaleX(0.9683)` 을 주입했다.
그 값이 «×1.15» 였던 것은 **제품의 scaleX 가 .842 이던 시절**뿐이다. 356 뒤 제품의 scaleX 는 **1** 이라,
같은 주입은 가로를 키우기는커녕 **3.2% 줄인다**:

```
평균 w  69.2 → 67.0   (목표 68 대비 −1.5% = 밴드 안 = 초록)
```

그래서 «빨간 항이 «평균 잉크 w» 다» 가 **(없음)** 으로 빨갛고, «세로 항은 초록으로 남는다» 도
같이 빨갛다(세로는 ⓑ 때문에 기준선부터 이미 빨갛다).

⚑ **여기서 놓치기 쉬운 것 — N1 첫 항 «게이트가 빨개진다» 는 «ok» 였다.** 손잡이는 빗나갔는데
기준선이 ⓑ 로 이미 빨개서 «빨개졌다» 가 맞아 버린 것이다. **되돌림 시험은 «빨개졌나» 가 아니라
«의도한 항목이 빨개졌나» 까지 물어야 성립한다**(LESSONS 219-③)는 규약이 이 자를 살렸다 — 그 항이
없었으면 8/15 가 아니라 «몇 개는 초록» 으로 지나갔다.

## 4. ⓑ — 세로 목표 85 는 **356 이 이미 71.6 으로 바꿔 둔 값**이다

등방으로는 «폭 68 · 높이 85» 를 동시에 만들 수 없다. 356 은 규칙대로 «작은 쪽»(`s = min(sx,sy)`)을
골랐고, 그러면 **폭은 68 그대로(Δ0)·높이는 `85 × .842 = 71.6`** 이 된다.
`tools/verifyA4.js` 120~125행이 **2026-08-29 에 이미 그 이관을 했다**:

```js
/* ★ 356 이관(주인 지시 2026-08-29) — 폭 68 은 그대로, **높이 85 → 71.6**. …
   ref bbox 85 와의 차는 «아트 대기» */
eq('아이콘 평균 잉크 h', +d.inkH.toFixed(1), 71.6, 4);
```

**`inkA4` 만 안 따라왔다.** 기준선 실측 평균 h **72.2** 는 71.6 대비 **+0.9%** 로 밴드 한복판인데,
85 로 재면 **−15.0%** 다. ⇒ `REF_H_ART = 85`(보고 전용 «아트 대기») 와
`REF_H = 85 × .842 = 71.6`(판정 목표)로 **갈랐다.**

**판정 몫(등재문이 이 행에 남긴 결정): «85 를 71.6 으로 간다» 를 채택했다.** 위임 규약(2026-09-01)대로
선택지·대가를 적고 그 회차에서 즉시 채택한다:

| | 안 | 대가 | 판정 |
|---|---|---|---|
| ⓘ | **세로 목표를 71.6 으로**(채택) | 아트 bbox 85 가 판정에서 빠진다 → 표·`REF_H_ART` 로 남긴다 | **자가 둘(verifyA4·inkA4) 있는데 한쪽만 이관돼 있던 것**을 맞춘다. 되돌림 가능 — `REF_H` 한 줄 |
| ⓒ | 세로 축을 판정에서 **빼고** 보고로만 | 세로가 통째로 안 지켜진다 — `scaleY`·`font-size` 를 흔들어도 초록 | 기각. probe361 N2·N3 가 통째로 죽는다 |
| ⓓ | 허용 오차를 ±16% 로 넓혀 85 를 유지 | «무르게 푼 수리» 그 자체 | 기각 |

⚠ **허용 오차는 한 칸도 안 넓혔다** — `AVG_TOL` 은 ±5% 그대로다. 바뀐 것은 «무엇의 ±5%» 뿐이고,
71.6 은 재측정한 값이 아니라 **85 에서 356 의 배율로 파생된 값**이다(`REF_H_ART * 0.842` 로 적어
산수를 코드 안에 남겼다). 측정표 §3 의 68×85 는 **안 건드렸다**(재측정 금지 규약 유효).

⚠ **종횡비 항(«찌그러짐 0»)은 `inkA4` 에 안 세웠다** — `verifyA4` [3] 이 이미 소유하고 있고
(`0.95 ±0.03`), 여기 또 세우면 probe361 P1(밴드 안쪽 흔들기)이 그 항에 걸려 «밴드 안인데 빨강» 이 된다.
**자가 둘이면 둘이 어긋난다** — 이 행이 고친 병이 바로 그것이다.

730 은 «자가 «제품이 지금 어떻게 생겼나» 를 상수로 박아 두면 다음 규격 변경에 부패한다» 를

```

```

⚠ **표시용 값(`toFixed(3)`)이 아니라 원값을 준다** — 반올림한 밑에 배율을 곱하면 밴드 가장자리에서
부호가 갈린다(A3-ⓑ 계열 함정).

그리고 손잡이를 **«몇 배를 곱하나» 가 아니라 «평균 잉크를 밴드의 어디로 옮기나»** 로 다시 적었다:

```js
const toW = frac => f(S.refW * (1 + frac) / S.mw);   // 평균 w 를 목표 대비 frac 지점으로
const OUT = 3 * S.tol / 100, IN = 0.5 * S.tol / 100; // 밴드 밖 3배 지점 · 밴드 절반 지점
```

| 절 | 옛 손잡이 | 새 손잡이 | 착지 |
|---|---|---|---|
| N1 | `scaleX(.842×1.15)` | `scaleX(sx × toW(+15%))` = ×1.1303 | 평균 w **+15.0%** (밴드 밖) |
| N2 | `font-size 78.3×1.12` | `font-size fs × toH(+15%)` = ×1.1401 | 평균 h **+15.1%** |
| N3 | `scaleY(1.12)` | `scaleY(sy × toH(+15%))` = 1.140 | 평균 h **+15.0%** |
| P1 | `scaleX(.842×1.03)` | `scaleX(sx × toW(+2.5%))` = ×1.0074 | 평균 w **+2.5%** (밴드 절반) |

⚑ **P1 이 옛 값 그대로였으면 «초록» 이 우연이 될 뻔했다** — 기준선이 +1.8% 인데 ×1.03 을 곱하면
**+4.85%**, 밴드 상한 5% 에서 **0.15% 남는다.** 밴드의 절반 지점으로 옮겨 그 우연을 없앴다.

§R(옛 «글리프별 ±12%» 재현)의 **«이탈 5종» 상수도 같은 병**이라 함께 걷었다 — 356 이관 뒤 실측은
**4종**이다(`meteor` 가 +12.7% → +11.8% 로 문턱을 넘어왔다). 못박을 주장은 «5종» 이 아니라
**«CSS 로는 초록이 될 수 없는 글리프가 남는다»** 이므로 `>= 1` + 이름 확인(`drain`·`lance`)으로 바꾸고,
옛 게이트 점수는 표본 수에서 계산해 찍는다(`23/27`).
