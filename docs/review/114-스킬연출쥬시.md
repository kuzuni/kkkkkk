## 반영하지 않은 것과 근거

- **AM② 처방 «충격파 최대 Ø 373 → 136(몸통 4배)»** — 채택하지 않았다. 운석의 **피해 반경은 r=130
  (Ø 260)이고 밸런스 고정값**이라 링을 136 으로 줄이면 «맞는 범위» 를 절반으로 거짓말하게 된다.
  두 비평가가 공통으로 문제 삼은 것은 «뷰포트 초과·화면 밖 잘림» 이므로 **피해 반경 바로 바깥**에서
  멈추는 값(Ø 291 = 54%)으로 맞췄다. 게이트에 «2단 최대 지름 ≤ 340 게임px(뷰포트의 63%)» 를 새로 건다.
- **AN④ 처방 «숫자 상승량 22.5 → 55 게임px»** — 채택하지 않았다. 9·10회차가 두 비평가(AI·AJ·AK)의
  공통 지적으로 상승을 67 → 38 → 28 로 **내린** 값이고, 같은 회차의 AM①·AN② 가 «숫자가 자기 적에서
  멀다» 를 최우선으로 잡고 있다. 정지 구간 문제는 **4번(합산 병합)** 으로 푼다 — 겹침이 사라지면
  정지가 가독성을 깨지 않는다. 다음 회차 채점에서 이 판단을 검증한다.
- **AN⑦ «bolt 체인 끝이 적 중심에서 35 게임px 떨어져 있다»** — 끝점은 `e.y − e.r`(머리 위)로 **적에
  스냅돼 있다**(코드 확인). 35 는 «중심까지» 의 거리이고 몸통 반지름 17 + 스프라이트 여백이다.
  중심에 꽂으면 번개가 몸통을 관통해 보이므로 그대로 둔다. 단 AM④ 의 «허공 가지» 는 위처럼 고쳤다.
- **AN⑨ «화구 피크에서 적·히어로 실루엣이 흰 코어에 묻힌다»** — 6회차부터 «아트 리소스 없이는 회수
  불가»(코어/외염/연기가 분리된 이펙트 시트 필요)로 분류된 항목이다. 그리기 순서를 바꾸면 폭발이
  캐릭터 뒤로 가 «터졌다» 가 사라진다.
