### §2 뿌리 — 297 규약이 **첫 프레임에만** 꺼져 있었다 (제품 1자리)

297 이 세운 규약: «꾹 누르는 동안에는 노드를 갈지 않는다 — 누른 노드를 `innerHTML` 로 날리면
터치의 암묵적 포인터 캡처가 끊긴다»(64 교훈 1 · 262 ⓑ). 그 규약은 `rtHoldOn(tag)` 이 참일 때만 걸리는데
`rtHoldStart` 의 **순서가 거꾸로**였다:

```
  rtHoldStop(false);
  if(!o.once()){ … }        ← 첫 발(구매·시도)  … 이 시점에 rtHold 는 아직 null
  o.live();                 ← 첫 렌더           … rtHoldOn(tag) === false ⇒ 통짜 innerHTML 교체
  rtHold = { … };           ← «홀드 중» 표시를 **여기서야** 세운다
```

그 한 프레임에서 `renderRunes`/`renderTemper` 가 `innerHTML` 을 갈아 끼우고, 방금 `#app` 위임이 붙인
`jz-dn` 이 **옛 노드와 함께 사라진다**. 60 은 정상이고, 누른 흔적만 없다.

**고친 것은 순서 하나**(`index.html` `rtHoldStart` — 표시를 첫 발보다 먼저 세우고, 첫 발 실패 갈래에서는
`o.end()` **전에** 도로 내려 통짜 렌더를 지킨다). 판정식·상수·CSS·레이아웃 **0줄 / Δ0px**.

**수리 후 같은 자로 재측정**: R-buy **0.00 → 22.86%** · T-up **0.00 → 25.88%** · 세 자리 모두
«같은 노드» true · `jz-dn` 16/50ms 둘 다 O · `scale 0.94`. `probe491` **55/55 PASS**.

| A | 세로 눌림이 없다 + 바닥 립이 안 접힌다 | y +4~6px · 립 5px → 1~2px |
| B | 누른 순간 **명도**가 안 움직인다 | Δ ≥ 18~20/255 (방향은 갈림 — BU «어둡게» · BV «밝게») |
| C | 룬·충전에 플로터가 **0개** | 대조군 규격(≈78×50 이상 · 대비 ≥150/255) · 버튼 중심 60px 이내 |

| E | [충전] pressed ↔ disabled 회색이 구분 불가 | Δ ≥ 40/255 |

⚠ **B 의 방향은 둘이 갈렸다**(어둡게 vs 밝게) — 2회차는 **한쪽을 골라 근거를 적어라**. 이 저장소에는 이미
«어둡게 = 죽은 버튼» 이라는 뜻이 못박혀 있다(`jz-sh` = `brightness(.82)` + shake, 60). 그러므로 **밝게(BV)** 가
어휘 충돌이 없는 쪽이다 — BU 의 «±20» 도 «명도를 움직여라» 지 «어둡게» 를 요구한 것은 아니다.

#### 2회차 착수 메모(다음 세션이 그대로 이어받을 것)

- **부품 하나 + 호스트 목록** 규약을 지켜라(개별 CSS 금지). 후보 세 부품:
  `.jz-dn`(누름) · `.fx-plus.hb`(회당 플로터 30px/.3s) · `hbBeat()`(호출 규약).
- ⚠ `.jz-dn` 에 **`filter:brightness()` 를 얹으면 호스트 자신의 `filter:drop-shadow(…)` 를 대체한다**
  (저장소에 그런 호스트가 여럿이다). 휘도를 건드릴 거면 그 목록을 먼저 세고 대가를 적어라.
- ⚠ 세로 이동은 **`translate:`(독립 속성)** 로만 — 저장소에서 `translate:` 를 쓰는 자리는 `jz122Sweep` 하나뿐이라
  안전하지만, `transform` 을 쓰면 글자 폭 보정(`scaleX`)과 모달 정렬이 통째로 날아간다(60 규약).
- ⚠ `jz-hb`(488 회당 맥박)는 이미 `transform:` 으로 **일부러** 갈라 놨다 — `jz-dn` 의 `scale:` 과 곱해지라고
  그렇게 한 것이므로 되돌리지 마라.
