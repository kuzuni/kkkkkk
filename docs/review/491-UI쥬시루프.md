### §2 뿌리 — 297 규약이 **첫 프레임에만** 꺼져 있었다 (제품 1자리)

297 이 세운 규약: «꾹 누르는 동안에는 노드를 갈지 않는다 — 누른 노드를 `innerHTML` 로 날리면
터치의 암묵적 포인터 캡처가 끊긴다»(64 교훈 1 · 262 ⓑ). 그 규약은 `rtHoldOn(tag)` 이 참일 때만 걸리는데
`rtHoldStart` 의 **순서가 거꾸로**였다:

```
  rtHoldStop(false);
  if(!o.once()){ … }        ← 첫 발(구매·시도)  … 이 시점에 rtHold 는 아직 null
  o.live();                 ← 첫 렌더           … rtHoldOn(tag) === false ⇒ 통짜 innerHTML 교체
  rtHold = { … };           ← «홀드 중» 표시를 **여기서야** 세운다
```

그 한 프레임에서 `renderRunes`/`renderTemper` 가 `innerHTML` 을 갈아 끼우고, 방금 `#app` 위임이 붙인
`jz-dn` 이 **옛 노드와 함께 사라진다**. 60 은 정상이고, 누른 흔적만 없다.

**고친 것은 순서 하나**(`index.html` `rtHoldStart` — 표시를 첫 발보다 먼저 세우고, 첫 발 실패 갈래에서는
`o.end()` **전에** 도로 내려 통짜 렌더를 지킨다). 판정식·상수·CSS·레이아웃 **0줄 / Δ0px**.

**수리 후 같은 자로 재측정**: R-buy **0.00 → 22.86%** · T-up **0.00 → 25.88%** · 세 자리 모두
«같은 노드» true · `jz-dn` 16/50ms 둘 다 O · `scale 0.94`. `probe491` **55/55 PASS**.
