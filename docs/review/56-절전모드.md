| 지시서 전제 | 레퍼런스 실측 | 이번 구현 |
|---|---|---|
| «화면을 어둡게»(딤) | 딤이 아니라 **완전 불투명 검정**(α=1.00, 6개 잉크 밴드 밖 `max(RGB)>3` 픽셀 **0개**) | `background:#000` + 하위 레이어 `visibility:hidden` |
| «전투는 계속»(보인다) | 전투가 **1픽셀도 안 보인다**. 로직만 돈다(방치 시간 `00:00:02` 진행 중) | `step(dt)` 만 돌리고 `draw/drawHud/drawTuto/renderUI` 전부 건너뜀 |
| «터치로 해제» | 화면 문구는 **«밀어서 잠금 해제»** | 문구는 레퍼런스대로, 동작은 **탭 1회 또는 120px 스와이프 둘 다** 수용 |

> 문구·동작이 어긋나는 지점은 저장소 주인 확인이 필요하다. UI-REFERENCE 는 «터치로 해제», 레퍼런스 이미지는
> «밀어서 잠금 해제» 다. 지금은 **레이아웃을 레퍼런스에 맞추고 동작은 둘 다 받는** 쪽으로 뒀다.

«전투는 계속, 렌더는 정지» 는 말이 아니라 숫자로 확인한다 — `verify56.js` 가 `CanvasRenderingContext2D.fillRect`

### 한 번 틀렸다가 잡은 것 (다음 세션용)

**«초당 1회 갱신» 을 dt 누적으로 세면 한 칸씩 늦게 보인다.** `svTick += dt; if(svTick>1)` 로 짰더니
`dt` 가 0.1 로 클램프돼 있어 누적이 실경과보다 뒤처지고, 갱신이 **초 경계 직전**에 걸려
1.9초가 지나도 화면은 `00:00:00` 이었다(verify56 이 잡았다). `Math.floor((now−svT0)/1000)` 이 바뀌는 순간에만
그리도록 바꿔서 드리프트를 0 으로 만들었다.
