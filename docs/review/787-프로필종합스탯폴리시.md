음성항 6.08 = 38×.16 · 라벨 x 261.42 · 라벨 자연폭 57.14). 240 이 지키려던 것은 그 숫자가 아니라
**«이 자리의 스트로크는 `--st-pft` 비율이다 · 스트로크가 레이아웃을 못 민다»** 이므로 333 처방대로 뜻으로 갈아 끼웠다:

| 옛 항 | 새 항 |
|---|---|
| 스트로크 4.37px | **실측 fs × .115** (fs 를 읽어 기대값을 만든다) |
| 음성항 6.08px | **실측 fs × .16** |
| 라벨 x 261.42 | **«라벨 중심 = 탭 칸 중심»** (스트로크가 한쪽으로 밀면 즉시 깨진다) |
| 라벨 자연폭 57.14 | **«자연폭 ÷ fs = 1.5037»** (글리프 advance 비 — fs 를 바꿔도 안 변한다) |

⚑ **무르게 푼 것이 아님을 되돌림 시험이 못박는다** — 속공간 하한 8 px² 과 §2 음성 대조(토큰을 옛 `.16` 으로
되돌리면 3.1 px² 로 다시 빨강)는 **한 줄도 안 건드렸고**, fs 를 38 로 되돌려도 **37/37 초록**이다.
즉 이 자는 이제 «38» 이라는 숫자가 아니라 **뜻**을 지킨다. 실제 속공간은 3.4 → **13.3 px²** 로 더 넓어졌다.
⚠ `--st-pft` 가 **em 기준**이라 fs 를 올려도 240 이 잡은 «칭» 받침 ㅇ 의 속공간 대 스트로크 비는 그대로다.
