## 2. 뿌리 — 「세우기는 세웠는데 **어느 프레임에** 세웠나」

808 은 «언제 찍는가» 의 경주(캡처 0.5s > 버스트 창 0.39s)를 홀드로 없앴다. 그 홀드는
MutationObserver 로 태어난 노드의 `remove` 와 CSS 애니를 멈춘다. 그런데 **관측자의 손은 노드가
처음 그려지기 전에 닿는다** — 그래서 애니가 **0% 에서** 굳는다.

```
@keyframes fxSpark{0%{transform:translate(0,0) scale(.26);opacity:.38} … 18%{scale(1);opacity:1} …}
```

0% 는 `scale(.26) opacity:.38` = **골짜기**다(면적 ×0.068 · 알파 0.38). 봉우리는 18%.
`probe836` [1] 이 지형을 통째로 찍었다(되돌림 프레임 · 프레임 전체):

|---|---|---|---|---|---|---|
| 크림 | **20** | 837 | 2,760 | **3,645** | 1,556 | 967 |

## 3. 처방 셋 (전부 «문턱을 안 내린다»)

등재문이 적어 둔 갈래 ⓐ(표본을 두껍게) · ⓒ(봉우리에 고정)를 **둘 다** 썼고,

### ① 홀드를 봉우리에 못박는다 — 음수 `animation-delay`
`animation-play-state:paused` 에 **각 요소 자신의** `animationDuration × −18%` 를 델레이로 준다.
= «시계를 봉우리에 맞춰 놓고 정지». 요소마다 길이가 다른 것(`fxSpark .38s` ↔ `fxSparkX .38s×--fxxr`)을
비율로 재므로 **러너·부하·상수에 안 붙는다**.

### ② 세는 자리를 **버스트의 색 띠**로 가둔다 (811 처방 «차이를 요소 상자 안으로 가둔다»)

⚑ **안쪽 26% 는 `--c` 와 무관하게 흰색**이라 색을 **하나도 안 되돌려도** 크림이 나온다.

### ③ 알의 자리에 **씨를 박는다** (668 «시드 고정»)
①②만으로도 되돌림 값은 안정됐지만(2,411~2,978, 폭 ×1.24) **«정상» 쪽이 281~610 으로 흔들려**
