### ⚠ 함정 1 — 687 의 광학 보정 −10 을 물려주면 **반대로** 어긋난다

687 4회차는 `margin-left:-10px` 로 잉크 중심을 잡아 뒀다. 그 근거는 **rstone 아트가 상자 대비
잉크 폭 .625**(viewBox `12 0 40 64`)라 좌우에 투명 10px 씩을 끼고 있다는 것이다.
**tstone 은 viewBox `8 8 48 48` = 1.0** — 여백이 없다. 공용 부품이 −10 을 들고 있으면 단련 쪽이
정확히 그만큼 **왼쪽으로** 밀린다. ⇒ 보정을 CSS 변수로 갈랐다:

```css
.cur-hd .cic{ … margin-left:var(--cur-dx,0px)}
.rn-hd{ … --cur-dx:-10px}     /* 이 아트만의 값 */
```

게이트도 이 비를 **손 상수로 적지 않는다** — `verify688` 이 SVG 파일의 viewBox 를 읽어 파생한다.
