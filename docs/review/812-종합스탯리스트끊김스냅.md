### 2-1 ⚑ 레퍼런스도 마지막 행을 자른다

측정표 `docs/measure/20-프로필팝업스펙정보.md` **§7-1 정오표**가 이미 적어 두고 있었다 —
ref 리스트 bbox **y977–1736(h760)** · 1행 밴드 시작 **y1000** · 피치 **60**. 산수:

| 값 | 계산 | 결과 |
|---|---|---|
| ref 상단 패딩 | 1000 − 977 | **23px** |
| ref 마지막(13) 행 남은 높이 | 1736 − (1000 + 60×12) | **16px** |

정오표 본문이 «하단은 13행이 **16px 노출된 채 클리핑**된다(스크롤 어포던스)» 라고 적고 있고,
**5회차 비평가 I·J 가 «13행 슬라이버 누락» 으로 독립 지적**한 자리가 바로 이것이다.
즉 이 화면에서 «자름» 은 결함이 아니라 **레퍼런스의 어포던스**이고, 지우면 ref 를 지운다.

## 3. 처방 — ⓐ 의 **정정판**(위임 규약 채택)

| 갈래 | 대가 | 판정 |
|---|---|---|
| ⓐ 문자 그대로 `floor(H/60)·60` | 기준 프레임 2280 이 **760 → 720**, ref 에서 40px 짧아지고 슬라이버가 0 이 된다(= ref 어포던스 삭제) | ✖ |
| ⓑ 하단 페이드 마스크 | ref 에 없는 잉크를 더한다(§7-1 «텍스트 페이드가 아니라 컨테이너가 그만큼 더 길다») | ✖ |
| ⓒ 스크롤바 노출 | 같은 이유 + `.spc-list::-webkit-scrollbar{width:0}` 는 ref 대조로 세운 값 | ✖ |
| **ⓐ′ ref 슬라이버 스냅** | 1600 에서 21px(한 행 미만)을 리스트↔탭 간격에 넘긴다 | **채택** |

```css
--spc-slv: 17px;   /* ref 가 마지막 행을 남기는 양 */
height: min(760px, calc(round(down, calc(100% - 596px - 23px - var(--spc-slv)), 60px) + 23px + var(--spc-slv)));
```

- 「패딩 23 + 온전한 행 n개 + **ref 슬라이버**」로 **내림 스냅**한다.
- 720 이 이미 60 의 배수라 **1841·1920·2280·2600 은 Δ0px** — 레퍼런스 자리를 안 옮긴다.
- **1600 만 661 → 640**(온전한 행 10 + 슬라이버 17). 버리는 21px 은 리스트↔탭 간격이 받는다
  (37.5 → 58.5 — 겹침은커녕 멀어지는 방향이라 351 7회차의 «155px 흡수» 산수는 그대로 산다).
- `round()` 미지원 엔진은 **옛 한 줄 폴백**으로 떨어진다(ref 프레임에서 같은 값이라 안전).
