### 이번 회차의 핵심 — «누적 +3px 드리프트» 의 진짜 원인
G⑨⑩ · H⑪ 이 각각 «효과 박스 +4», «플레이버·버튼 +3», «헤더 높이 +2» 로 따로 지적했지만
**원인은 하나**였다: A5 공용 `.mbox` 의 검정 테두리가 8px 인데 **ref 는 6px**(x540 실측 740–745)이라
헤더와 카드가 통째로 아래로 밀린 것. 앞 세션은 이걸 요소마다 `top −3px` 로 상쇄해 두었고(측정표 §13 과 어긋남),
그래서 «박스마다 다른 오프셋» 이라는 증상으로 보였다.
- `border-top-width:6px` · `border-bottom-width:6px`(ref 하단 검정 1680–1685 실측)
- `#modal` 은 `align-items:center` 라 **높이를 줄이면 상단도 따라 내려간다** → `padding-top:132 → 127` 로 역산
- 요소 로컬좌표를 **측정표 §13 원값으로 복원**(top 46→49 / 65→68 / 126→129 / 135→138 / 230→233 / 388→390 / 420→419 / 667→670)

### 본문 문구 — ref 는 «한 줄» 이다
4회차 스캔에서 ref 플레이버·효과가 각각 **1줄**(잉크 폭 548 / 615)인데 우리 플레이버가 **2줄**로 넘쳐 있었다.
`RELIC_FLAVOR` 9종을 21~23자로 다시 쓰고, 효과문은 ref 구조(**골드 토큰으로 시작**, 4회차 스캔에서
ref 골드 토큰이 x202~252 = 줄머리)에 맞춰 `<em>스탯명</em>+조사 …` 로 재작성했다.
조사는 받침으로 고르는 `josa()` 를 새로 넣어 «이(가)» 병기를 없앴다(병기하면 줄이 ref 보다 6% 길어진다).

### 기각 — 자체 재측정으로 재현되지 않은 것
- **딤 alpha .63 → .53 (Q③)** — ref 뒷배경은 «유물 그리드 페이지»(밝은 크림), 우리는 «전투 캔버스»(어두움)다.
  **바탕이 다르면 딤 위 최대 휘도로 alpha 를 역산할 수 없다.** R 도 같은 이유로 «불투명도 비교 불가» 로 감점 제외했다 — R 의 판단을 채택.
- **강화 버튼 상단 코너 반경 +3px (Q⑪)** — 행별 dark span 이 y1430 부터 ref 와 **완전 동일**(1430 433..646 · 1431 432..647 · 1432 431..648).
  차이는 최상단 2행의 AA 뿐 → K 방법론(«AA 램프 Δ≤2px 는 JPEG 노이즈») 대로 폐기.
- **배지 높이 −2px (Q⑨)** — 창 (380,1135)-(700,1210) dark bbox: ref 321×59 / cap 321×58 → Δ1. R 도 «298×59 vs 298×58» 로 감점 안 함.
- **아이콘 149 vs 148 · Lv 라벨 +1px · 패널 내폭 +2px (Q⑧⑩⑫ · R⑥⑫)** — 전부 Δ≤2px. 두 비평가가 서로 **반대 방향**으로 ±1px 를 요구한 항목도 있다(R⑫ `border-width +1` ↔ Q⑫ `width −2`).
- **진행바 노란 채움 −2px (R⑦)** — 그 폭은 **캡처 하네스가 ref 상태(1/3)를 만들려고 넣은 `33.3%`** 다. 게임 값이 아니라 채점 대상이 아니다.
- **보유 효과 라벨 잉크 높이 +2px (Q④)** — Q(L>205)는 «+2px», R(L>150)은 «h25 vs h25 완전 일치» 로 **정반대**다.
  자체 측정(L>205·sat<40)은 Q 와 같은 23 vs 25 지만, 폭은 101 vs 101 로 동일해 **fs 를 줄이면 폭이 어긋난다**(서체 잉크/어드밴스 비 차이).
  → 판정 보류, ⑥ 기록만 남긴다.
- **등급 칩 하단 소프트 그림자 3px (R④)** — 재현됨(ref y951~956 L191→196 완만 / cap 195.3 평탄). 다만 배경과의 차가 **최대 5/255(2%)** 라
  ⑤ 항목이고 통과를 막지 않는다. 아트 리소스 적용 시 일괄 반영 대상으로 기록만.
