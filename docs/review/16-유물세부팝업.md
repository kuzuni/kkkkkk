### 이번 회차의 핵심 — «누적 +3px 드리프트» 의 진짜 원인
G⑨⑩ · H⑪ 이 각각 «효과 박스 +4», «플레이버·버튼 +3», «헤더 높이 +2» 로 따로 지적했지만

헤더와 카드가 통째로 아래로 밀린 것. 앞 세션은 이걸 요소마다 `top −3px` 로 상쇄해 두었고(측정표 §13 과 어긋남),
그래서 «박스마다 다른 오프셋» 이라는 증상으로 보였다.
- `border-top-width:6px` · `border-bottom-width:6px`(ref 하단 검정 1680–1685 실측)
- `#modal` 은 `align-items:center` 라 **높이를 줄이면 상단도 따라 내려간다** → `padding-top:132 → 127` 로 역산

### 이번 회차의 핵심 — «줄 높이가 맞는다» 는 착시
1~4회차는 본문에 외곽선이 없어서 **줄 잉크 높이 36 = ref 36** 으로 «맞다» 고 판정해 왔다.
그런데 ref 의 36 은 **«몸통 27~29 + 외곽선»** 이었다. 외곽선을 넣고 나서야 우리 글리프가 43 이 되어
**몸통끼리는 우리가 30% 컸다**는 사실이 드러났다.
- **K 가 제시한 «몸통 27 + 편측 5» 를 그대로 넣었더니(fs29.5·stroke10) 검정 픽셀비가 30.6% → 50.6%** 로
  튀어 **오히려 나빠졌다.** ref 의 편측 5 는 JPEG 번짐을 포함한 값이다.
- 대신 **총 잉크높이(43 → 37)에 맞춰 fs·stroke·scaleX 를 같은 비율(0.86)로 축소**했다:
  `fs 38 → 32.7` · `stroke 6.4 → 5.9/6.1` · `scaleX .72 → .837` / `.75 → .872`.
  결과: 잉크높이 ref 37/39 → cap 37/36, 줄폭 ref 548/615 → cap 542/605,
  **검정 픽셀비 ref 31.3/30.6% → cap 31.6/30.x%**, 중성백 ref 25.2/21.3% → cap 18.0/15.x%.
  (남은 중성백 부족분은 **우리 서체 획이 가늘어서** — 스트로크를 더 줄이면 검정이 ref 아래로 내려간다)

> **교훈**: 외곽선 글자에서 «줄 잉크 높이» 는 **몸통 크기의 지표가 아니다.**
> 외곽선을 뺀 **흰 코어 높이**나, 양쪽에 같은 외곽선을 넣은 뒤의 **총 잉크높이**로 비교해야 한다.

> **교훈 2 (K 의 방법론)**: 테두리 두께 지적이 비평가마다 정반대로 나오면 임계값 문제다.
> **AA 램프의 50% 교차점**을 ref/cap 에 동일 적용하고 **Δ≤2px 는 JPEG 노이즈로 버린다.**
