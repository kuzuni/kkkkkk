### 1회차에 잡은 함정 2개 (다른 화면에서도 재발한다)

1. **행 자식을 전부 `position:absolute` 로 빼면 행 높이가 0 이 된다.** pitch 가 `margin-bottom` 값(20px)으로
   붕괴해 24행이 한 덩어리로 겹쳤다. 행 높이를 만드는 요소(여기서는 말풍선·카드)는 **흐름 안에 남겨야** 한다.
2. **그 요소의 세로 오프셋을 `margin-top` 으로 주면 마진이 행 밖으로 상쇄(collapse)된다.**
   `margin-top:49` 로 줬더니 49 가 행 사이 gap 에 합쳐져 pitch 가 132 → **144** 로 늘어났다(bbox 는 여전히 +49 라
   «버블 top» 검사만으로는 안 잡힌다). 49 를 **행의 `padding-top`** 으로 옮겨 해결 — absolute 자식의 기준은
   padding box 라서 아바타·이름줄의 `top:0` 은 그대로 행 top 을 가리킨다.
   → **게이트는 «요소 bbox» 만 보지 말고 «행 pitch» 를 같이 봐야 한다.** 1번은 pitch 로만 잡혔다.

### 원인 — **전역 클래스명 충돌** (`.cl`)

21 도감 팝업이 쓰는 **전역** 규칙이 그대로 내 카드 우칸에 걸렸다:

```css
.cl{position:relative;flex:none;width:895px;height:1543px;max-height:100%;
    border:solid #000;border-width:8px 5px 5px;  transform:translateY(-42px)}
```

- `transform:translateY(-42px)` → 우칸만 42px 위로 (X D1·D2·D3, Y D1·D2)
- `border-width:8px 5px 5px` → 칸 사이 «검정 5px 구분선» (X D5 — 레퍼런스는 0px)
- 같은 좌 5px 테두리가 우칸 내용을 밀어 아바타 중심 +4.5px (X D8, Y D7 후반)

즉 **비평가가 잡은 6건이 전부 이 한 줄의 파생**이었다. 「우칸만 짧다 / 아바타가 잘린다 /
이름줄·전투력줄이 −34~38px / 구분선 5px / 아바타 중심 +4.5px」가 한 원인으로 수렴한다.

> **교훈**: 이 파일은 CSS 가 한 덩어리라 **두 글자짜리 클래스명(`.cl`·`.cw`·`.av`·`.nk`·`.cp`·`.bg`)은
> 이미 임자가 있다.** 새 화면의 부품은 **전부 화면 프리픽스**(`ch-`)를 붙인다.
> 109(중복 키 `n`)와 같은 종류의 사고이고, 이번엔 «전역 셀렉터 충돌» 판이다.
> 게이트에 «두 칸의 top 일치·구분선 0px» 를 박아 재발을 막았다.
