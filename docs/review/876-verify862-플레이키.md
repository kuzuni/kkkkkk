  띠(6px)만큼 안으로 들어가(862 수리) **띠 기둥 [카드.x, 카드.x+6] 을 안 덮는다** → 액자선 잔존 100%.

## 3. 처방 — 위상 고정(deterministic phase-pin)

`#fxl` 의 모든 애니를 **선언으로** 정지한다:

```
#fxl, #fxl * { animation-play-state: paused !important }
```

SHOT 이 스텁·nogain 스타일을 넣는 자리(가장 위)에 같이 주입해, `rwSummonFx`/`fxFlash` 가 만드는 애니가
«지금 생기든 나중에 생기든» **첫 프레임(0%)에서 멈춘 채로 태어나게** 한다 — `getAnimations()` 타이밍과 무관해진다.
실제 위상은 기존 WAAPI 루프(`currentTime = T`)가 이중으로 못박는다.

  잡음이라 **캡처에서만** 숨겼다(`.fx-toast{display:none}`). 제품 불변.
