## 1. 무엇이 문제였나 — «홍보 · 착지 · 상품» 세 층이 어긋나 있었다

01 오프라인 보상 팝업 아래쪽 배너는 세 부분이 한 덩어리다(`index.html` ~11581).

```html

<div class="ofr-t2 s"><i>4시간 증가</i></div>
```

그런데 버튼은 `closeOfflineReward(); openShopPage();` 였고(~23979), `openShopPage()` 는
**열 때마다 `shopCat = 'summon'` 으로 강제 리셋**한다(~19253). 즉 «오프라인 보상 +4시간» 을
사겠다고 누른 사용자가 **소환 상자 15개가 깔린 소환 탭**에 떨어졌다. 광고 제거·자동 축복 같은
이용권 상품은 124 가 신설한 **«이용권» 탭**(`shopCat === 'pass'`)에만 있고, 홍보 대상인
«오프라인 보상 최대 시간 4시간 증가» 카드는 **151** 이 그 탭에 넣을 예정이다.

- **표기(홍보 문구)** — «4시간 증가», 이용권 상품
- **착지(버튼)** — 소환 탭 ← 여기만 어긋나 있었다
- **상품(카드)** — 이용권 탭(124 · 151)

LESSONS «156 비고» 2 의 «표기 · 지급 · 이펙트 세 층» 과 같은 모양이다. 여기서 진실로 삼을 층은
**표기와 주인 지시**(= 이용권 판매처)이므로 **착지를 고쳤다.**

작업 68 이 이 버튼을 «구버전 파란 패널 상점» 에서 10 상점 페이지로 옮겼을 때, 그 페이지에는
아직 이용권 탭이 없었다(124 는 그 뒤 작업이다). 68 의 수정은 그 시점에는 맞았고, **124 가
상품을 새 탭으로 옮기면서 이 버튼만 따라가지 않은 것**이다.

## 2. 고친 것 (3곳, 전부 `index.html`)

### ① `SHOP_CATS` 신설 (~19249)

```js
const SHOP_CATS = ['summon', 'coin', 'pass'];
```

`#shopCats` 의 `data-cat` 3종과 «한 벌» 이다. 모르는 값이 들어오면 `summon` 으로 폴백한다 —
탭이 늘거나 줄었는데 여기를 안 고치면 착지 탭이 **조용히 무시**되므로 주석에 그 짝을 적어 뒀다.

### ② `openShopPage(focus, cat)` — 착지 탭 인자 (~19254)

```js
function openShopPage(focus, cat){
  …
  shopCat = SHOP_CATS.indexOf(cat) >= 0 ? cat : 'summon';
  setShopCatTabs(shopCat);
  renderShopPage();
  …
  if(focus && shopCat === 'summon'){ … }   /* 73 ① 카드 스크롤 */
}
```

**«열고 나서 탭을 바꾸는» 순서를 쓰지 않은 이유**: 그러면 `renderShopPage()` 가 두 번 돈다
(소환 한 번 + 목적 탭 한 번). 소환 탭 렌더는 상자 15개 + 배너 카드라 가볍지 않고, 무엇보다
**한 프레임 동안 소환 탭이 보였다가 갈아 끼워지는 깜빡임**이 난다. 인자로 받아 한 번만 그린다
(게이트 [E] 가 이 «1회» 를 못 박는다).

`focus`(73 ① 가이드 배너용 상자 키)는 **소환 탭의 카드 순번**이라 다른 탭에서는
`li.children[i]` 가 엉뚱한 노드를 가리킨다 → `shopCat === 'summon'` 일 때만 쓰도록 묶었다.
기존 호출부는 전부 인자 1개(`openShopPage()` · `openShopPage('shield')` 등 8곳)라 **거동이 안 바뀐다.**

### ③ `openShopTab(cat)` 공용 헬퍼 + `ofrGo` 연결 (~19274 · ~23990)

```js
function openShopTab(cat){ openShopPage(null, cat); }
…
$('ofrGo').onclick = () => { closeOfflineReward(); openShopTab('pass'); };
```

PROGRESS 등재문이 «157(축복 프로모 [이동] → 이용권 탭)과 같은 «상점을 특정 탭으로 열기» 헬퍼가
필요하다» 고 적어 둔 그 헬퍼다. **157 은 다른 작업 단위라 손대지 않았다** — 그 세션이 이
한 줄(`openShopTab('pass')`)만 쓰면 된다.
