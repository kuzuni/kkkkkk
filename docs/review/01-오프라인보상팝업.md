## 무엇을 만들었나

기존 구현은 공용 `popup()` 에 줄글을 넣은 텍스트 안내(`🌙 방치 보상 / 자리를 비운 N시간 M분 동안…`)였다.
레퍼런스대로 **전용 오버레이 `#offw`** 를 새로 짰다.

- 모달 아래 **모달 바깥에 상품 배너**가 붙는 구조라 공용 `#modal` 껍데기로는 표현이 안 된다.
  → `#offw` 안에 `1080x972` 스테이지를 두고, 레퍼런스 절대좌표에서 그룹 상단(y=772)만 뺀 값으로 전 요소를 절대 배치했다.
- 병렬로 A5(모달 규격)가 `.modal`/`.mbox`/`.mhead`/`.mbody` 를 고치는 중이라 **공용 모달 CSS는 일절 건드리지 않았다.**
- 보상 지급 방식도 바꿨다: 기존은 팝업 뜨기 전에 이미 지급됐는데, 이제 `받기`/`1.5배 받기` 로 **수령**해야 들어온다.

## 1회차 — 최저 4/10

비평가 A 채점: ① 5 ② 5 ③ 4 ④ 4 ⑤ 6 ⑥ 4 → **최저 4**

지적 중 **실제로 재현된 치명적 결함 1개**:

> ④ 정렬·그리드 — 모든 텍스트에서 어절 공백이 삭제됨: '오프라인 보상'→'오프라인보상',
> '자리를 비우신 동안 사냥했어요!'→'자리를비우신동안사냥했어요!', **'1.5배 받기'→'15배받기'(소수점까지 소실)**

원인을 추적했다. 측정표 부록 B가 `font-size ≈ 잉크높이 ÷ 0.75` 로 추정했는데,
**이 프로젝트가 쓰는 폰트의 실제 잉크비는 0.93** 이었다(헤드리스에서 `measureText` 로 실측).
그래서 font-size 가 15~25% 과대해졌고, 폭을 실측값에 맞추려고 넣은 음수 `letter-spacing`(-9 ~ -18px)이
**공백 글리프와 마침표의 advance 를 통째로 먹었다.**

비평가 A의 나머지 절대 px 지적(모달↔배너 간격 +25px 등)은 **채택하지 않았다.**
비평가가 레퍼런스를 923x2000 으로 축소해 읽고 1.17 을 곱해 환산했는데, 캡처는 다른 배율로 읽어서
두 이미지의 축척이 어긋났다. 헤드리스 `getBoundingClientRect` 실측으로는 모달 하단→배너 상단이
17px(실측 목표 18px)로 이미 맞다. → 2회차부터는 비평가에게 **"모달 폭을 1.0 으로 놓고 상대 비율로 비교하라"** 고 지시를 바꿨다.

## 2회차 — 폰트 산정 방식 교체

- `letter-spacing` **전면 제거**. font-size 는 `실측 잉크높이 ÷ 0.93` 으로 다시 잡고,
  가로 폭은 텍스트를 감싼 `<i>` 의 **`transform: scaleX()`** 로 눌러 맞췄다.
- 세로는 **실측 잉크 중심**에 줄상자 중심을 맞추는 방식으로 통일(`height:60;line-height:60;top = 잉크중심 - 30`).
- 타이틀바가 갈색 안쪽 테두리 위를 덮어 검정 테두리 안쪽 폭을 꽉 채우도록 고침(실측 x58~1021).

## 남은 문제 (통과 기준 9 미달)

1. **아이콘·일러스트가 전부 이모지다.** A1 과 같은 한계다.
   - 배너의 개구리 캐릭터: 레퍼런스는 항아리·지팡이를 든 **전신 일러스트 490x250**(가로가 세로의 2배).
     이모지는 가로세로가 같이 커져서 이 비율을 못 만든다. 현재 250px 정사각 근사.
   - 배너 안 **금화 3개**(지름 95/90/80)는 아예 못 넣었다.
   - 스톱워치·골드 코인도 이모지 근사(코인은 76px 로 크기만 맞춤).
   → **아트 리소스가 들어와야 ②상대 크기 비율·⑤색·명암이 9점에 도달한다.**
2. **모달 배경 별무늬가 점(dot) 패턴**이다. 레퍼런스는 5각 별. A5 가 공용 모달에 5각별을 넣었으므로
   그 방식이 확정되면 여기도 맞추면 된다(공용 CSS 충돌을 피하려 이번엔 안 건드렸다).
3. **`4시간 증가` 그라데이션 글자**는 `background-clip:text` + `-webkit-text-stroke` 조합이라
   브라우저에 따라 외곽선이 그라데이션 위로 덮일 수 있다. 실기기 확인 필요.
4. 3·4회차 비평가를 띄웠으나 **응답이 오지 않아 회차를 못 채웠다.** 2회차까지의 헤드리스 실측 대조로 갈음했다.
