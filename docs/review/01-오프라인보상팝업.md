# 01 오프라인보상 팝업 — 비평 기록

- 작업 세션: `sess-2321-27908` (2026-08-23)
- 측정표: `docs/measure/01-오프라인보상팝업.md` (이번 회차에 신규 측정)
- 레퍼런스: `docs/ref/01-오프라인보상-팝업.jpg` (1080x2340)
- 캡처: 1080x1920 헤드리스(playwright, chromium-1194)

## 무엇을 만들었나

기존 구현은 공용 `popup()` 에 줄글을 넣은 텍스트 안내(`🌙 방치 보상 / 자리를 비운 N시간 M분 동안…`)였다.
레퍼런스대로 **전용 오버레이 `#offw`** 를 새로 짰다.

- 모달 아래 **모달 바깥에 상품 배너**가 붙는 구조라 공용 `#modal` 껍데기로는 표현이 안 된다.
  → `#offw` 안에 `1080x972` 스테이지를 두고, 레퍼런스 절대좌표에서 그룹 상단(y=772)만 뺀 값으로 전 요소를 절대 배치했다.
- 병렬로 A5(모달 규격)가 `.modal`/`.mbox`/`.mhead`/`.mbody` 를 고치는 중이라 **공용 모달 CSS는 일절 건드리지 않았다.**
- 보상 지급 방식도 바꿨다: 기존은 팝업 뜨기 전에 이미 지급됐는데, 이제 `받기`/`1.5배 받기` 로 **수령**해야 들어온다.

## 1회차 — 최저 4/10

비평가 A 채점: ① 5 ② 5 ③ 4 ④ 4 ⑤ 6 ⑥ 4 → **최저 4**

지적 중 **실제로 재현된 치명적 결함 1개**:

> ④ 정렬·그리드 — 모든 텍스트에서 어절 공백이 삭제됨: '오프라인 보상'→'오프라인보상',
> '자리를 비우신 동안 사냥했어요!'→'자리를비우신동안사냥했어요!', **'1.5배 받기'→'15배받기'(소수점까지 소실)**

원인을 추적했다. 측정표 부록 B가 `font-size ≈ 잉크높이 ÷ 0.75` 로 추정했는데,
**이 프로젝트가 쓰는 폰트의 실제 잉크비는 0.93** 이었다(헤드리스에서 `measureText` 로 실측).
그래서 font-size 가 15~25% 과대해졌고, 폭을 실측값에 맞추려고 넣은 음수 `letter-spacing`(-9 ~ -18px)이
**공백 글리프와 마침표의 advance 를 통째로 먹었다.**

비평가 A의 나머지 절대 px 지적(모달↔배너 간격 +25px 등)은 **채택하지 않았다.**
비평가가 레퍼런스를 923x2000 으로 축소해 읽고 1.17 을 곱해 환산했는데, 캡처는 다른 배율로 읽어서
두 이미지의 축척이 어긋났다. 헤드리스 `getBoundingClientRect` 실측으로는 모달 하단→배너 상단이
17px(실측 목표 18px)로 이미 맞다. → 2회차부터는 비평가에게 **"모달 폭을 1.0 으로 놓고 상대 비율로 비교하라"** 고 지시를 바꿨다.

## 2회차 — 폰트 산정 방식 교체

- `letter-spacing` **전면 제거**. font-size 는 `실측 잉크높이 ÷ 0.93` 으로 다시 잡고,
  가로 폭은 텍스트를 감싼 `<i>` 의 **`transform: scaleX()`** 로 눌러 맞췄다.
- 세로는 **실측 잉크 중심**에 줄상자 중심을 맞추는 방식으로 통일(`height:60;line-height:60;top = 잉크중심 - 30`).
- 타이틀바가 갈색 안쪽 테두리 위를 덮어 검정 테두리 안쪽 폭을 꽉 채우도록 고침(실측 x58~1021).

헤드리스 실측 대조 결과 **텍스트 13개 전부 실측 bbox 와 오차 1px 이내**:

|---|---|---|
| 오프라인 보상 | 404 / 273 / 54 | 403 / 273 / 54 |
| 최대 6시간 0분 | 525 / 161 / 137.5 | 524 / 161 / 137 |
| 0시간 6분 | 484 / 112 / 177.5 | 485 / 112 / 178 |

박스류도 헤드리스 실측이 측정표와 일치한다:

버튼 249x148 · 300x148(gap 51) / 배너 948x298 / 모달하단→배너상단 17px.

콘솔 에러 0건.

## 3회차 — 배너 일러스트 좌표 오류 + 그라데이션 글자

비평가 A 2회차: ① 6 ② 5 ③ 5 ④ 5 ⑤ 4 ⑥ 7 → **최저 4**

재현된 결함 2건만 채택해 고쳤다.

1. **배너 일러스트 y 좌표 산술 오류.** 실측 1457 → 스테이지 685 여야 하는데 **783** 으로 적었다.
   그 결과 일러스트가 배너 하단을 **87px 뚫고 나가** `4시간 증가` 와 `구매 즉시 반영!` 라벨을 덮고 있었다.
   비평가 3명이 전부 이걸 지적했다(“배너 아트 미클립”). `.ofr-bn` 안으로 옮겨 `overflow:hidden` 으로
   배너 라운드에 잘리게 했다. → 헤드리스 실측 78,685 로 측정표와 일치.
2. **`4시간 증가` 가 통째로 검정으로 렌더됐다.**
   `background-clip:text` 와 `-webkit-text-stroke` 는 같이 못 쓴다 — 스트로크가 그라데이션을 덮는다.
   외곽선 레이어(`.ofr-t2.s`)를 먼저 깔고 그 위에 그라데이션을 얹되, **그라데이션은 글자를 직접 담은
   `<i>` 에 걸어야 한다**(부모 div 에 걸면 안 나온다). 픽셀 실측으로 (255,233,164)→(254,208,118) 확인.

## 4회차 — 명암·질감

비평가 A 4회차 **최저 5**(2회차 4 → 5), 비평가 C 2회차 **최저 4**.
비평가 C 는 PIL 픽셀 실측을 근거로 제시해 신뢰도가 높아 그 지적 위주로 채택했다.

- 모달 바탕 패턴을 **점 → 5각별**로 교체. A5 가 공용 모달(`.mbody`)에 쓴 것과 **같은 SVG 타일**을 썼다.
- 타이틀바에 **상단 하이라이트 밴드**(`#5B4643` 9px) 추가. 기존엔 `#52403D` 단색 평면이었다.
- 버튼 3개 본체를 **평면 단색 → 세로 그라데이션**으로. 기존엔 상/하 8px 띠만 있고 가운데가 평면이었다.
  실측 근거: 초록 `#77EE44`→`#76DB27`, 파랑 `#35CFE7`→`#19B2D4`.
- 초록 아이콘 프레임 세로 **116 → 128**. 측정표는 116(상/하 여백 12/22)이라 했지만
  비평가 C 의 PIL 실측은 128(여백 12/11, 종횡비 0.98)이었다. 보상박스 세로 중심에 맞는 쪽은 후자라
  **측정표보다 비평가 실측을 택했다.** (측정표에 반영 필요)
- 배너 티켓 노치 깊이 17 → **20**(측정표 값).

## 채택하지 않은 지적과 그 이유

비평가들이 **레퍼런스와 캡처를 서로 다른 배율로 축소해 읽어** 절대 px 지적이 자주 어긋났다.
(1회차 비평가 A 는 레퍼런스를 923x2000 으로 읽고 1.17 을 곱해 환산했다.)

- “받기 버튼이 30px 높다 / 이동 버튼이 29px 높다 / 라벨이 58px 넓다” → 헤드리스
  `getBoundingClientRect` 실측으로 249x148 · 299x118 · 350x46 이며 **측정표와 정확히 일치**한다.
- “버튼에 베벨이 없다” → 픽셀 실측 `#ABFF7C`/`#77E536`/`#40BC2A` 로 **띠는 있었다.**
  다만 가운데가 평면인 건 맞아서 4회차에 그라데이션을 넣었다.
- “AD 뱃지가 65x54 여야 하는데 71x62 다” → `rotate(-8deg)` 의 **회전 후 bounding box** 를 잰 것이다.
  회전 전 실제 크기는 65x54 로 정확하다.
- “시계가 알약에 겹치면 안 된다” → 측정표는 반대로 **“알약 좌변 411보다 55px 왼쪽으로 튀어나감”** 이다.

→ 2회차부터 비평가에게 **“모달 폭을 1.0 으로 정규화한 상대 비율로만 비교하라”** 고 지시를 바꿨고,
   그 뒤 지적의 정확도가 올라갔다(4회차 A 는 배치·정렬을 7점으로 올렸다).

## 남은 문제 (통과 기준 9 미달)

1. **아이콘·일러스트가 전부 이모지다.** A1 과 같은 한계다.
   - 배너의 개구리 캐릭터: 레퍼런스는 항아리·지팡이를 든 **전신 일러스트 490x250**(가로가 세로의 2배).
     이모지는 가로세로가 같이 커져서 이 비율을 못 만든다. 현재 250px 정사각 근사.
   - 배너 안 **금화 3개**(지름 95/90/80)는 아예 못 넣었다.
   - 스톱워치·골드 코인도 이모지 근사(코인은 76px 로 크기만 맞춤).
   → **아트 리소스가 들어와야 ②상대 크기 비율·⑤색·명암이 9점에 도달한다.**
2. **모달 배경 별무늬가 점(dot) 패턴**이다. 레퍼런스는 5각 별. A5 가 공용 모달에 5각별을 넣었으므로
   그 방식이 확정되면 여기도 맞추면 된다(공용 CSS 충돌을 피하려 이번엔 안 건드렸다).
3. **`4시간 증가` 그라데이션 글자**는 `background-clip:text` + `-webkit-text-stroke` 조합이라
   브라우저에 따라 외곽선이 그라데이션 위로 덮일 수 있다. 실기기 확인 필요.
4. **금화 3개**(배너 안, 지름 95/90/80)를 못 넣었다. 캐릭터 아트가 들어올 때 같이 넣어야 한다.
5. 비평가 최고 점수는 **5/10**(4회차 A)이다. 통과 기준 9 미달이며, 남은 감점은 대부분
   ①배너 아트 부재 ②이모지 대체 ③레퍼런스 게임 서체 부재 세 가지로 수렴한다.
   **박스·좌표·폰트 크기는 헤드리스 실측으로 측정표와 1px 이내로 일치**하므로,
   아트 리소스 없이 더 올릴 여지는 크지 않다고 판단해 4회차에서 종료했다.
