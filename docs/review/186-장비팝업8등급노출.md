## 3. 자리를 «카드 안 빈 띠» 로 정한 이유 (기하 무회귀)

05 는 이미 ①~④ 8점을 받은 화면이다. 새 글자를 넣되 **칸을 1px 도 움직이지 않는** 자리는 하나뿐이었다:

```
카드(padding box 138×148) 세로 점유
   8 ~ 108   .ic     아이콘 상자 (실제 글리프 잉크는 y25~91)
  38 ~  93   .lock   자물쇠 49×55
  49 ~  81   .eqt    «장착 중»(보유 칸만)
 114 ~ 148   .pb     하단 재료 진행바
  ────────── 93 ~ 114 = 21px 이 유일한 빈 띠
```

→ `.ulk{top:94px;height:20px;font-size:20px}` (실측 top 99 / bottom 119, 자물쇠 bottom 98 · 진행바 top 119).
글자 크기 20 은 옆에 있는 `.pb>i`(0/N)와 같은 값이라 이 칸 안에서 새 눈금을 만들지 않는다.

**배경을 깔지 않은 것이 이 절의 핵심이다.** `tools/verify82.js` §0 이 **05 잠금 카드**를 캘리브레이션
기준으로 쓰는데, 그 프로브는 «아이콘을 숨겼을 때 달라지는 픽셀 비율» 이다. 새 요소에 배경이 있으면
아이콘 잉크를 가려 **05 의 기준값이 내려가고 스킬·펫 판정 하한(중앙값/2)이 통째로 흔들린다.**
투명 글자 + 아이콘 잉크(y25~91) 바깥 배치라 두 캡처에 똑같이 찍힌다 → 차분 기여 0.
실측으로도 `VERIFY82 14/14` 무변화(05 기준 최저/중앙/최고 그대로).
