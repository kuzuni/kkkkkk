#### A1 비고 (통과 기준 9 미달 — 남은 문제)

1. **아이콘이 이모지다.** 레퍼런스는 칸마다 폭이 다른 일러스트(영웅121·성장150·모험109·보물상자125·상점165)라
   칸별 font-size 로 근사했지만, 이모지는 가로세로가 같이 커져 **가로로 넓은 아트(상점 165×115)를 재현할 수 없다.**
   → 아트 리소스가 들어와야 ② 상대 크기 비율이 9점에 도달한다.
2. **라벨 2글자 폭이 +9%** (61 vs 56). 4글자('보물상자')는 120 vs 121 로 일치해서, 자간을 더 줄이면 4글자가 어긋난다.
   레퍼런스의 **좁고 높은 게임용 한글 서체**를 웹폰트로 넣기 전에는 트레이드오프다.
3. 탭바 **바로 위 보라색 튜토리얼 배너**(`#tuto` 의 `border:3px solid #6d54ad`)는 레퍼런스에 없다.
   **A1 구간이 아니라 손대지 않았다** — 별도 작업 단위에서 처리할 것.
4. NEW 리본 기울기는 측정(−22°)과 비평가 실측(−8° / −20.6°)이 엇갈려 **−20°** 로 정했다.

> 참고 — 이번에 잡은 CSS 함정 2개 (다른 화면에서도 그대로 재발한다):
> - **글리프 advance 보다 좁은 박스**에 `text-align:center` 를 쓰면 넘친 글리프가 가운데가 아니라 **좌측 정렬**돼
>   잉크가 우측으로 밀린다. 아이콘 박스는 advance 보다 넓게 잡을 것.
> - `*{box-sizing:border-box}` 리셋은 **의사요소(::before/::after)를 잡지 못한다.** 테두리를 준 의사요소는
>   `box-sizing` 을 직접 써 주지 않으면 테두리 두께만큼 커지고 중심이 밀린다.

**주의 — 이전 세션의 `#legacy{transform:scale(2)}` 스캐폴드 방식은 저장소 주인이 revert 했다.**
(래퍼를 통째로 scale(2) 하는 방식은 프레임 아래쪽에 검은 띠가 남는다)
이번에는 스캐폴드 없이 **CSS px 값을 실제로 2배**하고 **캔버스가 남는 높이를 흡수**하도록 했다. 되돌리지 말 것.

## 병렬 세션 규칙 (2026-08-24 도입)

여러 세션이 **동시에** 돈다. 전부 `index.html` 한 파일이므로 **작업 단위로 선점**해서 나눈다.

1. 작업 선택은 **티어 순**: **T1** 【⚑ 우선】 → **T2 주인 지시 TODO(24~36 — 설계 변경·신규 기능. 일반
   화면 루프보다 먼저)** → **T3** 한 번도 구현 안 된 일반 화면(`docs/review/<ID>-*.md` 없음 — 이게 남아
   있으면 재폴리시 금지) → **T4** 2차 폴리시 라운드(점수 낮은 순). 같은 티어 안은 표 순서, 대상은 항상
   미완료 + lock 없음. **통과·최종 목표는 전 화면 8점(2026-08-25 통과 기준 9→8 하향)**이되, 화면당 라운드
   상한 10회(세션 합산)를 채우면 «⏸ 보류» 하고 다음 화면으로 — 전 화면 커버 후 T4 에서 8점을 채운다. 아트/서체 한계 화면은
   «보류(아트 대기)». 상세: `ROUTINE.md` [-1]·[3] (골고루 규칙).
2. `docs/claims/<ID>.lock` 에 `<UTC시각> <세션식별자>` 한 줄을 쓰고 **커밋 + push**.
   - push 가 거부되면 `git pull --rebase` 후 다시 본다. 내 lock 이 아닌 남의 lock 이 생겼으면 **그 작업은 포기하고 다음 것**을 잡는다.
3. 잡은 작업의 코드 구간만 건드린다. **다른 작업 구간은 절대 손대지 않는다.**
4. 끝나거나 중단하면 성공·실패 무관하게 lock 을 **삭제**하고 push.
5. **50분 넘은 lock 은 죽은 것으로 보고 뺏는다**(회차마다 heartbeat 갱신 의무, 2026-08-25 90→50).
6. 비평 기록은 `docs/review/<ID>-이름.md` 에 **자기 파일로만** 쓴다 (공용 `review-log.md` 에 추가 금지).
7. push 전 항상 `git pull --rebase origin main`. `index.html` 이 충돌하면 **양쪽 변경을 모두 살린다**
   (서로 다른 구간이라 대부분 자동 병합됨). 병합 후 반드시 문법 검사 + **`node tools/smoke.js` PASS**(2026-08-25 필수 게이트).
   회차마다 `wip(<ID>)` 커밋 + lock 시각 갱신(heartbeat). 죽은 lock 판정은 **50분**.
8. `PROGRESS.md` 는 유일한 공용 파일이다. 충돌하면 **양쪽 행을 모두 살린다.**
