## 병렬 세션 규칙 (2026-08-24 도입)

여러 세션이 **동시에** 돈다. 전부 `index.html` 한 파일이므로 **작업 단위로 선점**해서 나눈다.

1. `docs/claims/<ID>.lock` 이 없는 **가장 앞 순서의 미완료 작업**을 잡는다 (아래 «작업 단위» 표 순서대로).
2. `docs/claims/<ID>.lock` 에 `<UTC시각> <세션식별자>` 한 줄을 쓰고 **커밋 + push**.
   - push 가 거부되면 `git pull --rebase` 후 다시 본다. 내 lock 이 아닌 남의 lock 이 생겼으면 **그 작업은 포기하고 다음 것**을 잡는다.
3. 잡은 작업의 코드 구간만 건드린다. **다른 작업 구간은 절대 손대지 않는다.**
4. 끝나거나 중단하면 성공·실패 무관하게 lock 을 **삭제**하고 push.
5. **90분 넘은 lock 은 죽은 것으로 보고 뺏는다.**
6. 비평 기록은 `docs/review/<ID>-이름.md` 에 **자기 파일로만** 쓴다 (공용 `review-log.md` 에 추가 금지).
7. push 전 항상 `git pull --rebase origin main`. `index.html` 이 충돌하면 **양쪽 변경을 모두 살린다**
   (서로 다른 구간이라 대부분 자동 병합됨). 병합 후 반드시 문법 검사 + 헤드리스 실행으로 확인.
8. `PROGRESS.md` 는 유일한 공용 파일이다. 충돌하면 **양쪽 행을 모두 살린다.**

## 결정 사항 / 미결 사항

- **확정(2026-08-24 변경)**: 기준 해상도 **1080×1920 (9:16)**, 폭 고정·세로 가변, 안전영역은 프레임 바깥 흡수
  (레퍼런스 캡처는 1080×2340 이지만 폭이 같으므로 **가로 수치는 1:1**, 세로 차이 420px 은 전투 캔버스가 흡수.
   전체를 1920/2340 으로 축소하지 말 것)
- **확정**: 전투 캔버스는 **월드 상수를 2배로 고치지 않고** `ctx.setTransform(2,0,0,2,0,0)` 로 확대한다
  (논리 좌표계는 계속 540 기준. `VW=540`, `VH = stagearea.clientHeight / 2`. 밸런스 영향 없음)
- **주의**: 기준이 9:16 이 되면서 사이드 아이콘 좌6 은 **캔버스 861px 안에 안 들어감**(756 필요, 여유 부족) — 아이콘 높이·gap 을 캔버스 높이에 비례시킬 것
- **미확인**: 노치 실기기에서 안전영역 동작 (헤드리스는 `env()` 가 항상 0)
- **미결**: 캐릭터 2명(햄지·매옹이) 구조로 갈지 1명 유지할지 — 6·20번 화면에 영향
- **미결**: 색·폰트(⑤⑥) 채점 포함 여부 — 아트 리소스 한계로 9점이 안 나오면 제외 검토
