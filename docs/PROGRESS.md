**지금 작업 중**: 화면 1 (오프라인보상 팝업) — 측정 서브에이전트 결과 대기 중

**이번 세션에서 한 일 (A 기초)**:
- `#app` 를 `540×960` → `1080×2340`(가변, clamp 1600~2600) 프레임으로 확장
- 기존 UI 전체를 `#legacy` 래퍼(540×960, `scale(2)`)로 감싸 1080 프레임 안에 그대로 얹음 —
  **로직·좌표·캔버스는 전혀 안 건드림, 회귀 없음.** 앞으로 화면별로 이 안의 조각을 하나씩
  1080좌표 신규 마크업으로 교체해 나가는 전략. 상세는 `UI-REFERENCE.md` 24-A 참고
- `#wrap` safe-area 패딩, `fit()` 을 `wrap.clientWidth/Height` 기준 + `visualViewport` resize 대응으로 교체
- `#app{flex:none}` 누락으로 좁은 뷰포트에서 프레임이 강제로 쪼그라드는 버그 발견·수정
- 헤드리스(playwright, `/opt/pw-browsers/chromium`)로 9:16/9:18/9:19.5/9:21/4:3 렌더 확인, 콘솔 에러 없음, 탭 클릭·모달 열기 등 인터랙션 정상 확인
