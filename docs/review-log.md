## A. 레이아웃 기초 (프레임 1080×2340 · 화면비 · 안전영역) — 2026-08-23

화면별 채점(①~⑥)이 아니라 **깨짐 검수**로 진행. 이 단계는 레이아웃 '재구성'이 아니라
'프레임 확대 + 세로 가변'만이라 레퍼런스와의 구성 차이는 채점 대상이 아니다.

### 1회차 — 미통과 (깨짐 2건)
- `최고 N` 배지: 글자 높이 **9px**, 형제 `1-1 스테이지`는 **22px** → 혼자 절반 크기
- 상점 아바타 셀 이모지: **20×22px**, 라벨(19px 폰트)과 같은 크기 → 약 20px 작음
- 원인: **`<style>` 블록만 2배 변환**하고 **JS 인라인 `font-size` 는 하나도 변환 안 됨**
  (미변환 위치: `1836`, `2434`, `2511`, `2514`, `2543`, `2544`, `2569`, `2581`, `2689`)
- 통과한 항목: 텍스트 잘림·겹침 0건 / 검은 띠 0건 / 캔버스가 남는 세로 정확히 흡수
  (2340→1161px, 1920→741px, 차이 420px = 프레임 차이 420px) / 사이드 아이콘 넘침 없음 /
  탭바가 프레임 하단에 0px 오차로 밀착 / 화면비를 바꿔도 캔버스 외 요소는 픽셀 diff 0
