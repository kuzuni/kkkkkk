# A1 — 하단 탭바 측정표

레퍼런스 `docs/ref/02·05·10·23`(1080×2340) 실측. **폭이 1080 으로 같으므로 가로·세로 모두 1:1 절대 px.**
탭바는 고정 요소이므로 세로 값도 변환 없이 그대로 쓴다. (재측정 금지)

좌표는 두 가지로 적었다 — `y(원본)` 은 2340 캡처 기준, `+n` 은 **탭바 상단(y=2160) 기준 오프셋**이며 구현에서 쓰는 값이다.
