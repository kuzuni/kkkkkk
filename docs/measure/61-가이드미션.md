# 61 가이드 미션 배너 측정표 — **미완료(진행중) 상태** · 02 보상받기 상태와의 DIFF

- 측정 일자: **2026-08-25**
- 레퍼런스: `docs/ref/32-가이드미션-미완료-상태.jpg` (1080×2340)
- 비교 대상: `docs/ref/02-기본-메인-화면.jpg` (1080×2340) — **보상받기(수령 가능) 상태**
- 비교 대상 수치는 `docs/measure/02-기본-메인-화면.md` **§4** 를 그대로 인용한다(재측정하지 않음).
- 측정 방식: JPEG 원본 디코드(`jpeg-js`) 후 **픽셀 직접 스캔** — 행/열 색전이 추적 + 색 마스크 bbox + 라운드 코너 원호 역산.
  → 별도 표기가 없는 값은 전부 **[실측]**. `[추정]` 은 기하 역산·최소자승 추정.
- 좌표는 **1080×2340 절대 px**. `프레임 y` 열은 **`ref y − 84`** (프레임 1080×2280, 가로 1:1).
  구현이 실제로 쓰는 `#stagearea` 기준 값은 02 표와 같은 규칙(`bottom = 2160 − ref_bottom`)으로 별도 표기한다.

> **결론 한 줄**: 배너 **바깥 상자는 두 상태가 동일**(x 620..1080 / y 1840..1989 / radius 26 / 우측 bleed).
> 바뀌는 것은 **채움(불투명 금색 → 반투명 검정)·테두리(검정 5 → 없음)·텍스트 3줄 구성·보상 박스 색**이다.

### 1-1. 채움 — **반투명 검정 (그라디언트 아님)** ★

02 는 **불투명 금색 세로 그라디언트 4단**, 32 는 **바닥 타일이 그대로 비쳐 보이는 반투명 검정 1단**이다.
(배너 내부 x621~945 구간에서 벽돌 이음매가 그대로 관찰된다 → 반투명 확정)

| 항목 | 값 |
|---|---|
| 합성식 추정 | `out = bg·(1−α) + C·α`, 상단쌍(y1834↔1846)·하단쌍(y1996↔1982) 최소자승 |
| **α** | R 0.54 / G 0.58 / B 0.55 (상단), R 0.62 / G 0.68 / B 0.62 (하단) → **평균 α ≈ 0.55** `[추정]` |
| **C (오버레이 색)** | (7, 8, 0) ~ (27, 22, 5) → 사실상 **검정** `[추정]` |
| 권장 구현값 | **`background: rgba(0,0,0,.55)`** (아주 미세한 웜 틴트를 살리려면 `rgba(12,8,2,.55)`) |
