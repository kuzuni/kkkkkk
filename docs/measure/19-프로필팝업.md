# 19. 프로필 팝업 — 픽셀 측정표

원본: `docs/ref/19-프로필-팝업.jpg` (1080×2340). 모든 좌표는 이 기준 좌표계의 절대 px.

## 요약
- **쉘 타입: (가) 전면 딤 + 중앙 다이얼로그 (검정+갈색 테두리)**
  - 패널이 좌우 여백(각 92px)을 가지며 x=0..1079 전체를 덮지 않음 → 바텀시트(나)/풀스크린(다)/전폭 밴드(라) 아님.
  - 패널 밖 배경은 게임 화면이 강하게 딤 처리되어 비침(잠금 아이콘·사이드 아이콘 실루엣 확인됨).
- **딤 추정**: 메인 화면(02) 바다색 (58,157,210) → 본 화면 (5,39,71). 채널별 잔존율 R 9% / G 25% / B 34% → 순수 검정 딤이 아니라 **짙은 남색 오버레이 ≈ rgba(0,20,50, 0.85)** 로 근사됨 (rgba(0,0,0,0.75)로도 유사하나 파란기가 남는 점 유의).
- **세로 좌표 매핑**: 구현 프레임 1080×1920. 중앙 다이얼로그이므로 **전 요소 `y_impl = y_ref − 210`** (센터 앵커) 적용 권장. 패널 border-box y 515..1910 → impl 305..1700 (패널 중심 y_ref 1212.5 = impl 1002.5, 화면 중심보다 약 42px 아래에 위치함도 참고).
