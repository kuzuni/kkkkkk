## 6. 우리 게임 설계 (레퍼런스와 다르게 가는 것)

- 데이터 소스는 **`S.own`**(id → `{n:재료 수, l:레벨}`) 이다. `SKILLS`·`EQUIPS`·`PETS`·`RELICS` 를 합쳐
  **보유 수량 n ≥ 1 인 것만** 등급 내림차순 → 카탈로그 순으로 정렬해 넣는다.
- 칸이 20개를 넘으면 본문이 세로 스크롤한다(레퍼런스는 20칸이 한 화면에 딱 맞는 상태).
  **격자 원점·pitch·칸 크기는 고정**이고 넘치는 행만 스크롤로 흘린다.
- 20칸이 안 차면 **빈 칸(`#CCC09C`)으로 채운다** — 레퍼런스 r4c4·r4c5 가 그 상태다.
  (LESSONS 34-2 «레퍼런스에 항상 있는 레이어는 숨기지 말고 비활성으로») 
- 진입은 **52 메뉴 → 가방**. 52 는 다른 워커가 잡고 있어 `openBag()` 를 전역으로 노출만 하고
  메뉴 배선은 52 작업이 한다. `tools/smoke.js` 오프너에는 `bag` 을 직접 추가했다.
