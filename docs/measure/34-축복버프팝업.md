# 34 축복(버프) 팝업 측정표 (레퍼런스 1080x2340 기준, 절대 px)

- 측정 일자: **2026-08-25** (sess-0344-11735, 워커 C)
- 레퍼런스: `docs/ref/34-축복-버프팝업.jpg` (1080 x 2340, JPEG)
- 스캔 도구: **`scan34.js`** (저장소 루트). 이 환경엔 **PIL 이 없어서** playwright chromium 의
  `canvas.getImageData` 로 JPEG 를 디코드하는 스캐너를 새로 만들었다. `node scan34.js <cmd>` 로 재현 가능:
  `box`(행/열 프로파일) · `map x0 y0 x1 y1 step`(블록 지도) · `row/col`(색 전이 구간) ·
  `raw row|col f a b`(픽셀 나열) · `mask x0 y0 x1 y1 <dark|bright|pale|yellow|cream|notcream>`(마스크 bbox) · `rect`(평균색·히스토그램).
  `SCAN_IMG=<다른 jpg> node scan34.js …` 로 **다른 레퍼런스에도 그대로 쓸 수 있다.**
- 표기: 좌표는 이미지 좌상단 원점, `x0..x1` 은 양끝 포함, `w = x1-x0+1`.
- 잉크는 **코어**(글자 본체 밝은 픽셀) / **잉크**(검정 외곽선 포함) 를 따로 적는다 (LESSONS 20-③).
- font-size 는 한글 **코어높이 ÷ 0.93**, 라틴/숫자는 **캡하이트 ÷ 0.72**.

## §9-1 초록 스트립 CTA — 작업 157 (2026-08-27, 저장소 주인 지시)

### 실측 (fs 70 · GameKR, `tools/verify157.js` · 캡처 `docs/review/34-r20-157.png`)

| 문구 | 글자수 | advance @fs70 | 상자(470) |
|---|---|---|---|

한글이 7 → 10 자로 늘어 advance 가 1.56 배가 됐다. 그대로 두면 **두 줄로 접히고 둘째 줄이 [이동] 버튼 위로 내려앉는다**

### 처방 — 높이는 지키고 가로만 조인다

```
.bls-promo .tx{ right:52px; width:636px; white-space:nowrap;
                transform:scaleX(.739); transform-origin:100% 50%; font-size:70px }
```

- `font-size` 를 내리면 §15-4 의 **잉크 높이 72(ref 74)** 가 같이 무너진다. 13회차가 fs 60→65→70 으로 두 번 올려 잡은 값이다

- `transform-origin:100% 50%` — A3 ⓓ 교훈("fs·scaleX 를 같이 걸면 잉크가 옆으로 밀린다")대로 **우변을 고정점**으로 박아
  13회차의 우측 정렬(우끝 959)을 그대로 남긴다.

### ⚠ 함정 — 상자를 470 에 두고 scaleX 만 걸면 우측 정렬이 통째로 뒤집힌다

`text-align:right` + `white-space:nowrap` 인데 **advance 가 상자보다 넓으면** Chrome 은 우측 정렬을 버리고
줄을 **상자 좌측 시작점에 붙인 뒤 우측으로 흘린다.** 실측으로 잉크 우끝이 959 가 아니라 **1075**(스트립 밖 x1016 초과)로 나갔다.

→ 상자를 **advance 보다 넓은 636** 으로 잡는다. `right:52` 와 `transform-origin:100% 50%` 이 고정점이라
**화면에 보이는 상자는 여전히 x420..890(=470)** 이고, 넓힌 몫은 전부 변환 전 좌표계에만 있다.
