# 34 축복(버프) 팝업 측정표 (레퍼런스 1080x2340 기준, 절대 px)

- 측정 일자: **2026-08-25** (sess-0344-11735, 워커 C)
- 레퍼런스: `docs/ref/34-축복-버프팝업.jpg` (1080 x 2340, JPEG)
- 스캔 도구: **`scan34.js`** (저장소 루트). 이 환경엔 **PIL 이 없어서** playwright chromium 의
  `canvas.getImageData` 로 JPEG 를 디코드하는 스캐너를 새로 만들었다. `node scan34.js <cmd>` 로 재현 가능:
  `box`(행/열 프로파일) · `map x0 y0 x1 y1 step`(블록 지도) · `row/col`(색 전이 구간) ·
  `raw row|col f a b`(픽셀 나열) · `mask x0 y0 x1 y1 <dark|bright|pale|yellow|cream|notcream>`(마스크 bbox) · `rect`(평균색·히스토그램).
  `SCAN_IMG=<다른 jpg> node scan34.js …` 로 **다른 레퍼런스에도 그대로 쓸 수 있다.**
- 표기: 좌표는 이미지 좌상단 원점, `x0..x1` 은 양끝 포함, `w = x1-x0+1`.
- 잉크는 **코어**(글자 본체 밝은 픽셀) / **잉크**(검정 외곽선 포함) 를 따로 적는다 (LESSONS 20-③).
- font-size 는 한글 **코어높이 ÷ 0.93**, 라틴/숫자는 **캡하이트 ÷ 0.72**.

## §10. 우리 게임 설계 (레퍼런스와 다르게 가는 것)

> 근거: `docs/UI-REFERENCE.md` «설계 확정» 1번 — **캐릭터는 «용사» 1명**. 레퍼런스의
> `햄지 공격력` / `매옹이 공격력` 2칸은 우리 게임엔 없다. **레이아웃(3칸 그리드)은 그대로 두고 항목만 바꾼다.**

| 레퍼런스 | 우리 게임 | 근거 |
|---|---|---|
| `햄지 공격력` / `매옹이 공격력` / `체력` | **`공격력` / `체력` / `공격 속도`** | 설계 확정 1 (캐릭터 1명). 3칸 구조·좌표는 유지 |
| 광고 시청으로 활성화 · `레벨 3 전까지 무료로 광고를 스킵해드려요!` | **광고 없음 — 무료 활성화.** 배너 문구 `축복은 언제나 무료! 만료되면 다시 받을 수 있어요` (23자, ref 와 같은 자수) | 이 게임엔 광고 SDK 가 없다(44 의 «결제 미연동» 과 같은 사유). 목업 문구를 만들지 않고 **실제 동작하는 규칙**으로 바꾼다 |
| 초록 스트립 `축복 자동 갱신!` + `[이동]`(유료 상품 크로스 프로모) | **`모든 축복 받기!` + `[받기]`** — 비활성 축복을 한 번에 활성화하는 **실제 버튼** | 유료 상품이 없으므로 «이동» 할 곳이 없다. 자수(8자 / 2자)는 ref 와 동일해 bbox 가 유지된다 |
| 지속시간 `00:01:22` (약 1분 22초 남음) | **30분 지속** — 표기는 같은 `HH:MM:SS` 포맷 | 방치형 페이스에 맞춤 |
| `Lv.1` + `3/4` | **축복 레벨** — 축복을 1개 켤 때마다 +1, **4개 채우면 레벨 +1** 이고 레벨당 지속시간 +5분 | ref 의 `3/4` 진행바를 그대로 쓰는 규칙 |
| `보너스 축복 — 골드 획득량 +50%` | **동일** (3개 전부 활성일 때만 적용) | ref 그대로 |

효과값은 **레퍼런스와 같은 +20%** 로 두고 `bonus()` 에 곱한다(`b.atk`·`b.hp`·`b.rate`), 보너스는 `b.gold *= 1.5`.
