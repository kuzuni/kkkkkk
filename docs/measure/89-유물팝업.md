# 89 유물 소환 팝업 측정

- 레퍼런스: `docs/ref/89-유물-팝업.png` — **실측 486×687** (지시서의 485×692와 상이. 실측 기준으로 측정)
- 배율: **×2.2222 (=1080/486)** 로 환산 (지시서의 ×2.2268=1080/485 대신 실측 폭 사용, 차이 ≤1px)
- 전체 화면 여부: **풀 스크린이 아님 — 크롭된 콘텐츠(팝업 패널) 영역**. 상태바·상단 재화 HUD·하단 탭바 없음. 이미지 4변 모두에 금색 장식 테두리(2~3px 라인 + 모서리 플러리시 ~35px)가 둘러져 있어 팝업 패널 전체가 딱 맞게 잘린 스크린샷.
- 1080×2280 프레임 매핑 판단: 환산 크기 1080×**1527**. 상단 HUD(~370px)와 하단 탭바(~380px) 사이의 중앙 영역, **대략 y≈370~1900** 에 배치되는 풀폭 팝업으로 추정.
