## 15. 구현 메모
- **레퍼런스에는 장착 버튼이 없다(강화 단일).** 우리 게임의 유물 수동 장착은 `autoEquipAll()`(상위 3개 자동 장착)이 대체하므로, 상세 팝업은 레퍼런스대로 강화 단일 버튼으로 두고 **강화 후 `autoEquipAll()` 호출**로 보유 효과가 유실되지 않게 한다.
- 플레이버 텍스트: RELICS 에 `fl` 필드 신설(정적 데이터라 세이브 마이그레이션 불필요).
- 효과 박스: 실제 스탯 효과(`RELIC_EFF` + `relicVal`)를 골드 강조로 렌더.
