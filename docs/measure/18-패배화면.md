# 18 패배 화면 측정표

> ⚑ **환산 주의 (2026-08-30, 작업 536)**: 이 표의 y 는 전부 **ref 절대 px**(1080×2340)다.
> 프레임(1080×2280) 값으로 쓸 때는 지시서 [2] 의 현행 변환 **`프레임 y = ref y − 84`** 하나만 쓴다 —
> `docs/review/18-패배화면.md` 에 적혀 있던 옛 «`− 210`»(1920 프레임 시절)은 **폐기**다.
> 제품은 현행 변환을 따른다(카드 outer 915/1095/1275 → **831/1011/1191**). 근거 `node tools/probe536.js`.

> **출처**: `docs/ref/18-패배-화면.jpg` — 원본 **1080×2340**, 좌표는 전부 원본 절대 px.
> **측정 방법**: python3 + PIL(+numpy) **픽셀 스캔만** 사용. 눈대중 수치 없음.
> - 딤 농도는 같은 장면인 `02-기본-메인-화면.jpg` 와 **영역별 평균 비교**(안정 영역 8곳)
> - 경계는 행/열 색전이 스캔, 모서리 반경은 코너 인셋 `r − √(r²−(r−d)²)` 피팅
> - 텍스트는 채움 마스크(잉크)와 스트로크 포함 bbox 를 따로 기록
> **폰트 규칙**: `font-size = 잉크높이 ÷ 0.93`(한글) / `÷ 0.70`(숫자·캡하이트)
> **스트로크 규칙**: CSS `-webkit-text-stroke` 는 실측(한쪽)의 **2배** 값을 준다.
> **테두리 기준**: bbox 는 **검정 외곽선 포함 바깥 기준**. 안쪽 값은 따로 적음.
