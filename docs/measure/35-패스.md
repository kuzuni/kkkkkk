# 35 패스 팝업 — «스테이지 패스» 탭 측정표

- 측정 일자: **2026-08-25** (sess-0358-27977, 워커 D)
- 레퍼런스: `docs/ref/35-패스-스테이지패스.jpg` (1080×2340, JPEG) / 대조: `docs/ref/36-패스-출석패스.jpg`, `docs/ref/02-기본-메인-화면.jpg`
- python3 + PIL + numpy 로 픽셀 직접 스캔(스크립트 75개). **눈대중 값 없음.**
- **좌표 규약**: `ref y` = 캡처 절대 y. `frame y = ref y − 84` (상단 84px 상태바/안전영역 제외). 가로는 1:1 무변환.
  좌표는 **양끝 포함** 인덱스, `w = x1−x0+1`.
- 텍스트는 **코어**(글자 본체, `min(RGB) > 215`) 와 **잉크**(검정 외곽선 포함, `max(RGB) < 58`) 를 따로 적었다.

## §11. 주의사항 / 신뢰도가 낮은 항목

1. **프레임 잔차 24px (중요)** — `2340 − 84 = 2256` 이지만 우리 프레임은 **2280** 이다.
   하단바를 `bottom:0` 에 붙이면 리스트가 24px 더 노출된다 → **리스트(스크롤 영역)가 잔차를 흡수**하는 것이 정답이다(0번 «남는 높이는 가변 요소가 흡수» 와 같은 처방).

2. **font-size 규약 충돌 (신뢰도 낮음)** — ① 받침 유무로 한글 코어높이가 0.80~0.91 배 흔들리고 ② 숫자 캡하이트/한글높이 비가 **≈0.89** 라 «숫자 ÷0.69» 규약을 그대로 쓰면 **30~40% 크게** 나온다.
   §7 의 «÷0.69» 값은 **규약 계산값일 뿐**이다. 구현 후 캡처 대조 필수.

3. **행 pitch 는 정수가 아니다** — 최소제곱 **229.85**. 230 으로 고정하면 6행 누적 0.9px 오차(무시 가능).

4. **행 1 상단과 행 6 하단이 잘려 있다** — 이는 «스크롤 중» 상태이며 리스트의 실제 시작/끝이 아니다.

5. **35 는 스크롤된 상태** (스테이지 65부터). 36 은 스크롤 최상단이라 «접속일» 알약이 보인다.
   35 최상단에도 같은 위치에 라벨 알약이 있을 가능성이 있으나 **미확인**.

6. **프리미엄 칸 radius 는 무료칸에서만 검증** — 프리미엄 칸은 우상단이 자물쇠에 가려 원호 피팅 RMSE 13.6px 로 무의미했다. **32.25** 는 가림 없는 무료칸 R4 에서만 4모서리 동시 피팅한 값(RMSE 0.72).

7. **별 워터마크 진폭이 JPEG 한계에 가깝다** — 휘도 차 −8~−13 뿐이라 별 bbox 는 ±3px 흔들린다. **좌표(pitch·오프셋)는 24개 blob 일관성으로 확인해 신뢰도가 높다.**

8. **«패턴이 행마다 리셋된다» 는 해석** — 같은 x 열 별의 y 간격이 154/76 교대로 나온 사실에서 유도. «전체 격자 + 행 경계 잘림» 가능성도 완전히 배제하지는 못했다.

9. ~~하단탭 아이콘 크기는 추정(±15px)~~ → **해소(5회차, `tools/scan35.py`)**. 칸 배경이 세로 그라디언트라
   단일 배경색으로는 못 뺀다 — **행별 배경을 «창 좌우 가장자리 8열의 중앙값»** 으로 잡으면 분리된다
   (행 전체의 중앙값을 쓰면 잉크가 행의 절반을 넘는 구간에서 «잉크 = 배경» 이 돼 마스크가 뒤집힌다).
   결과: 잉크 **h 92 · 바 본체 상단 +23**, 폭 167/132/145, 라벨 잉크 top **+117**(흰 코어 h 25).

12. **자물쇠·체크 스캔은 창을 «칸 우단 쪽»(x≥968)으로 좁혀야 한다(5회차)** — 창을 칸 안쪽까지 열면
   **칸 아이템 아이콘(잉크 78~90×63~85)** 이 자물쇠로 잡혀 «ref 85×97 / 우리 67×73» 처럼 **크기가 2배로, 방향이 반대로** 읽힌다.
   실제 값은 ref **50×60**, 4회차 구현은 **41×35**(세로 −42%)였다.

10. **무료 vs 프리미엄 헤더 라벨 크기 차이** — 코어 h 41 vs 45, advance 40.0 vs 44.3 으로 **1.10 배**. 받침 차이(0.91)와 겹쳐 단정하기 어렵다 → **둘 다 48px** 로 두는 것을 권장(구현이 이 방식).

11. **닫기 ✕ 없음은 «검출 실패» 가 아니라 «없음»** — 히어로 우상단 포함 전 영역 스캔에서 버튼형 요소가 없다. 이탈 경로는 하단바 ← 뿐이다.
