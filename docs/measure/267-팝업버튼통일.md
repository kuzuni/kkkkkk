## 4. 닫는 길 (버튼을 없앤 자리의 대체 경로)

`#modal` 딤 탭 — `$('modal').onclick = e => { if(e.target === $('modal')) closeModal(); }`.
`.mbox` 를 통과한 탭은 딤이 아니므로 오작동하지 않는다(181-(라) 가 같은 근거를 쓴다).
같은 규격의 선례: **70 출석 보상 팝업**(레퍼런스에 하단 버튼·✕ 가 없어 딤 탭으로만 닫는다) ·
**08 스킬 세부**(UI-REFERENCE 831 «닫기 버튼은 없다 … 등재 267 방향과 같다»).
