# 05 무기 팝업 측정표 (레퍼런스 1080x2340 기준, 절대 px)

- 측정 일자: **2026-08-24**
- 레퍼런스: `docs/ref/05-무기-팝업.jpg` (1080 x 2340, JPEG)
- 측정 방식: **python3 + PIL 픽셀 직접 스캔**. 스캔라인 색 전이점 / 색 마스크 bbox / 코너 원호 최소자승 피팅 / `06-장비-팝업.jpg` 와의 픽셀 대조(딤 산출). 눈대중 값 없음.

  라틴/숫자만 있는 문자열(`Lv. 2`, `0/3`)은 잉크가 **캡하이트**라 이 공식이 과소평가된다 — 해당 항목에 별도 표기.

>   그 폐기된 104 를 써서 «위 여유 52» 라고 적었으나 **실측은 14** 다(`tools/probe558.js`).
> * 치우침(위 − 아래)은 **모든 프레임에서 상수 14** 다 — 패딩(126/150)과 띠(142/180)의 차라
>   짧은 프레임만의 병이 아니다. 다만 여유의 합이 14 로 줄어드는 구간에서만 «맞닿음» 으로 드러난다.
> * ⇒ 558 이 `#wpnw{--wm-sk:clamp(0px, calc(1805px − var(--frameh)), 7px)}` 로 **위에서 빼고 아래에 더해**
