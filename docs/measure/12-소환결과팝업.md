# 12 소환 결과 팝업 측정표

- **측정 기준: 원본 1080×2340 절대 px, PIL 픽셀 스캔**
- 레퍼런스: `docs/ref/12-소환-결과-팝업.jpg` (1080 × 2340, JPEG)
- 대조 레퍼런스(딤 산출용): `docs/ref/10-상점-팝업-소환-탭.jpg` (동일 배경 = 상점 팝업 소환 탭)
- 측정 방식: Python + Pillow. 스캔라인 색 전이점 / 색 마스크 bbox / 코너 원호 피팅 / A·B 이미지 픽셀 대 픽셀 최소자승 회귀. **눈대중 값 없음.**
- 좌표는 모두 **원본 1080px 폭 기준 절대 px**, `x`/`y`는 요소 **좌상단**, 정수 반올림.
- 텍스트 높이는 **잉크 bbox**(실제 글자 픽셀의 최소~최대 y). `환산 font-size = 잉크높이 / 0.93`.
- 측정 일자: 2026-08-24

## 0. 껍데기 판정 — **(라) 전면 딤 + 전폭(full-bleed) 결과 밴드 오버레이**

**결론: ⓐ 가운데 다이얼로그도, ⓑ 전체화면 페이지도, ⓒ 바닥 시트도 아니다.**
**화면 전체를 진하게 딤(α≈0.80) 처리한 위에, ① 리본 헤더 ② 전폭 가로 밴드 패널(그리드) ③ 하단 재소환 버튼 3개 ④ `터치하여 닫기` 4덩어리가 따로따로 떠 있는 «결과 연출 오버레이»다.**
그리드 패널을 감싸는 좌우 테두리·모서리 라운드가 **전혀 없다** — 패널이 x=0 과 x=1079 를 그대로 물고 있다.

| 판정 근거 | 실측 |
|---|---|
| 패널 좌우 끝 | x **0 ~ 1079** — `y=795` / `y=1000` / `y=1329` **가로 전 라인 스캔**으로 확인. x=0,2,5,100,300,540,800,900,1050,1077,1079 전부 동일색 |
| 패널 상하 | y **793 ~ 1331** (금색 라인 바깥 기준). 화면 위로 793px, 아래로 1009px 배경이 남음 → 전체화면 페이지 아님 |
| 바닥 시트 여부 | **아님**. 패널이 화면 하단(2340)에 붙어 있지 않고, 패널 아래에 딤된 배경 + 별도 버튼/닫기 안내가 있음 |
| 뒤에 비치는 화면 | **있음**. `무기 상자` 카드(y 240~690), `스킬 상자` 카드(y 1350~1650), 하단 서브탭·탭바가 그대로 비침 → 딤 확정 |
| 배경 동일성 검증 | `10-상점-팝업-소환-탭.jpg` 와 `무기 상자` 카드 좌표가 **완전 일치**(픽셀 대 픽셀 상관). 같은 페이지 위 오버레이 |
| 하단 버튼 3개 | **딤 안 걸린 전경**. 같은 좌표의 B 이미지는 `#272731`(빈 배경)인데 A 는 `#989898` — B 에는 아예 없는 요소 |
| 패널 투명도 | **불투명**. 패널 내부는 x=0~1079 전 구간 `#2A2835` 단일색인데, B 이미지 같은 좌표엔 분홍 `방어구 상자` 카드가 있음 → 전혀 비치지 않음 |

### 0-1. 딤 오버레이 알파 산출

동일 콘텐츠 영역(`x 60~900, y 240~690` + `x 60~900, y 1360~1650`, 3px 간격 = 채널 샘플 20.7만개)에서
`A = k·B` 최소자승 회귀.

| 항목 | 값 |
|---|---|
| 영역 | 화면 전체 `0,0 ~ 1080×2340` (패널/리본/버튼/닫기문구 제외 전면) |
| 색 | `#000000` |
| **sRGB 최소자승 k** | **0.1979** → **α = 0.802** |
| 절편 포함 fit | `A = 0.2135·B − 2.75` |
| 밝기 구간별 비율 | b 160~200 → 0.198 / b 200~240 → **0.208** / b 240~255 → 0.203 (밝은 구간에서 안정) |
| **권장 CSS** | **`background: rgba(0,0,0,0.80)`** |
| 딤 후 대표 배경색 | 페이지 여백 `#020202`~`#030303`, 순수 검정과 거의 구분 안 됨 |

> 참고: 어두운 구간(b<80)에서는 비율이 0.13~0.26 으로 튀지만 JPEG 양자화 잡음 때문이며,
> 밝은 구간이 일관되게 0.20 이므로 **α = 0.80** 이 맞다. (linear-light 감마 2.2 가정 시 α=0.97 이 나오지만
> 밝기 구간별 비율이 sRGB 공간에서 훨씬 평평하므로 **sRGB 직접 합성**이 맞다.)

## 9. 불확실한 항목

| 항목 | 잰 값 | 왜 애매한가 |
|---|---|---|
| 딤 알파 | **0.80** | sRGB 최소자승 k=0.1979. 밝은 구간(b≥160)에서 0.198~0.208 로 안정적이라 신뢰도 높음. 다만 절편 포함 fit 은 `0.2135·B − 2.75` 라 **α=0.78~0.80** 범위. 어두운 구간은 JPEG 잡음으로 판독 불가 |
| 리본 검정 외곽선 **상단** 두께 | 측정 불가 | 리본 위 배경이 딤으로 `#000000~#030301`. 검정 외곽선과 배경이 구분 안 됨. 좌우(4~6px)로 유추할 수밖에 없음 |
| 리본 중앙 밴드 radius | **≈ 8** | dx가 dy에 대해 5,4,3,2,1,0 으로 **선형**이라 원호라기보다 45° 챔퍼에 가깝다. 실제 CSS 는 `border-radius: 8px~10px` 급 |
| 버튼 검정 외곽선 두께 | **좌우 4~6 / 상하 6** | ①좌 4px(117~120) vs ①우 6px(358~363), ②좌 6px(416~421). JPEG AA 때문에 4/5/6 확정 불가. **5px 권장** |
