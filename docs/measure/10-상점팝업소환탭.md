# 10 상점 팝업 — 소환 탭 측정표 (레퍼런스 1080×2340 기준, 절대 px)

- 측정 일자: **2026-08-24**
- 레퍼런스: `docs/ref/10-상점-팝업-소환-탭.jpg` (1080×2340, JPEG)
- 측정 방식: **python3 + PIL + numpy 픽셀 직접 스캔** (독립 측정 2인 A/B). 행/열 색전이 프로파일 · 서브픽셀 임계교차 · 색마스크 bbox · 코너 원호 최소자승 피팅 · `02/07/13` 과의 픽셀 대 픽셀 나눗셈. **눈대중 값 0개.**
- 좌표: 레퍼런스 절대 px, 요소 **좌상단** 기준, 정수 반올림. bbox 는 검정 외곽선 **포함(바깥)** 기준.
- font-size = **실측 잉크높이 / 0.93** (한글). 라틴/숫자(`Lv.2` `100/130` `2/2` `1,000` `3,000` `AD`)는 잉크가 캡하이트라 이 식이 **과소** → 해당 항목에 «(과소)» 표기, 실제 지정값은 약 1.25~1.3배.
- `-webkit-text-stroke` 는 윤곽 중심에 그려져 바깥으로 절반만 보인다 → 실측 N px = CSS **2N** px.

```
프레임 y = 레퍼런스 y − 84     (상태바 84px 제외)
프레임 x = 레퍼런스 x
```

## 4. 구현 메모 (측정 중 확인된 함정)

1. 경험치 바 왼쪽 끝(안쪽 166)은 Lv 알약이 30px 덮어 직접 못 잰다 → 카드 3장 채움률 회귀로 L=166.1/W=299.5 도출.
2. Lv 알약 높이 44 는 바가 없는 열(x=140)에서. 캡 곡선 위(x112)에서 재면 31 로 과소.
3. 🔍 버튼을 «파랑 아님» 마스크로 재면 카드2·3(분홍/보라)에서 화면 전체가 잡힘 → 채도 마스크 `max−min<45`.
4. `100/130` 은 외곽선 없음(노랑 위 흰 AA). 다른 버튼 텍스트만 검정 스트로크.
5. 라틴/숫자 font-size 는 캡하이트라 과소 → 실제 약 1.25~1.3배.
6. 배경 blob 무늬·상자 아트·💎·🔍·▶AD 는 **아트 리소스**라 CSS/이모지로 근사(색·명암 항목 감점 예상, A1~A5 와 같은 천장).

## 6. 정오표 — 작업 81 (2026-08-26): 41 재화 바 포함
