# 10 상점 팝업 — 소환 탭 측정표 (레퍼런스 1080×2340 기준, 절대 px)

- 측정 일자: **2026-08-24**
- 레퍼런스: `docs/ref/10-상점-팝업-소환-탭.jpg` (1080×2340, JPEG)
- 측정 방식: **python3 + PIL + numpy 픽셀 직접 스캔** (독립 측정 2인 A/B). 행/열 색전이 프로파일 · 서브픽셀 임계교차 · 색마스크 bbox · 코너 원호 최소자승 피팅 · `02/07/13` 과의 픽셀 대 픽셀 나눗셈. **눈대중 값 0개.**
- 좌표: 레퍼런스 절대 px, 요소 **좌상단** 기준, 정수 반올림. bbox 는 검정 외곽선 **포함(바깥)** 기준.
- font-size = **실측 잉크높이 / 0.93** (한글). 라틴/숫자(`Lv.2` `100/130` `2/2` `1,000` `3,000` `AD`)는 잉크가 캡하이트라 이 식이 **과소** → 해당 항목에 «(과소)» 표기, 실제 지정값은 약 1.25~1.3배.
- `-webkit-text-stroke` 는 윤곽 중심에 그려져 바깥으로 절반만 보인다 → 실측 N px = CSS **2N** px.


## 7. 정오표 — 작업 102 (2026-08-26): 노랑/회색은 «버튼 순번» 이 아니라 **«구매 가능 여부»** 다

§2 의 «17 ② 노랑 버튼 / 22 ③ 회색 버튼» 은 **색을 버튼 순번의 속성으로 적어 둔 것이 오독**이었다.
이 레퍼런스는 **다이아 1,000 상태**(= `DEF().dia`)로 찍혔고, 10회=1,000 은 살 수 있어 노랑,
30회=3,000 은 못 사서 회색이다 — **같은 프레임에 두 상태가 같이 찍힌 것**이다.
근거: ① 두 버튼의 유일한 차이가 «가격 ≤ 보유 다이아» 뿐이다 ② 가격 글자색이 흰색/빨강으로 갈린다
(색 자체가 «부족» 관용 신호다) ③ 12 레퍼런스는 무료 0/1 · 다이아 0 상태라 **버튼 3개가 전부** 은색+빨강이다
— 순번 규칙이라면 12 의 «10회» 버튼도 노랑이어야 한다.

| 상태 | 면(--f1→--f2) | 상단 림(--ring) | 하단 립(--lip) | 인셋 알약(--p1→--p2) | 라벨 | 가격/횟수 |
|---|---|---|---|---|---|---|
| **충분(`.rich`)** | `#FCEF31`→`#FEC01D` | `#F6EF3E` | `#D87C0D` | `#C39313`→`#C38607` | `#FFFFFF`(§2 18 실측 `#F8F8F8`) | **`#FFFFFF`** (bbox 실측 n=643 평균 `#F1F1F1`, 최빈 255,255,255) |
| **부족(`.lack`)** | `#A8A8A8`→`#989898` | `#D2D2D2` | `#747474` | `#747474`→`#6C6C6C` | `#DADADA` | **`#EB6D68`** |
