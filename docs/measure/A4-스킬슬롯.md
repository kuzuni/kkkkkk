# 측정표 — A4 스킬 슬롯 (전투 화면 최하단 원형 8칸)

대상: `docs/ref/02-기본-메인-화면.jpg` (1080×2340)
방법: 배경 워터색 `rgb(58,158,210)` 대비 non-bg 마스크 → 행/열 프로파일로 행 경계와 8칸 분리,
      슬롯 중심 기준 **반지름별 중앙값 색 프로파일**(각도 5° × 72방향)로 링 구조 분해.
모든 값은 **1080×2340 절대 px**. 가로 수치는 프레임 1080×1920 에 **1:1** 로 그대로 쓴다.

> **한 번 측정한 화면은 재측정하지 않는다.** 이후 세션은 이 표를 그대로 쓴다.

## 1. 슬롯 중심 x (실측)

| # | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| 중심 x | 86 | 216.5 | 347 | 476.5 | 606 | 736.5 | 866.5 | 996.5 |
| 간격 | – | 130.5 | 130.5 | 129.5 | 129.5 | 130.5 | 130 | 130 |

→ pitch 는 **130 균일**. 1번 슬롯만 bbox 133×159 로 더 큰데, 이는 **활성 상태의 발광(glow)** 때문이며
   원 자체의 지름은 나머지와 같다(깨끗한 6·8번 슬롯 bbox = 118×119).

## 2. 링 구조 — 반지름별 색 프로파일

중심에서 바깥으로 **4겹**이다. (r = 중심으로부터의 반지름)

| 구간 | r | 두께 | 역할 | 색 (상태별) |
|---|---|---|---|---|
| well (안쪽 원) | 0 – 43 | 지름 **88** | 아이콘이 놓이는 안쪽 원판 | 활성 `#fdfd10` / 대기 `#367cc1` / 잠금 `#454464` |
| 안쪽 어두운 테두리 | 44 – 47 | **4** | well 과 컬러 링 분리 | `#00040b` (≈ `#030509`) |
| **컬러 링** | 48 – 55 | **8** | 상태 표시 링 | 활성 `#ffb92b` / 대기 `#25d8ff` / 잠금 `#b9bccb` |
| 바깥 어두운 외곽 | 56 – 59 | **4** | 배경과 분리 | `#00040b` |

- 링대 전체 두께 = `(120 − 88) / 2` = **16** = 4 + 8 + 4 ✓
- well 실측 bbox 89×89 (y 2030–2118) → 지름 **88~89**

### 상태 3종 (UI-REFERENCE ⑤ «노랑=활성, 파랑=대기, 미해금은 자물쇠»)

| 상태 | 레퍼런스 슬롯 | well | 컬러 링 (r48~55) | 추가 |
|---|---|---|---|---|
| 활성 | 1번 | `#367cc0` (**파랑 그대로**) | `#ffb92b` (골드) | well 가장자리에 **노란 안쪽 링 r36~43 (두께 8) `#fefe0c`** |
| 대기 | 2·3번 | `#367cc1` (파랑) | `#25d8ff` (시안) | – |
| 잠금/빈칸 | 4~8번 | `#454464` (남보라) | `#b9bccb` (회색) | – |

> **주의 — 활성 슬롯의 well 을 노랗게 칠하면 안 된다.** 1차 구현에서 그렇게 했다가 바로잡았다.
> 레퍼런스 1번 슬롯은 well 이 다른 장착 슬롯과 똑같은 파랑이고, 노랑은 **well 가장자리의 링(r36~43)** 일 뿐이다.
> 그 바깥에 r60~67 두께 8 의 노란 글로우 링(`#fefe11`, 글로우 포함 지름 135)도 있으나,
> 이는 **발동 순간의 일시 이펙트**(01·18·19·20·21번 캡처에는 없음)라 상시 표시하지 않는다.

### 레퍼런스에 없는 것 (확인 완료)

| 항목 | 확인 |
|---|---|
| 슬롯 위 HP 바 | **없음.** 슬롯 행 바로 위는 좌 `마을` 버튼(y ≤1996) / 우 `[보상받기]` 배너(y ≤1989) |
| 쿨타임 오버레이 | 23장 전부에서 **관측 안 됨** (내부는 항상 균일한 flat fill) |
| 슬롯 안 레벨/숫자 텍스트 | **없음.** `Lv` 표기는 스킬 팝업 타일에만 존재 |
| 「빈 슬롯」 상태 | **없음.** 슬롯은 장착 아니면 잠금 두 가지뿐 |
| 펫/동료 머리 뱃지 | 장착 슬롯 하단에 44×44 로 10px 돌출 (아트 리소스 없어 미구현) |

## 4. 쿨타임 오버레이

레퍼런스 02번 캡처에는 쿨타임 진행 중인 슬롯이 없어 **직접 측정 불가**.
UI-REFERENCE ⑤ 는 «쿨타임은 슬롯 위에 오버레이» 로만 규정.
→ 기존 구현(아래→위로 차오르는 어두운 판)을 유지하되 **well(88) 안쪽만 덮어 컬러 링을 가리지 않게** 한다.

## 5. CSS 이식표

`#slots` 컨테이너

| 속성 | 값 |
|---|---|
| display | `flex` |
| justify-content | `center` |
| gap | `10px` |
| margin | `26px 0 16px` (아래 16 + `#battlefoot` padding-bottom 10 = **26**) |

`.slot2` 한 칸

| 속성 | 값 |
|---|---|
| width / height | `120px` / `120px` |
| border-radius | `50%` (정원) |
| border | 없음 — 링은 전부 `inset box-shadow` 로 그린다 |
| background | 대기·활성 `#367cc1` / `.empty` `#454464` |
| box-shadow | `inset 0 0 0 4px #030509, inset 0 0 0 12px <링색>, inset 0 0 0 16px #030509` |
| box-shadow (`.ready` 만) | 위에 더해 `, inset 0 0 0 24px #fefe0c` — spread 16→24 가 곧 r36~43 노란 안쪽 링 |
| 링색 | 대기 `#25d8ff` / `.ready` `#ffb92b` / `.empty` `#b9bccb` |
| font-size (스킬 아이콘) | `84px` (렌더 잉크 80×80, 레퍼런스 68×85) |
| font-size (자물쇠 `.lk`) | `60px` (렌더 잉크 48×68, 레퍼런스 56×64) + `filter:grayscale(1) brightness(3)` 로 백색화 |

> `box-shadow` 3겹은 **바깥것을 먼저 쓴다**(먼저 쓴 것이 위에 그려짐).
> spread 4 → r56–59, spread 12 → r48–55, spread 16 → r44–47 이 되어 실측 4겹 구조와 정확히 일치한다.
