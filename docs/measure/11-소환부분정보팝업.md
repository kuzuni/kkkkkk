# 11 소환 부분 «확률 정보» 팝업 측정표 (레퍼런스 1080x2340 기준, 절대 px)

- 측정 일자: **2026-08-24**
- 레퍼런스: `docs/ref/11-소환-부분-정보-팝업.jpg` (1080 x 2340, JPEG)
- 측정 방식: **python3 + PIL 픽셀 직접 스캔**. 스캔라인 색 전이점 / 색 마스크 bbox / `10-상점-팝업-소환-탭.jpg` 와의 픽셀 대조(딤 역산). 눈대중 값 없음.
- 표기: `x`/`y` 는 요소 **좌상단**, 값은 정수 px, 색은 실제 픽셀 RGB.
- **✔ = 픽셀 스캔으로 확정** / **(추정) = 피팅·계산·역산** / **(미확정)** = 판정 불가.
- font-size 는 **실측 잉크높이 / 0.93** (프로젝트 폰트 잉크비 0.93). 한글 문자열은 이 값이 정확하다.
  라틴/숫자만 있는 문자열(`2`, `0.83333%`, `(25%)`)은 잉크가 **캡하이트**라 이 공식이 과소평가된다 — 해당 항목에 별도 표기.
- JPEG 경계 번짐 때문에 각 스캔의 임계값을 명시함(예: 검정 판정 ΔRGB<55).

## 9. 구현 시 주의

1. **정중앙 다이얼로그** — 폭 797, 화면 정중앙(x 539.5 / y 1175). 구현 프레임(1920)에서는 **`ref y − 210`** 으로 옮기면 프레임 중심 960에 정확히 앉는다. 가로는 무변환.
2. **딤은 화면 전체 `rgba(0,0,0,0.55)`** (실측 투과 0.44). 뒤 배경은 화면 10(상점 소환탭)이 그대로 딤된 상태 — 모달 밖은 게임 화면.
3. **등급바 · 아이템 알약은 좌우 폭·정렬이 동일**(x 214~865 / 216~863, 폭 651·647). 알약은 완전 캡슐(radius≈h/2), 검정 테두리 없이 크림 본문 위에 얹힌 밝은 알약이며 **행 사이 구분선은 없다**(크림 여백 8px 이 분리).
4. **텍스트 3정렬 규칙**: 이름=좌측정렬(x304 고정), 확률=우측정렬(x833 고정), 안내문·타이틀·단계·등급바텍스트=가운데정렬. 확률은 시안(`#ACFBFF`)+어두운 외곽선, 이름은 순검정.
