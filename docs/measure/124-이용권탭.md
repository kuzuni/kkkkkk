> 레퍼런스 스크린샷이 **없는** 화면이다(«우리 게임 설계» — 저장소 주인 지시 2026-08-26).
> 그래서 «레퍼런스 실측» 이 아니라 **기존 부품에서 파생한 값**만 적는다. 새 좌표계를 만들지 않았다.

## §1 카테고리 탭 바 — 2칸(.sp2) → 3칸(.sp3)

바 껍데기(`#shopCats.stabs`)는 **96 공용 부품 그대로**다. 바꾼 것은 칸 분할 하나뿐이다.

| 항목 | 값 | 근거 |
|---|---|---|
| 바 | x45 · w990 · h99 · 검정 6 · radius 50 | 96 공용 부품 (변경 없음) |
| 콘텐츠(패딩) 상자 | x51 · w978 | 990 − 6×2 |
| 칸 폭 | **326.0** | 978 ÷ 3 |
| 칸 left (프레임) | 51 / 377 / 703 | 51 + 326·n |
| 칸 우단 | 1029 | = 바 안쪽 오른끝 (Δ0) |
| 라벨 잉크 | 소환 177.4~250.6 · 재화 500.7~579.3 · 이용권 807.0~924.9 | 실측 (칸 중앙 ±3px 안) |

- CSS 는 `%` 로 적었다(`width:33.3333% · left:0/33.3333%/66.6667%`) — sp2 와 같은 규칙이라
  바 폭·테두리가 바뀌어도 칸이 저절로 따라간다. **px 상수로 박지 말 것.**
- 3글자 라벨(«이용권», 잉크 폭 117.9)이 326 칸에 여유 있게 들어간다 — fs43·scaleX.914 그대로.
- **10·13 측정표 §8 «탭 2칸» 은 정오표 처리**(아래 §5).
