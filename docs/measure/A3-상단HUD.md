## 구현 메모

- 최상위 `.hud`는 `position: relative; height: 226px;` 로 잡고, 내부에 (a) `.hud__statusbar` (height 84, bg `#281F1A`), (b) `.hud__bar` (`position:absolute; top:84; left:0; right:0; height:104; background:#42362A; border-bottom:4px solid #000; box-shadow: inset 0 6px 0 #000;`) 를 둔다. 배틀 영역은 `margin-top: 188px` 가 아니라 HUD 전체 226px 아래에서 시작하되, 좌측 플레이트가 배틀 배경 위로 떠 보이도록 `z-index`만 올린다.
- 좌측 어두운 플레이트는 `.hud__profile { position:absolute; left:0; top:84px; width:466px; height:142px; background:#332822; }` 에 `clip-path: polygon(0 0, 466px 0, 360px 142px, 0 142px)` 를 적용해 36.7° 사선을 만든다. 검은 외곽선은 `filter: drop-shadow()` 대신 4px 큰 동일 clip-path 의사요소를 `#000`으로 깔아 재현한다.
- 초상화 카드는 플레이트 안에서 `position:absolute; left:0; top:0; width:141px; height:141px;` 절대배치. 3중 레이어(검은 외곽선 3px → 갈색 프레임 9px → 내부 테두리 4px → 이미지 111x113)는 `border: 3px solid #000; background:#735C4E; padding:9px;` + 내부 `div`에 `border:4px solid #030000; border-radius:6px;` 로 중첩한다. `border-radius: 16px`.
- 닉네임/칭호/전투력은 초상화 오른쪽에 세로 flex 컬럼(`left:151px; top:96px; display:flex; flex-direction:column; align-items:flex-start;`). 행 간격은 닉네임 알약 하단(126) → 칭호 알약 상단(131) = `gap:5px`, 칭호 하단(172) → 전투력 상단(176) = `gap:4px` 이므로 `gap:5px` 하나로 통일해도 오차 1px.
- 닉네임 알약은 `padding: 0 50px; height:30px; border-radius:15px; background:#000; line-height:30px;` — 텍스트가 좌우 정확히 50px 여백으로 중앙 정렬되므로 padding 방식이 맞다.
- 칭호 알약은 육각 배너이므로 `clip-path: polygon(13px 0, calc(100% - 13px) 0, 100% 50%, calc(100% - 13px) 100%, 13px 100%, 0 50%)` (w=229, h=41). 안쪽 베벨은 `linear-gradient(#7B6857 0 4px, #443B36 4px calc(100% - 5px), #635145 calc(100% - 5px) 100%)`.
- 전투력 행은 `display:flex; align-items:center; gap:11px;` 이고 컬럼의 마지막 행이 자연스럽게 메인 바 아래 25px까지 내려간다 — 별도 `overflow:hidden` 을 걸면 잘리므로 `.hud__bar`에 `overflow:visible` 유지 필수.
- 재화 알약 2개는 `position:absolute; right:26px; top:115px; display:flex; gap:49px;` 로 우측 정렬. 각 알약은 `width:211px; height:50px; border-radius:25px; background:#221B13;` 로 폭 고정.
- 코인/젬 아이콘은 알약의 좌측 끝 중앙에 걸치므로 알약 내부에서 `position:absolute; left:-31px; top:-6px; width:63px; height:63px;` (아이콘 중심 = 알약 left + 0, top + 25). `z-index:2`로 알약 위에 올린다.
- 재화 텍스트는 알약 안에서 `padding-left:56px;` 기준 좌측 정렬(골드 x=639 = 583+56)이 아니라, 아이콘 폭을 뺀 나머지 영역의 중앙 정렬로 보는 편이 값이 잘 맞는다: `padding-left:18px;` 를 준 뒤 `justify-content:center` (골드 텍스트 중심 697.5 = (601+794)/2).
- `+` 버튼, 설정/우편 아이콘 등 부가 버튼은 이 HUD 밴드에 0개다. 잠금 아이콘·메뉴 그리드 버튼은 y=250 아래 배틀 영역 요소이므로 HUD에 포함하지 말 것.
- 숫자 텍스트(전투력/골드/젬)에는 `-webkit-text-stroke: 3px #000; paint-order: stroke fill;` 를 적용해야 레퍼런스의 두꺼운 검은 외곽선이 재현된다. 닉네임/칭호 텍스트에는 외곽선을 넣지 않는다.
