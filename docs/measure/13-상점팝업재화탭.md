# 13 상점 팝업 — 재화 탭 측정표 (레퍼런스 1080×2340 기준, 절대 px)

- 측정 일자: **2026-08-24**
- 레퍼런스: `docs/ref/13-상점-팝업-재화-탭.jpg` (1080×2340, JPEG)
- 측정 방식: **python3 + PIL + numpy 픽셀 직접 스캔**. 행/열 색전이 프로파일(Σ|Δchannel| 임계) · 색마스크 bbox · 서브픽셀 임계교차 · 코너 원호 최소자승 피팅(r 0.5px 격자 탐색) · `10` 측정표와의 좌표 대조 · 크림패널 대비 채널별 나눗셈으로 오버레이 α 역산. **눈대중 값 0개.**
- 좌표: 레퍼런스 절대 px, 요소 **좌상단** 기준, 정수 반올림. bbox 는 검정 외곽선 **포함(바깥)** 기준이며, 항목마다 «안/밖» 을 명시했다.
- font-size = **실측 잉크높이 / 0.93** (한글). 라틴/숫자(`5H 12M` `x50` `(1/1)` `AD`)는 잉크가 캡하이트라 **/0.70** 으로 따로 계산해 «fs(라틴)» 으로 표기했다. 두 값을 혼동하지 말 것.
- `-webkit-text-stroke` 는 윤곽 중심에 그려져 바깥으로 절반만 보인다 → 실측 N px 은 CSS **2N** px 으로 적었다.
- 가려진 도형(초기화 알약 상단, 리본에 가린 꼬리, 탭바 3번째 ✦)은 가림이 없는 행/열만 골라 스캔했고, 못 재는 값은 «(추정)» 으로 표시했다.

## 10. 구현 메모 (측정 중 확인된 함정)

1. **`재화 상점` 타이틀은 흰색이 아니라 `#FFF8AA` 연노랑**이고, `상품` 밴드 글자도 같은 색이다. 반면 리본·버튼·카드 글자는 순백 `#FFFFFF`. 섞지 말 것.
2. **`평생 광고 제거` 글자는 세로 그라디언트**(`#F8EBB4`→`#F5CA59`). 단색으로 칠하면 틀린다.
3. **`평생 광고 제거` 배너 배경은 그라디언트가 아니라 단색 `#43BCF5`** 다. 어둡게 보이는 부분은 45° 마름모 무늬(`#3AA7E8`) 애셋이다.
4. `초기화` 알약 상단은 리본에 가려 직접 못 잰다 → 좌하단 원호(r=28)와 텍스트 세로중심(802.5)으로 h=56 / top=775 를 역산했다.
5. 카드 헤더 잉크를 «min>185» 마스크로 재면 헤더 상단 하이라이트 림(`#8CF4FF`, min=140)과 AD 뱃지 금색이 섞여 카드 전폭이 잡힌다 → **min>170 AND (max−min)<30** 무채색 조건 필수.
6. `×N` 수량 텍스트를 패널 전체 bbox 로 재면 아이콘의 흰 하이라이트가 섞인다 → 열 방향 run 을 뽑아 **연속 픽셀 수 20 이상인 덩어리만** 채택해야 x572~652 같은 진짜 잉크가 나온다.
