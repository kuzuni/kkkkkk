# 70 출석 보상 팝업 — 측정표

> **측정 기준: 레퍼런스 `docs/ref/70-출석보상-팝업.jpg` 1080×2340, 상단 84px 이 상태바(안전영역),
> 프레임 y = ref y − 84 (가로 1:1).** 게임 프레임은 1080×2280.
> 표의 좌표는 **레퍼런스 절대 px** 를 기준으로 적고, 세로는 «프레임 y» 열을 같이 둔다.
> 측정 도구: **`tools/scan70.py`** (PIL 행/열 색전이 단면 · 면적 히스토그램 · 마스크 bbox · 코너 반경 역산).
> 눈대중 수치 없음. 추정치는 «(추정)» 으로 표시했고 §11 에 모아 두었다.
> font-size 는 이 프로젝트 폰트 잉크비 **0.93** 기준 `font-size ≈ 잉크높이 / 0.93` 로 계산했다. (0.75 아님)

## 0. 원본 구조와 «무시 영역» 먼저

원본은 다른 게임의 **«이벤트» 팝업 → «신규 유저 출석 이벤트» 탭**이다.
우리가 따올 것은 **가운데의 노란 캘린더 헤더 + 크림 본문 + 7칸 카드 구성**뿐이다.

| 구역 | ref y | 프레임 y | 우리 게임 |
|---|---|---|---|
| ⛔ «이벤트» 헤더 탭 (뒤쪽 다이얼로그의 상단 바) | **614 … 697** (검정 외곽 614~621 · 채움 622~693) · x **81…998** (검정 외곽 81~89 / 990~998) | 530 … 613 | **안 만든다** |
| ✅ **출석 패널** (노란 밴드 + 크림 본문) | **690 … 1766** | **606 … 1682** | 이게 우리 팝업 |
| ⛔ 뒤쪽 다이얼로그 하단 회색 림 | **1762 … 1795** (`#675D53`) | 1678 … 1711 | 안 만든다 |
| ⛔ «진행 중 / 진행 예정» 탭 스트립 | **1820 … 1925** · x **141…933** (검정 외곽 기준, 열별 휘도 최소점) | 1736 … 1841 | 안 만든다 |
| ⛔ 하단 안내문구 «보물상자 1개 …(0/1)» | ≈ 1930 … 1960 | 1846 … 1876 | 안 만든다 |

> 근거: `col 700 580 700 8` → 622~689 이 뒤 바의 채움 `#110D0C`, 690~693 이 우리 밴드의 검정 외곽.
> `rowmean 250 830 585 700` 에서 y614 에 휘도 0.3 의 검정 외곽선이 잡힌다.
> 하단은 `rowmean 200 900 1795 1945` 에서 1820(트랙 외곽) → 1925(트랙 끝) 구간이 잡힌다.

> 즉 «헤더 밴드가 본문보다 좌우로 11px 씩 튀어나온» 형태다. `row 760 55 115 8` 에서 x80 부터 바로 노랑.

> 📌 크림 본문 채움 **x 91…987 = 897** 은 `docs/measure/A5-모달.md` 의 표준 다이얼로그 폭(**91…988, 897**)과 **정확히 일치**한다.

### ① 수령 완료 — **1일차 · 2일차 · 3일차** (1행 전부)

| 항목 | 값 | 근거 |
