## 2. 메뉴 칸 8개

| 항목 | 레퍼런스 | 프레임 |
|---|---|---|
| 좌변 | x780 | **x780** (패널 로컬 19) |
| 우변 | x879 | x879 |
| 폭 | **99~100** | 99 |
| 높이 | **100** | 100 |
| 세로 pitch | **110** (칸 간격 **10**) | 110 |
| 1번 칸 상변 | y233 | **y149** (패널 로컬 8) |
| 반경 | **35** (`rad52.js` 36행 피팅, MSE **1.44**) | 35 |
| 테두리 | **없음** | — |
| 채움 | 총 투과율 **0.14** → 패널 위에 `rgba(0,0,0,.80)` (0.72 × 0.20 = 0.144) | 동일 |

칸 상변(레퍼런스): 233 · 343 · 453 · 563 · 673 · 783 · 893 · 1003 → **프레임 149 · 259 · 369 · 479 · 589 · 699 · 809 · 919**

패널 안쪽 패딩: **좌 19.5 · 우 19 · 상 8.5 · 하 9**.

**검산이 딱 맞는다**: 8칸×100 + 7갭×10 + 상8.5 + 하9 = **887.5** = 패널 높이 **887**. ✓

### 2-1. ⚠ 1회차에 이 표를 88×80 · 상변 244 로 **잘못 적고 한 번 커밋했다** — 원인과 재발 방지

- **틀린 방법**: 폭을 `raw row` 3행(y250 · y690 · y1020)에서 쟀다. 셋 다 **칸 위끝 + 6** 이다.
  반경이 35 라 그 높이는 아직 **코너 원호 한가운데**고, 좌우가 각각 5px 씩 안쪽으로 들어와 **88** 로 읽힌다.
  세 행이 전부 같은 값이라 «세 번 독립 확인했다» 는 착각까지 했다 — 실제로는 **같은 오차를 세 번 반복**한 것이다.
- **높이도 같은 이유**: `edge52.js` 를 x774(패널띠) vs x790(칸 안)으로 돌렸는데, x790 은 좌변(780)에서 **10px** 안쪽이라
  코너 원호가 위아래를 각각 ~5.5px 씩 잘라 **80** 으로 읽혔다.
- **맞는 방법**: 반경이 큰 라운드 사각형은 **직선부에서만** 잰다.
  · 세로변 → **칸 중심 x830 의 `raw col`** (y232 띠 → y234 칸 / y1101 칸 → y1105 띠)
  · 가로변 → **칸 위끝 + 47 의 `raw row`** (x778 띠 → x782 칸 / x878 칸 → x880 띠)
  · 반경 → `rad52.js` 로 **여러 행을 동시 피팅** (LESSONS 22-②). 단면 하나로는 절대 안 된다.
- **교차 검산을 반드시 걸어라**: «칸 높이 × 8 + 간격 × 7 + 상하 패딩 = 패널 높이» 가 맞는지 본다.
  틀린 값(80/30)으로는 8×80 + 7×30 + 18 + 17 = **875 ≠ 887** 이라 그때 바로 걸렸어야 했다.
- 비평가 2명이 «칸 100×100 · 간격 10» 이라고 한 것이 **옳았다**. LESSONS 21-④(«비평가 수치는 자체 스캔으로 다시 낸다»)는
  «자체 스캔이 항상 이긴다» 가 아니다 — **자체 스캔의 표본 위치가 틀렸을 수 있다.** 둘이 어긋나면 **제3의 검산식**으로 가른다.

- 그 바의 해골 마커 (x817..862, y330..372) → 우편 봉투 «위» 에 겹친다. **우편 아이콘의 일부가 아니다.**
- 작은 적 HP 바 (x752..892, y782..810) → **6번 «절전»** 상단을 가로지른다.
- 떠오르는 데미지 숫자 → 5번·7번 왼쪽에 겹친다.
- 우측 «정령의 집 + 21:27:54» 위젯 (x860..1065, y837..953) → 패널 우측 가장자리를 덮는다.

> **우리 구현에서는 이 겹침을 재현하지 않는다.** 우리 메뉴는 오버레이라 최상위다.
> 비평가에게 «② ③ 채점에서 ※ 표시 4칸의 잉크 수치는 오염 표본이니 감점 근거로 쓰지 말 것» 을 알린다.

## 5. 우리 게임 설계와 다른 점 (비평가에게 반드시 알릴 것)

1. **레퍼런스의 우측 세로 아이콘 열(이벤트·특권·첫구매·정령의집 타이머, x940~1065)은 우리 게임에 없다** —
   **작업 49(저장소 주인 지시)로 우측 사이드를 전부 삭제**했다. 우측에 남는 것은 `#menub` 하나뿐이다.
   → 이 열의 부재는 **감점 대상이 아니다.**
2. 레퍼런스의 좌측 열·전투 내용·스테이지 헤더는 52 의 작업 범위가 아니다(각각 A2 · 02 · 28 소속).
3. 8칸 중 **랭킹·가방·절전·설정은 각각 작업 54·53·56·55 의 화면**이라 52 가 만들지 않는다(지시서 [1] «잡은 작업 단위 딱 1개»).
   52 의 범위는 **열림/닫힘 · 8칸 배치 · 진입점 배선**까지다.
