# 21 도감(보너스) 팝업 측정표 (레퍼런스 1080x2340 기준, 절대 px)

- 측정 일자: **2026-08-24**
- 레퍼런스: `docs/ref/21-도감-보너스-팝업.jpg` (1080 x 2340, JPEG)
- 측정 방식: **python3 + PIL 픽셀 직접 스캔**. 스캔라인 색 전이점 / 색 마스크 bbox·행 프로파일 / 코너 원호 피팅. 눈대중 값 없음.
- 표기: `x`/`y` 는 요소 **좌상단**, 값은 정수 px, 색은 실제 픽셀 RGB.
- **✔ = 픽셀 스캔 확정** / **(추정) = 피팅·역산** / **(미확정) = 판정 불가**.
- font-size: 한글 = **잉크높이 / 0.93**, 숫자·라틴 = **잉크높이 / 0.70** (잉크=캡하이트). 잉크 높이 실측값을 우선 기록.

## 10. 세로 좌표 변환 참고 (ref 1080x2340 → 프레임 1080x1920)

- 껍데기 판정: **딤 위 가운데 다이얼로그** → 가로 1:1, 세로는 **화면 중심 정렬 관례** 적용.
- ref 중심 y **1170** → 프레임 중심 y **960**, 즉 **`frame_y = ref_y − 210`** (전 요소 일괄 평행이동).
