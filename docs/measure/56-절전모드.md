# 56 — 절전 모드 측정표

레퍼런스 `docs/ref/56-절전모드.jpg` (1080×2340, 최상단 84px 상태바).
**변환은 단 하나: 프레임 y = 레퍼런스 y − 84** (가로 1:1). 기준 프레임 1080×2280.
대조군: `docs/ref/02-기본-메인-화면.jpg` (평상시 메인).

측정 방법: Pillow 로 픽셀 직접 스캔(행/열 프로파일, 잉크 bbox, 임계값 스윕, 코너 반경 피팅).
본 문서의 모든 좌표는 **절대 px**. 텍스트 높이는 **잉크 bbox**(실제 글자 픽셀의 최소~최대 y).
`font-size (추정)` = 한글은 잉크높이 ÷ **0.75**(받침 포함 기준), 라틴/숫자는 cap·digit height ÷ **0.72**.

## 0. 먼저 — 전제 3가지가 실측과 다르다 ⚠

작업 지시에 적힌 전제와 레퍼런스 실측이 **세 군데 어긋난다**. 구현 전에 반드시 확인할 것.

| 전제 | 실측 | 근거 |
|---|---|---|
| «전체화면이 **어두워진다**»(딤) | **딤이 아니라 완전 불투명 검정**. α = **1.00** | 6개 잉크 덩어리를 뺀 **전 픽셀이 정확히 RGB(0,0,0)**. `>3` 인 픽셀 **0개** |
| «**전투는 계속 돌아간다**»(보인다) | **전투 화면이 1픽셀도 안 보인다.** 배경·캐릭터·적·HUD 전부 소거 | 위와 동일 |
| «**터치하면** 해제된다» | 화면 문구는 «**밀어서 잠금 해제**» (slide to unlock) | y2124..2166 실측 텍스트 |

즉 이 화면은 «전투 위에 씌운 반투명 딤» 이 아니라 **전투를 통째로 가리는 잠금화면(lock screen)** 이다.
전투는 **로직만** 계속 돌고(방치 시간 `00:00:02` 가 흐르는 중), **렌더링은 완전히 숨긴다**.
목적이 전력 절감이므로 «GPU 그리기를 멈춘다» 는 동작이 맞고, 화면 우상단의 **배터리 잔량 배지(10%)** 가 그 의도를 뒷받침한다.

### 2-2. 전역 검증

- 전체 화면(1080×2340 = 2,527,200 px) 중, §3 에 나오는 **6개 잉크 덩어리의 y 밴드를 제외한 모든 픽셀**을 스캔:

| 항목 | 값 |

## 6. 구현 메모

### 6-1. 레이어 / z-index

- 절전 오버레이는 **게임의 모든 레이어보다 위**에 온다. 순서 기준:
  `전투 캔버스 < 상단 HUD < 사이드 아이콘 < 탭바 < 모달(A5) < 토스트 < **절전 오버레이**`.
- 우리 z 체계 기준 **모달(A5)보다 위**여야 한다 — 모달이 떠 있는 상태에서 절전이 걸려도 모달을 덮어야 한다.
  권장: `z-index: 9000` (토스트/네트워크 인디케이터만 그 위, 있다면 9500).
- 오버레이는 **프레임 전체 1080×2280 을 덮는다** (`position:fixed; inset:0`).
  레퍼런스에서 상태바 안전영역(ref y0..83)까지 검정이므로, **safe-area 패딩을 주지 말 것** —
  배경은 안전영역까지 뻗고, **내부 콘텐츠만** 안전영역 아래에서 시작한다(A 배지 frame y28.5 = 안전영역 밖 여백 28.5).

### 6-2. 배경은 «딤» 이 아니라 «완전 차폐»

- `rgba(0,0,0,.85)` 같은 값 금지. **`background:#000` 불투명**.
- 목적이 절전이므로 오버레이를 켜는 순간 **하위 전투 렌더 루프를 실제로 멈춰야** 한다:
  - `requestAnimationFrame` 루프 정지 / 스프라이트 애니메이션 `pause`
  - 전투 컨테이너 `visibility:hidden`(또는 `display:none`) — `opacity:0` 만으로는 GPU 합성이 계속 돈다
  - **전투 «로직»(방치 시간·처치 수·골드 누적)은 계속 돌린다.** 패널 3행이 그 값을 라이브로 보여준다(§3-5).
- 절전 진입 시 3행 값은 **0 부터 다시 세는 세션 누적**이다 (레퍼런스가 `00:00:02` / `0` / `+0`).
  → 진입 시점을 기준점으로 잡고 delta 를 표시할 것. 누적 전체값이 아니다.

### 6-3. 해제 인터랙션 — **터치가 아니라 스와이프**

- 문구가 `밀어서 잠금 해제` 이므로 **드래그/스와이프 제스처**로 해제하는 것이 원문에 맞다.
- **히트 영역**: 오버레이 전면(1080×2280 전체)에서 포인터 이벤트를 받는다.
  레퍼런스에 슬라이더 트랙·핸들이 **없으므로** 특정 좁은 영역만 잡는 UI 가 아니다.
- 권장 구현: 화면 어디서든 시작한 **세로 또는 가로 스와이프 이동거리 ≥ 120px** 이면 해제.
  (안전장치) 단순 탭도 해제로 받되, 오탐 방지를 위해 **탭 해제는 두 번 탭 또는 300ms 이상 롱프레스**로 두는 편이 방치형 게임 UX 에 안전하다.
  ⚠ 기획이 «터치 1회 해제» 를 원한다면 **문구를 `화면을 터치하면 해제됩니다` 로 바꿔야** 원문·동작이 일치한다.
  레퍼런스 그대로 갈 거면 문구는 `밀어서 잠금 해제` 고정.
- 오버레이는 **하위로 이벤트를 통과시키면 안 된다** (`pointer-events:auto`, 하위 `pointer-events:none`).
  절전 중 잘못된 탭이 스킬/탭바를 누르는 사고를 막는다.

### 6-4. 정렬 함정 3가지

1. **`STAGE 80` 은 텍스트만 중앙 정렬** — 아이콘 포함 묶음을 중앙 정렬하면 35px 어긋난다(§3-4).
2. **날짜가 MM/DD/YYYY 미국식** — 로케일 포맷터를 그냥 쓰면 한국식으로 바뀐다. 기획 확인 필요(§3-3).
3. **pill radius 는 28 이지 32(완전 스타디움)가 아니다** — `border-radius:9999px` 로 쓰면 안 된다.
   패널 radius 는 **36**.

### 6-5. 그 외

- **배터리 값은 기기 실제 잔량**(`navigator.getBattery()` 등). 값을 못 얻으면 배지를 **숨겨라** —
  가짜 값을 넣지 말 것. 배지 자체가 «절전 중» 이라는 의미 전달의 일부다.
- 시계는 `HH:MM` 24시간, **초 없음**. 1분마다 갱신하면 충분하다(절전이므로 1초 타이머 금지).
- 패널 3행 값은 **1초 주기 갱신**이 필요하지만, 텍스트 노드만 바꾸는 수준이라 부하가 거의 없다.
  전면 리렌더가 아니라 `textContent` 직접 갱신으로 처리할 것.
- 진입/이탈 트랜지션은 레퍼런스로 판정 불가(스틸 1장). 권장 **fade 200~250ms**, `추정`.
- 하단 `밀어서 잠금 해제` 의 하단 여백이 **frame 198** 로 크다 — 홈 인디케이터/제스처바 회피 여유.
  기기별 하단 safe-area 가 커지면 이 텍스트가 가리지 않도록 `bottom: max(198px, env(safe-area-inset-bottom) + 120px)` 권장.
