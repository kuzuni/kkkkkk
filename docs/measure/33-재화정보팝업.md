# 33 재화 정보 팝업 («보석») 측정표 (레퍼런스 1080x2340 기준, 절대 px)

- 측정 일자: **2026-08-24**
- 레퍼런스: `docs/ref/33-재화-정보-팝업.jpg` (1080 x 2340, JPEG)
- 스캔 스크립트: **`s33b.py`** (저장소 루트). `python3 s33b.py` 로 아래 수치 전량 재생성 가능.
- 측정 방식: **python3 + PIL 픽셀 직접 스캔**. 스캔라인 색 전이점 / 색 마스크 bbox / 원호 최소제곱 radius 피팅 / `02-기본-메인-화면.jpg` 와의 픽셀 선형회귀(딤 역산). **눈대중 값 없음.**
- 표기: 좌표는 이미지 좌상단 원점. `x0..x1` 은 **양끝 포함** 픽셀 인덱스, `w = x1-x0+1`.
- **잉크 bbox** 는 두 가지로 병기한다 — `코어`(글자 본체 밝은 픽셀만) / `잉크`(검정 외곽선 포함).
- font-size 는 프로젝트 규약대로 **한글 코어높이 ÷ 0.93**, 라틴/숫자는 **캡하이트 ÷ 0.72**. 두 값이 어긋나는 항목은 별도 표기.
- 임계값: 검정 판정 `max(RGB) < 45`, 크림 이탈 판정 `Σ|ΔRGB| > 60`, 패널 경계 판정 `R < 218`(크림 240 ↔ 패널 196~199 의 중간값).

## §12. 측정 주의 / 오차 메모

- 배경(게임 스테이지)이 어두운 갈색이라 **팝업 외곽 검정의 코너**는 배경과 구분이 안 된다 → 검정 안쪽 갈색 박스 코너를 피팅하고 두께를 더해 산출. radius 오차 **±3px**.
- 설명/리스트 패널 fill 은 **반투명**이라 아래 별 워터마크 위에서 값이 ±6 흔들린다. 표의 값은 무늬 없는 구간의 median.

- 모든 색은 JPEG 원본의 median. 경계 1px 은 전부 AA 이므로 두께 표기에서 제외했다.
