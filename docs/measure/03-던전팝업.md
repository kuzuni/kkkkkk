## 부록 C. 확정하지 못한 항목 목록

1. **재화 알약·레벨 알약·횟수 알약의 좌측 끝 x** — 아이콘이 항상 알약 좌측 캡을 덮는다. 상단/하단 엣지 스텝 검출 시작점에서 캡 보정 8px를 빼 역산한 **추정치**(142 / 134 / 329).
2. **잠금 카드(3·4·5) 재화 알약의 우측 끝 x·width** — 자물쇠 아이콘(x 487~592)과 일러스트가 우단을 가려 **미확정**. 엣지 신호는 x 476~478에서 끊긴다.
3. **좌측 서브탭(🔒)의 우측 끝 x·width** — 던전 탭이 위에 겹쳐 그려져 **미확정**. 노출된 채움 끝은 523.
4. **서브탭 바의 상단 y와 height** — 카드5 하단 테두리와 검정이 붙어 분리 불가. 코너 원호 피팅 역산으로 **2021 / 98 (추정)**.
5. **잠금 카드 자물쇠 아이콘의 외곽선 유무·두께** — 어두운 딤 배경과 구분되지 않음.
6. **`가이드미션 …` 문구의 font-size** — 한글 기준 55, 숫자 기준 48로 13% 불일치. 48~55 구간으로만 확정.
7. **`가이드미션 …` 문구 외곽선 두께** — 검정 딤 위 검정 외곽선이라 경계 분리 불가 (4~5px 추정).

## 3-8. 카드 우측 몬스터 일러스트(썸네일) — 작업 72 신규 측정 (2026-08-25, sess-0703-19500 워커 A)

초판 측정표는 카드 우측을 «선버스트 일러스트 바탕» 으로만 적었고 **그 위에 올라간 몬스터 일러스트의
bbox 가 없었다.** 작업 72 에서 스캐너 `tools/scan72.py` 로 새로 잰다.

측정 방식 — **국소 경사(3px 간격 RGB 합차) 밀도**. 선버스트는 큰 부채꼴이라 열당 3~4px 수준으로
완만하고, 몬스터 아트는 외곽선·하이라이트 때문에 20~120px 로 뛴다. 그 전이점이 일러스트 좌측 경계다.

| 항목 | 카드1 (골드 던전) | 카드2 (보석 던전) |
|---|---|---|
| 경사 밀도 전이 x (배경 4/열 → 20+/열) | **713** | **723** |
| x 질량 2% / 50% / 95% / 98% | 713 / 855 / 1008 / 1017 | 670 / 860 / 1017 / 1019 |
| y 질량 2% / 95% / 98% (카드 top 기준 상대) | 9 / 323 / 336 | 9 / 335 / 338 |
| 어두운 외곽선(휘도<45) 밀집 시작 x | 780 | 740 |

- 카드 안쪽 박스: x **57~1022**, y = 카드 top+8 ~ top+341 (테두리 좌우 7 · 상하 8 — §3-1).
- **결론: 일러스트는 카드 안쪽 «우측 정렬 315×334»** — 절대 x **708~1022**, 세로는 카드 안쪽 전체.
  **아래가 카드 하단 테두리에서 잘려 들어간다**(y 질량 98% 가 상대 336~338 = 안쪽 바닥 341 코앞).
- 좌측 경계는 **하드 엣지가 아니라 페이드** — 카드1 은 713, 카드2 는 670 부터 신호가 뜨는데
  둘 다 «5% 질량» 은 728~738 이다. 즉 **약 60px 구간에 걸쳐 배경으로 녹아든다.**
- 좌측 텍스트 클러스터의 우단(재화 알약 429, `남은 횟수` 알약 450)과 **250px 이상 떨어져 있어 겹치지 않는다.**
- 잠금 카드(3·4·5)는 딤(§3-7-1) 때문에 경사 신호가 죽어 개별 측정 불가. 레이아웃은 5장 동일(§3-7-4)이고
  **딤과 자물쇠가 일러스트 위에** 온다.
