# 103 채팅 화면 측정

- 레퍼런스: `docs/ref/103-채팅-팝업.png` — **실측 499×804** (지시서의 499×805와 세로 1px 차이. 실측 기준)
- 환산 배율: **×2.16433 (= 1080/499)**, 가로·세로 **등방**
- 환산 전체 크기: **1080 × 1740** → 기준 프레임 2280 중 **1740** 만 담긴 크롭. 위쪽 ~540px(상태바+헤더)이 잘려 있음
- 표기 규칙: 모든 수치는 `ref px → 1080환산 px`. 좌표는 **좌상단 원점, 끝 좌표 포함(inclusive)**, `w = x1−x0+1`
- 색은 **참고값**(이 게임 공통 UI 로 교체 예정). 기하는 픽셀 스캔 실측

## §2 상단 영역

**없음.** 레퍼런스는 채팅 리스트 중간부터 크롭돼 있어 헤더·타이틀·탭/필터 칩이 프레임 안에 존재하지 않는다.
y0..8(→0..17)은 아무 잉크도 없는 순백이고, y9(→19)부터 스크롤로 반쯤 올라간 메시지 행의 아바타 좌측 보더가 시작한다.

> 이식 시: 이 게임의 공통 팝업 헤더를 그대로 얹고, 아래 §3 리스트를 헤더 아래 스크롤 영역에 넣으면 된다. 레퍼런스에서 «리스트 첫 행 top ↔ 프레임 top» 여백은 측정 불가(잘림).

| 말풍선 우변 ↔ 시각 우끝 차 | **14** | **30** |

> 좌우가 비대칭이다: 이름줄의 시각은 x447 까지 나가지만 말풍선은 x433 에서 끊긴다.

> 이식 시엔 `행 padding: 0 51 0 63 (→ 0 110 0 136)` + `.bubble { margin-right: 14 → 30 }` 로 재현 가능.
