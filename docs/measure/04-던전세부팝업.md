# 04 던전 세부 팝업 측정표

- **측정 기준: 원본 1080×2340 절대 px, PIL 픽셀 스캔**
- 레퍼런스: `docs/ref/04-던전-세부-팝업.jpg` (1080 × 2340, JPEG)
- 측정 방식: Python + Pillow 로 스캔라인 색 전이점 / 색 마스크 bbox / 코너 원호 피팅. 눈대중 값 없음.
- 좌표는 모두 **원본 1080px 폭 기준 절대 px**, `x`/`y`는 요소 **좌상단**, 정수 반올림.
- 텍스트 높이는 **잉크 bbox**(실제 글자 픽셀의 최소~최대 y). `font-size ≈ 잉크높이 / 0.93`.
- 측정 일자: 2026-08-24

## 0. 껍데기 판정 — **(가) 가운데 다이얼로그 모달**

**결론: 화면 전체를 딤 처리한 위에 얹힌 가운데 정렬 다이얼로그 모달이다.**
바닥 시트(나)도, 전체화면 페이지(다)도 아니다. 근거:

| 판정 근거 | 실측 |
|---|---|
| 모달 폭 | **796px** (화면 1080의 73.7%) — 폭 1080 꽉 참(바닥시트/전체화면)이 아님 |
| 좌우 바깥 여백 | 좌 **142** / 우 **142** (1080-937-1=142) → 완전 좌우 대칭, 가로 중심 540 |
| 상하 바깥 여백 | 위 **614** / 아래 **529** → 상하 모두 여백 있음 = 화면에 떠 있는 박스 |
| 세로 중심 | 모달 중심 y **1212** vs 화면 중심 1170 → 42px 아래, 사실상 세로 중앙 |
| 딤(어두운 오버레이) | **있음**. 화면 전체(상단 HUD·하단 탭바 포함) 전면 딤 |
| 헤더 바 | **있음** — 모달 상단 짙은 갈색 타이틀바 (`보석 던전`), 높이 90 |
| 테두리 | 바깥 검정 **6~7px** + 안쪽 갈색 **9px** (합계 15~16px) |
| radius | 바깥 약 **42**, 갈색 링 기준 **36**, 안쪽 본문 약 **27** |
