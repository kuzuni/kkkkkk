# 07 스킬 팝업 측정표 (레퍼런스 1080x2340 기준, 절대 px)

- 측정 일자: **2026-08-24**
- 레퍼런스: `docs/ref/07-스킬-팝업.jpg` (1080 x 2340, JPEG)
- 측정 방식: **python3 + PIL 픽셀 직접 스캔**. 행/열 색전이 프로파일 / 색마스크 bbox / 코너 원호 최소자승 피팅 / `02-기본-메인-화면.jpg` 와의 픽셀 대조(딤 산출). **눈대중 값 없음.**
- 표기: `x`/`y` 는 요소 **좌상단**, 값은 정수 px, 색은 실제 픽셀 RGB.
- **✔ = 픽셀 스캔으로 확정한 값** / **(추정) = 원호 피팅·계산·역산으로 얻은 값** / **(미확정)** = 판정 불가.
- font-size 는 **실측 잉크높이 / 0.93**. 한글 문자열은 이 값이 정확하다.
  라틴/숫자만 있는 문자열(`Lv. 8`, `7/9`)은 잉크가 **캡하이트**라 이 공식이 과소평가된다 — 해당 항목에 별도 표기.

## ⚠ 좌표계 — 레퍼런스 y → 프레임 y 환산 규칙

레퍼런스 **최상단 84px(y 0~83)은 상태바(안전영역)** 이라 프레임에 넣지 않는다.
이 문서의 모든 y 는 **레퍼런스 절대 y** 이고, 프레임 좌표는 아래 식으로 변환한다.

```
프레임 y = 레퍼런스 y − 84
프레임 x = 레퍼런스 x        (가로는 1:1, 폭 1080 동일)
```

주요 환산 예시:

| 요소 | 레퍼런스 y | 프레임 y |
|---|---|---|
| 시트 바깥 top | **676** | **592** |
| 헤더 밴드 | 684 ~ 796 | 600 ~ 712 |
| 본문 시작 | 797 | 713 |
| 장착 슬롯 패널 | 832 ~ 1028 | 748 ~ 944 |
| 그리드 패널 | 1070 ~ 1749 | 986 ~ 1665 |
| 총 보유 효과 텍스트 | 1771 ~ 1809 | 1687 ~ 1725 |
| 버튼 행 | 1841 ~ 1971 | 1757 ~ 1887 |
| 서브탭 바 | 2020 ~ 2118 | 1936 ~ 2034 |
| 시트 바닥(잘림) | **2160** | **2076** |
