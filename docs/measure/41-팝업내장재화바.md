### 2.1 좌단 역산 근거

아이콘 bbox 중심(골드 528 / 다이아 828.5)이 **알약 좌측 캡의 원 중심**(= 좌단 + 24.5)과 일치한다고 두면
좌단 = 503.5 / 804 이고, 이때 폭이 각각 253.5 / 253 으로 **우단 실측(757/1057)과 254 로 수렴**한다.
두 알약 독립 역산이 같은 폭을 주므로 채택. (measure/03 §3-4 의 «캡 보정» 과 같은 방법)
